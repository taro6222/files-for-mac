# Files macOS 0.1.0

Files for Mac은 Windows용 Files를 참고해 만든 독립 프로젝트입니다. 이 이미지는 개발 프리뷰이며 정식 출시 검증은 진행 중입니다.

## 설치

1. 로컬 프리뷰는 `Files-macOS-preview.dmg`와 같은 폴더에서 `shasum -a 256 -c Files-macOS-preview.dmg.sha256`을 실행합니다. 정식 배포 이미지의 이름은 `Files-macOS.dmg`입니다.
2. DMG를 열고 `Files macOS.app`을 Applications 폴더에 복사합니다. 시스템 Applications에 쓸 권한이 없으면 사용자 홈의 Applications 폴더를 선택할 수 있습니다.
3. 복사한 앱을 실행합니다. 배포용 Developer ID 서명과 공증이 적용된 다운로드는 정식 출시 검증 후 제공할 수 있습니다.

## 업데이트

앱 메뉴의 **업데이트 확인…**에서 현재 설치 버전과 정식 배포 버전을 확인할 수 있습니다. 정식 업데이트가 표시되면 GitHub 릴리스에서 `Files-macOS.dmg`와 `Files-macOS.dmg.sha256`을 내려받습니다. 두 파일이 있는 폴더에서 `shasum -a 256 -c Files-macOS.dmg.sha256`을 실행합니다. 기존 앱을 종료하고 보관한 뒤, 서명·공증된 새 앱으로 교체합니다. 복원 절차는 아래 복구 항목에 있습니다.

## 사용 범위

- 탭·분할 보기·검색·미리보기·파일 속성, 로컬 파일 복사·이동·이름 변경·휴지통 및 실행 취소를 제공합니다. 분할 보기의 각 패널에서 폴더 읽기를 중단하고 다시 시도할 수 있습니다.
- ZIP과 단일 7z 안에서 파일 추가·폴더 생성·이름 변경·삭제와 실행 취소·다시 실행을 사용할 수 있습니다. RAR과 분할 7z의 내부 편집은 지원하지 않습니다.
- 파일 추가 시 암호화를 선택할 수 있으며, 기존 암호화 파일과 7z 헤더의 보호를 유지합니다. 파일이 없는 ZIP은 추가 파일의 암호를 새로 지정하거나 암호화를 명시적으로 해제할 수 있습니다.
- 앱 메뉴의 압축 편집 기록 및 복구에서 실제 파일 상태를 확인한 뒤 이전 버전으로 복원할 수 있습니다. 편집 실패·취소 때 남은 파일과 이전 원본은 보존합니다. 일부 파일 속성이나 볼륨에서는 안전한 편집을 완료하지 못할 수 있으며 원본을 확인한 뒤 다시 시도해야 합니다.
- 파일 작업 센터에서 복사·이동·폴더 병합의 항목별 진행과 결과를 보고 작업을 취소할 수 있습니다. 같은 앱 실행 중 최근 닫은 결과를 확인하고 완료 기록을 지울 수 있습니다.
- 파일 작업 센터에서 Return을 누르면 선택한 작업의 세부 창이 열립니다. 진행 중인 작업은 Command+마침표로 취소할 수 있습니다.
- 속성 창에서 CRC32·MD5·SHA-1·SHA-256·SHA-384·SHA-512를 계산하고 해시값 또는 다른 파일과 비교할 수 있습니다.
- 파일 속성에서 선택한 파일 또는 폴더의 POSIX 권한을 편집하고 목록에서 사용자·그룹을 고르거나 이름을 입력해 확장 ACL 규칙을 추가할 수 있으며, macOS 텍스트 형식으로 편집할 수 있습니다.
- 파일 또는 폴더 한 건의 그룹 소유권을 macOS 권한이 허용하는 범위에서 변경할 수 있습니다.
- 폴더의 POSIX 권한, 확장 ACL 또는 그룹 소유권을 하위 파일과 폴더에도 적용하고 처리 건수를 확인할 수 있습니다.
- APFS·대소문자 구분 APFS·exFAT의 파일 작업과 시스템 휴지통을 확인했습니다. 시험용 SMB 3.1.1 공유에서 복사·이동·실행 취소의 파일 시각과 읽기 전용 공유의 쓰기 거부를 검증했습니다. 교체 파일을 게시한 뒤 원본을 삭제하기 전에 세션이 끊겨도 같은 마운트에서 재연결해 이동과 실행 취소를 완료했습니다. 파일 데이터 기록 중 단절, 장기 단절과 서버 권한 변경은 검증 중입니다.
- FTP·FTPS·SFTP는 로컬 시험 서버에서 검증했습니다. Git은 기본 원격 작업과 병합 충돌 표시를 제공하며, 루프백 서버에서 SSH 에이전트와 HTTPS의 macOS Keychain 인증을 확인했습니다. 외부 서비스 로그인·토큰 갱신과 실제 클라우드 계정은 검증 중입니다.
- 설치 이미지에는 Apple Silicon과 Intel 바이너리가 들어 있습니다. 이전 프리뷰는 Apple Silicon macOS 27.2와 Sonoma 14.8.7, macOS 15 Intel 러너에서 기동을 확인했습니다. Sonoma 초기 버전과 Sonoma Intel 설치, 지원 환경의 전체 수동 UI 검증은 진행 중입니다.
- Windows용 Files와는 시스템 메뉴, 압축 형식, 클라우드 및 파일 시스템 통합 범위가 다릅니다. 화면 대조와 VoiceOver 검증은 진행 중입니다.

## 복구

- 복사 또는 이동이 일부 실패하면 결과 창에서 재시도 가능한 항목을 확인합니다. 덮어쓰기 없는 교차 볼륨 이동은 게시 전 실패 후 임시 복사본의 정리가 끝났을 때 재시도할 수 있습니다. 교체 이동이나 게시를 시도한 뒤 발생한 오류는 결과 창의 출발지·대상·백업 상태를 확인한 뒤 복구합니다. 휴지통으로 이동한 파일은 앱에서 복원을 시도할 수 있습니다.
- 교체 이동 결과에 백업 경로가 표시되면 기존 대상의 백업을 해당 위치에서 찾을 수 있습니다. 대상에 새로 생긴 파일은 그대로 두고, 백업을 별도 이름으로 복사해 내용을 확인합니다.
- 테스트 버전을 교체하기 전에는 앱의 고급 설정에서 설정을 내보내고 기존 앱 번들을 보관합니다. 교체 후 문제가 발생하면 앱을 종료하고 보관한 번들을 복원한 뒤 필요한 경우 설정을 가져옵니다.
