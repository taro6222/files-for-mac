# 개발 현황

갱신: 2026-09-09

## 이번 구현 단위

M0 기준 고정·소스 인벤토리 생성, M1 실제 로컬 파일 탐색의 첫 개발 프리뷰를 구현했다. 현재 M0와 M1은 진행 중이며 M2는 착수 전이다.

| 영역 | 상태 | 내용 |
|---|---|---|
| 원격 기반 | 완료 | 지정 origin의 초기 LICENSE/이력 보존 |
| 기준 원본 | 완료 | v4.2.9/SHA 고정 |
| 원본 인벤토리 | 진행 | 202 명령 후보·143 설정·33 화면 소스. 전수 동작 검증 아님 |
| 네이티브 앱 | 구현 | AppKit 창·사이드바·홈·상세 목록·경로 |
| 로컬 I/O | 검증 | 비동기 열거·숨김 항목·크기·종류·오류 상태 |
| 탐색 상태 | 검증 | 히스토리·선택/스크롤 상태 모델·오래된 비동기 결과 방지 |
| 파일 목록 | 구현 | 다중 선택·자연 정렬·열 정렬/재배치/크기 저장 |
| 편의 기능 | 구현 | 즐겨찾기·최근 위치·폴더 선택·시스템 열기·Finder 표시 |
| 테스트 | 통과 | 8개 Swift Testing 테스트, 10,000항목 포함 |
| 실제 UI | 부분 확인 | 홈/실제 폴더 상세 목록·한국어·어두운 테마; 정렬/아이콘 배치 수정 |

## M1 종료 전 남은 작업

1. 경로 자동 완성, 확장자 표시 토글, 홈 드라이브 카드·최근 기록 삭제.
2. 즐겨찾기 순서/섹션 설정 및 다중 창의 설정 변경 동기화.
3. 현재 path ID를 볼륨·파일 identity와 directory-entry 관계로 보강; 외부 이름 변경 시 선택 유지.
4. 폴더 감시를 비동기 provider 이벤트로 이동; 파일 자체 metadata 갱신과 볼륨 제거 처리.
5. 10,000항목 첫 화면 latency와 스크롤 측정, 순차 전체 열거 대신 배치 첫 표시.
6. 최소 창/밝은 테마/영어/키보드 전 흐름/VoiceOver/실제 권한 거부 검증.
7. 표 헤더·폰트·간격 원본 Windows 캡처와 대조; 실제 검증 이미지 저장 체계.

위 목록을 완료해 M1 게이트를 통과한 뒤 M2 작업 저널·복사/이동·충돌·취소·탭·분할에 진입한다. M2 구현 전에 볼륨 간 이동 및 충돌 정책 테스트 fixture를 먼저 만든다.

## 변경 규칙

현재 구현을 완전 기능 앱 또는 원본 UI 완전 일치로 표시하지 않는다. 각 단계 종료 시 검증 결과와 문서를 갱신하고 관련 변경을 커밋한 뒤 origin에 푸시한다. 사용자가 이 절차를 상시 승인했다. 이번 첫 개발 프리뷰는 M0/M1 진행 중인 상태로 커밋한다.
