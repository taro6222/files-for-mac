# 개발 현황

갱신: 2026-09-09

## 이번 구현 단위

M0 기준 고정·소스 인벤토리 생성에 이어 M1 세 번째 개발 단위(사이드바 섹션·키보드 이동·설정 복원)를 구현했다. 현재 M0와 M1은 진행 중이며 M2는 착수 전이다.

| 영역 | 상태 | 내용 |
|---|---|---|
| 원격 기반 | 완료 | 지정 origin의 초기 LICENSE/이력 보존 |
| 기준 원본 | 완료 | v4.2.9/SHA 고정 |
| 원본 인벤토리 | 진행 | 202 명령 후보·143 설정·33 화면 소스. 전수 동작 검증 아님 |
| 네이티브 앱 | 구현 | AppKit 창·사이드바·홈·상세 목록·경로 |
| 로컬 I/O | 검증 | 배치 열거·숨김 항목·메타데이터·파일 identity·오류 상태 |
| 탐색 상태 | 검증 | 히스토리·선택 복원·외부 rename 대응·오래된 비동기 결과 방지 |
| 파일 목록 | 구현 | 다중 선택·자연 정렬·열 정렬/재배치/크기 저장 |
| 편의 기능 | 구현 | 경로 추천·확장자 옵션·공유 즐겨찾기 순서·홈 용량·최근 기록 삭제 |
| 테스트 | 통과 | 21개 Swift Testing 테스트, 10,000항목·FSEvents·권한 거부 포함 |
| 실제 UI | 부분 확인 | 사이드바 접기·순서·재실행 복원, 키보드 초점/화살표/문맥 메뉴 확인 |
| 폴더 감시 | 검증 | FSEvents 이벤트, 현재 위치/직접 자식 갱신, 종료 해제 |

## M1 종료 전 남은 작업

1. 10,000항목 UI 첫 frame/스크롤·반복 성능 측정. 현재 provider 첫 배치 측정과 구분.
2. 최소 창/밝은 테마/영어/키보드 전 흐름/VoiceOver/실제 권한 거부 검증.
3. 원본 Windows 캡처와 표 헤더·폰트·간격 대조; fixture 기반 검증 이미지 보관.
4. macOS 최소 버전·Intel·네트워크 볼륨에서 감시/볼륨 제거 시험. 원격 파일 시스템의 이벤트 전달 차이 검증.
5. 사이드바 섹션 접힘·순서 저장과 재실행 복원은 완료. 장시간·다중 창 반복 조작 검증은 계속한다.

위 목록을 완료해 M1 게이트를 통과한 뒤 M2 작업 저널·복사/이동·충돌·취소·탭·분할에 진입한다. M2 구현 전에 볼륨 간 이동 및 충돌 정책 테스트 fixture를 먼저 만든다.

## 변경 규칙

현재 구현을 완전 기능 앱 또는 원본 UI 완전 일치로 표시하지 않는다. 각 단계 종료 시 검증 결과와 문서를 갱신하고 관련 변경을 커밋한 뒤 origin에 푸시한다. 사용자가 이 절차를 상시 승인했다. 각 개발 단위는 M0/M1 진행 상태를 정확히 표시해 커밋한다. [두 번째 개발 단위 검증](verification/m1/INCREMENT_02.md)을 참고한다.
