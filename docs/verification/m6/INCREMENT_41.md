# M6 Increment 41 — 대상 선택 기반 심볼릭 링크 생성

검증일: 2026-11-14

## 원본 확인

- 고정 SHA `99951c6`의 `CreateShortcutFromDialogAction`은 현재 위치가 쓰기 가능한 경우 별도 대상 선택 대화상자를 열어 바로가기를 만든다.
- FilesMac은 Windows `.lnk` 대신 앞서 검증한 macOS 심볼릭 링크를 플랫폼 대응으로 사용한다.

## 구현

- 파일 메뉴에 `대상을 선택해 심볼릭 링크 만들기…` 명령을 추가해 명령 팔레트에서도 검색할 수 있게 했다.
- `NSOpenPanel`에서 파일 또는 폴더 하나를 선택한 뒤 링크 이름을 확인하고 현재 폴더에 생성한다.
- 선택 항목 컨텍스트 명령과 이름·충돌·원본 변경 오류 처리, 배타적 생성 코어를 공유한다.
- 현재 위치가 없거나 로딩·파일 작업 중일 때 명령을 비활성화한다.

## 검증

- Swift 전체 테스트 168개 및 FilesMac 빌드 통과.
- 한국어/영어 × 밝게/어둡게 UI 4개 조합에서 파일 메뉴·명령 팔레트 등록을 포함한 회귀 검증과 패리티 감사가 통과했다.

실제 샌드박스 배포에서는 외부 대상의 security-scoped bookmark 수명 정책을 M7 패키징 조건과 함께 재검증한다.
