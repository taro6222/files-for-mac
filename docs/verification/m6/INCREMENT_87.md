# M6 Increment 87 — 탭 스크롤 방향 정책

검증일: 2026-11-14

## 구현

- 일반 설정의 `탭 스크롤 방향 반전`을 기본값 꺼짐으로 제공하고 `UserDefaults`와 JSON archive에 저장한다.
- 탭 헤더 영역의 트랙패드·마우스 휠 입력만 네이티브 이전/다음 탭 명령으로 전달한다.
- 수평·수직 변화량 중 큰 축을 사용하고 0.5 미만의 미세 이동은 무시한다.
- 연속 제스처는 시작 phase에서 한 번만 처리해 관성 스크롤이 여러 탭을 건너뛰지 않도록 한다.
- 반전 설정은 동일한 입력의 이전/다음 판정을 정확히 뒤집는다.
