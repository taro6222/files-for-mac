# M6 Increment 14 — 속성 화면 대응

검증일: 2026-11-14

## 판정

- 일반·상세·해시·메인 속성 및 보안 화면의 적용 가능한 정보를 하나의 AppKit 정보 패널에 연결했다.
- 소유자·그룹·POSIX mode와 접근 상태는 읽기 전용이며 ACL 편집을 구현했다고 표시하지 않는다.
- Windows 실행 파일 호환성, Libraries, `.lnk` 전용 속성 화면은 플랫폼 제외로 확정했다.

## 검증

- 기존 UI QA의 정보 창, SHA-256, Finder 태그 검사가 4개 언어·테마 조합에서 통과했다.
- SHA-256 known vector와 파일 metadata 단위 테스트가 통과한다.
- `scripts/audit-parity.py`: 화면 33행, macOS 대체 14, 플랫폼 제외 3, 검토 대기 16; 전체 감사 유효.

## 남은 항목

- 사용자 지정·서명 화면과 나머지 설정/shell 화면은 별도 검토한다.
