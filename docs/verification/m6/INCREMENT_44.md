# M6 Increment 44 — 테마 명령

검증일: 2026-11-14

## 구현

- 앱 메뉴의 테마 하위 메뉴에 시스템 설정 사용, 밝게, 어둡게, 밝게/어둡게 전환 명령을 추가했다.
- 모든 명령은 기존 `BrowserPreferences.appearance` 단일 상태를 변경하므로 열린 창과 이후 생성 창, 설정 화면, 내보내기 JSON이 같은 값을 사용한다.
- 시스템 기본 명령은 macOS의 현재 appearance를 강제로 복제하지 않고 `.system`으로 되돌려 시스템 변경을 계속 추적한다.
- 네 명령 모두 명령 팔레트와 사용자 키보드 단축키 설정에 등록된다.

## 검증

- Swift 전체 테스트 169개와 FilesMac 빌드, appearance 기본값·영속화·알림 검증이 통과했다.
- 한국어/영어 × 밝게/어둡게 UI 4개 조합에서 네 명령 등록과 기존 외형 설정 왕복이 통과했다.

`ToggleAppTheme`는 명시적 밝게/어둡게 사이를 전환하며 시스템 모드에서 실행하면 어둡게로 시작한다.
