# M6 Increment 70 — 카드 레이아웃·보기 크기 명령

검증일: 2026-11-14

## 구현

- Windows의 Cards 레이아웃을 macOS 네이티브 그리드 렌더러에 연결한다.
- 보기 크기 축소·확대 명령은 작게·보통·크게 프리셋 사이에서 한 단계씩 이동한다.
- 분할 보기에서는 활성 pane의 폴더별 설정을 우선하고, 저장된 폴더 설정이 없으면 전역 크기를 갱신한다.
- 최소·최대 프리셋에서는 해당 방향 명령을 비활성화하고 세 명령을 메뉴·명령 팔레트에 노출한다.

## 자동 검증

- 카드 명령이 그리드 모드를 선택하고 축소·확대가 경계 내에서 저장되는지 실제 AppKit UI에서 확인한다.
- 세 명령이 언어·테마 4개 조합의 명령 팔레트 카탈로그에 포함되는지 확인한다.
- 패리티 감사에서 명령 3개와 설정 1개의 구현 또는 macOS 대체 근거를 확인한다.

## 결과

- Swift Testing 177개 통과.
- 한국어·영어 × 밝게·어둡게 4개 실제 AppKit 조합에서 각 181개 검사 통과.
- 패리티 감사 통과: 명령 202/202, 설정 143/143, 화면 33/33.
