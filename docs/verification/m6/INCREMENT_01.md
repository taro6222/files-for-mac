# M6 첫 번째 개발 단위 검증

검증일: 2026-11-14

## 범위

- 고정 원본 인벤토리의 스키마·행 수·identity 중복·증거 누락 자동 감사기 추가
- 명령 202개, 설정 143개, 화면 33개 기준을 실행 가능한 게이트로 고정
- 상태별 집계를 사람이 추측하지 않고 CSV에서 직접 산출

## 검증

`scripts/audit-parity.py --json` 실행 결과:

- 명령: 202/202, identity 중복 0, 증거 누락 0
- 설정: 143/143, identity 중복 0, 증거 누락 0
- 화면: 33/33, identity 중복 0, 증거 누락 0
- 전체 스키마·기준 개수: 통과

## 감사 결과

- 명령 202개 모두 `awaiting-behavior-review`
- 설정 143개 모두 `awaiting-behavior-review`
- 화면 33개 모두 `awaiting-individual-review`

이는 앱에 구현된 기능이 없다는 뜻이 아니라, 고정 원본 인벤토리와 현재 macOS 구현 사이의 개별 대응 판정이 아직 CSV에 반영되지 않았다는 뜻이다. M6 종료 조건인 `stub 0, 미검증 0`을 충족하지 않았으므로 완료로 표시하지 않는다.

## 다음 작업

1. macOS에 직접 대응하는 항목을 구현 증거와 함께 `implemented`로 판정한다.
2. macOS 시스템 동작으로 대체하는 항목은 플랫폼 결정 근거를 연결한다.
3. Windows 전용 또는 의도적 제외는 단순 미구현이 아니라 승인 가능한 차이로 기록한다.
4. 명령·설정·화면의 `awaiting-*` 합계가 0이 될 때까지 게이트를 유지한다.
