# M6 Increment 24 — 파일 크기 단위

검증일: 2026-11-14

## 구현

- 이진(1024)·십진(1000) 파일 크기 단위를 전역 설정으로 제공한다.
- 상세 목록, 보조 pane, 상태 막대, 정보 창의 크기 표시에 동일 설정을 적용한다.
- 일반 설정 창에서 단위를 변경하며 모든 창의 공유 환경 설정 알림으로 즉시 갱신한다.
- 설정 JSON에 단위를 포함하고 이전 JSON에 필드가 없으면 이진 단위로 호환 복원한다.
- 손상된 저장 값이나 import 값은 각각 기본값 복구 또는 전체 import 거부로 처리한다.

## 검증

- 기본값·영구 저장·손상 복구·formatter 호출과 archive 왕복을 Swift Testing으로 검증한다.
- UI QA는 일반 설정 창에서 단위를 변경한 뒤 원래 값으로 복원한다.
- `SizeUnitFormat` 설정을 실제 구현 증거와 함께 `implemented`로 전환한다.

M6 나머지 설정·명령 검토가 남아 전체 완료로 표시하지 않는다.
