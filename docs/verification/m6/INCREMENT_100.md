# M6 Increment 100 — 파일 미리보기 메모리 캐시

- 상세·그리드·목록·계층형 컬럼과 양쪽 pane이 파일별 AppKit 미리보기 캐시를 공유한다. 경로·identity·수정 시각·크기로 캐시 키를 구성한다.
- 고급 설정에서 사용 여부, 8–512 MiB 메모리 비용 한도, 비우기를 제어한다. 기본 한도는 32 MiB다. 캐시를 끄거나 비용 한도를 변경하면 기존 항목을 비운다.
- 비용 한도는 AppKit 이미지 표현의 픽셀 비용 추정값이며 메모리 상주량은 OS와 AppKit의 메모리 관리에 따라 달라진다.
- 고정 원본의 설정 화면은 디스크 캐시를 설명한다. 해당 버전의 크기 조회와 비우기 함수는 TODO 상태이며 macOS판은 디스크에 미리보기 파일을 저장하지 않는다. [원본 캐시 설정](https://github.com/files-community/Files/blob/99951c66928c4da714da8b1dd46039421182cbab/src/Files.App/ViewModels/Settings/AdvancedViewModel.cs#L364-L414)
