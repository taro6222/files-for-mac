## 판정

- 관리자 실행 경고, WSL 표시·펼침, Start 고정, NTFS ADS 표시·생성은 macOS에 같은 운영체제 개념이 없어 플랫폼 제외로 확정했다.
- FilesMac은 백그라운드 상주 agent와 텔레메트리를 제공하지 않으므로 시스템 트레이 아이콘과 영구 사용자 ID도 제외했다.
- 이름만 비슷한 xattr, Finder 즐겨찾기, 메뉴 막대 항목을 동등 기능으로 오인하지 않는다.
