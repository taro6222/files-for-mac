# M6 Increment 99 — 동기화 상태 정렬·그룹화·열

- macOS Foundation에서 iCloud 항목에 제공하는 상태를 로컬 목록을 읽을 때 수집한다. 다운로드·업로드·충돌·오류 및 오프라인 사용 가능 여부를 표시한다. 상태를 제공하지 않는 항목은 열에 대시로 표시되고 그룹화에서 별도로 분류된다. [Apple URL 리소스 메타데이터](https://developer.apple.com/documentation/foundation/urlresourcevalues/isubiquitousitem)
- 이동 메뉴와 명령 팔레트에서 동기화 상태로 정렬·그룹화한다. 상세 보기의 열 헤더로도 정렬할 수 있다. 기존 폴더 우선 배치 및 정렬 방향을 적용한다.
- 보기 옵션에서 양쪽 상세 pane의 상태 열을 표시하거나 숨긴다. 기본값은 숨김이며 설정 내보내기와 가져오기에 포함된다. 기본 pane의 열 너비는 기존 AppKit 레이아웃 저장 경로를 따른다.
- 실제 iCloud 계정에서 상태 전환은 M5 실환경 수용 검증 항목으로 남아 있다.

## 검증

- Swift Testing 196개 통과. 상태 없음과 알려지지 않은 iCloud 상태의 분리, 오름차순·내림차순, 상태 보존, 설정 재생성 및 내보내기·가져오기 왕복을 확인했다.
- 한국어·영어 × 밝게·어둡게 AppKit 자동 검증에서 각 216개 통과. 열 표시와 숨김, 사용자 크기 조절 속성, 두 명령의 활성화와 미보고 항목 처리를 확인했다.
- 패리티 감사에서 명령 202개, 설정 143개, 화면 33개를 확인했다.
