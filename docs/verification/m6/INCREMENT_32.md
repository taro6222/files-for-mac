# M6 Increment 32 — 컨텍스트 메뉴 표시 설정

검증일: 2026-11-14

## 구현

- 압축 탐색·선택 항목 압축, 터미널에서 열기, 선택 항목으로 새 폴더 만들기 메뉴의 표시 여부를 각각 저장한다.
- 일반 설정 창에서 세 설정을 변경하며 모든 열린 브라우저 창에 즉시 적용한다.
- 상세·그리드·목록·컬럼 보기가 공유하는 컨텍스트 메뉴에 동일하게 적용한다.
- JSON archive 왕복과 이전 archive의 기본값 `true`를 지원한다.

## 검증

- 기본값·영구 저장·중복 알림 방지·archive 왕복 단위 테스트를 추가했다.
- 전체 Swift 테스트 165개가 통과했다.
- UI QA가 실제 `NSMenuItem.isHidden` 상태를 한국어/영어 × 라이트/다크 4개 조합에서 검증했다.

아직 UI가 없는 원본 컨텍스트 메뉴 항목 설정은 구현된 것처럼 분류하지 않고 검토 대기로 유지한다.
