# M6 Increment 29 — 사이드바 표시 설정

검증일: 2026-11-14

## 구현

- 보기 옵션에서 네이티브 사이드바 전체를 표시하거나 숨길 수 있다.
- 공유 환경 설정 변경을 모든 브라우저 창에 즉시 적용한다.
- 기존 사이드바 폭 autosave와 섹션 접힘·순서 설정은 숨김 상태와 독립적으로 보존한다.
- 설정 JSON archive에 표시 상태를 포함하며 이전 archive에는 기본값 `true`를 적용한다.

## 검증

- 툴바·상태 막대 검증에 사이드바 기본값·영구 저장·중복 알림 방지를 추가한다.
- archive 왕복에서 숨김 상태를 복원한다.
- UI QA가 사이드바를 실제로 숨기고 다시 표시해 창 레이아웃을 확인한다.

M6 나머지 설정·명령 검토가 남아 전체 완료로 표시하지 않는다.
