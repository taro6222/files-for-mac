# M6 Increment 78 — 기본 파일·폴더 정렬 배치

검증일: 2026-11-14

## 구현

- 일반 설정에 `폴더 우선`, `파일·폴더 혼합`, `파일 우선`의 3상태 기본 배치 제어를 추가한다.
- 기본 배치를 `UserDefaults`와 설정 export/import archive에 저장하고 모든 새 창에서 사용한다.
- 새 분할 pane은 현재 위치와 보기 모드를 이어받되 저장된 기본 배치를 사용한다.
- 세션이나 탭 snapshot을 복원할 때는 해당 snapshot의 정렬 상태를 우선해 사용자의 기존 탭 배치를 덮어쓰지 않는다.
- 원본의 두 불리언 설정을 상호 모순이 없는 단일 `SortDirectoryPlacement` 값으로 표현한다.

## 자동 검증

- 기본값, 3상태 저장, 중복 변경 알림 방지와 재생성 복원을 단위 테스트한다.
- 설정 archive 왕복에서 `filesFirst` 값을 검증하고 잘못된 archive는 기존 상태를 변경하지 않는 계약을 유지한다.
- 실제 AppKit 일반 설정 창에서 3상태 제어의 변경과 되돌리기를 한국어·영어 × 밝게·어둡게 조합으로 실행한다.
- 패리티 감사에서 두 원본 설정의 구현 근거와 전체 인벤토리 무결성을 확인한다.
