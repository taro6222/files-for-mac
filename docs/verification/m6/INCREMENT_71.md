# M6 Increment 71 — 클립보드 잘라내기·붙여넣기

검증일: 2026-11-14

## 구현

- 파일 보기의 표준 ⌘X 명령이 선택 URL과 FilesMac 전용 잘라내기 의도를 시스템 클립보드에 기록한다.
- ⌘V는 일반 파일 URL이면 기존 안전 복사·폴더 병합 흐름을, FilesMac 잘라내기 의도이면 검증·교체 백업·Undo를 지원하는 안전 이동 흐름을 사용한다.
- 이동 정책을 실제로 선택한 시점에만 클립보드를 비워 취소 시 잘라내기 의도를 보존한다.
- 복사 명령은 잘라내기 표식을 제거하며 작업 중에는 잘라내기·붙여넣기 명령을 비활성화한다.

## 자동 검증

- 실제 AppKit 선택 항목에서 잘라내기 표식과 붙여넣기 활성 조건, 복사 후 표식 제거를 확인한다.
- 잘라내기·복사·붙여넣기 명령이 언어·테마 4개 조합의 명령 팔레트 카탈로그에 포함되는지 확인한다.
- 패리티 감사에서 CutItem과 PasteItem의 구현 근거를 확인한다.

- 한국어·영어 × 밝게·어둡게 4개 실제 AppKit 조합에서 각 184개 검사 통과.
- 패리티 감사 통과: 명령 202/202, 설정 143/143, 화면 33/33.
