# M6 Increment 36 — 새 탭·창·pane 열기

검증일: 2026-11-14

## 구현

- 선택한 단일 폴더 또는 선택이 없을 때 현재 위치를 새 탭·새 창·새 pane에서 연다.
- 새 pane은 기존 secondary pane이 있으면 그 위치를 바꾸고, 없으면 좌우 분할로 생성한다.
- 파일 또는 복수 선택에서는 세 명령을 비활성화한다.
- 일반 설정에서 세 메뉴의 표시 여부를 독립적으로 저장하고 모든 열린 창에 즉시 적용한다.
- JSON archive 왕복과 이전 archive 기본값 `true`를 지원한다.

## 검증

- 전체 Swift 테스트 166개가 통과했다.
- UI QA가 세 메뉴의 숨김 상태와 현재 폴더를 실제 secondary pane에 여는 동작을 한국어/영어 × 라이트/다크 4개 조합에서 검증했다.
- 새 탭은 macOS 네이티브 tabbed window에, 새 창은 독립 `BrowserWindow`에 연결된다.

홈·사이드바 전용 원본 변형 명령은 별도 동작 검증 전까지 검토 대기로 유지한다.
