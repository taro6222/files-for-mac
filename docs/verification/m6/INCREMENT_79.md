# M6 Increment 79 — 상세 열 자동 맞춤 정책

검증일: 2026-11-14

## 구현

- 일반 설정에 상세 보기 열 너비 자동 맞춤 옵션을 추가하고 기본값은 원본과 같은 꺼짐으로 유지한다.
- 설정을 `UserDefaults`와 설정 export/import archive에 저장한다.
- 옵션이 켜진 경우 기본 pane과 보조 pane의 디렉터리 읽기가 정상 완료된 시점에 표시 중인 상세 열을 내용에 맞춘다.
- 부분 batch마다 반복 조정하지 않고 로딩 완료 전환에서 한 번만 적용해 스크롤 중 열 흔들림을 방지한다.
- 수동 `열 너비 자동 맞춤` 명령과 기존 네이티브 열 너비 autosave는 그대로 유지한다.

## 자동 검증

- 기본값, 저장, 중복 변경 알림 방지, 재생성 및 archive 왕복을 단위 테스트한다.
- 실제 AppKit 일반 설정 창에서 옵션 변경과 원상 복원을 네 언어·테마 조합으로 실행한다.
- 기존 10,000개 fixture의 수동 자동 맞춤 범위 검사를 함께 통과시킨다.
- 패리티 감사에서 설정 구현 근거와 전체 인벤토리 무결성을 확인한다.
