# M6 Increment 12 — 툴바·상태 막대 표시 설정

## 구현

- 툴바와 상태 막대 표시 여부를 기본 활성 설정으로 추가하고 `UserDefaults`에 저장한다.
- 보기 옵션 메뉴에서 두 영역을 독립적으로 표시·숨김 처리한다.
