# M6 Increment 48 — 압축 해제 위치 명령

검증일: 2026-11-14

## 대응

- `DecompressArchiveHere` → 선택한 모든 지원 아카이브를 현재 폴더에 순차 추출한다.
- `DecompressArchiveHereSmart` → 검증된 항목의 최상위 경로가 하나면 현재 폴더에 추출하고, 둘 이상이면 아카이브 기본 이름의 고유 하위 폴더를 만든다.
- `DecompressArchiveToChildFolder` → 각 아카이브마다 기본 이름의 고유 하위 폴더를 만들고 추출한다.

세 명령은 주 메뉴·컨텍스트 메뉴·명령 팔레트에 연결했다. 여러 아카이브를 한 번에 선택할 수 있고, 기존 `ZipArchiveProvider`의 경로 탈출·링크·특수 항목 차단, staging/publish/rollback 및 안전 지점 중단 계약을 그대로 사용한다. 새 하위 폴더 이름이 겹치면 숫자 접미사를 붙이며, 실패 후 비어 있는 폴더만 정리한다.

## 차이와 경계

- macOS 앱은 Windows 원본의 flyout 대신 네이티브 메뉴 항목 세 개를 제공하므로 분류는 `E`다.
- 암호화 아카이브는 현재 provider capability가 지원하지 않으므로 이 단위에서도 지원으로 표시하지 않는다.
- 스마트 판단은 추출 전에 정규화·보안 검증을 통과한 entry만 사용한다.
