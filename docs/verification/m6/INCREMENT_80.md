# M6 Increment 80 — 시작 새 탭·선택 탭 복원

검증일: 2026-11-14

## 구현

- 일반 설정에 `시작할 때 새 탭 추가` 옵션을 추가하고 기본값은 원본과 같은 꺼짐으로 유지한다.
- 마지막 세션을 복원한 뒤 옵션이 켜져 있으면 같은 네이티브 탭 그룹에 시작 위치 탭을 하나 추가한다.
- 옵션이 꺼져 있으면 종료 직전 활성 탭 인덱스를 저장하고 다음 실행에서 복원된 탭을 다시 선택한다.
- 저장된 음수 인덱스는 `-1`로 복구하고 범위를 벗어난 인덱스는 안전하게 무시한다.
- 두 값을 `UserDefaults`와 설정 export/import archive에 포함한다.

## 자동 검증

- 기본값, 저장, 음수 복구, 중복 변경 알림 방지, 재생성과 archive 왕복을 단위 테스트한다.
- 실제 AppKit 일반 설정에서 시작 새 탭 옵션을 변경하고 원상 복원한다.
- 한국어·영어 × 밝게·어둡게 UI 회귀와 전체 패리티 감사를 실행한다.
