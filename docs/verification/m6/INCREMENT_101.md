# M6 Increment 101 — 최근 파일 전송 실행 취소

- 편집 메뉴와 ⌘Z로 앱의 복사·이동 저널을 확인하고, 실행 취소할 수 있는 전송 중 가장 최근 완료 기록을 연다. 작업 유형별 명령도 제공한다.
- 확인 창이 열려 있는 동안 다른 창에서 작업을 실행했으면 저널과 현재 작업 상태를 다시 확인한다. 실행 후 양쪽 pane을 갱신한다.
- 개별 엔진의 대상 identity·내용·충돌 검사와 결과 표시를 그대로 사용한다. 부분 이동 실행 취소로 저널을 갱신해도 작업 자체의 완료 시각으로 순서를 판단한다.
- 이 명령은 안전 저널이 있는 복사·이동을 대상으로 한다. 원본의 이름 변경·생성·휴지통 작업을 포함하는 이력과 재실행은 후속 범위다. [원본 파일 작업 이력](https://github.com/files-community/Files/blob/99951c66928c4da714da8b1dd46039421182cbab/src/Files.App/Utils/Storage/History/StorageHistoryOperations.cs)

## 검증

- Swift Testing 197개 통과. 복사와 이동의 처리 순서, 실제 파일 복원, 저널 소진을 확인했다.
- 한국어·영어 × 밝게·어둡게 AppKit 파일 작업 검증에서 각 29개 통과. 실제 확인 창에서 복사 실행 취소를 실행해 목록 갱신과 기존 파일 보존을 확인했다.
