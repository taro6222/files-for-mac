# M6 Increment 28 — macOS 포인터·선택 동작

검증일: 2026-11-14

## 판정

- 상세·그리드·목록은 macOS 표준 더블 클릭으로 파일과 폴더를 연다.
- 컬럼 보기는 단일 선택으로 다음 계층 컬럼을 펼친다.
- 선택은 hover가 아니라 명시적 클릭·키보드로 변경하고 Command/Shift 다중 선택과 네이티브 강조를 사용한다.
- Windows touch-only 단일 클릭과 선택 체크박스를 이름만 같은 사용자 옵션으로 복제하지 않는다.

## 검증

- 기존 UI QA가 네 보기 모드의 열기·포커스·선택 identity·컬럼 계층 확장을 검증한다.
- 소스에 고정된 네이티브 동작이 있는 5개 설정만 `platform-alternative`로 판정한다.
- 아직 없는 배경 더블 클릭 상위 이동 등은 대기 상태를 유지한다.
- 인벤토리 감사가 전체 행 수와 상태 분류를 검증한다.

M6 전체는 완료로 표시하지 않는다.
