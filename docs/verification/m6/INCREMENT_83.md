# M6 Increment 83 — 앱 배경 표시 제어

검증일: 2026-11-14

## 구현

- 배경 이미지를 영역 채우기, 전체 이미지 맞춤, 비율 무시 늘이기의 세 방식으로 표시한다.
- 수평 정렬은 왼쪽·가운데·오른쪽, 수직 정렬은 아래·가운데·위로 제공한다.
- 불투명도는 0...1 범위로 제한하고 외형 설정 슬라이더에서 즉시 변경한다.
- 기본값은 원본과 같은 영역 채우기·불투명도 1·가운데 정렬이다.
- 설정은 `UserDefaults`와 JSON archive에 저장되며 기본 pane과 보조 pane에 즉시 반영된다.
- 투명도 감소 접근성 overlay는 사용자 이미지 설정과 별도로 계속 적용한다.
