# M6 Increment 18 — 개발 앱 설정

검증일: 2026-11-14

## 구현

- 네이티브 개발자 도구 설정 창에서 `.app` 번들을 선택하거나 해제할 수 있다.
- 선택 경로는 로컬 `UserDefaults`에 저장되고 열린 창에 즉시 공유된다.
- “개발 앱에서 열기”는 선택 항목 또는 현재 폴더 URL을 `NSWorkspace`로 전달하며 shell 문자열을 구성하지 않는다.
- 저장된 앱이 없거나 제거된 경우 명령을 비활성화하거나 명확한 오류를 표시한다.

## 검증

- 선택 경로 저장·재생성·해제 단위 테스트를 추가했다.
- `swift test`: 157개 통과.
- `scripts/verify-ui.sh`: 기존 4조합 회귀 통과.
- 잘못된 `AppChoiceStore` 문서 증거를 실제 구현 경로로 교정했다.

## 남은 항목

- 앱 bookmark가 필요한 sandbox 배포 구성은 M7 서명 entitlement 결정과 함께 재검증한다.
