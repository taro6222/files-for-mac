# M6 Increment 51 — 안전한 이미지 좌우 회전

검증일: 2026-11-14

## 구현

- `RotateLeft`와 `RotateRight`를 파일 메뉴·컨텍스트 메뉴·명령 팔레트에 연결하고 여러 이미지를 순차 처리하는 진행/중단 창을 제공한다.
- ImageIO가 동일 포맷으로 읽고 쓸 수 있는 단일 프레임 일반 파일만 허용한다. 심볼릭 링크, 비이미지, 애니메이션 및 다중 페이지 파일은 거부한다.
- 픽셀을 재압축하지 않고 1~8 방향 메타데이터를 좌우 90도 합성한다. 일반·미러 방향을 모두 명시적으로 매핑한다.
- 원본을 같은 디렉터리의 staging으로 복사해 권한과 확장 메타데이터를 보존하고, 별도 출력의 재개방·포맷·프레임 수를 확인한 뒤 staging 내용만 교체한다.
- 게시 직전 원본 identity·크기·수정일을 다시 검사하고 `replaceItemAt`으로 원자 교체한다. 실패 시 원본은 바꾸지 않고 임시 파일을 정리한다.
- 중단은 현재 파일의 원자 교체가 끝나는 안전 지점에서 적용하며 이미 완료된 파일은 결과로 유지한다.

## 자동 검증

- PNG 픽셀 payload 크기와 POSIX 권한을 유지하면서 오른쪽 방향 1→6, 왼쪽 6→1을 확인한다.
- 비이미지 거부 및 미러 방향 좌우 매핑을 확인한다.
- 실제 AppKit 진행 창으로 오른쪽/왼쪽 회전을 실행하고 파일 방향 값, 메뉴/팔레트 등록 및 4개 언어·테마 조합을 확인한다.

전체 Swift Testing 172개, AppKit UI 4개 조합 및 패리티 감사를 실행한다.
