# M6 Increment 37 — Finder 태그 편집 메뉴

검증일: 2026-11-14

## 구현

- 파일 컨텍스트 메뉴에 `Finder 태그 편집…` 항목을 추가한다.
- 기존 정보 창의 Finder 태그 읽기·쓰기 UI로 연결해 별도 중복 편집기를 만들지 않는다.
- 선택이 없으면 비활성화하며 단일·복수 선택 정보 창 규칙을 그대로 적용한다.
- 일반 설정에서 메뉴 표시 여부를 저장하고 모든 열린 창에 즉시 적용한다.
- JSON archive 왕복과 이전 archive 기본값 `true`를 지원한다.

## 검증

- 기존 Finder 태그 identity 보호 왕복 검증을 포함한 전체 Swift 테스트 166개가 통과했다.
- UI QA가 실제 태그 편집 메뉴의 숨김 상태를 한국어/영어 × 라이트/다크 4개 조합에서 확인했다.
- 기존 UI QA가 정보 창의 태그 저장과 재조회까지 검증한다.

나머지 M6 설정과 명령은 계속 검토 대기로 유지한다.
