# M6 Increment 65 — 진단·도움말 열기 명령

검증일: 2026-11-14

## 구현

- 앱 지원 디렉터리에 줄바꿈을 제거한 이벤트만 기록하는 0600 권한 진단 로그를 생성한다.
- 로그 파일 열기와 Finder 위치 보기를 제공한다.
- 현재 설정을 기존 검증된 export 스키마의 0600 JSON 스냅샷으로 원자 저장한 뒤 연다.
- 온라인 도움말, 현재 위치를 선택한 개발 앱에서 열기, 선택 파일을 TextEdit에서 편집하는 macOS 대응 명령을 제공한다.
- 자격증명과 파일 경로 같은 사용자 내용을 자동으로 로그에 기록하지 않는다.

## 자동 검증

- 임시 루트에서 로그 append, 줄바꿈 제거, 결정적 파일 경로, 설정 원자 저장과 0600 권한을 단위 테스트한다.
- 6개 명령 selector가 메뉴와 명령 팔레트에 등록되는지 확인한다.
- 전체 Swift Testing과 한국어/영어 × 밝게/어둡게 UI 4개 조합 및 패리티 감사를 실행한다.
