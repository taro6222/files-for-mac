# M6 Increment 81 — 새 탭 dual-pane·전환 정책

검증일: 2026-11-14

## 구현

- 일반 설정에 새 탭을 dual pane으로 시작하는 옵션과 새 탭으로 즉시 전환하는 옵션을 추가한다.
- 두 옵션은 원본과 동일하게 기본 꺼짐이며 `UserDefaults`와 설정 archive에 저장한다.
- 새 탭 즉시 전환이 꺼져 있으면 네이티브 탭을 추가하되 기존 탭의 포커스를 유지한다.
- dual-pane 옵션이 켜져 있으면 일반 새 탭 명령으로 만든 workspace에 두 번째 pane을 즉시 설치한다.
- 시작 시 추가하는 새 탭은 시작 동작의 명시적 대상이므로 일반 전환 옵션과 무관하게 선택한다.
