# M6 Increment 74 — 폴더 경로 정렬·그룹화

검증일: 2026-11-14

## 구현

- 각 항목 URL의 표준화된 상위 폴더 경로를 정렬·그룹 키로 사용한다.
- 같은 폴더 경로에서는 기존의 안정적인 항목 identity 보조 정렬을 유지한다.
- 명령은 활성 pane의 정렬·그룹 상태를 갱신하고 기존 탭·분할 세션 저장 경로로 보존된다.
- 일반 단일 폴더 보기에서는 하나의 경로 그룹, 여러 위치 검색 결과에서는 위치별 그룹을 제공한다.

## 자동 검증

- 서로 다른 두 상위 경로와 같은 경로의 복수 항목으로 결정적 순서와 그룹을 단위 테스트한다.
- 실제 AppKit에서 두 명령의 모델 반영과 명령 팔레트 노출을 언어·테마 4개 조합으로 확인한다.
- 패리티 감사에서 GroupByFolderPath와 SortByPath의 구현 근거를 확인한다.

- 한국어·영어 × 밝게·어둡게 4개 실제 AppKit 조합에서 각 187개 검사 통과.
- 패리티 감사 통과: 명령 202/202, 설정 143/143, 화면 33/33.
