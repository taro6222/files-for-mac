# M6 Increment 91 — 임시 파일 모음

검증일: 2026-11-14

- Shelf는 로컬 파일과 폴더를 창 간에 공유하는 세션 목록이다. 선택한 항목을 편집 메뉴에서 추가하거나 파일 URL을 Shelf에 드롭할 수 있다.
- 복사와 이동의 대상은 활성 탐색 pane의 현재 폴더다. 기존 충돌 처리와 진행 창을 사용한다. 휴지통 이동은 별도 확인을 거치며, 목록의 제거 버튼은 목록에서만 항목을 뺀다.
- 파일 시스템 식별자를 추가 시 기록하고 작업 전과 확인 후에 검사한다. 그 사이 항목이 바뀌면 작업을 중단하고 오래된 참조를 목록에서 뺀다. 작업 시작 이후의 동시 변경은 기존 파일 작업 엔진의 정책을 따른다.
- Shelf 표시와 선택적 툴바 버튼 표시 설정은 저장되며 설정 아카이브에 포함된다. 모아 둔 파일 참조는 세션 종료 시 사라진다.
- 고정 원본의 [복사·이동·휴지통 명령](https://github.com/files-community/Files/tree/99951c66928c4da714da8b1dd46039421182cbab/src/Files.App/Actions/Shelf)과 [Shelf UI](https://github.com/files-community/Files/blob/99951c66928c4da714da8b1dd46039421182cbab/src/Files.App/UserControls/Pane/ShelfPane.xaml.cs)에 대응한다. 현재 구현은 파일 감시 대신 작업 시점에 오래된 참조를 검사한다.
