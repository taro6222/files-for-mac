# M6 Increment 84 — 취소 가능한 폴더 크기 계산

검증일: 2026-11-14

## 구현

- 일반 설정의 `폴더 크기 계산`을 기본값 꺼짐으로 제공하고 `UserDefaults`와 JSON archive에 저장한다.
- 활성화하면 현재 위치의 탐색 가능한 폴더를 utility 작업에서 재귀 열거하고 일반 파일의 논리 크기를 합산한다.
- 심볼릭 링크는 대상과 하위 항목을 따라가지 않아 중복 계산과 순환을 막는다.
- 탐색 또는 창 종료 시 계산을 취소하고, 완료 결과는 시작 위치와 현재 위치가 같은 경우에만 적용한다.
- 진행 중 작업을 렌더링마다 재시작하지 않으며 새 탐색에서는 취소된 작업 참조를 비우고 다시 계산한다.
- 기본 pane과 보조 pane의 상세 크기 열 및 자동 열 맞춤에 계산 결과를 반영한다.
- 읽을 수 없는 폴더는 부분 크기를 표시하지 않고 알 수 없는 상태로 유지한다.
