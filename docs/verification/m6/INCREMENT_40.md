# M6 Increment 40 — 심볼릭 링크 메뉴 표시 설정

검증일: 2026-11-14

## 구현

- 일반 설정의 컨텍스트 메뉴 영역에 `심볼릭 링크 만들기 표시` 선택 항목을 추가했다.
- 기본값은 원본 `ShowCreateShortcut`과 같은 `true`이며 변경 즉시 모든 브라우저 창에 반영된다.
- UserDefaults 영속화와 설정 JSON 내보내기·가져오기에 포함했다. 이전 JSON에 필드가 없으면 `true`로 안전하게 마이그레이션한다.
- UI QA가 설정을 끈 동안 실제 컨텍스트 메뉴 action이 숨겨지고 복원되는지 검증한다.

## 검증

- Swift 전체 테스트 168개 및 FilesMac 빌드 통과.
- 기본값, 영속화, 중복 알림 방지와 설정 archive 왕복을 자동 검증했다.
- 한국어/영어 × 밝게/어둡게 UI 4개 조합과 패리티 감사가 통과했다.

`CreateShortcutFromDialog`는 별도 파일 선택 대화상자 의미를 확인하기 전까지 검토 대기로 유지한다.
