# M6 Increment 77 — Finder 태그·경로 상세 열

검증일: 2026-11-14

## 구현

- 상세 보기에 Finder 태그와 상위 폴더 경로 열을 추가한다.
- 태그 열은 복수 태그를 표시하고 태그가 없으면 대시를, 경로 열은 표준화된 상위 폴더 경로를 표시한다.
- 두 열의 표시 여부를 전역 설정·export/import에 저장하고 모든 창에 즉시 반영한다.
- 열 너비와 순서는 macOS 네이티브 `NSTableView` autosave를 사용해 재실행 후 복원한다.
- 두 열은 헤더 클릭 정렬과 기존 자동 너비 맞춤 동작에 참여한다.

## 자동 검증

- 표시 설정의 기본값, 변경 알림 중복 방지, 재생성 및 archive 왕복을 단위 테스트한다.
- 실제 AppKit 4개 조합에서 두 열 표시와 최소 너비를 확인한다.
- 패리티 감사에서 열 표시 2개와 너비 2개의 구현·macOS 대체 근거를 확인한다.
