# M6 Increment 25 — 폴더 새 탭 열기

검증일: 2026-11-14

## 구현

- 일반 설정에서 폴더를 현재 pane 대신 새 네이티브 탭으로 여는 옵션을 제공한다.
- 기본 pane의 상세·그리드·목록·컬럼 보기와 보조 pane의 모든 보기 모드에 동일 동작을 적용한다.
- 새 탭은 현재 브라우저의 `addTabbedWindow` 경로를 사용해 선택한 폴더 위치에서 시작한다.
- 설정은 영구 저장과 JSON archive 왕복을 지원하며 이전 archive에는 기본값 `false`를 적용한다.

## 검증

- 기본값·저장·중복 알림 방지·archive 왕복을 Swift Testing으로 검증한다.
- UI QA는 일반 설정 창에서 옵션을 변경한 뒤 원래 상태로 복원한다.
- 기존 보조 pane 탐색 회귀는 기본값에서 현재 pane 탐색을 계속 검증한다.

M6 나머지 설정·명령 검토가 남아 전체 완료로 표시하지 않는다.
