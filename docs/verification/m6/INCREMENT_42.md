# M6 Increment 42 — 안전한 빈 파일 생성

검증일: 2026-11-14

## 구현

- 파일 메뉴와 명령 팔레트에 `새 파일…` 명령을 추가했다.
- 이름 검증 후 상위 폴더의 열린 descriptor identity를 재확인하고 `openat(O_CREAT | O_EXCL)`로 빈 파일을 생성한다.
- 같은 이름의 파일·폴더·깨진 링크가 있으면 기존 항목을 절대 덮어쓰지 않는다.
- 변경 전에 작업 저널을 기록하고, 성공 후 새 항목을 선택하며 숨김 파일 생성 시 기존 표시 정책을 유지한다.

## 검증

- Swift 전체 테스트 169개 및 FilesMac 빌드 통과.
- Unicode 파일명, 0바이트 결과, 저널 성공, 충돌 시 기존 내용 보존을 자동 검증했다.
- 한국어/영어 × 밝게/어둡게 UI 4개 조합의 파일 메뉴·명령 팔레트 등록과 패리티 감사가 통과했다.

템플릿 기반 문서 생성은 별도 원본 명령이 확인될 때 독립 기능으로 다룬다.
