# M6 Increment 23 — 네이티브 수명주기·날짜 정책

검증일: 2026-11-14

## 판정

- 파일 목록과 정보 창의 날짜는 `DateFormatter`의 macOS 언어·지역 설정을 따른다.
- 새 탭은 단일 `NSApplication`의 현재 브라우저에 `addTabbedWindow`로 추가한다.
- Windows 상태센터 teaching tip과 백그라운드 실행 알림은 별도 상주 agent가 없는 FilesMac에 제공하지 않는다.
- 리뷰·후원 요청 팝업과 이를 위한 클릭 추적 설정은 만들지 않는다.

## 검증

- 기존 UI 검증은 한국어/영어와 네이티브 탭 생성·복원 흐름을 포함한다.
- 소스 증거가 있는 2개 항목만 `platform-alternative`, 명시적 제품 경계 4개만 `platform-excluded`로 전환한다.
- 아직 구현되지 않은 시작 탭 선택, 탭 전환, 커스텀 외형 설정은 대기 상태를 유지한다.
- 인벤토리 스키마·행 수·허용 상태 감사 통과를 요구한다.

M6 전체는 완료로 표시하지 않는다.
