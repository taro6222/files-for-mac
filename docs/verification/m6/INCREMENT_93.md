# M6 Increment 93 — 모든 폴더에서 같은 보기 사용

- 보기 옵션과 이동 메뉴에서 켤 수 있다. 활성 pane의 보기 모드·크기·정렬·그룹을 초기 공유값으로 저장한다.
- 옵션을 켜면 열린 창과 분할 pane이 같은 설정을 사용한다. 보기 모드, 보기 크기, 열 머리글 정렬 및 그룹 명령에서 변경한 값이 함께 적용된다.
- 옵션을 끄면 저장된 폴더별 보기 모드와 크기가 다시 적용된다. 폴더별 설정 저장소에는 공유 변경을 쓰지 않는다. 정렬과 그룹은 기존 pane 상태 모델을 계속 사용한다.
- 공유값과 활성 여부를 설정 파일에 저장하고 내보내기·가져오기에 포함한다. 기존 설정 파일의 기본값은 꺼짐이다.
- 원본은 공통 기본값과 폴더별 데이터베이스를 전환한다. macOS판은 활성 pane 설정을 공통값의 시작점으로 사용한다. [고정 원본 코드](https://github.com/files-community/Files/blob/99951c66928c4da714da8b1dd46039421182cbab/src/Files.App/Helpers/Layout/LayoutPreferencesManager.cs#L379)
