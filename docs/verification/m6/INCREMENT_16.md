## 구현

- 앱 메뉴에 네이티브 About와 릴리스 노트 진입점을 추가했다.
- About는 런타임 버전·빌드, 고정 원본 기준, 라이선스와 데이터 안전 원칙을 표시한다.
- 릴리스 노트는 개발 프리뷰 포함 범위, 알려진 제한, 플랫폼 차이와 복구 원칙을 한국어/영어로 제공한다.
- 정식 서명·공증·DMG·업데이트 및 미검증 환경을 완료로 오인하지 않도록 화면에 명시했다.
