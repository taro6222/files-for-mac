# M6 Increment 45 — 기존 창·pane·chrome 명령 재조정

검증일: 2026-11-14

## 범위

기존 구현과 자동화 증거를 다시 대조해 다음 원본 명령을 중복 코드 없이 구현 상태로 연결했다.

- 새 창, 닫은 탭 다시 열기
- 좌우 분할, 상하 분할
- 사이드바 전환, 툴바 전환, 툴바 사용자 지정
- 릴리스 노트 열기

`CloseActivePane`은 현재 `보조 pane 닫기`와 의미가 완전히 같지 않으므로 이번 재조정에 포함하지 않았다.

## 증거

- 새 창 반복 생성·해제와 workspace 선택 상태 보존 UI 검증
- 닫은 탭 용량·최근 순서·workspace 복원 단위 테스트
- 양 방향 분할, 보조 pane 보기·선택·탐색 UI 검증
- 사이드바·툴바 표시 설정의 영속화·즉시 반영 및 4개 UI 조합 검증
- 툴바 사용자 지정 창의 전체 항목 수·순서·숨김·초기화 검증
- 릴리스 노트 창의 실제 개발 프리뷰 콘텐츠 검증
- 각 action이 앱 메뉴와 명령 팔레트에 등록됐는지 자동 확인

Swift 전체 테스트 169개, 한국어/영어 × 밝게/어둡게 UI 4개 조합, 패리티 감사가 통과했다. 첫 UI 실행에서 옵션 팝업에만 있던 사이드바·툴바·사용자 지정 action이 주 메뉴 기반 명령 팔레트에 누락된 것을 발견해 보기 메뉴에도 연결한 뒤 네 조합을 다시 통과시켰다.
