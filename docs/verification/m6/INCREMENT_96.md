# M6 Increment 96 — 폴더 펼치기

- 일반 설정에서 옵션을 켜면 단일 일반 폴더의 컨텍스트 메뉴·파일 메뉴·명령 팔레트에서 실행할 수 있다.
- 선택한 폴더 아래에 있는 파일·심볼릭 링크·패키지를 조사하고, 선택한 폴더의 바로 아래로 옮길 항목 수와 목적지를 확인 창에 표시한다. 링크 대상과 패키지 내부를 탐색하지 않는다.
- 기존 이동 작업의 진행률·취소·저널·실행 취소를 사용한다. 이름 충돌은 건너뛴다. 계획 이후 바뀐 원본은 실패로 보고한다.
- macOS판은 실행 취소에 필요한 폴더 구조를 보존한다. 원본에는 빈 디렉터리 정리와 디렉터리 이동도 있다. [고정 원본 코드](https://github.com/files-community/Files/blob/99951c66928c4da714da8b1dd46039421182cbab/src/Files.App/Actions/FileSystem/FlattenFolderAction.cs)

## 검증

- Swift 테스트 195개 통과. 임시 폴더에서 충돌 양쪽 보존, 링크 순환 방지, 개별 항목 이동, 실행 취소와 교체 원본 거부를 확인했다.
- 한국어·영어 × 밝게·어둡게 AppKit UI 각 213개 통과. 메뉴 옵션의 기본 비활성 상태, 폴더와 파일에 따른 활성 조건, 명령 팔레트 등록을 확인했다. 확인 대화상자부터 파일 작업까지의 UI 종단 간 검증은 남아 있다.
- 패리티 감사 통과. 검토 대기는 명령 9개, 설정 8개다.
