# M6 Increment 85 — Finder 미리보기·일반 아이콘 정책

검증일: 2026-11-14

## 구현

- 일반 설정의 `썸네일 표시`를 기본값 켜짐으로 제공하고 `UserDefaults`와 JSON archive에 저장한다.
- 켜짐에서는 파일 경로별 `NSWorkspace` Finder 아이콘을 사용해 시스템이 제공하는 파일별 미리보기와 사용자 지정 아이콘을 보존한다.
- 꺼짐에서는 파일 내용을 읽지 않고 확장자의 `UTType` 일반 아이콘을 사용한다. 폴더와 패키지도 각각 일반 folder/bundle 아이콘으로 고정한다.
- 상세·그리드·단일열 목록·계층형 컬럼 보기와 기본·보조 pane에 같은 정책을 즉시 적용한다.
- 상세 보기 아이콘 캐시는 정책과 경로 또는 UTI 종류를 키에 포함해 설정 전환 시 이전 미리보기가 남지 않도록 했다.
