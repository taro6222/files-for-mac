# M6 Increment 35 — 경로 복사 명령

검증일: 2026-11-14

## 구현

- 선택 항목 경로와 현재 폴더 경로를 텍스트 클립보드에 복사한다.
- 각 범위에 일반 경로와 따옴표로 감싼 경로 변형을 제공한다.
- 복수 선택은 한 줄에 한 경로를 기록하고 따옴표·역슬래시를 손실 없이 escape한다.
- 일반 설정에서 네 컨텍스트 메뉴 항목의 표시 여부를 한 설정으로 제어한다.
- 설정 저장·JSON archive 왕복·이전 archive 기본값을 지원한다.

## 검증

- Unicode·공백·따옴표·역슬래시 고정 벡터를 포함한 전체 Swift 테스트 166개가 통과했다.
- UI QA가 네 명령의 실제 메뉴 숨김 상태를 한국어/영어 × 라이트/다크 4개 조합에서 검증했다.
- 명령 팔레트는 같은 메뉴 action을 자동 인덱싱한다.

M6의 나머지 설정과 명령은 계속 검토 대기로 유지한다.
