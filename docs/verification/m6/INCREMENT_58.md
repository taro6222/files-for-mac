# M6 Increment 58 — 그리드 그룹 섹션

검증일: 2026-11-14

## 구현

- 그리드의 단일 섹션 가정을 제거하고 `FileGrouping` 결과를 `NSCollectionView` 다중 섹션으로 표시한다.
- 그룹화가 켜진 경우 이름·수정일·크기·종류의 지역화된 헤더를 표시하고, 그룹 없음에서는 기존과 같이 헤더가 없는 단일 섹션을 사용한다.
- 선택 복원, 더블 클릭 열기, 컨텍스트 메뉴 선택, 드래그 source와 drop target은 평면 row 번호가 아니라 section/item `IndexPath`로 항목 identity를 찾는다.
- 주 pane과 보조 pane 모두 각자의 탭 그룹 상태를 그리드에 전달한다.

## 자동 검증

- 10,000항목 fixture의 그리드에서 이름 그룹이 여러 섹션과 비어 있지 않은 헤더를 만들고 기존 선택 identity를 보존하는지 확인한다.
- 그룹 해제 후 기존 그리드 열기·드래그·보기 크기·선택 회귀 검사를 계속 수행한다.
- 상세·목록 섹션과 사용자 명령이 연결되기 전까지 관련 원본 명령은 완료 처리하지 않는다.
