# M6 Increment 66 — 컴팩트 오버레이 창 모드

검증일: 2026-11-14

## 구현

- 현재 브라우저 창을 화면 우상단의 460×620pt 이하 floating 보조 창으로 전환한다.
- 오버레이는 모든 Space와 전체 화면 보조 영역에 참여하며 최소 창 크기를 일시적으로 축소한다.
- 진입 전 프레임, 최소 크기, 창 레벨, collection behavior를 보존하고 종료 시 그대로 복원한다.
- 시작·종료·전환 명령의 활성·선택 상태를 현재 모드에 맞추고 명령 팔레트에 노출한다.

## 자동 검증

- 실제 창에서 floating 레벨, Space behavior, 크기 제한과 원래 프레임·최소 크기 복원을 확인한다.
- 3개 selector가 메뉴와 명령 팔레트에 등록되는지 확인한다.
- 전체 Swift Testing과 한국어/영어 × 밝게/어둡게 UI 4개 조합 및 패리티 감사를 실행한다.
