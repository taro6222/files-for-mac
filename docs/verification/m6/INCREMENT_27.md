# M6 Increment 27 — 파일 확장자 변경 경고

검증일: 2026-11-14

## 구현

- 단일 파일 이름 변경에서 확장자가 달라질 때 실제 변경 전에 두 번째 확인을 요구한다.
- 대소문자만 달라진 확장자와 폴더 이름은 경고하지 않는다.
- 일반 설정에서 경고를 끌 수 있으며 기본값은 원본과 같은 활성화 상태다.
- 설정은 영구 저장과 JSON archive에 포함하며 이전 archive에는 기본값 `true`를 적용한다.
- 배치 이름 변경은 기존 전체 계획 미리보기·충돌 검증을 유지하고 경고 sheet를 항목마다 반복하지 않는다.

## 검증

- 기본값·저장·중복 알림·archive 왕복과 확장자 비교 규칙을 Swift Testing으로 검증한다.
- UI QA는 일반 설정의 경고 옵션을 변경한 뒤 원래 상태로 복원한다.
- 실제 rename은 확인 응답 전에는 실행 함수에 진입하지 않는 sheet 흐름으로 분리한다.

M6 나머지 설정·명령 검토가 남아 전체 완료로 표시하지 않는다.
