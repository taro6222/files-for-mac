# M6 Increment 26 — 상위 이동 폴더 복원

검증일: 2026-11-14

## 구현

- 상위 폴더로 이동할 때 떠난 자식 폴더를 선택하고 화면에 표시하는 설정을 제공한다.
- 기본값은 원본과 같은 활성화 상태이며 일반 설정에서 끌 수 있다.
- 기본 pane과 보조 pane의 상세·그리드·목록·컬럼 렌더러가 같은 identity 선택을 사용한다.
- 설정은 영구 저장과 JSON archive에 포함하며 이전 archive에는 기본값 `true`를 적용한다.

## 검증

- 기본값·저장·중복 알림 방지·archive 왕복을 Swift Testing으로 검증한다.
- UI QA가 실제 중첩 fixture에서 상위 이동 후 떠난 폴더 identity와 상세 목록 선택을 확인한다.
- 일반 설정 창에서 옵션을 변경한 뒤 원래 상태로 복원한다.

M6 나머지 설정·명령 검토가 남아 전체 완료로 표시하지 않는다.
