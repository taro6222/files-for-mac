# M6 Increment 88 — 네이티브 탭 작업·진행 표시 경계

검증일: 2026-11-14

## 판정

- `ShowTabActions`는 Windows 탭 UI의 작업 버튼 노출 설정이다. FilesMac은 `NSWindow` 네이티브 탭 바에 닫기·추가·순서 변경·창 분리를 맡기고, 탭 생성·복제·닫기·이전/다음 명령은 메뉴와 단축키로 제공하므로 별도 복제 설정을 만들지 않는다.
- `StatusCenterVisibility`는 Windows 상태센터의 상시/작업 중 표시 정책이다. FilesMac은 영구 상태센터 대신 복사·이동·압축·이름 변경·삭제 작업별 AppKit 창에서 진행률·현재 항목·중단·결과를 표시한다.
- 상태센터 teaching tip, 백그라운드 실행 알림, 앱 종료 뒤 계속 실행 표시는 기존 결정대로 플랫폼 제외를 유지한다. 이번 판정은 실제 작업 진행 표시만 macOS 대체로 인정한다.

- 직전 코드 기준 Swift Testing 190개 통과 상태를 유지했다.
- 직전 코드 기준 한국어·영어 × 밝게·어둡게 실제 AppKit 4개 조합에서 각 196개 검사 통과 상태를 유지했다.
- 네이티브 탭 명령, 탭 그룹 복원, 다중 창 왕복, 복사·이동·압축 작업 창의 진행·중단 검증 기록을 재확인했다.
