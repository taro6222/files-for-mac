# M6 Increment 59 — 목록 그룹 행

검증일: 2026-11-14

## 구현

- 목록 보기의 평면 행을 그룹 헤더와 파일 항목을 구분하는 표시 행 모델로 전환했다.
- 헤더는 `NSTableView` group row로 표시하고 선택·열기·드래그 source·drop target에서 제외한다.
- 선택 저장·복원은 표시 행 번호가 아니라 파일 identity로 수행해 그룹의 생성·해제·방향 변경에도 유지된다.
- 주 pane과 보조 pane은 각 탭에 저장된 그룹 상태를 독립적으로 목록에 전달한다.

## 자동 검증

- 10,000항목 fixture 목록에서 종류 그룹이 여러 지역화 헤더를 만들고 기존 선택 identity를 보존하는지 확인한다.
- 그룹을 해제한 뒤 기존 목록 포커스·폴더 열기·보기 전환 회귀 검사를 계속 수행한다.
- 상세 보기와 사용자 명령이 연결되기 전까지 관련 원본 명령은 완료 처리하지 않는다.
