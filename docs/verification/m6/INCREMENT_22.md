# M6 Increment 22 — 시작 폴더 설정

검증일: 2026-11-14

## 구현

- 일반 설정 창에서 시작 폴더를 선택하거나 홈 시작으로 되돌릴 수 있다.
- 시작 위치는 표준화된 절대 경로로 저장하며 설정 JSON 내보내기·가져오기에 포함한다.
- 세션 복원이 성공하면 복원 세션을 우선하고, 복원할 세션이 없을 때만 시작 폴더를 적용한다.
- 저장된 경로가 사라졌거나 폴더가 아니면 빈 창의 홈으로 안전하게 복구한다.

## 검증

- 저장·복원·초기화와 손상된 상대 경로 복구를 Swift Testing으로 검증한다.
- 설정 archive 왕복에서 시작 위치를 보존하고 상대 경로 import를 거부한다.
- 일반 설정 창은 기존 UI 4조합 회귀 검증에 포함한다.
- `OpenSpecificPageOnStartup`과 경로 설정을 개별 대응표에서 판정한다.

M6의 나머지 설정·명령 검토가 남아 전체 완료로 표시하지 않는다.
