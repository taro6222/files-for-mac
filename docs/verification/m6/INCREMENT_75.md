# M6 Increment 75 — 홈·사이드바 위치 작업

검증일: 2026-11-14

## 구현

- 홈과 사이드바의 모든 실제 위치에 파일 URL 복사와 Terminal 열기 메뉴를 제공한다.
- 즐겨찾기가 아닌 위치는 사이드바에 고정하고 즐겨찾기 위치는 명시적으로 고정 해제할 수 있다.
- 위치 복사는 표준 macOS 파일 URL pasteboard를 사용해 Finder 및 다른 앱과 호환한다.
- Terminal 열기는 기존 다중 위치 실행 경로를 재사용해 시스템 Terminal 앱에 URL을 전달한다.

## 자동 검증

- 실제 홈·사이드바 메뉴에 복사·Terminal·고정·해제 selector가 노출되는지 확인한다.
- fixture 위치의 클립보드 URL, 고정, 해제를 실제 AppKit 환경에서 확인한다.
- 패리티 감사에서 홈·사이드바 관련 명령 6개의 구현 근거를 확인한다.
