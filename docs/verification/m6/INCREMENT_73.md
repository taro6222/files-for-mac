# M6 Increment 73 — Finder 태그 정렬·그룹화

검증일: 2026-11-14

## 구현

- 로컬 폴더와 검색 결과 열거 시 macOS `tagNames` resource value를 파일 모델에 보존한다.
- 태그 정렬은 전체 태그 문자열을 안정적으로 비교하고 태그 없는 항목을 먼저 배치한다.
- 태그 그룹화는 첫 Finder 태그를 그룹 키로 사용하고 태그 없는 항목을 별도 그룹으로 표시한다.
- 정렬·그룹 명령은 활성 pane에 적용되고 탭·분할 pane의 기존 상태 저장 경로로 보존된다.

## 자동 검증

- 태그 있음·없음·복수 태그 fixture의 결정적 정렬과 그룹 키를 단위 테스트한다.
- 실제 AppKit에서 두 명령의 모델 반영과 명령 팔레트 노출을 언어·테마 4개 조합으로 확인한다.
- 패리티 감사에서 GroupByTag와 SortByTag의 구현 근거를 확인한다.
