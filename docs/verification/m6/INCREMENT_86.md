# M6 Increment 86 — 빈 공간 이중 클릭 상위 이동

검증일: 2026-11-14

## 구현

- 일반 설정의 `빈 공간을 이중 클릭하여 상위 폴더로 이동`을 기본값 켜짐으로 제공하고 `UserDefaults`와 JSON archive에 저장한다.
- 상세·그리드·단일열 목록·계층형 컬럼 보기에서 이중 클릭 위치를 hit-test해 항목과 빈 배경을 구분한다.
- 항목 이중 클릭은 기존 파일 열기·폴더 탐색을 유지하고, 빈 배경 이중 클릭만 상위 폴더 이동으로 전달한다.
- 기본 pane과 보조 pane이 각각 자신의 현재 위치와 상위 이동 선택 복원 정책을 사용한다.
- 설정이 꺼져 있으면 빈 배경 이중 클릭은 탐색 상태를 변경하지 않는다.
