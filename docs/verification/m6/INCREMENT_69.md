# M6 Increment 69 — 홈 위젯 접힘 상태

검증일: 2026-11-14

## 구현

- 빠른 접근, 드라이브, 최근 위치 홈 섹션을 키보드 접근 가능한 disclosure 버튼으로 전환한다.
- 세 섹션의 펼침 상태를 표시 여부와 독립적으로 저장하고 다중 창에 즉시 반영한다.
- 설정 export/import에는 선택 필드로 포함해 이전 archive는 기존 기본값인 펼침 상태로 복구한다.
- 네트워크 위치는 장착 볼륨·위치에 통합하고 Finder 태그는 검색 명령으로 제공하므로 별도 홈 위젯을 만들지 않는다.

## 자동 검증

- 세 상태의 기본값, 중복 변경 알림 방지, 재생성 저장과 표시 설정 독립성을 단위 테스트한다.
- 실제 홈 UI에서 세 disclosure가 모두 접히고 다시 펼쳐지는지 언어·테마 4개 조합으로 확인한다.
- 패리티 감사에서 7개 설정의 구현 또는 macOS 대체 근거를 확인한다.
