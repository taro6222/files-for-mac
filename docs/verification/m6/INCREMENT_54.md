# M6 Increment 54 — 상세 열 너비 자동 맞춤

검증일: 2026-11-14

## 대응

- 고정 원본의 `AutoFitColumns`와 같이 항목이 있는 상세 보기에서만 명령을 활성화한다.
- 주 pane과 보조 pane의 보이는 열마다 헤더와 전체 항목의 표시 문자열을 측정해 가장 긴 값에 맞춘다.
- 이름 열은 파일 아이콘 공간을 별도로 확보하고, 모든 열은 기존 최소 폭과 720pt 상한을 적용해 비정상적으로 긴 파일명으로 UI가 무한히 넓어지는 것을 막는다.
- 메뉴·컨텍스트 메뉴·명령 팔레트는 동일 selector와 활성 조건을 사용한다.

## 자동 검증

- 10,000개 항목 상세 보기에서 열을 최소 폭으로 축소한 뒤 명령 실행 결과가 콘텐츠 폭으로 확장되고 최소·최대 경계를 지키는지 확인한다.
- 한국어/영어 × 밝게/어둡게 UI 4개 조합에서 명령 등록과 실제 열 너비 변경을 확인한다.

전체 Swift Testing 173개, AppKit UI 4개 조합 및 패리티 감사를 실행한다.
