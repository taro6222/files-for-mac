# M6 Increment 21 — 일반·Finder 태그 설정 화면

검증일: 2026-11-14

## 구현

- 네이티브 일반 설정 창에서 마지막 세션 계속 여부와 홈의 빠른 접근·드라이브·최근 위치 표시를 제어한다.
- 언어와 날짜 형식은 macOS 시스템 설정을 따른다는 정책을 창에 명시한다.
- 홈 섹션 setter는 동일 값 재설정 시 알림과 저장을 반복하지 않는다.
- Tags 화면은 기존 항목별 Finder 태그 편집과 태그 검색으로 대응한다.
- 앱 소유 전역 태그 이름·색상·순서 레지스트리는 공개 Finder API에 동등한 기능이 없어 플랫폼 차이로 기록한다.

## 검증

- Swift Testing은 홈 섹션 설정의 저장·복원과 동일 값 무알림을 검증한다.
- UI QA는 일반 설정 창을 열어 세 홈 위젯을 변경하고 원래 상태로 복원한다.
- 기존 Finder 태그 코어의 정규화·identity 재검증과 정보·검색 UI 검증 증거를 유지한다.
- 화면 인벤토리는 33개 모두 판정됐지만 설정·명령의 개별 검토가 남아 M6를 완료로 표시하지 않는다.
