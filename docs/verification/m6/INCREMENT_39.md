# M6 Increment 39 — macOS 심볼릭 링크 생성

검증일: 2026-11-14

## 구현

- 선택 항목 하나에 대해 현재 폴더에 macOS 심볼릭 링크를 만드는 컨텍스트 명령과 이름 입력 화면을 추가했다.
- 같은 폴더의 원본은 상대 경로로 연결해 폴더 이동 후에도 링크 관계가 유지되도록 했다.
- `symlinkat`의 배타적 생성 의미를 사용해 기존 파일·폴더·깨진 링크를 덮어쓰지 않는다.
- 이름 검증, 원본 존재 확인, 상위 폴더 identity 재확인 뒤 생성하며 성공 시 새 링크를 선택한다.

## 검증

- Swift 전체 테스트 168개 통과 및 FilesMac 빌드 통과.
- 파일 내용 왕복, Unicode 이름, 상대 target, 중복 대상 비덮어쓰기, 잘못된 이름과 사라진 원본 거부를 자동 검증했다.
- `CreateShortcut`만 구현으로 판정했다. 별도 파일 선택 대화상자 동작인 `CreateShortcutFromDialog`와 표시 설정은 계속 검토 대기다.

실제 APFS/exFAT/SMB 간 링크 의미 차이와 Finder alias 호환성은 별도 환경 검증 항목으로 남긴다.
