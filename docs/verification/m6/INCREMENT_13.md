# M6 Increment 13 — 탐색·외형 화면 대응

검증일: 2026-11-14

## 판정

- 홈, 메인 탐색 셸, 상세·목록·그리드·계층형 컬럼 보기의 사용자 목적을 현재 AppKit 구현과 연결했다.
- 외형 설정과 툴바 사용자 지정 화면을 실제 설정 저장 및 UI QA 증거에 연결했다.
- Windows XAML과 픽셀 동등하다고 주장하지 않으며, macOS 네이티브 AppKit 구조이므로 8개 모두 `platform-alternative`로 판정했다.

## 검증 증거

- 직전 `scripts/verify-ui.sh` 결과에서 한국어/영어 × 밝게/어둡게 4조합이 통과했다.
- 10,000개 상세 목록, 각 보기 포커스·선택 identity·폴더 열기·세션 복원, 최소 창, 다중 창, 설정 패널을 실제 창에서 검사한다.
- `scripts/audit-parity.py`: 화면 33행, macOS 대체 8, 개별 검토 대기 25; 전체 감사 유효.

## 남은 항목

- 속성 하위 화면, 나머지 설정 화면, shell/splash/release 화면은 개별 목적과 실제 구현을 계속 대조한다.
- Windows 실행 캡처와의 최종 시각 비교는 여전히 출시 게이트에 남아 있다.
