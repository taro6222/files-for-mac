# M6 Increment 72 — 선택 폴더·심볼릭 링크 붙여넣기

검증일: 2026-11-14

## 구현

- 선택 항목이 탐색 가능한 폴더 하나일 때 해당 폴더를 복사·잘라내기 클립보드의 대상으로 사용한다.
- 일반 복사 payload는 안전 복사·폴더 병합 흐름을, 잘라내기 payload는 안전 이동·Undo 흐름을 그대로 사용한다.
- 심볼릭 링크 붙여넣기는 클립보드의 각 로컬 파일 URL에 대해 상대 링크를 만들고 기존 항목을 절대 교체하지 않는다.
- 항목별 실패를 분리해 표시하고 성공 후 대상 pane만 다시 읽는다.

## 자동 검증

- 실제 AppKit 선택 폴더에서 선택 대상 붙여넣기 활성 조건을 확인한다.
- 두 붙여넣기 변형이 언어·테마 4개 조합의 명령 팔레트에 포함되는지 확인한다.
- 기존 코어 테스트에서 상대 심볼릭 링크, 충돌 비교체, 유효하지 않은 이름·누락 원본 차단을 확인한다.
