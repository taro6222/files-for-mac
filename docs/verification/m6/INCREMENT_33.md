# M6 Increment 33 — 사이드바 고정 메뉴

검증일: 2026-11-14

## 구현

- 컨텍스트 메뉴에서 선택한 단일 폴더를 사이드바 즐겨찾기에 추가하거나 제거한다.
- 선택이 없으면 현재 위치를 대상으로 하며, 파일 또는 복수 선택에는 명령을 비활성화한다.
- 일반 설정에서 메뉴 표시 여부를 변경하고 모든 열린 창에 즉시 적용한다.
- 표시 설정의 영구 저장·JSON archive 왕복·이전 archive 기본값을 지원한다.

## 검증

- 설정 기본값·영구 저장·중복 알림 방지와 archive 왕복을 전체 Swift 테스트 165개로 검증했다.
- UI QA가 메뉴 항목의 실제 표시 상태를 한국어/영어 × 라이트/다크 4개 조합에서 검증했다.
- 즐겨찾기 추가·제거는 기존 공유 `BrowserPreferences.toggleFavorite` 경로를 사용해 모든 창과 홈·사이드바에 동기 적용된다.

나머지 원본 컨텍스트 메뉴와 설정은 계속 검토 대기로 유지한다.
