# M6 Increment 50 — 앱 사용자 지정 배경

검증일: 2026-11-14

## 구현

- 이미지로 디코드 가능한 단일 일반 파일만 `앱 배경으로 설정` 명령에 허용한다.
- 원본 경로를 계속 참조하지 않고 100 MiB 상한, 심볼릭 링크 거부, 복사 전후 identity·크기·수정일 재검증을 거쳐 사용자 Application Support의 앱 관리 파일로 원자적으로 게시한다.
- 설정 경로는 UserDefaults와 버전 지정 설정 내보내기/가져오기에 포함하며 절대 경로만 허용한다. 파일이 없어지거나 손상되면 배경 설정을 안전하게 해제한다.
- aspect-fill 이미지 위에 시스템 동적 배경색을 반투명으로 덧씌워 텍스트 대비를 유지하고, macOS 투명도 감소 설정에서는 덮개를 더 불투명하게 한다.
- 상세·그리드·목록·컬럼 및 보조 pane의 스크롤 배경을 함께 전환한다. 열린 모든 창은 공유 설정 알림으로 즉시 갱신된다.
- 파일 메뉴·컨텍스트 메뉴·명령 팔레트에 설정/지우기 명령을 등록하고 외형 설정 창에도 현재 상태와 초기화 버튼을 제공한다.

## 자동 검증

- 설정 영속화 및 설정 아카이브 왕복, 상대 경로 거부.
- 실제 UI 캡처 PNG를 앱 관리 배경으로 설치·표시·초기화하고 비이미지 입력을 거부한다.
- 한국어/영어 × 밝게/어둡게에서 메뉴 등록, 열린 창 즉시 반영, 외형 설정 초기화를 확인한다.

전체 Swift Testing 170개, AppKit UI 4개 조합 및 패리티 감사를 실행한다.
