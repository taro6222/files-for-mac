# M6 Increment 64 — 네이티브 탭 명령

검증일: 2026-11-14

## 구현

- AppKit 탭 그룹에서 이전·다음 탭으로 이동한다.
- 현재 탭, 나머지 탭, 왼쪽 탭, 오른쪽 탭, 전체 탭 닫기를 네이티브 창 닫기 흐름에 연결한다.
- 닫히는 각 탭은 기존 `onClose` 경로를 지나므로 닫은 탭 복원용 workspace snapshot을 그대로 남긴다.
- 메뉴 활성 조건은 현재 탭 위치와 그룹 크기를 반영하며 모든 명령을 명령 팔레트에도 노출한다.

## 자동 검증

- 7개 selector가 메뉴와 명령 팔레트에 등록되는지 확인한다.
- 기존 다중 창·탭 생성/닫기 수명주기 및 workspace 저장 회귀를 UI 검증에서 함께 확인한다.
- 전체 Swift Testing과 한국어/영어 × 밝게/어둡게 UI 4개 조합 및 패리티 감사를 실행한다.
