# M6 Increment 56 — 일반 파일 그룹 코어

검증일: 2026-11-14

## 구현

- 이름, 수정일, 크기, 종류 그룹 필드와 오름·내림 방향, 수정일 연·월·일 단위를 직렬화 가능한 값으로 정의했다.
- 입력 배열 안의 항목 순서는 각 그룹 안에서 보존하고 그룹 키만 방향에 따라 정렬한다. 기존 정렬과 그룹화를 독립적으로 합성하기 위한 기반이다.
- 이름은 발음 구별 기호와 대소문자를 접어 첫 영숫자로 그룹화하고, 수정일 미확인·크기 미확인·종류 미확인을 별도 키로 보존한다.
- 크기는 폴더, 미확인, 빈 파일, 1MB 미만, 1GB 미만, 1GB 이상으로 나눠 경계가 안정적이다.

## 자동 검증

- 이름 정방향·역방향, 같은 이름 그룹 안의 원래 순서, 수정일 월 단위, 크기 경계, 종류 및 빈 입력을 확인한다.
- 이 증분은 UI 명령을 완료 처리하지 않는다. 후속 증분에서 탭 상태 저장과 상세·목록·그리드 섹션에 연결한다.
