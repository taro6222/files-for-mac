# M6 Increment 30 — 상세 열 표시 설정

검증일: 2026-11-14

## 구현

- 상세 보기의 수정일·종류·크기·Git 상태 열을 보기 옵션에서 각각 표시하거나 숨긴다.
- 원본 기본값과 같이 수정일·종류·크기는 표시하고 Git 상태는 숨긴다.
- 공유 환경 설정 변경을 모든 브라우저 창에 즉시 적용한다.
- 설정 JSON archive에 네 열의 표시 상태를 포함하며 이전 archive에는 원본 기본값을 적용한다.

## 검증

- 기본값·영구 저장·중복 알림 방지와 archive 왕복을 단위 테스트한다.
- UI QA가 네 열의 숨김·표시 조합을 실제 `NSTableColumn` 상태로 확인한다.
- 전체 Swift 테스트 164개와 한국어/영어 × 라이트/다크 UI 조합을 실행한다.

생성일 열과 추가 Git metadata 열 등 아직 제공하지 않는 원본 열은 계속 검토 대기로 유지한다.
