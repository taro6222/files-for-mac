# M6 Increment 53 — 선택 토글·Finder 태그 명령

검증일: 2026-11-14

## 대응

- `ToggleSelect`는 Windows의 체크박스와 독립된 focus item 모델 대신 macOS 상세·그리드·목록·컬럼 선택 모델에서 현재 포커스된 선택 항목을 토글한다. 주/보조 pane 모두 지원한다.
- `OpenAllTagged`는 앱 소유 태그 그룹 전체를 즉시 여는 대신, 선택 항목의 첫 Finder 태그를 현재 위치 하위 범위의 기존 검색 창에 적용한다. 사용자는 결과를 검토한 뒤 파일 또는 폴더를 열 수 있다.
- `RemoveTags`는 선택한 각 항목의 Finder 태그 snapshot과 file identity를 읽고, identity가 그대로일 때만 빈 태그 배열로 교체한다. 일부 실패가 나머지 처리를 막지 않으며 완료 후 활성 pane을 갱신한다.
- 세 명령은 파일 메뉴·컨텍스트 메뉴·명령 팔레트에 등록한다.

## 자동 검증

- Finder 태그 설정·중복 정규화·빈 배열 제거·외부 교체 identity 거부.
- 실제 AppKit 정보 창에서 태그를 설정한 뒤 같은 태그 검색 결과, 일괄 제거, 포커스 선택 토글을 확인한다.
- 한국어/영어 × 밝게/어둡게 UI 4개 조합에서 명령 등록과 동작을 확인한다.

전체 Swift Testing 173개, AppKit UI 4개 조합 및 패리티 감사를 실행한다.
