# M6 Increment 90 — 검색 결과의 상위 폴더 열기

검증일: 2026-11-14

- 검색 결과의 컨텍스트 메뉴와 선택 항목용 버튼에서 상위 폴더를 열고 결과 항목을 선택한다. 검색을 시작한 보조 pane이 닫혔으면 기본 pane을 사용한다.
- 검색 결과를 가리던 현재 폴더 이름 필터를 지운다. 숨김 검색 결과에는 해당 pane의 숨김 항목 표시를 켠다. 상세·목록·그리드에서는 선택 항목으로 스크롤한다.
- 다른 검색 범위를 열면 이전 범위의 결과를 초기화한다. 일반 검색과 Finder 태그 검색의 결과 열기 콜백을 창을 표시할 때 각각 설정한다.
- 원본은 검색 결과에 선택 항목이 있을 때 해당 상위 폴더로 이동하면서 항목의 선택을 요청한다. [고정 원본 코드](https://github.com/files-community/Files/blob/99951c66928c4da714da8b1dd46039421182cbab/src/Files.App/Actions/FileSystem/OpenItemAction.cs#L105)
