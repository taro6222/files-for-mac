# M6 Increment 63 — 생성일 상세 열

검증일: 2026-11-14

## 구현

- 주 pane과 보조 pane 상세 보기에 생성일 열을 추가하고 실제 `FileItem.created`를 지역화된 날짜·시간으로 표시한다.
- 원본 기본값과 같이 생성일 열은 기본적으로 숨기고 보기 옵션에서 즉시 전환한다.
- 주 상세 열의 기본 너비를 200pt로 두고 AppKit 열 autosave로 사용자가 조절한 너비와 순서를 복원한다.
- 표시 설정은 다중 창에 동기 반영되며 설정 내보내기·가져오기와 이전 archive 기본값 복구를 지원한다.

## 자동 검증

- 생성일 열 설정의 기본값, 중복 알림 방지, 재시작 저장과 archive 왕복을 단위 테스트한다.
- 실제 UI에서 생성일 열 표시, 유효 너비, 다른 열과 독립적인 가시성을 확인한다.
- 전체 Swift Testing과 한국어/영어 × 밝게/어둡게 UI 4개 조합 및 패리티 감사를 실행한다.
