# M6 Increment 31 — 네이티브 스크롤 정책

검증일: 2026-11-14

## 판정

- 원본 `EnableSmoothScrolling`은 앱 내부에서 스크롤 애니메이션 사용 여부를 선택한다.
- FilesMac의 상세·그리드·목록·컬럼 보기는 모두 AppKit `NSScrollView`를 사용한다.
- 관성, 트랙패드·마우스 입력, 동작 줄이기 등은 macOS 시스템과 AppKit이 결정하므로 별도 앱 토글을 추가하지 않는다.

## 검증

- 상세 목록 10,000개, 100단계 스크롤, 마지막 행 도달 검증이 기존 UI QA 4개 조합에서 통과했다.
- 패리티 감사에서 해당 설정을 근거가 있는 `platform-alternative`로 집계한다.

나머지 미판정 설정과 명령은 계속 검토 대기로 유지한다.
