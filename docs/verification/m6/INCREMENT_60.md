# M6 Increment 60 — 상세 그룹 행

검증일: 2026-11-14

## 구현

- 주 pane과 보조 pane 상세 보기의 평면 행을 공통 `DetailDisplayRow` 기반 그룹 헤더·파일 행으로 전환했다.
- 헤더는 이름 열의 `NSTableView` group row로 표시하며 선택, 더블 클릭, drag source, drop target에서 제외한다.
- 선택 저장·복원, 선택 반전, 포커스 선택 토글, Git 열 갱신과 외부 변경 후 재렌더링은 파일 identity를 표시 행으로 다시 매핑한다.
- 컨텍스트 메뉴와 파일 열기는 선택된 표시 행에서 실제 `FileItem`을 확인한 뒤 실행한다.

## 자동 검증

- 10,000항목 상세 보기에서 크기 그룹이 여러 지역화 헤더를 만들고 기존 선택 identity를 보존하는지 확인한다.
- 그룹 해제 뒤 열 자동 맞춤, 검색, 정보 창, 정렬, 히스토리 및 선택 명령의 기존 회귀 검사를 계속 수행한다.
- 사용자 그룹 명령이 연결되기 전까지 관련 원본 명령은 완료 처리하지 않는다.
