# M6 Increment 89 — 현재 폴더 이름 필터

검증일: 2026-11-14

- 편집 메뉴, 툴바의 보기 옵션, 명령 팔레트 및 ⇧⌘F로 필터 입력란을 연다. 열 때 활성 pane의 필터 입력란에 초점을 둔다.
- 현재 폴더의 항목 이름을 대소문자와 발음 구별 기호를 무시해 부분 일치시킨다. 네 가지 로컬 보기에서 같은 목록을 사용한다.
- 필터 표시 설정은 창 간에 공유하고 설정 내보내기에 포함한다. 검색어는 pane별로 유지하며, 같은 위치의 새로고침 후 유지하고 다른 위치로 이동하거나 입력란을 닫으면 초기화한다. 계층형 컬럼에서 펼친 자식 폴더는 그대로 탐색할 수 있다.
- 원본 동작은 [Files v4.0 릴리스 노트](https://www.files.community/blog/posts/v4-0-0)의 현재 폴더 이름 필터를 기준으로 확인했다.

## 검증

- Swift Testing 191개 통과. 새로고침, 폴더 이동, 결과에서 빠진 항목의 선택 해제 및 설정 내보내기·가져오기를 확인했다.
- 한국어·영어 × 밝게·어둡게 AppKit 네 조합에서 각각 199개 검사 통과. 입력 초점, 10,000개 항목의 이름 필터, 분할 pane별 검색어 및 닫을 때 전체 목록 복원을 확인했다.
- 패리티 감사 통과. 검토 대기 항목은 명령 21개와 설정 22개다.
