# M6 Increment 61 — 일반 그룹 명령

검증일: 2026-11-14

## 구현

- 그룹 없음, 이름, 수정일, 크기, 종류 명령을 주 pane과 보조 pane의 활성 모델에 연결한다.
- 수정일 연·월·일 직접 명령과 현재 수정일 그룹의 연·월 단위 명령, 날짜 단위 순환을 제공한다.
- 그룹 오름차순·내림차순·방향 전환을 정렬 방향과 독립적으로 저장한다.
- 메뉴의 선택 상태와 활성 조건은 현재 그룹 필드·방향·날짜 단위를 반영하며 같은 selector가 명령 팔레트에 등록된다.
- 컬럼 보기는 macOS 계층 탐색 구조를 유지하지만 그룹 상태는 탭에 보존되어 상세·목록·그리드로 전환하면 즉시 적용된다.

## 자동 검증

- 14개 selector가 명령 팔레트에 모두 등록되는지 확인한다.
- 10,000항목 상세 보기에서 크기 그룹 오름차순과 내림차순 헤더 순서가 정확히 반전되는지 확인한다.
- 수정일 월 단위와 내림차순 상태가 `TabSnapshot`에 함께 저장되는지 확인한다.
- 전체 Swift Testing과 한국어/영어 × 밝게/어둡게 UI 4개 조합 및 패리티 감사를 실행한다.
