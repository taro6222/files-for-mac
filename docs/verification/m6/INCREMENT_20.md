# M6 Increment 20 — 설정 내보내기·가져오기

검증일: 2026-11-14

## 구현

- 탐색·외형·홈·툴바·개발 앱·폴더별 보기 설정을 버전이 지정된 JSON으로 내보낸다.
- 가져오기는 버전, enum 전체 집합, 중복, 필수 툴바 항목, 절대 경로를 먼저 검증한다.
- 전체 검증이 끝난 뒤에만 설정과 영구 저장소를 변경하므로 실패 시 기존 설정을 보존한다.
- AppKit 고급 설정 창에서 네이티브 저장·열기 패널로 JSON 파일을 선택한다.
- Windows 시작 프로그램, system tray, Explorer 대체, thumbnail cache 항목은 macOS 플랫폼 차이로 기록한다.

## 검증

- 설정 왕복 복원과 잘못된 값 입력의 무변경 동작을 Swift Testing으로 검증한다.
- UI QA는 고급 설정 창을 실제로 열고 한국어/영어 × 밝게/어둡게 조합에서 표시 여부와 렌더링을 확인한다.
- 인벤토리 감사로 Advanced 화면만 근거가 있는 `platform-alternative`로 전환한다.

## 남은 화면

- General·Tags 설정 화면을 원본의 적용 가능한 목적과 대조한다.
