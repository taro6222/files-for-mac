# M6 Increment 103 — 템플릿으로 파일 생성

- 새 항목 창에서 기존 일반 파일을 선택하고 저장할 이름을 입력한다. Windows 등록 템플릿 목록 대신 macOS 파일 선택 창을 사용한다.
- 기존 복사 엔진으로 원본 내용과 메타데이터를 복사한다. 템플릿과 대상 폴더 identity를 확인하고, 충돌 시 기존 항목을 보존한다. 생성된 파일은 복사 실행 취소 기록에 포함된다.
- Swift Testing 199개 통과. 이름 지정, 원본 내용 보존, 대상 충돌, 심볼릭 링크 거부를 확인했다.
- AppKit 파일 작업 검증은 한국어·영어 × 밝게·어둡게 각 31개 통과했다. 실제 이름 입력 확인 창에서 생성한 파일과 원본의 내용을 확인했다.
