# M6 Increment 102 — 이동 재실행

- 편집 메뉴, 명령 팔레트, ⇧⌘Z에서 같은 앱 세션의 최근 이동 실행 취소를 재실행한다.
- 원래 이름과 대상 폴더를 사용한다. 대상 폴더 identity, 되돌린 원본 identity와 내용 스냅샷을 검사하고 기존 항목과 충돌하면 건너뛴다.
- 정상 재실행은 기존 이동 엔진이 저널을 작성하고 새 실행 취소 기록을 생성한다. 새 복사·이동이 완료되면 이전 재실행은 비활성화된다.
- 덮어쓰기 이동, 일부만 실행 취소된 이동, 재시작을 거친 이동 및 복사·이름 변경·휴지통 재실행은 이 구현 범위 밖이다. 전체 Windows 작업 이력과의 차이로 추적한다. [원본 재실행 코드](https://github.com/files-community/Files/blob/99951c66928c4da714da8b1dd46039421182cbab/src/Files.App/Utils/Storage/History/StorageHistoryOperations.cs)

## 검증

- Swift Testing 198개 통과. 대상 충돌과 변경 원본 보존, 정상 재실행과 재실행 후 다시 취소를 확인했다.
- 한국어·영어 × 밝게·어둡게 AppKit 파일 작업 검증 각 30개 통과. 실제 확인 창을 통해 이동 실행 취소와 재실행을 차례로 실행하고 대상 파일 내용을 확인했다.
