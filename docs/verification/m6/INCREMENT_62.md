# M6 Increment 62 — 생성일 정렬·그룹화

검증일: 2026-11-14

## 구현

- `FileItem`에 선택적 생성일을 추가하고 로컬 열거, 로컬 검색, Spotlight 검색에서 macOS `creationDate`를 전달한다.
- 생성일 정렬을 기존 자연 정렬·폴더 배치·방향 정책과 같은 경로로 처리한다.
- 생성일 그룹과 연·월·일 직접 명령을 주·보조 pane, 메뉴, 명령 팔레트에 연결한다.
- 생성일을 제공하지 않는 원격·압축 공급자는 값을 추정하지 않고 알 수 없음 그룹으로 유지한다.

## 자동 검증

- 생성일 일 단위 버킷이 결정적으로 정렬되고 누락 값이 알 수 없음으로 분리되는지 단위 테스트한다.
- 10,000항목 실제 로컬 fixture에서 생성일 정렬과 그룹 명령·상태를 확인한다.
- 전체 Swift Testing과 한국어/영어 × 밝게/어둡게 UI 4개 조합 및 패리티 감사를 실행한다.
