# M6 Increment 92 — Git 마지막 커밋 열

검증일: 2026-11-14

- 기본 pane 상세 보기의 보기 옵션에서 마지막 커밋 날짜, 제목, 작성자, SHA를 각각 표시한다. 표시 설정은 기본값이 꺼짐이며 설정 아카이브에 포함한다. 열 너비와 순서는 기존 AppKit 상세 열 자동 저장을 사용한다.
- Git HEAD가 추적하는 파일을 대상으로 리터럴 경로 조회를 수행한다. 화면 표시 요청을 순차 처리하고 같은 목록에서 조회한 경로를 재사용한다. 탐색 또는 새로고침으로 목록이 바뀌면 기존 결과를 폐기한다.
- 현재 파일 경로 기준 이력을 표시한다. SHA 열에는 앞 12자리를 표시하고 도구 설명에는 전체 해시를 표시한다. 보조 pane의 Git 열은 후속 작업이다.
- [고정 원본의 파일별 커밋 조회](https://github.com/files-community/Files/blob/99951c66928c4da714da8b1dd46039421182cbab/src/Files.App/Services/Git/LibGit2Service.cs#L466)를 확인했다. macOS판은 시스템 Git의 경로별 로그를 사용하므로 병합 커밋에서 이력 선택이 달라질 수 있다.
