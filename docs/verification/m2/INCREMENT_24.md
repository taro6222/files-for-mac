# M2 스물네 번째 개발 단위 검증 — 폴더 병합 계획

검증일: 2026-11-13

## 구현 범위

- 소스·대상이 모두 폴더인 경우 하위 트리를 읽기 전용으로 순회한다.
- 항목을 `누락 항목 복사`, `기존 폴더 재귀 병합`, `파일 충돌`, `파일/폴더 유형 충돌`로 구분한다.
- 심볼릭 링크는 따라가지 않고 파일형 항목으로 취급한다.
- 실행기가 저장·표시할 수 있도록 상대 경로와 소스·대상 URL을 포함한 Codable 계획을 만든다.

## 자동 검증

전체 Swift 테스트와 `FilesMac` 빌드 결과: 71개 테스트 통과.

새 fixture는 중첩 폴더의 누락 파일, 같은 이름의 파일 충돌, 폴더 대 파일 유형 충돌을 한 계획에서 구분하고 계획 후 대상 내용이 전혀 바뀌지 않았음을 검증한다.

## 현재 경계

- 이 개발 단위는 충돌 계획만 생성하며 실제 병합을 실행하지 않는다.
- 실행 시 각 대상의 존재·종류를 다시 확인하고, 누락 항목만 원자적으로 게시해야 한다.
- 병합으로 기존 폴더에 추가된 결과를 안전하게 실행 취소하려면 생성된 각 하위 항목의 identity와 snapshot을 별도로 저널링해야 한다.
- 폴더 병합 UI와 실제 APFS/exFAT/SMB 검증은 다음 단위에 남아 있다.
