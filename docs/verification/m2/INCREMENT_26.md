# M2 스물여섯 번째 개발 단위 검증 — 폴더 병합 UI

검증일: 2026-11-13

## 구현 범위

- 단일 선택 소스와 대상의 같은 이름 항목이 모두 실제 디렉터리일 때만 `폴더 병합` 정책을 표시한다.
- 일반 `양쪽 유지`, `건너뛰기`, `취소`와 병합을 별도 버튼으로 구분한다.
- 병합 창에서 원본·대상, 계획된 추가/충돌 수, 상대 경로별 계획과 실행 결과를 표시한다.
- 사용자가 취소하면 실행기에 safe-point 취소를 전달하고 작업 중 창 닫기를 막는다.
- 병합 완료 뒤 작업 대상 pane을 다시 읽는다.

## 검증

- 전체 Swift Testing 73개 통과.
- `FilesMac` 앱 빌드 통과. 새 병합 창과 복사 대화상자 응답 분기까지 컴파일·링크했다.

## 남은 항목

- 다중 선택에서 여러 충돌 폴더를 한 작업으로 병합하는 조정 계층은 아직 없다.
- AppKit 실제 창에서 버튼 순서, 키보드 포커스, 취소·결과 표시를 수동 검증해야 한다.
- 실제 외장·네트워크 볼륨 검증 전이므로 M2 전체 완료로 표시하지 않는다.
