# M2 아홉 번째 개발 단위: 교차 볼륨 이동

작성일: 2026-09-10

## 구현 내용

- 소스 항목과 대상 폴더의 파일 시스템 장치 번호로 동일/교차 볼륨 경로를 구분한다.
- 교차 볼륨 이동은 다음 순서로 처리한다.
  1. 대상 폴더 안에 작업별 임시 디렉터리를 생성한다.
  2. 원본의 파일 내용, 디렉터리 구조, 권한, 심볼릭 링크를 SHA-256 기반 스냅샷으로 기록한다.
  3. 임시 위치에 복사하고 복사본과 원본을 모두 다시 검증한다.
  4. descriptor 기준 `RENAME_EXCL`로 최종 이름을 원자적으로 공개한다.
  5. 원본을 다시 검증한 후 삭제한다.
- 검증 실패나 이름 경쟁이 발생하면 원본을 삭제하지 않고 항목별 실패·충돌 상태를 남긴다.
- 최종 공개 후 원본 삭제가 실패하면 변경되지 않은 대상 복사본을 회수해 원본과 대상의 중복 잔존을 줄인다.
- 교차 볼륨 교체는 기존 대상을 복구할 백업이 필요하므로 현재 명시적으로 거부한다.

## 검증

- `SWIFT_TMPDIR=/tmp swift test`
- Swift Testing 54개 통과, `FilesMac` 앱 타깃 빌드 통과
- 강제 교차 볼륨 경로로 다음을 검증했다.
  - 폴더 내부 파일 내용과 심볼릭 링크 보존
  - 검증 완료 후 원본 삭제와 임시 디렉터리 정리
  - 대상 충돌 시 원본과 기존 대상 모두 보존
  - 교체 요청 시 백업 미지원 오류와 양쪽 항목 보존
