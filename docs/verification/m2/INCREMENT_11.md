# M2 열한 번째 개발 단위: 이동 취소와 진행 표시

작성일: 2026-09-10

## 구현 내용

- 이동 엔진에 스레드 안전한 취소 신호와 단계별 진행 이벤트를 추가했다.
- 이동 창에 항목 진행 막대와 다음 실시간 단계를 표시한다.
  - 원본 확인
  - 기존 항목 백업
  - 교차 볼륨 복사
  - 내용 검증
  - 결과 확정
  - 원본 정리
- 이동 창의 하단 버튼은 실행 중 `취소`, 종료 후 `닫기`로 동작한다.
- 취소 요청 후 새 항목은 시작하지 않고 `cancelled`로 기록한다.
- 교차 볼륨 복사·검증·결과 공개·원본 삭제 사이의 안전 지점에서 취소를 검사한다.
- 교체 백업 후 취소되면 대상이 아직 공개되지 않은 경우 백업을 기존 이름으로 복원한다.
- 앱 종료 경고에 복사와 이동 작업 창에서 취소할 수 있음을 반영했다.

## 검증

- `SWIFT_TMPDIR=/tmp swift test`
- Swift Testing 56개 통과, `FilesMac` 앱 타깃 빌드 통과
- 교차 볼륨 복사 완료 후 검증 단계에서 취소 신호를 주입했다.
  - 작업과 항목 상태가 `cancelled`로 종료
  - 원본 파일 유지
  - 최종 대상 미공개
  - `.files-move-*` 임시 디렉터리 정리
- 기존 복사 취소·이동 실행 취소·교체 백업 회귀 테스트 통과

## 제한 및 다음 단계

- Foundation의 단일 `copyItem` 호출 중에는 즉시 중단되지 않고 호출이 반환되는 안전 지점에서 취소된다. UI에 이 동작을 명시한다.
- 동일 볼륨의 원자적 이름 변경은 매우 짧은 단일 시스템 호출이므로 호출 도중 취소할 수 없다.
- 다음 개발 단위는 배치 이름 변경 계획, 충돌 사전 검사, 항목별 결과 UI다.
