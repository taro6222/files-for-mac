# M2 스물다섯 번째 개발 단위 검증 — 폴더 병합 실행

검증일: 2026-11-13

## 구현 범위

- 계획 당시 대상 루트, 각 대상 부모, 기존 충돌 항목의 파일 시스템 identity를 실행 시 재검증한다.
- 누락 항목을 같은 대상 부모의 임시 경로에 복사하고 소스·임시 결과의 전체 snapshot을 검증한다.
- `RENAME_EXCL`로 누락 이름에만 원자적으로 게시해 계획 이후 나타난 외부 항목을 덮어쓰지 않는다.
- 파일 충돌과 파일/폴더 유형 충돌은 변경 없이 보존하고 항목별 상태를 병합 JSON 저널에 기록한다.
- 병합에서 새로 만든 각 하위 항목만 identity·snapshot과 함께 복사 Undo 저널에 등록한다.

## 자동 검증

전체 Swift 테스트와 `FilesMac` 빌드 결과: 73개 테스트 통과.

추가 fixture는 기존 파일을 보존하면서 누락 파일만 게시하고 안전 Undo로 그 파일만 제거하는 흐름, 계획 이후 외부 파일이 나타난 경쟁 조건에서 해당 파일을 보존하는 흐름을 검증한다.

## 남은 항목

- 병합 정책 선택, 계획 요약, 항목별 결과를 AppKit 복사 흐름에 연결해야 한다.
- 취소는 파일 단위 safe point이며 대형 단일 파일의 즉시 중단은 제공하지 않는다.
- 실제 APFS/exFAT/SMB에서 identity와 원자 게시 동작을 별도 검증해야 하므로 M2 완료로 표시하지 않는다.
