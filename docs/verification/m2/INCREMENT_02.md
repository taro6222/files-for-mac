# M2 두 번째 개발 단위: 양쪽 유지와 파일 클립보드

날짜: 2026-09-10. M2 진행 중.

## 사용 흐름

파일 목록에 초점이 있을 때 ⌘C는 선택 파일 URL을 시스템 클립보드에 기록하고, ⌘V는 현재 폴더에 복사한다. 경로 입력 등 텍스트 필드의 기본 복사/붙여넣기는 유지한다. 홈·읽기 중·복사 작업 진행 중·파일 URL 없는 클립보드에서는 파일 붙여넣기를 비활성화한다.

⌘V 또는 기존 ⇧⌘C 대상 선택 뒤, 이번 작업의 충돌 정책을 **양쪽 유지 / 건너뛰기 / 취소**로 선택한다. 충돌이 실제 있는지 전수 사전 탐색하는 화면이 아니라 작업 시작 전 정책 선택이다. 파일·폴더를 덮어쓰거나 병합하지 않는다.

양쪽 유지는 `name.txt → name (2).txt → name (3).txt` 순서로 시도한다. 폴더 이름은 전체 이름 뒤에 번호를 붙인다. 최종 확정마다 `RENAME_EXCL`을 사용하여 외부 프로세스가 같은 이름을 먼저 만들었어도 다음 번호를 시도한다. 실제 대상 경로를 저널과 결과 화면에 기록한다. 번호는 최대 10,001까지 시도하며 이름 길이 등 파일 시스템 오류는 해당 항목 실패로 표시한다.

## 검증

- 기존 이름과 (2) 존재 시 (3) 생성, 기존 내용 유지, 저널의 실제 대상 일치.

- 같은 폴더 안에서 dotfile 복제, 원본·출력 내용 일치.
- 기존 건너뛰기/취소/내용 검증 회귀 테스트 통과.

- 실제 AppKit: ⌘C·⌘V → 양쪽 유지 → `example (2).txt`, 완료 1/1 확인.

## 남은 범위

Finder와의 파일 클립보드는 표준 NSURL pasteboard 형식을 사용하지만 실제 Finder 왕복 검증은 아직 하지 않았다. file promise·드래그·이동 붙여넣기는 미구현이다. 긴 파일명 자동 축약·패키지 확장자를 보존하는 복제 이름 정책도 후속 보완이다.

교체/병합/항목별 충돌 질문, SQLite 저널·강제 종료 복구, 이동·삭제·이름 변경·undo·탭·분할은 여전히 남아 있다. 첫 단위의 메타데이터·대용량 취소·내구성 제한은 그대로 적용한다. 다음 구현은 새 폴더·단일 이름 변경 등 실제 파일 관리 명령으로 이어간다.
