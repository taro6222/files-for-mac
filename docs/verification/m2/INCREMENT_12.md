# M2 열두 번째 개발 단위: 배치 이름 변경

작성일: 2026-11-13

## 구현 내용

- 다중 선택의 파일 메뉴와 문맥 메뉴에 `일괄 이름 변경…`을 추가했다.
- 찾기/바꾸기 입력으로 전체 새 이름 계획을 생성하고 결과 창에서 원본→대상 이름을 표시한다.
- 파일 변경 전에 전체 계획을 검사한다.
  - 금지 이름과 경로 문자
  - 계획 내부 중복 이름
  - 선택하지 않은 기존 항목 및 깨진 심볼릭 링크와의 충돌
  - 사라진 원본
- 하나라도 사전 검사에 실패하면 전체 계획을 `rejected`로 기록하고 파일을 변경하지 않는다.
- 적용 가능한 계획은 고유 임시 이름을 거치는 2단계 변경으로 처리해 `A↔B` 같은 순환 교환을 지원한다.
- 항목별 `completed/unchanged/conflict/invalid/notFound/failed` 상태와 JSON 저널을 기록한다.
- 번호 패턴은 확장자를 보존하는 코어 API로 추가했다. 번호 패턴 선택 UI와 정규식은 후속 범위다.

## 검증

- `DEVELOPER_DIR=/Library/Developer/CommandLineTools SWIFT_TMPDIR=/tmp swift test`
- Swift Testing 59개 통과, `FilesMac` 앱 타깃 빌드 통과
- 순환 이름 교환 후 두 파일 내용과 이름이 정확히 교환됨
- 계획 내부 중복과 선택 외 기존 대상 충돌 시 원본·기존 대상 무변경
- 찾기/바꾸기와 번호 패턴의 확장자 보존 확인

## 환경 메모와 다음 단계

- 전체 Xcode 라이선스는 관리자 승인 전이라 Command Line Tools 경로로 검증했다. 앱과 테스트 타깃은 빌드됐지만 Xcode IDE 기반 빌드 재검증은 남아 있다.
- 다음 단계는 번호 패턴 UI와 정규식 미리보기 또는 탭/분할 탐색 기반이다.
