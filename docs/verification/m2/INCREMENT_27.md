# M2 스물일곱 번째 개발 단위 검증 — 다중 선택 폴더 병합

검증일: 2026-11-13

## 구현 범위

- 다중 선택 중 하나 이상이 기존 대상 폴더와 충돌하면 폴더 병합 정책을 제공한다.
- 대상에 없는 최상위 항목은 일반 안전 복사, 폴더/폴더는 재귀 병합, 파일 또는 유형 충돌은 보존으로 처리한다.
- 내부 복사·병합 엔진의 개별 Undo 생성을 억제하고 배치가 만든 모든 결과를 하나의 Undo 레코드로 통합한다.
- 결과 창에서 소스별 상태, 추가 항목 수, 보존한 충돌 수와 오류를 표시한다.
- 배치 시작 전 저널을 만들며 항목별 결과를 계속 저장한다.

## 자동 검증

전체 Swift Testing 74개 및 `FilesMac` 빌드 통과.

새 fixture는 한 작업에 누락 파일, 기존 폴더 병합, 파일 충돌을 함께 넣어 대상 충돌 내용이 보존되는지, 두 생성 결과가 같은 operation ID의 Undo에 포함되는지, Undo 뒤 기존 폴더와 기존 파일이 남는지 검증한다.

## 남은 항목

- 실제 AppKit에서 다중 선택→정책 선택→취소/완료→Undo 전체 흐름을 키보드와 마우스로 검증해야 한다.
- 실패 주입, 외장 APFS/exFAT, SMB에서 원자 게시와 취소 동작 검증이 남아 있어 M2 전체 완료로 표시하지 않는다.
