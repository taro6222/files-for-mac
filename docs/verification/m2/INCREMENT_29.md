# M2 스물아홉 번째 개발 단위 검증 — 취소·저널 장애 주입

검증일: 2026-11-13

## 구현 범위

- 다중 병합 배치가 각 최상위 항목 완료 뒤 index, 전체 수, 소스, 상태를 진행 콜백으로 보낸다.
- 병합 작업 창은 이 신호로 결정적 진행 막대와 현재 항목 상태를 표시한다.
- 취소 요청 이후 아직 시작하지 않은 항목을 `cancelled`로 기록하고 이미 완료된 결과는 통합 Undo에 유지한다.
- 진행 작업의 명시적 capture를 사용해 작업 창 수명과 약한 UI 진행 콜백의 의도를 분리했다.

## 장애 주입 결과

- 첫 항목 완료 진행 신호에서 취소: 첫 파일만 게시되고 두 번째 파일은 생성되지 않으며 상태가 `cancelled`, Undo에는 첫 결과 하나만 포함됨.
- 저널 경로를 디렉터리 대신 파일로 구성: 배치가 `failed`와 journal error를 반환하고 대상 폴더에는 어떤 항목도 생성하지 않음.
- 전체 Swift Testing 76개 통과, `FilesMac` 빌드 통과.

## 남은 환경 검증

- 외장 APFS, 대소문자 구분 APFS, exFAT, SMB에서 원자 게시·교차 볼륨 이동·취소를 확인해야 한다.
- 시스템 Trash를 사용하는 이동·복원 UI는 별도 실제 사용자 승인 환경에서 검증해야 한다.
