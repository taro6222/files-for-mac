# M2 열세 번째 개발 단위: 배치 이름 변경 패턴 UI

작성일: 2026-11-13

## 구현 내용

- 일괄 이름 변경 입력 화면에서 세 가지 방식을 선택할 수 있다.
  - 찾기 및 바꾸기
  - 기본 이름과 시작 번호를 사용하는 번호 매기기
  - 캡처 그룹 치환을 지원하는 정규식
- 번호 매기기는 파일별 기존 확장자를 보존하고 0 이상의 시작 번호를 받는다.
- 정규식은 `NSRegularExpression`으로 컴파일하며 잘못된 패턴은 파일 작업 전에 안내한다.
- 입력 다음 단계에서 최대 20개의 `기존 이름 → 새 이름`과 나머지 항목 수를 표시한다.
- 사용자가 미리보기 확인 화면에서 다시 승인해야 실제 배치 변경 창을 시작한다.
- 실제 실행 시에는 기존 전체 계획 충돌 검사를 다시 수행하므로 미리보기 이후 외부 변경도 덮어쓰지 않는다.

## 검증

- Swift 패키지 캐시를 Command Line Tools 도구체인으로 정리한 뒤 전체 테스트 실행
- `DEVELOPER_DIR=/Library/Developer/CommandLineTools SWIFT_TMPDIR=/tmp swift test`
- Swift Testing 60개 통과, `FilesMac` 앱 타깃 빌드 통과
- `IMG_0042.jpg` 패턴에서 캡처 그룹을 사용한 `Photo-0042.jpg` 치환 확인
- 닫히지 않은 괄호 정규식이 오류로 거부되는지 확인
- 기존 순환 교환·중복·외부 충돌·번호 확장자 보존 회귀 테스트 통과

## 제한 및 다음 단계

- 미리보기 목록은 대화상자 가독성을 위해 처음 20개만 표시하고 전체 개수는 별도로 표시한다.
- 대소문자 무시, 정규식 옵션, 0 채움 번호 형식은 아직 제공하지 않는다.
- 다음 단계는 탭 생성·닫기·복원과 탭별 탐색 상태 기반이다.
