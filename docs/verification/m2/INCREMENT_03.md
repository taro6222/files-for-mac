# M2 세 번째 개발 단위: 새 폴더와 단일 이름 변경

날짜: 2026-09-10. M2 진행 중.

## 사용 방법과 구현

- 현재 폴더에서 ⇧⌘N 또는 파일/문맥 메뉴의 새 폴더 명령 → 이름 입력 → 만들기.
- 한 항목 선택 → 파일/문맥 메뉴의 이름 변경 → 전체 이름(확장자 포함) 입력 → 변경.
- 완료 후 해당 폴더를 다시 읽고 결과 항목을 선택해 표시한다. 다른 위치로 탐색한 경우 이전 위치로 강제 이동하지 않는다.
- 빈 이름, 공백만 있는 이름, `.`, `..`, `/`, `:`, NUL을 거부한다. 나머지 이름 길이/권한 등은 파일 시스템이 판정한다.
- mkdirat 및 renameatx_np(RENAME_EXCL)로 기존 파일·폴더·깨진 링크를 덮어쓰지 않는다. 상위 폴더 descriptor identity를 재확인하며, 이름 변경 시 목록에서 읽은 원본 identity와 현재 값을 비교한다.
- 작업 전 Application Support의 operations에 `entry-UUID.json` 계획을 저장하고 완료/실패를 기록한다. 시작 기록 실패 시 작업하지 않는다. 실행 성공 후 기록 실패는 성공을 되돌리지 않고 별도 안내한다.
- 작업은 백그라운드에서 수행한다. 진행 중 일반 앱 종료를 보류한다. 원자적 단일 명령의 중간 취소는 제공하지 않는다.

## 검증

Swift Testing **41개 통과**(기존 36 + 신규 5). 신규 검사는 이름 검증, 한글 폴더 생성·이름 변경·내용/저널 보존, 기존 깨진 링크와 충돌 시 원본 보존, identity 불일치 거부·링크 자체 이름 변경, 저널 저장 실패 시 무변경이다.

Swift Debug/Release와 Xcode Debug 빌드가 통과했다. Xcode 프로젝트에 새 코어 파일을 등록했다.

실제 AppKit UI에서는 독립 `org.taro6222.files-for-mac.entry-qa` 앱에서 `/private/tmp/files-entry-ui-20260910`을 사용했다.

1. ⇧⌘N으로 한글 이름 `생성 검증` 폴더를 만들고 목록에서 선택됨을 확인했다.
2. 문맥 메뉴에서 `renamed`로 변경하고 변경된 행의 선택 유지를 확인했다.
3. 같은 `renamed`로 새 폴더 생성을 시도해 충돌 안내와 기존 폴더 보존을 확인했다.

첫 자동 타이핑에서는 잘못된 이름 안내가 나왔고, 이후 메뉴 추적 상태가 남아 도구 세션을 재연결했다. 메뉴의 Cancel 접근성 동작으로 복구한 뒤 필드 값을 확인하며 재검증했다. 한글 값 설정 및 초점을 명시한 영문 키보드 입력이 통과했다. 이 결과를 한글 IME 전체 조합 검증으로 확대 해석하지 않는다.

## 남은 범위

일괄 이름 변경, 대소문자만 변경할 때 파일 시스템별 동작, 확장자 변경 안내, 자동 이름 제안, 실행 취소는 후속 범위다. 현재 대소문자 변경이 시스템에서 충돌로 판정되면 안전하게 실패하며 임시 이름 우회는 하지 않는다. 계획/완료 JSON은 재시작 복구나 SQLite 저널 구현을 대신하지 않는다. identity 검사와 syscall 사이 외부 경쟁을 완전히 잠그는 보장은 없다.

M1 환경별 미검증 목록은 유지한다. 다음 기능은 휴지통 이동과 작업 결과 표시이며, 영구 삭제·자동 복원과 구분한다.
