# M4 열 번째 개발 단위 검증

검증일: 2026-11-13

## 범위

- 검색 패널의 Finder 태그 입력과 공백 구분 AND 검색
- 최소·최대 파일 크기 바이트 입력과 범위 검증
- 수정일 이후·이전 선택 컨트롤과 로컬 시간대의 일 시작·종료 경계
- 이름 없이 태그만 입력한 검색
- 잘못된 숫자, 음수, 최소값이 최대값보다 큰 입력의 실행 차단과 오류 표시

## 검증

- 전체 Swift 테스트 및 FilesMac 빌드: 92개 테스트 통과
- UI 자동 검증: 한국어/영어와 밝게/어둡게의 4개 조합 모두 통과
- `searchMetadataFilters`: 이름·Finder 태그·1~10바이트 조합이 정확히 한 결과를 반환
- `searchSizeValidation`: 숫자가 아닌 크기 입력을 거부하고 오류 상태를 표시
- `search-advanced.png`: 고급 필터 컨트롤, 필터 결과, 다크 모드 대비를 시각 확인

## 남은 항목

- KB/MB/GB 파일 크기 단위 선택
- Spotlight adapter와 콘텐츠 검색 capability
- 저장된 검색 조건과 최근 검색 관리

따라서 M4 완료로 표시하지 않는다.
