# M4 네 번째 개발 단위 검증

검증일: 2026-11-13

## 범위

- 파일·폴더의 표준 URL, 디렉터리·심볼릭 링크 여부
- 논리 크기와 실제 할당 크기
- 생성·수정·디렉터리 추가 날짜
- 소유자·그룹·POSIX 권한
- Uniform Type Identifier와 Finder 태그, 볼륨 이름
- 읽기·쓰기·실행 가능 여부
- 1 MiB 청크의 취소 가능한 스트리밍 SHA-256과 처리 바이트 진행 콜백
- 폴더 해시 요청의 명시적 미지원 오류

## 검증

전체 Swift 테스트 및 FilesMac 빌드 결과: 91개 테스트 통과. 임시 파일의 크기·권한·UTI·수정 날짜를 확인하고, `abc`의 SHA-256을 알려진 벡터 `ba7816bf...15ad`와 비교했다. 폴더 해시는 `directoryUnsupported`로 분리되는 것도 검증했다.

## 남은 항목

- 네이티브 정보·속성 패널과 다중 선택 요약
- 대형 파일 해시 진행·취소 및 파일 변경 감지 UI
- Finder 태그 쓰기·색상·왕복 검증
- Quick Look 포맷별 로딩·오류 격리

따라서 M4 완료로 표시하지 않는다.
