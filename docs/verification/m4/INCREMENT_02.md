# M4 두 번째 개발 단위 검증

검증일: 2026-11-13

## 범위

- 검색 root·query·결과·진행·취소·오류·건너뛴 위치를 분리한 상태 모델
- 새 검색 시작 시 기존 task 취소 및 결과 초기화
- query generation으로 취소를 무시하는 backend의 늦은 결과도 폐기
- 배치 결과의 부분 표시와 접근 실패 위치 누적
- 빈 검색어의 안전한 no-op과 명시적 취소 상태

## 검증

전체 Swift 테스트 및 FilesMac 빌드 결과: 90개 테스트 통과. 지연된 이전 검색보다 새 검색을 먼저 완료시키는 가짜 backend로 결과 혼입이 없음을 확인했고, 접근 실패 개수·완료·명시적 취소 상태를 검증했다.

## 남은 항목

- 탐색 창의 ⌘F 진입과 검색 패널
- 범위·종류·숨김 필터 및 결과 열기 UI
- 진행·부분 결과·취소·오류의 실제 화면 검증
- Spotlight capability 표시와 고급 메타데이터 필터

따라서 M4 완료로 표시하지 않는다.
