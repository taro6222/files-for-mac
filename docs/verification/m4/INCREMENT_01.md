# M4 첫 번째 개발 단위 검증

검증일: 2026-11-13

## 범위

- Spotlight 색인에 의존하지 않는 로컬 디렉터리 열거 검색
- 현재 폴더와 하위 폴더 포함 범위
- 모든 항목, 파일만, 폴더만 종류 필터
- 숨김 항목 포함 여부와 package 내부 제외
- 공백으로 나눈 다중 검색어, 대소문자 및 발음 구별 기호를 무시한 파일명 비교
- 128개 단위 결과 스트림, 취소 전파, 접근 실패 위치 개수 전달

## 검증

전체 Swift 테스트 및 FilesMac 빌드 결과: 89개 테스트 통과. 임시 fixture에서 현재 폴더/재귀 범위, 파일/폴더, 숨김 항목, `Résumé`/`resume` Unicode 검색을 검증했고 기존 탐색·파일 작업 테스트도 모두 통과했다.

## 남은 항목

- query generation 변경 시 이전 결과 폐기와 부분 결과 상태 모델
- 검색 진행·중단·재시도 및 범위·필터 UI
- Spotlight adapter와 직접 열거 결과의 capability 표시
- 태그·날짜·크기·콘텐츠 검색

따라서 M4 완료로 표시하지 않는다.
