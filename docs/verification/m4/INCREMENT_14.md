# M4 열네 번째 개발 단위 검증

검증일: 2026-11-13

## 범위

- 선택 파일·폴더를 기본 연결 앱으로 열기
- 선택 항목을 Finder에서 표시
- `NSSharingServicePicker`로 macOS 공유 서비스 연결
- 선택 폴더 또는 선택 파일의 상위 폴더를 Terminal에서 열기
- 애플리케이션 선택 패널을 통한 다른 앱·IDE로 열기
- 상세·그리드·목록·컬럼 보기의 공통 문맥 메뉴와 메인 메뉴 연결
- 셸 명령 문자열 대신 URL 및 `NSWorkspace.OpenConfiguration` 사용

## 검증

- 전체 Swift 테스트 및 FilesMac 빌드: 94개 테스트 통과
- `systemOpenCommands`: 네 가지 시스템 열기 명령이 모든 보기의 공통 문맥 메뉴에 연결됨을 확인
- UI 자동 검증: 한국어/영어와 밝게/어둡게의 4개 조합 모두 통과
- 보조 pane 선택에도 Finder·공유·다른 앱 명령이 활성화되도록 검증 규칙 통합

## 검증 한계와 남은 항목

- 자동 검증에서는 Finder·Terminal·공유 대상·사용자 선택 앱을 실제 실행하지 않았다. URL과 다중 선택 전달은 실제 앱 수용 검증으로 유지한다.
- 실제 외장 볼륨 장착·추출과 Spotlight 인덱싱 환경 검증을 계속 진행한다.

따라서 M4 완료로 표시하지 않는다.
