# M4 열세 번째 개발 단위 검증

검증일: 2026-11-13

## 범위

- 모든 드라이브 문맥 메뉴에서 Disk Utility 열기
- `isEjectable` 또는 `isRemovable`인 볼륨에만 추출 명령 노출
- 추출 전 사용자 확인
- 복사·이동·병합·삭제·복원·이름 변경 등 파일 작업 중 추출 차단
- `NSWorkspace.unmountAndEjectDevice` 공식 API 사용과 실패 이유 표시
- 장착 해제 알림을 통한 홈·사이드바 자동 갱신

## 검증

- 전체 Swift 테스트 및 FilesMac 빌드: 94개 테스트 통과
- 내부 볼륨에는 추출 capability가 없고 제거 가능 볼륨에만 활성화되는 모델 테스트 통과
- UI 자동 검증: 한국어/영어와 밝게/어둡게의 4개 조합 모두 통과
- 기존 홈·사이드바·검색·파일 작업 UI 회귀 확인

## 검증 한계와 남은 항목

- 자동 검증 환경에서는 실제 사용자 외장 드라이브를 추출하지 않았다.
- 실행 중 쓰기가 있는 실제 APFS/exFAT 외장 볼륨과 SMB 연결 해제는 별도 수용 검증으로 유지한다.
- Finder·터미널·IDE·공유 등 시스템 열기 명령을 계속 구현한다.

따라서 M4 완료로 표시하지 않는다.
