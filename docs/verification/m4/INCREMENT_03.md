# M4 세 번째 개발 단위 검증

검증일: 2026-11-13

## 범위

- 탐색 창과 명령 팔레트에서 접근 가능한 `⌘F` 네이티브 검색 패널
- 현재 폴더/하위 폴더, 모든 항목/파일/폴더, 숨김 포함 필터
- 직접 열거 검색임을 명시한 진행·완료 capability 상태
- 검색 중단, 부분 결과, 접근 실패 위치와 오류 표시
- 이름·위치·종류 결과 열, 더블클릭 시 상위 폴더 탐색 및 항목 선택
- utility 창 전환 뒤 히스토리 선택 행 표시 복원 보강

## 자동 및 실제 UI 검증

전체 Swift 테스트 및 FilesMac 빌드 결과: 90개 테스트 통과. `DEVELOPER_DIR=/Library/Developer/CommandLineTools scripts/verify-ui.sh` 결과 한국어/영어 × 밝게/어둡게 네 조합에서 `searchWindow`, `searchResults`, `searchCapability`를 포함한 모든 검사가 `true`였다.

각 조합의 `search.png`를 생성했다. 한국어 다크 화면에서 검색어, 범위·종류·숨김 컨트롤, 이름·위치·종류 열, 직접 열거 결과 상태와 단일 정확 결과를 직접 확인했다. 10,000항목 자동 새로고침과 히스토리 검증이 겹치지 않도록 검증 순서를 분리했고 기존 선택·스크롤 복원도 다시 통과했다.

## 남은 항목

- Spotlight adapter와 인덱싱 여부 표시
- 태그·날짜·크기·콘텐츠 필터
- 검색 결과 문맥 메뉴 및 양쪽 pane 대상 열기
- 대규모 재귀 검색 취소·권한 실패 실환경 검증

따라서 M4 완료로 표시하지 않는다.
