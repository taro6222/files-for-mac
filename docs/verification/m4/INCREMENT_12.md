# M4 열두 번째 개발 단위 검증

검증일: 2026-11-13

## 범위

- `MountedVolumeProvider`로 장착 볼륨 열거를 UI에서 분리
- 볼륨 이름, 총/가용 용량, 포맷 설명, 내장/로컬/읽기 전용/제거/추출 가능 상태 모델링
- 비정상 용량 값의 사용량 비율을 0~1로 제한
- 기존 장착·해제 알림으로 홈과 사이드바를 다시 구성
- 홈 드라이브 카드에 포맷과 읽기 전용 상태를 추가 표시

## 검증

- 전체 Swift 테스트 및 FilesMac 빌드: 94개 테스트 통과
- `mountedVolumeCapabilitiesClampUsageAndRestrictEject`: 사용량 경계와 제거 가능 capability 확인
- UI 자동 검증: 한국어/영어와 밝게/어둡게의 4개 조합 모두 통과
- 기존 홈 용량 카드, 사이드바 위치, 탐색과 파일 작업 회귀 확인

## 남은 항목

- 실행 중 파일 작업을 고려한 안전한 추출 UI와 성공/실패 상태
- Disk Utility 연결
- 실제 외장 APFS/exFAT 및 SMB 장착·해제 이벤트 검증

따라서 M4 완료로 표시하지 않는다.
