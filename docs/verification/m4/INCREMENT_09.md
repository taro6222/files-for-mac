# M4 아홉 번째 개발 단위 검증

검증일: 2026-11-13

## 범위

- Finder 태그의 공백 구분 AND 검색
- 논리 파일 크기의 inclusive 최소·최대 경계
- 수정 날짜의 inclusive 이후·이전 경계
- 이름 없이 태그만으로 검색 가능
- 이름·태그·크기·날짜·종류·범위 필터의 조합
- 메타데이터가 없는 항목은 해당 필터가 있을 때 명시적으로 제외

## 검증

전체 Swift 테스트 및 FilesMac 빌드 결과: 92개 테스트 통과. `Résumé report.txt` fixture에 `Important`, `검토` Finder 태그와 고정 수정 날짜를 기록한 뒤 이름·두 태그·5~20바이트·동일 시작/끝 날짜를 동시에 적용해 정확히 한 결과가 나오는 것을 확인했다. 존재하지 않는 태그와 최소 크기 초과는 빈 결과를 반환했다.

## 남은 항목

- 검색 패널 고급 필터 컨트롤과 입력 검증
- 로컬 시간대 기준 날짜 시작·종료 UI
- 파일 크기 단위 선택과 잘못된 범위 오류
- Spotlight adapter와 콘텐츠 검색 capability

따라서 M4 완료로 표시하지 않는다.
