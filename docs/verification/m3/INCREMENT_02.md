# M3 두 번째 개발 단위 검증

검증일: 2026-11-13

## 범위

- 기본 pane과 보조 pane 각각의 보기 모드 팝업
- 상세·목록·그리드·컬럼·적응형 선택지의 한국어/영어 레이블
- 각 컨트롤이 자기 pane의 상태만 변경하는 명확한 대상 지정
- 세션 복원 및 모델 변경 시 컨트롤 선택 상태 동기화
- 접근성 레이블과 툴팁

## 자동 검증

전체 Swift 테스트 및 FilesMac 빌드 결과: 81개 테스트 통과.

## 현재 동작과 한계

- 보기 모드 선택과 pane별 저장·복원 상태는 실제 AppKit 컨트롤에 연결되었다.
- 현재 파일 표시는 기존 상세 테이블 렌더러를 유지한다.
- 목록·그리드·컬럼을 선택해도 해당 전용 렌더러로 바뀌었다고 주장하지 않는다.
- 다음 단위에서 실제 렌더러와 선택·스크롤 identity 이전을 구현한다.

따라서 M3 완료로 표시하지 않는다.
