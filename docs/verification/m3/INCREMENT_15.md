# M3 열다섯 번째 개발 단위 검증

검증일: 2026-11-13

## 범위

- 표준화된 폴더 경로별 보기 모드와 보기 크기 저장
- 폴더별 값이 전역 보기 크기보다 우선하고, 설정 해제 시 전역값으로 복귀
- 기본·보조 pane의 직접 탐색 및 뒤로·앞으로 이동에 동일 규칙 적용
- 폴더별 설정이 활성화된 상태에서 모드·크기 변경 시 해당 폴더 값 갱신
- 손상된 JSON을 빈 설정으로 복구하고 알 수 없는 경로 상태가 UI를 막지 않도록 처리

## 자동 및 실제 UI 검증

전체 Swift 테스트 및 FilesMac 빌드 결과: 88개 테스트 통과. 단위 테스트에서 경로 표준화, 저장·재로딩, 제거, 손상 데이터 복구를 검증했다.

`DEVELOPER_DIR=/Library/Developer/CommandLineTools scripts/verify-ui.sh` 결과 한국어/영어 × 밝게/어둡게 네 조합에서 `folderViewApplied`, `folderViewReset`을 포함한 모든 검사가 `true`였다. 기존 상세·그리드·목록·컬럼·적응형 보기와 선택·탐색 회귀 검사도 모두 통과했다.

## 남은 항목

- 모든 폴더별 값을 한 번에 확인·초기화하는 관리 화면
- 원본 Windows 화면과 macOS 적응형 기준의 시각 비교 승인
- VoiceOver, 키보드 전체 흐름, 대비 증가·투명도 감소 수동 확인
- M1 실제 compositor/FPS 및 SMB 환경 검증은 별도 미완료 상태 유지

따라서 M3 완료로 표시하지 않는다.
