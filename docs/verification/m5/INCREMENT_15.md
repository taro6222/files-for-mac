# M5 열다섯 번째 개발 단위 검증

검증일: 2026-11-14

## 범위

- 앱 메뉴에서 여는 네이티브 원격 연결 관리 창
- FTP/FTPS/SFTP/SMB 프로토콜, 이름, 호스트, 포트, 절대 루트 경로, 사용자 이름, 암호 입력
- 프로토콜 변경 시 기본 포트 제안과 기존 프로필 선택·수정
- 새 암호를 입력할 때만 Keychain 항목 생성·갱신, 빈 암호는 기존 참조 보존
- 프로필 삭제 시 연결된 Keychain 항목도 삭제
- 실제 protocol backend 전에는 연결 성공처럼 보이는 동작을 노출하지 않음

## 검증

- 전체 Swift Testing 116개 및 FilesMac 빌드 통과
- `scripts/verify-ui.sh` 한국어/영어 × 라이트/다크 4조합 전체 통과
- 각 조합에서 원격 연결 창 표시와 격리된 QA 저장소에 SFTP 프로필 저장 후 목록 1개 표시 확인
- 원격 연결 창 캡처를 각 조합 결과 디렉터리에 보관
- QA에서는 실제 Application Support와 로그인 Keychain을 사용하지 않아 사용자 데이터 무변경

## 검증 한계와 남은 항목

- 실제 로그인 Keychain 저장·갱신·삭제는 서명된 앱 수용 검증이 남아 있다.
- 암호 입력을 포함한 UI 자동화는 Keychain을 건드리지 않도록 제외했다.
- SMB 마운트 및 FTP/FTPS/SFTP 목록·전송 backend와 인증 실패·재인증 UI가 남아 있다.

따라서 M5 원격 연결 영역 완료로 표시하지 않는다.
