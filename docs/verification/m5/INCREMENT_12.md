# M5 열두 번째 개발 단위 검증

검증일: 2026-11-13

## 범위

- iCloud ubiquitous 항목에 macOS 공개 API 기반 `지금 다운로드`와 `공간 비우기` 명령 제공
- 파일 메뉴와 목록·그리드 공용 컨텍스트 메뉴에 동일 명령 연결
- 단일 선택이며 ubiquitous 항목으로 확인된 경우에만 명령 활성화
- 일반 File Provider 및 로컬 항목에서는 다운로드·공간 비우기·영구 오프라인 유지 capability를 모두 비활성화
- 공개 API로 보장되지 않는 영구 `항상 다운로드 유지` 동작은 노출하지 않음
- 작업 완료 후 활성 pane을 새로 읽어 상태 표시 갱신

## 검증

- 일반 로컬 fixture의 세 capability가 모두 false임을 확인
- 지원하지 않는 다운로드·공간 비우기 호출이 `unsupported`로 실패하고 원본 내용이 바뀌지 않음을 확인
- 전체 Swift Testing 111개 통과
- `scripts/verify-ui.sh` 한국어/영어 × 라이트/다크 4조합 전체 통과
- 각 조합에서 두 클라우드 컨텍스트 명령 존재와 일반 항목의 보수적 비활성 판정 확인
- 기존 10,000개 항목·두 pane·보기 모드·파일 작업·압축 회귀 검사도 모두 true

## 검증 한계와 남은 항목

- 현재 환경에서 실제 iCloud online-only 항목의 다운로드·evict 성공은 재현하지 않았다.
- Dropbox·OneDrive 등 일반 File Provider 전용 동기화 명령은 공개 공통 API가 없어 제공하지 않는다.
- 실제 설치 공급자별 online-only·오프라인·충돌·네트워크 단절 수용 검증이 남아 있다.

따라서 M5 클라우드 영역 완료로 표시하지 않는다.
