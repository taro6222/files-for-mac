# M7 Increment 127 — 대용량 파일 이동의 검증 진행 표시

같은 볼륨의 일반 파일을 이동하거나 기존 파일을 백업할 때, 실행 취소용 스냅샷을 만들기 전에 진행 상태를 표시한다. 기존 폴더 검증 단계와 동일한 취소 신호를 사용한다. 일반 파일을 검증하는 시점에 취소하면 원본을 유지하고 대상을 만들지 않는 회귀를 추가했다.

Apple Silicon macOS 27.2 (26B123)에서 최적화 FilesCore 빌드로 512 MiB 파일을 같은 APFS 볼륨 내에서 다섯 번 이동·실행 취소했다. 원본과 대상 디렉터리의 장치 번호가 일치했다. 시험 직전에 임시 파일을 만들고 OS 캐시를 공유했다. 아래는 각 실행의 경과 시간이다.

| 측정 | 최솟값 | 중앙값 | 최댓값 |
| --- | ---: | ---: | ---: |
| 파일 이동 | 196.5 ms | 204.7 ms | 240.3 ms |
| 이동 전 스냅샷 | 194.9 ms | 203.1 ms | 235.8 ms |
| 실행 취소 | 382.2 ms | 402.4 ms | 528.3 ms |
| 네이티브 이름 변경 | 0.053 ms | 0.068 ms | 0.122 ms |
| 이동 호출부터 검증 진행 콜백까지 | 0.670 ms | 0.802 ms | 3.292 ms |

네이티브 이름 변경은 검증 비용을 분리하기 위한 참고값이다. 실행 취소는 현재 같은 파일을 사전 확인과 이동 직전에 두 번 읽는다. 위 진행 콜백 값은 엔진 측정이며 화면 표시까지의 지연은 별도 검증이 필요하다.

Swift 테스트 227개, 실제 APFS·대소문자 구분 APFS·exFAT 마운트 검사 5개가 통과했다. 한국어·영어와 밝은·어두운 테마에서 AppKit 파일 작업 검사도 조합별 68개가 통과했다.
