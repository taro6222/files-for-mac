# M7 Increment 47 — 취소 시 변경된 교체 백업 보존

교체 이동이 취소되거나 실패하면 자동 복원 전에 백업의 식별 정보와 기록된 폴더 내용을 검사한다. 백업이 외부에서 수정됐거나 내용을 확인할 수 없으면 백업을 보존하고 결과와 작업 저널에 경로를 남긴다. 검사를 통과한 백업은 기존 무덮어쓰기 경로로 복원한다.

교차 볼륨 교체 이동의 검증 단계에서 이미 백업된 폴더의 하위 파일을 수정하고 취소한다. 원본과 수정된 백업의 내용, 대상 경로가 비어 있는지, 취소 결과와 저널의 백업 경로를 검사한다. 실제 SMB에서는 정상 응답하는 공유에서 실행해야 한다. 검사와 복원은 별도 파일 시스템 호출이므로 마지막 검사 직후 발생하는 외부 변경까지 검증한 결과는 아니다.

Apple Silicon macOS 27.2 (26B123)에서 Swift 시험 206개와 APFS·대소문자 구분 APFS·exFAT 볼륨 매트릭스 3개를 통과했다.
