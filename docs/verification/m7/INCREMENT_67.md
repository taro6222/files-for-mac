# M7 Increment 67 — 장시간 메모리 계측 보강

장시간 시험은 macOS `TASK_VM_INFO`에서 RSS와 물리 메모리 사용량(`phys_footprint`)을 같은 시점에 측정한다. 두 값의 최댓값은 각 사이클과 종료 시 갱신한다. 첫 사이클, 약 30초 간격, 종료 시점의 보고서 표본에 두 값이 들어간다. 기존 RSS 필드는 유지한다.

Apple Silicon macOS 27.2에서 최신 Git 조회 변경을 포함한 최적화 빌드의 예비 시험이 36.24초에 13사이클을 완료했다. 최대 RSS는 150.9 MiB, 최대 물리 메모리 사용량은 69.3 MiB였다. 각 표본의 두 값이 양수이며 해당 최댓값 이하임을 확인했다. 작업 폴더 직접 빌드가 지연돼 로컬 임시 스냅샷에서 빌드했고, 변경 파일이 작업 트리와 바이트 단위로 일치함을 확인했다.

이전 8시간 후보 `dab9839`와 상세 셀 재사용 후보 `b59771a`의 약 90사이클 표본은 각각 RSS 146.7 MiB(94사이클), 156.8 MiB(91사이클)였다. 초기 표본의 변동과 실행 시점 차이를 고려해 개선 여부는 장시간 추세와 추가 물리 메모리 표본으로 판정한다.
