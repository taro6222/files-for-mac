# M7 Increment 176 — 원본 대응 인벤토리의 근거 검증

CI에서 사용하는 인벤토리 감사에 고정 원본 SHA, 분류 코드, CSV 행 구조, 명령 대응 열 및 저장소 내부 근거 경로 검사를 추가했다. 새 검사에서 명령 팔레트의 근거 파일명이 이전 이름으로 남아 있음을 발견해 현재 구현 파일로 수정했다.

명령 202개, 설정 143개, 화면 33개가 구조 검사를 통과했다. 격리 복제본에서 다른 SHA, 허용하지 않는 분류, 삭제된 근거 경로, 열 개수가 틀린 행, 명령 대응 열 누락을 각각 주입해 모두 실패로 판정하는 것을 확인했다.

구조 검사는 고정된 목록의 행과 근거 위치를 확인한다. 출시 판정에는 항목별 실제 동작·화면 증거와 적용 기능 검증률이 추가로 필요하다.
