# M7 Increment 44 — 교차 볼륨 폴더 이동 실행 취소

새 교차 볼륨 이동의 실행 취소 기록에 대상 폴더와 교체 시 보관한 폴더의 하위 경로, 파일 내용 해시, 권한 및 심볼릭 링크 대상을 저장한다. 대상에는 복사 검증에서 이미 얻은 결과를 재사용한다. 실행 취소 시 폴더 자체의 식별 정보와 하위 항목을 검사해, 파일을 제자리에서 편집해 폴더 자체의 수정 시간이 그대로여도 변경을 감지한다. 기존 기록은 읽을 수 있으며 하위 항목 기록이 없는 경우에는 폴더 자체의 식별 정보로 확인한다.

교차 볼륨 경로를 사용하도록 설정한 자동 시험에서 이동된 폴더와 교체 백업 폴더의 하위 파일을 각각 수정했다. 실행 취소가 변경을 보고하고 수정한 파일과 다른 쪽 폴더를 보존하는지 확인했다. 같은 볼륨의 폴더 실행 취소와 실제 SMB 환경의 하위 파일 변경 회귀는 남아 있다.

Apple Silicon macOS 27.2에서 Swift 시험 205개와 기존 APFS·대소문자 구분 APFS·exFAT 볼륨 매트릭스 시험 3개가 통과했다.
