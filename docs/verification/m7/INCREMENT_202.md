# M7 Increment 202 — 컬럼 보기에서 상위 경로 표시

현재 폴더 왼쪽에 볼륨 루트까지 읽을 수 있는 상위 폴더 목록을 표시한다. 상위 컬럼마다 현재 경로에 해당하는 하위 폴더를 선택 상태로 표시한다. 현재 폴더의 파일은 먼저 표시하고 상위 목록은 백그라운드에서 읽는다. 비공개 폴더나 존재가 확인되지 않는 경로에서 열거가 끊기면 확인한 컬럼을 표시한다.

상위 컬럼의 항목을 선택하면 해당 컬럼의 폴더로 이동해 선택을 유지한다. 현재 폴더 컬럼에서 왼쪽 방향키를 누르면 상위 폴더로 이동해 방금 떠난 폴더를 선택한다. 이동 이력은 기존 탐색 모델을 사용한다. 기본 패널과 분할 패널에 적용했다. 상위 경로가 바뀌거나 패널이 닫힐 때 이전 열거를 취소한다.

[Windows 공통 폴더 시험](INCREMENT_201.md)은 선택한 폴더의 하위 항목과 상위 경로가 함께 보이는 기준을 제공한다. macOS는 창 너비에 맞춰 오른쪽의 활성 컬럼을 보여 주며 나머지 상위 컬럼은 수평으로 스크롤해 볼 수 있다.

Apple Silicon macOS 27.2 영어·밝은 테마의 AppKit 검사 284개를 통과했다. 공통 폴더의 상위 컬럼과 하위 항목을 동시에 확인했고, 왼쪽 방향키 동작으로 방금 떠난 폴더가 상위 위치에서 선택됐다. [상위 경로를 표시한 컬럼 화면](ui-05-macos-ancestor-columns.png)

분할 패널의 상위 컬럼 표시를 포함한 AppKit 파일 작업 검사 71개를 한국어·영어와 밝은·어두운 테마 네 조합에서 각각 통과했다.
