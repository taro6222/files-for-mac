# M7 Increment 18 — 교차 볼륨 교체 이동 중단

마운트한 볼륨을 대상으로 기존 파일 교체 중 취소하는 시나리오를 추가했다. 원본을 임시 위치에 복사한 뒤 검증이 시작될 때 취소를 요청한다. 결과가 취소로 기록되고, 원본과 기존 대상이 각각 이전 내용을 유지하며, 대상 폴더에 임시 복사본이나 백업이 남지 않는지 검사한다. SMB 검증에서는 저널을 로컬에 둬 실제 앱의 저장 경로와 같은 조건을 사용한다.

같은 시나리오를 실제 APFS·대소문자 구분 APFS·exFAT 테스트 볼륨에서 실행했다. 볼륨 검증 3개와 Swift Testing 201개를 통과했다. 이 Mac에는 마운트된 SMB 공유가 없으며, 로컬 APFS를 SMB 검증기에 넘기면 상태 코드 65로 거부됨을 확인했다. SMB에서의 실행·연결 중단·재연결·권한·외부 변경 반영은 남아 있다. [실제 SMB 검증 실행 방법](../m2/INCREMENT_32.md)
