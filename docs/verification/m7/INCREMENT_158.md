# M7 Increment 158 — 파일 그룹 소유권

단일 파일이나 폴더의 권한 시트에서 그룹 소유권을 바꿀 수 있다. 일반 계정에서는 현재 프로세스의 기본·보조 그룹을 후보로 표시한다. 적용 여부는 macOS가 판정한다. 시트에서 그룹을 바꿀 때 setuid 또는 setgid 비트가 해제될 수 있음을 표시한다.

대상 경로를 심볼릭 링크 역참조 없이 열어 파일 식별자와 기존 소유자·그룹, POSIX 모드 및 ACL을 확인한다. 파일 디스크립터에서 그룹만 요청하고 실제로 적용된 그룹을 확인한다. POSIX 및 ACL 편집에서도 기존 소유자나 그룹이 변경된 스냅샷을 거부한다.

사용자 소유자 변경과 하위 항목 일괄 적용은 남아 있다.

Swift 테스트 236개가 통과했다. 실제 파일의 그룹을 바꾼 뒤 소유자와 ACL을 대조하고, 이전 그룹을 기록한 스냅샷과 존재하지 않는 그룹을 거부하는지 확인했다. SwiftPM이 컴파일한 테스트 객체를 Swift Testing 런타임에 직접 링크했다.

한국어·영어와 밝은·어두운 테마 네 조합에서 각각 AppKit 검사 264개가 통과했다. 속성 창에서 다른 그룹을 골라 저장한 뒤 APFS의 실제 그룹, 소유자, POSIX 모드와 두 ACL 항목을 대조했다.
