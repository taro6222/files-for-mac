# M7 Increment 43 — 교차 볼륨 이동의 게시 후 변경 감지

복사본을 대상 경로에 게시한 뒤 원본을 삭제하기 전에 대상의 파일 식별 정보와 내용을 다시 확인한다. 대상이 같은 내용의 다른 파일로 교체돼도 원본 삭제를 중단한다. 게시 전 확보한 대상 식별 정보를 실행 취소 기록에 사용한다.

원본 삭제 전 정리에서는 게시한 항목과 내용이 일치하는 대상만 삭제 대상으로 삼는다. 원본 폴더 삭제를 시도한 이후에는 일부 하위 항목이 지워졌을 수 있으므로 검증된 대상 사본을 보존한다. 교차 볼륨 이동의 실행 취소에도 같은 원칙을 적용한다.

실제 APFS, 대소문자 구분 APFS, exFAT 볼륨 회귀에 게시 직후 대상 이름을 같은 내용의 다른 파일로 교체하는 시나리오를 포함했다. 이동 실패 상태와 원본, 외부 교체본, 외부에서 이름을 바꾼 게시본의 내용을 검사한다. 기존 복사·이동·실행 취소·교체 취소도 같은 볼륨에서 실행한다. SMB 검증 스크립트에도 이 시나리오가 포함되며 정상 응답하는 공유에서 실행해야 한다.

검사와 삭제는 별도의 파일 시스템 호출이다. 검사 직후 외부 프로세스가 경로를 바꾸는 경우를 포함한 전체 동시 변경 검증과 추가 해시 읽기의 대용량 이동 성능 측정은 남아 있다.

Apple Silicon macOS 27.2 (26B123)에서 Swift 테스트 204개와 실제 로컬 볼륨 매트릭스 3개가 통과했다.
