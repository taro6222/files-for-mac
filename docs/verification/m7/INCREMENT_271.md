# M7 Increment 271 — SMB 접근 시각 복원 뒤 게시본 식별자

[SMB 3.1.1 실마운트](https://github.com/taro6222/files-for-mac/actions/runs/44078458467)에서 복사본의 생성·수정·접근 시각이 원본과 일치했다. 교차 볼륨 이동 두 건은 게시본의 변경 검사에서 원본을 보존하고 중단했다. 읽기 전용 공유와 일반 세션 재연결은 통과했다.

기존 SMB 실행 취소 장부는 파일의 변경 시각(ctime)을 식별자에 포함한다. 접근 시각을 설정하면 변경 시각도 갱신될 수 있으므로 게시된 경로를 그대로 비교하면 앱이 직접 쓴 변경도 거부하게 된다. 접근 시각을 설정하는 파일 디스크립터에서 이전 변경 시각을 확인하고, 성공한 설정의 새 변경 시각만 장부에 반영한다. 전후 파일 속성과 열린 게시 핸들의 확인을 거친 후 원본을 삭제한다. 이전 변경 시각이 일치하지 않으면 중단한다.

로컬 Swift 시험은 75개 통과했고 실마운트·휴지통 등 지정 환경이 없는 시험 11개는 건너뛰었다. APFS·대소문자 구분 APFS·exFAT·FAT32·HFS+ 마운트 시험 5개가 통과했다. 변경 시각 조정과 접근 시각 보존을 포함한 SMB 이동과 실행 취소는 실제 공유에서 다시 검사한다.
