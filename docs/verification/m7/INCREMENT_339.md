# M7 Increment 339 — 압축 생성 형식 선택

상태: 구현·로컬 검증 완료. M7 정식 출시는 미완료다.

원본 UI-13은 이름과 압축 형식을 별도로 선택한다. 기존 macOS 저장 창은 ZIP·7z 확장자를 허용하지만 별도 선택기가 없어 7z를 사용하려면 확장자를 직접 입력해야 했다. 실제 메뉴가 사용하는 NSSavePanel에 ZIP (.zip)·7z (.7z) 팝업을 추가했다. 기본값은 ZIP이며 선택한 포맷 하나만 허용해 저장 URL의 확장자와 기존 엔진의 포맷 판별을 연결한다.

[Apple accessoryView 문서](https://developer.apple.com/documentation/appkit/nssavepanel/accessoryview)와 [allowedContentTypes 문서](https://developer.apple.com/documentation/appkit/nssavepanel/allowedcontenttypes)의 공개 저장 패널 API를 사용한다. 패널은 뷰를 보유하고 뷰는 패널을 약하게 참조한다. 형식을 바꾸면 마지막 ZIP·7z 확장자만 대체하고 다른 이름 부분·대소문자·현재 저장 위치를 보존한다. 빈 이름은 빈 값으로 유지하며 반복 선택으로 확장자를 더하지 않는다. 한글·여러 확장자·이미 입력한 압축 확장자를 검사한다.

압축 생성·추출 엔진, 게시 전 검증·기존 대상 보호·취소 정책은 변경하지 않는다. 암호·분할 압축·업데이트 지원을 추가한 것으로 표시하지 않는다. 이 변경은 원본의 압축 생성 옵션 중 형식 선택 대응이며 전체 원본 대화상자의 동등성을 의미하지 않는다.

실제 NSSavePanel의 액세서리 팝업과 NSControl action 전달로 기본값·7z 전환·수정 이름/왕복·빈 이름/명시적 확장자를 검사한다. 액세서리 캡처는 구성요소 렌더링이며 전체 저장 창·물리 입력 수용을 대체하지 않는다. 전체 UI의 ZIP·7z 실제 생성/추출·취소 검증도 유지한다. Core 코드를 바꾸지 않아 Core/볼륨 시험은 반복하지 않는다.

인증서·공증 프로필은 사용자 준비 중이며 화면 잠금 해제 응답을 기다린다. 최신 두 CPU·장시간·실제 입력/VoiceOver·전체 원본 UI 상태 대조·지원 환경·외부 서비스·정식 서명/공증은 열린 게이트다.

네 언어/테마 조합 전체 UI 각각 310개·탭 경계 각각 18개, Debug·Release 빌드·parity 구조 감사·검증 스크립트 구문 검사가 통과했다. [소스·바이너리·보고서·캡처 해시](archive-format-339-verification.json). 새 검사는 기존 306개에 위 네 가지 실제 컨트롤 검증을 추가한 것이며 원본 대응 항목 수나 전체 수용률로 집계하지 않는다.

이전 고정 소스 05dd05d는 ARM·Intel 두 원격 작업 모두 성공했고 각각 네 조합 303개/18개를 실제 보고서로 확인했다. 세션 비율 위치 오차 최대 ARM 0.4pt·Intel 0.2pt였다. 압축 기본값 변경 소스 7da2fd7의 ARM도 네 조합 306개/18개 성공이며 Intel은 확인 시점에 실행 중이었다. 774083b 조기 진단 실행은 별도로 진행 중이다. 이들 결과를 새 형식 선택 소스의 원격 수용으로 대체하지 않는다.
