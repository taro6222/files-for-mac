# M7 Increment 119 — 이전 이동 기록의 실행 취소

교체 백업이 없는 이전 폴더 이동 기록은 폴더 식별자, 데이터 포크와 권한을 확인한 뒤 내부 파일의 현재 리소스 포크를 함께 돌려놓는다. 교차 볼륨에서는 임시 복사본과 원본을 검증한 뒤에 원본을 제거하며, 다시 실행에도 리소스 포크를 포함한 전체 스냅샷을 사용한다.

새 이동 기록에는 리소스 포크 검증 적용 여부를 저장한다. 새 폴더 이동 기록의 실행 취소는 전체 스냅샷이 일치해야 한다. 교체 백업과 복사 실행 취소의 비교 기준은 계속 적용한다. 이전 교체 이동이나 이전 복사 기록에 포크 해시가 없으면 수동 복구가 필요할 수 있다.

포크 해시와 적용 여부가 없는 이전 형식의 이동 기록을 재현해 실행 취소와 다시 실행에서 포크가 보존되는지 검사했다. 새 기록에서 이동 뒤 리소스 포크가 추가된 파일도 검사했다.

Swift 테스트 221개와 실제 APFS·대소문자 구분 APFS·exFAT 마운트 검사 4개가 통과했다. 새 기록의 변경 감지 시험에서는 실행 취소가 멈췄고 대상의 포크가 보존됐다.
