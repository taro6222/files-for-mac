# M7 Increment 229 — 정보 패널의 Git 상태

정보 패널에서 파일 하나 또는 폴더 하나를 선택하거나 새로고침하면 그 항목의 Git 상태를 조회한다. 추적 중인 파일은 변경 없음 또는 상태 코드를 표시하고, 미추적 파일과 병합 충돌은 상태를 문장으로 표시한다. 폴더는 범위 안의 변경 항목 수를 표시한다. 파일 이름은 리터럴 경로로 전달한다. 미리보기로 바꾸면 상세 Git 표시를 해제한다.

[macOS CI](https://github.com/taro6222/files-for-mac/actions/runs/43668046777)의 Swift 컴파일러가 상세 속성을 구성하는 식에서 타입 검사 시간 제한에 걸렸다. 서식 있는 값을 먼저 계산하고 상세 목록의 원소 타입을 지정했다. Git 상태 조회는 선택을 바꾸거나 패널을 닫을 때 취소한다. 동일 CI의 SMB 실마운트 결과는 후속 실행에서 확인한다.

Apple Silicon macOS 27.2에서 AppKit 검사 306개를 통과했다. 임시 Git 저장소를 복제해 상태 열을 끈 상태에서도 추적 중인 파일, 특수 문자가 있는 미추적 파일, 병합 충돌이 정보 패널에 표시되고 미리보기로 바꾸면 지워지는 것을 확인했다. Swift Testing 실행기로 저장소 탐색, 특수 파일명, 선택 경로의 변경 여부와 폴더 내 변경 수를 확인하는 세 시험을 통과했다.
