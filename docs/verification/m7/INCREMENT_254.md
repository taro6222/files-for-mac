# M7 Increment 254 — SMB 생성·접근 시각 실마운트 측정

APFS 시험 파일에 서로 다른 생성·접근·수정 시각을 넣고 일반 복사로 SMB 공유에 게시한다. 게시 직후 내용을 읽기 전에 세 시각을 기록하고 수정 시각과 파일 바이트를 검사한다. 별도 SMB 시험 파일에 파일 디스크립터로 생성·접근 시각을 설정한 뒤 반환 오류와 다시 조회한 값을 기록한다. 두 결과를 대조해 현재 전송 경로와 서버·클라이언트의 명시적 시각 설정 지원을 확인한다.

로컬에서 통합 시험 4개를 컴파일했다. SMB 마운트 없이 실행하면 4개 모두 건너뛰는 것을 확인했다. 셸 구문 및 대응표 감사도 통과했다. 생성·접근 시각 보존 판정은 실제 러너의 측정이 필요하다.
