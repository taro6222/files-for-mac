# M7 Increment 245 — SMB 서버의 쓰기 거부 시험

기존 읽기·쓰기 Samba 공유에 별도 서버 읽기 전용 공유를 추가했다. 두 공유를 같은 macOS 러너에 인증으로 마운트한다. 읽기 전용 공유에는 사전에 만든 교체 대상이 있다. [Samba의 공유별 읽기 전용 설정](https://www.samba.org/samba/docs/current/man-html/smb.conf.5.html#READONLY)

통합 시험은 읽기 전용 경로가 실제 `smbfs`에 있고 목록과 기존 파일을 읽을 수 있는지 확인한다. 새 파일 생성 시 쓰기 거부를 확인한 후 FilesCore로 복사와 기존 대상 교체 이동을 시도한다. 실패 결과를 기록하면서 두 원본과 기존 대상의 바이트 및 디렉터리 항목을 보존하고 실행 취소 항목이 생기지 않아야 한다.

Apple Silicon에서 Swift Testing 시험을 컴파일해 마운트가 없으면 건너뛰고 로컬 경로는 거부하는 것을 확인했다. Python 모의 시험으로 두 마운트 경로와 두 번째 마운트 실패 시 첫 번째 마운트의 정리를 확인했다. 실제 Samba의 권한 거부 결과는 실마운트 실행에서 확인한다.
