# M7 Increment 143 — 다운로드 이미지와 빌드 이미지 대조

다운로드한 정식 DMG를 검증할 때, 빌드 호스트에서 별도로 기록한 Team ID와 SHA-256을 지정할 수 있다. 로컬 이미지와 체크섬 파일이 일치해도 별도 SHA-256과 다르면 서명 검사 전에 코드 65로 종료한다. 인자를 생략하면 기존 호출 형식도 사용할 수 있다. [다운로드 검증 절차](INCREMENT_21.md)

셸 문법을 확인했고, 잘못된 SHA 형식과 불일치를 각각 거부했다. 실제 프리뷰 DMG 복사본은 올바른 SHA-256으로 이미지 무결성 검사를 통과한 뒤 서명이 없어 거부됐다. 기존 한 인자와 두 인자 호출에서도 서명 검사까지 도달했다. Developer ID로 서명·공증한 다운로드와 Finder 최초 실행 검증은 남아 있다.
