# M7 Increment 261 — Windows 작업 센터의 복사 완료·지우기

고정 Windows 원본 Files v4.2.9의 실제 창에서 `preview.txt`를 `Workshop` 폴더에 복사했다. 작업 센터에 `Copied 1 item to "Workshop"`가 표시됐다. 완료 항목을 지운 뒤 해당 카드가 사라지고 지우기 버튼이 비활성화됐다. 양쪽 시험 파일은 같은 SHA-256을 유지했다. 다운로드한 두 PNG의 SHA-256과 접근성 트리, 캡처 기록의 대상·복사 해시를 대조했다. [Windows 화면과 결과](https://github.com/taro6222/files-for-mac/actions/runs/43677965855)

macOS의 [작업 센터](INCREMENT_255.md)에서도 복사 결과와 대상을 확인할 수 있다. 현재 Mac은 닫은 작업을 최근 50건까지 보관한다. 해당 기록을 직접 지우는 동선, Windows에서 전송 중 진행·취소 화면, 실제 VoiceOver 탐색이 남아 있다.
