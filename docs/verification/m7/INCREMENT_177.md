# M7 Increment 177 — 고정 원본과 인벤토리 재대조

`python3 scripts/inventory-upstream.py --check`는 고정 GitHub 원본에서 명령·설정의 원본 필드를 다시 추출하고, 조사 대상 파일과 Views 아래 XAML 목록을 대조한다. 검토 결과가 담긴 CSV는 읽기 전용으로 유지한다. `--check --source-tree <경로>`로 고정 커밋의 로컬 복사본에서도 실행할 수 있다.

공개 GitHub 원본과 기존 로컬 아카이브로 각각 실행해 명령 202행, 설정 143행, 조사 대상 파일 183행, 화면 33행이 일치했다. 격리 복제본에서 명령 ID 하나를 바꾼 경우와 XAML 행 하나를 삭제한 경우를 각각 실패로 판정했다. 인벤토리에서 정한 원본 필드의 대조이며 매개변수별 명령, 복합 설정, 대화상자·컨트롤 내부 및 Windows 실행 상태 검증은 별도 범위다.
