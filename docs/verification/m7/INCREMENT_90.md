# M7 Increment 90 — 충돌 파일의 텍스트 미리보기

복사·이동 충돌 창에서 원본과 기존 대상의 UTF-8 텍스트를 메타데이터 아래에 표시한다. 파일당 최대 4 KiB를 보여주며 더 긴 파일에는 생략 표시를 붙인다. 일반 파일을 읽기 전용으로 열고, 메타데이터를 읽은 시점과 파일을 연 시점의 장치·inode가 일치하는지 검사한다. 마지막 경로 요소가 심볼릭 링크인 항목은 링크를 따라가 읽지 않는다. 바이너리나 UTF-8 이외의 데이터, 폴더에는 텍스트 미리보기 불가 상태를 표시한다.

Apple Silicon macOS 27.2에서 한국어·영어와 밝게·어둡게의 파일 작업 검사 각 56개를 통과했다. 원본과 대상의 서로 다른 본문을 같은 충돌 창에서 확인하고, 건너뛰기 뒤 두 파일의 내용이 유지되는지 확인했다. 이미지·PDF 등의 미리보기와 Windows 실행 화면 대조는 남아 있다.
