# M7 Increment 133 — FAT32·HFS+ 생성 시간 보존

macOS 27.2에서 임시 RAW 이미지를 FAT32와 저널링 HFS+로 각각 포맷했다. 파일과 폴더의 생성 시간에 홀수 초 + 999 ms를 기록하고 다시 읽었다. HFS+는 같은 정수 초를, FAT32는 직전 짝수 초를 반환했다. 이 결과를 반영해 HFS+가 포함된 전송에서 1초 미만, FAT 계열이 포함된 전송에서 2초 미만의 생성 시간 차이를 허용한다.

볼륨 검사 스크립트에 두 형식을 추가했다. 최상위 폴더, 하위 폴더, 파일에 서로 다른 생성 시간을 설정하고 APFS에서 각 볼륨으로 복사·이동한 뒤 실행 취소로 APFS에 돌아오는 경로를 검사한다.

Swift 테스트 229개와 실제 마운트 검사 6개가 통과했다. 생성 시간 검사는 대소문자 구분 APFS·exFAT·FAT32·HFS+의 네 조합에서 통과했다. SMB 생성 시간과 각 볼륨의 접근 시간 보존은 후속 검증 대상이다.
