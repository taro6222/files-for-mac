# M7 Increment 33 — 장시간 시험 중 탐색 이력과 RSS 관찰

기존 장시간 시험은 매 사이클마다 폴더로 이동한 뒤 새 탐색으로 홈을 열었다. 이 방식은 닫힌 탭을 해제해도 주 창의 뒤로 가기 이력을 두 항목씩 늘린다. 탐색 이력의 증가와 반복 작업의 메모리 사용을 구분하기 위해 새 시험은 뒤로 가기로 홈에 복귀하고 이력 크기가 일정한지 확인한다. RSS 표본에 실제 경과 초를 기록하며 마지막 표본도 최댓값에 반영한다.

Apple Silicon macOS 27.2 (26B123)의 예비 시험은 69.02초 동안 21사이클을 완료했다. 최대 RSS는 162.73 MB였다. 이 실행은 동선과 보고서를 확인하는 예비 시험이다. [보고서](release-soak-balanced-smoke.json)

기존 두 8시간 시험은 각각의 빌드에서 계속 관찰한다. 이력 크기를 일정하게 유지하는 최신 빌드에서도 8시간 결과와 메모리 추세를 확인해야 한다.
