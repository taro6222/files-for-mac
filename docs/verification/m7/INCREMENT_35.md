# M7 Increment 35 — 홈의 네트워크 위치

시스템 볼륨 정보가 비로컬로 표시하는 마운트는 홈의 네트워크 위치 제목 아래에 표시한다. 위치 이름을 누르면 해당 마운트의 탐색 경로를 연다. 네트워크 위치가 없으면 제목을 숨긴다. 드라이브 표시와 펼침 설정은 네트워크 위치에도 적용한다.

macOS 27.2 (26B123)에서 네트워크 볼륨 메타데이터를 주입한 AppKit 시험으로 접근성 이름, 로컬 드라이브 카드 표시, 네트워크 경로를 여는 동작과 드라이브 표시 끄기를 확인했다. 실제 SMB 마운트 동작은 별도로 검증해야 한다.

한국어·영어 및 밝게·어둡게 조합별 AppKit 파일 작업 검사 44개를 통과했다.
