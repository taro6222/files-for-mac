# M7 Increment 106 — Launch Services 기동 경로 대조

Apple Silicon macOS 27.2 (26B123)에서 같은 프리뷰 DMG의 ad-hoc 격리 복사본을 Launch Services로 새로 실행했다. 창이 표시되면 접근성 메뉴를 통해 정보 창을 열었다. 프로세스 아키텍처는 arm64로 확인했다. 두 시험 모두 20회였고 OS 캐시를 공유했다.

| 격리 설치 위치 | 정보 창 표시 p95 | 최대 |
|---|---:|---:|
| 프로젝트의 `build` 하위 | 10.955초 | 11.369초 |
| 시스템 임시 디렉터리 | 545 ms | 841 ms |

프로젝트 경로 시험의 지연은 대부분 시작 폴더 창이 표시되기 전에 발생했다. 별도의 시스템 임시 경로 대조에서 현재 이미지 2회는 430–499 ms, 이전 이미지 2회는 439–608 ms였다. 임시 경로에서 같은 지연이 재현되지 않았다. 두 20회 시험은 실행 경로와 시각이 달랐으므로 파일 경로 자체가 원인인지 확인하는 작업이 남아 있다.
