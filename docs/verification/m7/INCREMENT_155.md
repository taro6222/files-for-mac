# M7 Increment 155 — 계정 이름으로 ACL 규칙 추가

파일 권한 시트의 ACL 편집에서 사용자 또는 그룹을 선택하고 계정의 짧은 이름을 입력한다. 허용·거부와 읽기·쓰기·실행/탐색을 지정하면 규칙이 편집기 끝에 추가된다. macOS ACL 파서가 계정을 확인하고 정규화된 항목을 반환한다. 확인할 수 없는 이름과 ACL의 구분 문자를 포함한 이름은 거부한다.

저장을 누를 때 파일 식별자와 기존 권한을 확인하는 경로는 이전과 같다. 기존 규칙의 순서와 POSIX 모드는 유지된다. 상세 권한과 상속 플래그는 텍스트 편집기에서 수정할 수 있다. 계정 목록 탐색, 소유자 변경, 하위 항목 일괄 적용은 남아 있다.

Swift 테스트 234개와 한국어·영어 × 밝은·어두운 테마의 AppKit 검사 263개가 각 조합에서 통과했다. 현재 사용자와 everyone 그룹, 존재하지 않는 이름과 구분 문자가 섞인 이름을 Swift에서 검증했다. AppKit에서는 기존 ACL 뒤에 everyone 쓰기 규칙을 붙인 뒤 저장하고 실제 파일의 순서와 POSIX 모드를 대조했다. SwiftPM이 컴파일한 테스트 객체를 Swift Testing 런타임에 직접 링크해 실행했다.
