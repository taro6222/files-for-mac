# M7 Increment 96 — Samba 공유의 서버와 macOS 마운트 대조

Apple Silicon macOS 27.2에서 Alpine 3.22의 Samba 4.21.9-r1을 루프백에만 바인딩하고, 임시 공유에서 시험했다. Linux `smbclient`로 인증 공유에 16바이트 파일을 올리고 목록 조회, 다운로드, 원본과의 바이트 비교, 삭제를 완료했다.

macOS `mount_smbfs`에서는 게스트 연결과 인증 연결이 모두 마운트됐다. 두 연결은 SMB 3.1.1을 협상했고, 인증 연결에서 서버 로그에 AES-128-GMAC 서명이 확인됐다. 두 마운트 모두 기본 디렉터리 조회가 8초 안에 반환되지 않았다. 인증 마운트에 `verify-smb-volume.sh`를 실행했을 때도 8초 뒤 코드 124로 종료돼 Files의 파일 작업 검증에는 도달하지 못했다.

시험 서버를 SMB 2.1로 제한한 뒤 추가 마운트를 시도했으나 연결 단계에서 코드 68을 반환했다. SMB 2.1 목록 조회 결과는 확보하지 못했다. 임시 컨테이너를 제거하고 시험 마운트 두 개가 해제된 것을 확인했다.

정상 응답하는 macOS SMB 마운트에서 파일 작업, 연결 중단·재연결, 권한, 외부 변경 반영을 이어서 검증해야 한다.
