# M7 Increment 338 — Git 지연 중 진단 수집

상태: DEBUG 진단 보강·로컬 검증 완료. Git 지연 원인과 M7 정식 출시 게이트는 미완료다.

55c1bee 원격 검증에서 Intel 전체 작업은 성공했지만 첫 Git 조회는 7.690초였다. 같은 소스의 ARM 첫 조회는 10.033초에 snapshot 단계로 실패했다. 실패 후 부모 스택을 수집하는 동안 직접 Git 자식이 종료될 수 있어, 그 뒤 검색 실패를 원래 시점의 자식 부재로 해석할 수 없다.

이번에는 최초 조회가 1초 이상 실행 중이면 기존 부모/직접 Git 자식 진단 수집을 시작한다. 10초 성공 기준과 판정 시점은 유지하며, 판정을 먼저 고정한 뒤 진단 도구 종료를 기다린다. 기존 실패 시점의 보조 수집도 유지한다. DEBUG 밖 두 파일 내용은 7da2fd7과 동일함을 비교했다. Core와 배포 실행 코드는 변경하지 않아 해당 시험과 Release 빌드를 반복하지 않았다. 수집 도구는 실행 시간에 영향을 줄 수 있으므로 성능 수용 자료로 사용하지 않는다.

로컬에서는 FILES_GIT_TRACE_AFTER_MS=10으로 정상 조회 중에도 수집 경로를 실행했다. 네 조합 전체 UI 각각 306개·탭 경계 각각 18개와 Debug 빌드·parity 구조 검사가 통과했다. 네 부모 sample은 종료 코드 0이며 실제 비어 있지 않은 파일을 확인했다. 직접 자식 검색은 모두 1로, 조회가 짧은 로컬 실행에서 지연 원인을 입증하지 않는다. [소스·바이너리·보고서·스택 해시](git-early-338-verification.json).

05dd05d ARM 원격 작업은 전체 UI 네 조합 각각 303개·경계 18개와 프리뷰 시작 검증까지 성공했다. 최초 Git 조회는 0.331초라 시간 초과 스택은 생성되지 않았다. 대신 335단계에서 보완한 desktop-session-comparison.json 네 개의 실제 보존을 확인했고 비율 위치 오차 최대는 0.4pt였다. Intel 작업은 확인 시점에 진행 중이었다. 이 실행은 압축 기본 이름 변경 전 소스이며 최신 변경의 수용으로 대체하지 않는다.

인증서와 notarytool 프로필은 사용자 준비 중이다. 화면 잠금 해제 응답도 기다린다. Git 간헐 지연 해결·최신 양쪽 CPU 수용·장시간 추세·실제 입력/VoiceOver·전체 원본 UI 상태 대조·지원 환경·외부 서비스·정식 서명/공증은 남아 있다.
