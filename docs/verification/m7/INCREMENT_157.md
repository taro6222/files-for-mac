# M7 Increment 157 — 권한·해시 기능을 포함한 프리뷰와 장시간 시험

앱 소스 `24036846f1a7d0d47c6e89ac669fae73b0283f76`에서 유니버설 개발 프리뷰를 빌드했다. 해시 계산·비교와 POSIX·확장 ACL 편집, 사용자·그룹 선택을 포함한다. 프리뷰의 두 슬라이스와 SDK가 기록한 최소 macOS 14.0 대상, ad-hoc 서명, DMG 내용물과 SHA-256을 확인했다.

Apple Silicon macOS 27.2에서 이전 프리뷰 설치, 손상된 교체본 거부, 새 프리뷰 설치, 이전 프리뷰 복원을 확인했다. 설정과 사용자 파일을 대조했으며 구형 탭 세션이 새 형식으로 저장되고 복원한 버전에서 다시 열렸다. [설치 결과](preview-install-2403684.json)

동일 앱 소스의 최적화 QA 바이너리로 `full` 부하 28,800초 시험을 시작했다. 바이너리 SHA-256 `093f0d045fe37d16a3f0ba036a9bf4084cd121afd55d2bb0d9204a837ee7beea`를 대조했다. 실행 중 보고서에서 78초, 28사이클을 확인했다. 완료 여부와 메모리 추세는 최종 결과로 판정한다. 이전 후보 시험도 별도로 진행 중이다.

Launch Services에서 각 프리뷰를 20회 기동했다. 공유 OS 캐시와 장시간 시험이 동시에 실행된 조건에서 정보 창 표시 p95는 새 프리뷰 814 ms, 이전 프리뷰 재측정 872 ms였다. 두 측정은 순차 실행했다. 이전 프리뷰의 기존 기록은 576 ms였으며, 콜드 시작 목표는 별도로 검증해야 한다. [새 프리뷰](preview-launch-services-2403684.json) · [이전 프리뷰 재측정](preview-launch-services-2d6d5ba-loaded.json)
