# M7 Increment 318 — 여러 원본 복사의 전체 데이터 합계

상태: 구현·Swift·Debug·Release·실제 볼륨·파일 작업 UI·제한 실행기·네 조합 전체 AppKit 검증 통과. 새 원격 수용과 전체 M7 출시는 미완료다.

복사 진행에 현재 파일·폴더의 바이트와 별도로 선택한 여러 원본의 누적 바이트·전체 예정량·데이터 백분율을 표시한다. 완료 보고서와 작업 센터의 종료 문구도 최종 집계를 사용한다. 기존 항목 수·단계·현재 항목 문구와 검증/게시 중 작업 표시를 유지하며 새 데이터 비율은 별도 안내 줄에 표시한다. 이동·병합 선택 전체의 집계와 원본 전체 UI 상태 대응은 후속 항목이다.

필수 무결성 스냅샷을 먼저 수집해 원본별 논리 데이터 포크 크기를 합산하고 실제 복사에서 해당 스냅샷을 재사용한다. 별도 재귀 크기 조회나 같은 원본의 최초 해시를 중복 수행하지 않는다. 소비한 준비 스냅샷은 배열에서 즉시 해제한다. 목적지 identity·원본 shelf/template 검증과 자기 하위 복사 거부는 긴 스냅샷 조회보다 먼저 수행한다. 사전 확인 중에도 UI는 전체 데이터 확인 상태를 표시하고 취소할 수 있다.

처음부터 건너뛸 이름 충돌은 예정량 0으로 처리한다. 사전 확인 후 새 충돌이 생겨 복사를 건너뛰면 예정량도 줄인다. 늦게 전달된 이전 예정량·단계·바이트가 되돌아오지 않도록 집계 순번을 확인한다. 어느 원본의 크기를 알 수 없거나 합산이 넘치면 전체 크기 미확인으로 표시하며 백분율을 만들지 않는다. 바이트는 NativeFileCopy가 전달한 원본별 최대 관측값을 누적하고 클론·희소 파일의 논리 크기를 유지한다.

이 값은 검증·게시 전에 staging한 데이터다. 이미 복사했으나 검증에서 거부되거나 이후 충돌한 시도의 바이트도 포함될 수 있다. 실패·취소 시에는 마지막 콜백 관측값이며 물리 I/O나 작업 성공률·현재 남은 임시 파일 크기가 아니다. 전체 데이터 100%라도 완료/실패/충돌 결과는 별도로 확인한다. 저장한 seconds는 사전 확인 종료 이후의 경과이며 원본 사이의 검증 시간도 포함한다.

사전 확인 후 뒤 원본이 바뀌면 준비 스냅샷과 복사 후 원본을 비교해 게시를 거부한다. 선택 전체를 원자적으로 동결하는 기능은 아니다. 원본 재검증·비덮어쓰기 게시·안전한 취소·완료 항목의 Undo를 유지한다. 최종 집계는 CopyReport의 선택적 필드로 저장하며 이 필드가 없는 기존 저널도 읽는다. 최종 UI는 늦은 콜백에 의존하지 않고 보고서 집계를 사용한다.

새 Swift 시험 다섯 개는 여러 원본·하위 폴더/링크의 합계와 충돌 제외·Undo·기존 저널 읽기, 뒤 원본 변경 거부, 불명 크기 원본과 정상 원본의 독립 처리, 사전 확인 중 취소, 확인 후 생긴 충돌의 예정량 교정을 검사한다. 전체 352개 보고 중 성공 334개·환경 건너뜀 18개다. 제한 실행기 10개·다섯 실제 파일 시스템의 기존 시험 7개와 네 조합 파일 작업 UI 각각 82개·전체 AppKit 각각 283개도 통과했다. Debug·일반 Release 빌드와 Xcode 프로젝트 생성 후 차이 없음도 확인했다. 고정 Debug SHA-256은 `3e72e0b340ec50a6a2acd25c6eb574c4a9ae2d95a30197ee69ae2d27464e9e81`다.

DEBUG UI 검증은 두 실제 원본의 32KB+64KB와 보존 충돌 128KB를 사용해 현재 파일 64KB·전체 96KB를 구분한다. 실제 콜백을 진행 창에 재생해 늦은 프레임 거부와 최종 보고서 요약을 확인한다. 기존 남은 항목 검사는 안내 줄이 늘어난 레이아웃에서 현재 항목 첫 줄을 확인하며 기대 문구는 유지한다. [소스·바이너리·보고서 해시와 네 조합 캡처](selection-copy-verification.json).

새 원격 수용, 이동·병합의 전체 선택 데이터 집계, 잔여 메모리 증가와 최신 소스 장시간, Intel 전체 UI·성능, 실제 접근성·원본 상태 대조·정식 서명·공증은 남아 있다. 인증서와 공증 프로필은 준비 중이다.

기본 push CI는 전체 AppKit과 Xcode 검사를 생략한다. 따라서 기본 작업의 성공을 전체 UI·Xcode 수용으로 집계하지 않으며, 새 소스에서는 전체 AppKit·Xcode·프리뷰 교체/복원을 명시한 별도 workflow_dispatch로 검증한다.
