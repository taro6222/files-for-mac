# M7 Increment 45 — 같은 볼륨의 폴더 이동 실행 취소

같은 볼륨에서도 이동할 폴더와 교체 백업의 하위 항목을 검증하고 실행 취소 기록에 저장한다. 대상의 식별 정보는 이름을 바꾸기 전에 확보한다. 이동이 끝난 뒤 하위 파일이 수정되면 실행 취소를 중단해 변경된 폴더를 보존한다.

읽을 수 없는 하위 경로나 FIFO 같은 특수 파일로 인해 폴더를 검증할 수 있는 범위를 벗어나는 경우, 파일 시스템이 허용한 이동은 완료하고 해당 항목의 실행 취소가 제공되지 않는 이유를 표시한다. 교체 백업이 있으면 그 경로를 결과에 표시한다. 기존 실행 취소 기록은 기존 방식으로 읽는다.

하위 파일 내용이 바뀐 이동 대상과 교체 백업, FIFO가 들어 있는 폴더의 이동을 자동 시험에 포함했다. 실제 APFS·대소문자 구분 APFS·exFAT에서는 같은 볼륨에서 폴더를 옮기고 하위 파일을 수정한 뒤 실행 취소의 결과와 파일 내용을 비교한다. 실제 SMB 및 폴더 내용 검증에 따른 대규모 같은 볼륨 이동 성능은 추가 검증 대상이다.

Apple Silicon macOS 27.2 (26B123)에서 Swift 시험 206개와 실제 로컬 볼륨 매트릭스 시험 3개가 통과했다.
