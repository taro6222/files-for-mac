# M7 Increment 260 — SMB 생성 시각 복원

[SMB 3.1.1 실마운트 측정](https://github.com/taro6222/files-for-mac/actions/runs/43677645532)에서 통합 시험 4개가 통과했다. macOS 15.8.2와 Samba 4.25.1에서 APFS 파일을 복사한 뒤 수정 시각과 바이트는 같았다. 생성 시각은 원본의 수정 시각으로, 접근 시각은 검증 시점의 시각으로 바뀌었다. 별도 SMB 파일에 생성·접근 시각을 명시적으로 설정하면 원래 값을 모두 다시 읽을 수 있었다.

SMB를 생성 시각 복원과 비교에 포함했다. 임시 복사본에서 생성 시각을 복원한 뒤 SMB FILETIME의 100 ns 단위와 Foundation 표현 정밀도를 고려해 대조한다. 시간 불일치는 전송 확인에서 거부하고 실행 취소 기록은 정확히 비교한다. 복원에 실패하면 기존 전송 오류 경로에서 처리한다.

로컬 Swift 전송 시험 25개가 통과했고 통합 환경이 없는 시험 10개는 건너뛰었다. 별도 마운트한 APFS·대소문자 구분 APFS·exFAT·FAT32·HFS+ 통합 시험 5개가 통과했다. SMB 실마운트에서는 복사본의 생성 시각이 원본과 일치하는지 명시적으로 검증한다. SMB 모델·버전별 동작과 접근 시각 복원은 남아 있다.
