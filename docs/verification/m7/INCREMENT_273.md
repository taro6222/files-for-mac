# M7 Increment 273 — 실제 볼륨의 이동 결과 창 재시도

대소문자 구분 APFS 시험 볼륨에 쓰기 권한이 없는 대상 폴더를 만들고 앱에서 교차 볼륨 이동을 시작한다. 실패 결과 창의 다시 시도 버튼과 원본 바이트, 빈 대상 폴더를 확인한다. 시험 폴더의 쓰기 권한을 복원한 뒤 버튼을 눌러 정상 이동과 실행 취소를 대조한다.

macOS 27.2 AppKit 빌드에서 한국어·영어와 밝은·어두운 테마 네 조합의 파일 작업 검사 79개씩을 통과했다. 키보드 회귀에서는 Return 입력이 숨겨진 세부 창을 실제로 다시 표시하는지 확인했다.

macOS CI는 기존 볼륨 매트릭스의 마운트를 유지한 채 AppKit 파일 작업 검사를 실행한다. 이 케이스의 macOS 15 두 아키텍처 CI 결과는 후속 실행에서 확인한다.
