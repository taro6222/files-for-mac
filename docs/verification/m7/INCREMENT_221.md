# M7 Increment 221 — Windows 탭 드롭 전 대상 탭 선택

[Windows 재시험](https://github.com/taro6222/files-for-mac/actions/runs/43665389837)은 검색 결과에서 뒤로 이동해 공통 폴더로 돌아갔고 두 번째 탭에서 `Alpha`를 열었다. 첫 탭 클릭 후 캡처된 접근성 트리에서는 `Alpha`가 선택된 채였고 창에는 `column-note.txt`만 보여 드래그 전 검증이 중단됐다.

`Alpha` 탭이 선택됐는지 확인하고 Windows 원본의 이전 탭 명령인 `Ctrl+Shift+Tab`을 보낸다. 드래그를 시작하기 전에 공통 폴더의 경로와 항목, 첫 탭의 선택 상태를 함께 확인한다. 저장된 실제 접근성 트리는 첫 탭 선택 조건을 충족하지 않았고 선택 상태를 바꾼 모의 트리는 통과했다. 선택 여부가 없거나 두 탭이 모두 선택된 입력은 거부했다. 실제 드래그와 분할 패널 결과는 후속 Windows 실행에서 검증한다.
