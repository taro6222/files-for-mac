# M7 Increment 41 — 보조 패널 접근성

보조 패널의 뒤로, 앞으로, 상위 폴더, 새로고침, 숨김 항목 버튼 및 상세 파일 목록에 한국어와 영어 접근성 이름을 제공한다. 탐색 버튼의 활성 여부를 현재 경로와 방문 기록에 맞추고, 숨김 항목 버튼에는 토글 상태를 표시한다. 접근성 클릭은 일반 버튼 클릭과 같은 동작으로 처리한다.

Apple Silicon macOS 27.2 (26B123)의 AppKit 창을 사용해 접근성 이름, 이동 전후 탐색 버튼 활성 상태, 접근성 클릭으로 숨김 상태를 바꾸고 되돌리는 동작을 검사했다. 한국어·영어와 밝은·어두운 모드 네 조합에서 51개씩 통과했다. VoiceOver 음성 안내와 별도 프로세스에서 배포된 프리뷰의 접근성 트리를 읽는 검증은 남아 있다.
