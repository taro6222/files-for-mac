# M7 Increment 255 — 파일 작업 센터 진행 막대

복사·이동·폴더 병합이 진행되는 동안 작업 센터의 각 행에 처리 항목 수와 AppKit 진행 막대를 함께 표시한다. 진행 막대에는 처리 건수와 전체 건수를 읽을 수 있는 한국어·영어 접근성 설명을 제공한다. 완료하거나 취소된 결과에는 상태와 대상 경로를 표시한다.

Apple Silicon macOS 27.2 (26B123)의 실제 AppKit 파일 작업 검사에서 한국어·영어와 밝은·어두운 테마 네 조합마다 76개를 통과했다. 복사를 시작했을 때 표시된 막대의 크기, 전체·현재 값과 접근성 설명을 읽었다. 작업 센터에서 복사를 취소한 뒤 원본 보존과 대상 파일 부재, 결과와 함께 막대가 사라지는 것을 확인했다. 대응표 감사에서 378건 모두 분류됐다.

Windows 실행 화면과의 대조, 실제 VoiceOver 탐색 및 전체 전송의 남은 바이트 표시는 남아 있다.
