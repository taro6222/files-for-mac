# M7 Increment 64 — 상세 목록의 동일한 행 재사용

새로 계산한 상세 행이 기존 행과 같으면 테이블을 다시 로드하지 않는다. 행 내용이나 순서가 바뀌거나, 상세 보기로 돌아오거나, 표시 설정이나 파일 전용 아이콘을 갱신해야 할 때는 다시 로드한다. Git 상태와 커밋 정보는 현재 표시 중인 Git 셀에 반영한다.

Apple Silicon macOS 27.2에서 영어·어두운 테마의 전체 AppKit 검사 221개와 파일 작업 검사 53개가 통과했다. 새 검사는 상세 목록에서 같은 렌더링을 다시 요청해도 선택 행과 기존 셀 객체가 유지되는지 확인한다. 이전 후보의 힙에서는 목록 셀 804개, AppKit 의존성 컨텍스트 115,322개, 물리 메모리 112.7 MiB를 관찰했다. 이 변경의 8시간 메모리 추세는 추가 검증 항목이다.
