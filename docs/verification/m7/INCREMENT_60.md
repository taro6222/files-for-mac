# M7 Increment 60 — 홈 화면 재사용

홈 화면은 최근 위치, 환경설정 또는 볼륨 목록이 변경됐을 때 다시 구성한다. 폴더에서 홈으로 돌아올 때 표시할 내용이 그대로면 기존 AppKit 뷰를 재사용한다. 홈이 가려진 동안 변경된 내용은 홈을 다시 표시할 때 반영한다.

Apple Silicon macOS 27.2의 디버그 빌드에서 한국어·영어와 밝은·어두운 테마를 조합한 네 가지 시험을 실행했다. 모든 조합에서 변경 없는 홈 뷰의 재사용, 최근 위치 갱신, 네트워크 위치의 키보드 탐색과 볼륨 섹션 표시 전환이 통과했다. 로컬 임시 경로에서 수행한 전체 AppKit 회귀는 조합별로 53개 중 51개가 통과했다. 그리드 활성화 시 선택 복원과 템플릿 파일 생성 검사는 실패가 남아 있다.

실행 중인 8시간 시험의 바이너리는 이전 후보 `dab9839`다. 홈 재사용에 따른 장시간 메모리 효과는 별도로 측정해야 한다.
