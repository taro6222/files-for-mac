# M7 Increment 68 — 로컬 임시 경로의 프리뷰 설치·복원

프리뷰 설치 검증에 `--run-parent` 옵션을 추가했다. 이 옵션은 기존 디렉터리 아래에서 읽기 전용 마운트와 격리된 홈을 만든다. 작업 폴더에서 디렉터리 조회가 중단될 때 로컬 임시 경로에서 같은 검증을 반복할 수 있다.

Apple Silicon macOS 27.2에서 `--run-parent /private/tmp`로 두 프리뷰를 검사했다. 설치, 손상된 교체본 거부, 정상 교체, 이전 앱과 사용자 파일 복원 뒤 시작 창이 열렸다. 새 이미지의 SHA-256은 [현재 프리뷰](PREVIEW_0.1.0.md)와 일치했다. Python 구문 검사와 일반 파일을 부모로 지정했을 때 종료 코드 2도 확인했다.

별도로 `fc10112912237dc0795ed340e131b8f10b8e3efe` 소스의 28,800초 탐색·복사·탭 시험을 시작했다. 실행 프로세스와 바이너리 SHA-256을 대조했고 초기 보고서에서 RSS와 물리 메모리 값이 함께 기록됐다. 최종 종료 코드와 메모리 추세는 진행 중이다.
