# M7 Increment 34 — 교체된 폴더의 자동 갱신 복구

주 창과 분할 창에서 폴더 읽기 오류 뒤 새로고침하면 해당 경로의 감시를 다시 등록한다. 등록할 수 없는 상태에서도 사용자 새로고침으로 재등록을 시도한다. 주 창의 감시 이벤트는 목록만 다시 읽어 감시 이벤트가 재등록을 반복하지 않도록 했다.

Apple Silicon macOS 27.2 (26B123)의 AppKit 시험에서 감시 중인 임시 APFS 폴더를 제거해 읽기 오류를 확인했다. 같은 경로에 폴더를 다시 만든 뒤 오류 화면의 재시도 버튼을 눌러 새 파일이 표시되고 새 감시 객체가 등록되는지 확인했다. 이후 추가 파일이 자동으로 표시됐다. 한국어·영어 및 밝게·어둡게 조합별 파일 작업 검사 42개가 통과했다. 폴더 재생성 시나리오는 주 창에서 검증했다.

실제 SMB 연결 중단·재연결에서의 갱신과 권한 검증은 남아 있다.
