# M7 Increment 92 — 장시간 시험의 AppKit 객체 보유

상세 목록을 홈에서 분리한 빌드(`9a65f0e`)의 8시간 전체 부하 시험이 약 138분에 2,600사이클을 기록했다. 주 창의 상세 목록 셀은 주기 표본마다 88개 이하였지만, 물리 메모리의 첫 표본은 58.3 MiB, 마지막 표본은 185.4 MiB, 사이클 종료 시점의 최대 계측값은 195.0 MiB였다. 시험은 계속 실행 중이다.

Apple Silicon macOS 27.2에서 약 18분의 세 대조 실행과 약 135분의 전체 실행에 `heap -s -sortBySize`를 적용했다. 대조 실행은 같은 `c192235` 바이너리를 사용했다.

| 실행 | `NSKeyValueDependencyContext` | `NSKVONotifying_NSScroller` |
|---|---:|---:|
| 탐색 | 20,214 | 2 |
| 탐색·탭 | 31,455 | 411 |
| 탐색·탭·전송 | 27,876 | 353 |
| 8시간 시험 중간 스냅샷 | 234,686 | 495 |

탐색만 실행한 경우에도 AppKit 관찰 객체가 남았다. 보조 탭의 컨트롤러와 폴더 감시 객체 해제를 사이클마다 확인했지만, 탭을 반복한 두 대조 실행에는 더 많은 스크롤바 객체가 남았다. 스냅샷 간 실행 시간과 사이클 수가 달라 관찰 객체 수에 대한 기능별 증가율을 확정할 수 없다.

탭·전송 반복에서 원본과 대상이 번갈아 최근 위치에 기록되면서 홈의 뷰가 갱신된다. 이 경로의 영향을 확인하기 위해 `c192235` 임시 빌드에서 최근 방문 기록 호출만 끄고 탭 및 전체 부하의 30분 대조를 시작했다. 제품 코드에는 실험을 반영하지 않았다. 30분 대조와 8시간 전체 시험의 종료를 기다린 뒤 비교한다.
