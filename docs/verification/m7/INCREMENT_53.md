# M7 Increment 53 — 교차 볼륨 실행 취소의 중복 사본 복구

교체 이동을 실행 취소하다 복사본을 원래 위치에 게시한 직후 중단되면, 두 위치에 항목이 남을 수 있다. 재시도 시 원래 위치의 사본을 저널의 식별 정보 및 검증 기록과 대조한다. 이동 대상의 식별 정보와 양쪽 내용이 일치하는 경우에만 이동 대상에 남은 사본을 정리하고 백업을 복원한다. 이동 대상의 하위 항목 기록이 있으면 함께 대조한다. 변경이 발견되면 두 사본과 백업을 보존한다.

자동 시험은 교차 볼륨 경로를 강제하고 게시 직후 오류를 주입한다. 저널을 다시 읽어 두 사본이 그대로인 경우와 이동 대상 사본이 바뀐 경우를 각각 검사한다. 실제 프로세스 강제 종료와 물리 볼륨 간 중단 복구, SMB 검증은 남아 있다.

Apple Silicon macOS 27.2 (26B123)에서 Swift 시험 211개를 통과했다.
