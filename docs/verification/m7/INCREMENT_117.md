# M7 Increment 117 — APFS 파일 메타데이터 보존

Apple Silicon macOS 27.2에서 로컬 APFS와 별도로 마운트한 대소문자 구분 APFS 볼륨 사이의 복사, 복사 실행 취소, 이동, 이동 실행 취소를 검증했다. 선행 하이픈, 공백, 한글, 이모지와 개행이 있는 파일을 사용했다.

복사 결과, 다른 볼륨으로 이동한 결과, 실행 취소 후 복원된 원본에서 데이터 포크, 권한과 실행 비트, 수정 시간, ACL, 확장 속성, 리소스 포크, Finder 태그 확장 속성의 바이트가 일치했다. 이동 후에는 원래 위치가 비었고, 실행 취소 후에는 대상에서 파일이 사라졌다.

마운트한 볼륨을 사용한 메타데이터 회귀를 포함해 Swift 테스트 219개가 통과했다. 회귀는 `scripts/verify-volume-matrix.sh`의 mountedVolume 필터에 포함된다. 현재 파일 작업의 게시 전 스냅샷은 내용과 대상 식별자를 확인한다. 위 속성의 보존은 이 APFS 시험에서 확인했으며, 모든 속성의 게시 전 비교와 대상 파일 시스템의 속성 손실 안내는 출시 검증에 남아 있다.
