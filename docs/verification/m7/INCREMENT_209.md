# M7 Increment 209 — 분할 패널의 경로 입력 보호

보조 패널에서 폴더 경로를 입력하던 중 같은 위치의 목록을 다시 읽으면 경로가 현재 폴더의 값으로 덮어써졌다. AppKit 검사에서 실제 필드 편집기에 경로를 넣고 같은 위치의 목록을 다시 읽어 재현했다.

같은 폴더를 갱신하는 동안 활성 편집기의 경로를 유지한다. 폴더가 바뀌거나 편집이 끝난 상태에서 화면을 갱신하면 경로 필드에 현재 위치를 표시한다. 새로고침을 마친 뒤에도 편집기에 입력이 남는지 검사한다.

수정 전 영어·밝은 테마에서 재현 검사만 실패했다. 수정 후 Apple Silicon macOS 27.2에서 앱 빌드와 영어·밝은 테마 AppKit 검사 293개가 통과했다. 한국어·영어와 밝은·어두운 테마의 파일 작업 검사도 각 72개를 통과했다.
