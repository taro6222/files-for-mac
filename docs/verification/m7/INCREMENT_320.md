# M7 Increment 320 — 겹치는 폴더 Undo의 검증 후 통합

상태: 구현·Swift·다섯 실제 파일 시스템·네 조합 메뉴 Undo/전체 UI·Debug·Release 검증 통과. 새 원격·지원 환경 전체 수용과 M7 출시는 미완료다.

앞선 원본이 만든 폴더 안에 다음 원본의 파일을 추가하면 Undo 기록이 상위·하위로 겹친다. 이제 이후 변경 전 기존 상위 결과가 자신의 기록과 일치하는지 확인하고 디렉터리 descriptor를 유지한다. 최종 시점에는 기존 기준에 실제 게시한 하위 결과만 합쳐 예상 내용·권한·ACL·확장 속성·생성 시각·소유 UID/GID를 만든다. 실제 트리가 예상값과 완전히 같고 원래 디렉터리임이 확인될 때만 하위 기록을 상위 기록에 통합한다.

staging 생성·게시·정리는 부모 수정 시각을 바꾼다. 실행기는 정리 후 열린 부모 descriptor로 관측한 수정 시각과 identity를 기록한다. 이 자체 변경 근거가 있는 디렉터리만 예상 시각을 갱신하며, 현재 트리를 무조건 새 기준으로 사용하거나 시각 검사를 생략하지 않는다. 근거가 없거나 외부 변경·불명 메타데이터가 있으면 기존 기록을 보존해 보수적으로 처리한다. 통합 처리는 배경 작업에서 수행한다.

통합된 상위 기록에도 각 하위 결과의 identity 경계를 유지한다. 내용·메타데이터를 그대로 복제한 다른 파일로 바꿔도 해당 결과를 삭제하지 않는다. 통합 기록은 `tree-v1|` identity 표식과 필수 하위 경계를 사용한다. 새 형식을 이해하지 못하는 기존 identity matcher는 이 기록을 승인하지 않으므로 보존한다. 구버전 설치 앱 자체를 실행한 수용 검증을 뜻하지 않는다. 기존 기록은 새 필드가 없어도 읽으며, 소유권 baseline이 없는 기록은 통합 대상으로 승격하지 않는다.

Undo 메타데이터에는 대상에서 관측한 UID/GID를 선택적 필드로 보관한다. 이는 복사 원본의 소유권을 강제로 바꾸거나 대상에 동일 소유권을 강제하는 정책이 아니다. 새 기록에서 관측 가능한 소유권 변경을 추가로 검사한다. 병합의 게시 identity도 기존 CopyEngine의 열린 handle 경로로 확정해 경로 기반 inode를 쓰는 파일 시스템의 변경 감지 경로를 재사용한다. 실제 SMB 수용은 별도로 남아 있다.

기존 같은 이름 폴더 회귀는 Undo 기록 한 개·전체 복원·대상 폴더 제거를 요구하도록 강화했다. 새 시험은 외부 내용·추가 파일·부모/하위 수정 시각·xattr·권한·ACL·그룹 변경을 변경 전 기준 수집 전/후에 주입한다. 세 원본의 중첩 소유 관계·저널 재읽기, 내용/메타데이터가 같은 하위 파일의 identity 교체, 자체 날짜 근거 누락, 잘못된 경계 형식도 검사한다.

DEBUG UI는 별도 임시 fixture에서 두 원본을 실제로 병합한 뒤 브라우저의 Undo 메뉴를 검증하고 확인 시트를 승인한다. 완료 시트의 ‘복사 실행 취소 완료’, 대상 폴더 제거, 두 원본 내용 보존, Undo 저널 소진을 확인한다. [소스·바이너리·보고서 해시와 네 조합 시트 캡처](overlapping-undo-verification.json). 자체 AppKit 동작 검증이며 물리 키보드·VoiceOver 검증을 대신하지 않는다.

실제 볼륨의 전용 시험은 APFS·대소문자 APFS·exFAT·FAT32·HFS+ 각각의 중첩 병합·한 번의 전체 Undo를 통과했다. 기존 시험과 함께 실제 볼륨 시험 8개 및 네 조합의 파일 작업 UI 각각 83개가 통과했다. 새 시험이 명시적으로 환경 fixture를 요구하므로 일반 Swift 실행은 전체 367개 중 성공 348개·환경 건너뜀 19개로 보고한다. 제한 실행기 10개도 통과했다. 새 원격 수용·Intel ACL 계정 규칙 실패 조사·이동 선택 전체 집계·메모리 안정성·최신 소스 장시간·정식 서명·공증은 남아 있다. 인증서와 공증 프로필은 사용자 준비 중이다.

최종 Debug·일반 Release 빌드와 Xcode 프로젝트 생성 후 차이 없음을 확인했다. 전체 AppKit은 네 조합 각각 283개를 통과했다. 고정 Debug SHA-256은 `f47dc26002d8aba9a5214a74fad35d6d9bc6e0aef1a26a2976b9eea7536ef1ed`이다.
