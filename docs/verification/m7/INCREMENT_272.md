# M7 Increment 272 — 교차 볼륨 이동 실패 항목 재시도

덮어쓰기 없이 이동하던 파일이 게시 전에 실패하면 기존 결과 창에서 실패 항목을 재시도할 수 있다. 원본 식별자가 유효하고 임시 복사본의 정리가 끝났을 때 다시 시도할 항목을 등록한다. 재시도 시 원본과 대상 폴더의 식별자를 다시 대조하고 덮어쓰기 없는 원자적 게시를 사용한다. 게시를 시도한 이후의 오류와 기존 파일을 교체하는 이동은 결과 및 복구 경로에 남긴다.

실제 APFS와 대소문자 구분 APFS 볼륨에서 게시 전 임시 파일을 변경해 오류를 주입했다. 원본을 보존하고 임시 복사본을 정리했다. 첫 재시도에서 다른 파일이 대상으로 생기자 양쪽 파일을 보호했고, 충돌이 해소된 뒤 재시도와 실행 취소가 통과했다. 게시 후 외부에서 대상을 교체한 경우에도 원본을 보존했고 재시도 항목을 등록하지 않았다.

Swift 시험 75개와 실제 볼륨 시험 6개가 통과했다. 통합 환경이 없는 12개는 로컬 기본 실행에서 건너뛰었다. SMB 재시도와 교체 후 실패 복구의 UI 동선은 별도로 검증한다.
