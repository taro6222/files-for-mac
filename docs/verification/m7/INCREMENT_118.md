# M7 Increment 118 — 리소스 포크 검증

일반 파일의 검증 스냅샷에 리소스 포크 SHA-256을 추가했다. 리소스 포크는 최대 1 MiB씩 읽으며, 기존 데이터 포크 검사와 같은 중단 신호를 확인한다. 복사와 교차 볼륨 이동은 임시 결과가 원본과 일치해야 최종 경로에 게시한다. 교차 볼륨 이동은 게시 뒤에도 두 파일을 확인한 다음 원본을 제거한다. [macOS 확장 속성 읽기 API](https://developer.apple.com/library/archive/documentation/System/Conceptual/ManPages_iPhoneOS/man2/fgetxattr.2.html)

1 MiB를 넘는 리소스 포크의 마지막 바이트를 변경하는 회귀를 두 단계에서 실행했다. 게시 전 변경은 결과가 최종 경로에 생성되지 않았고 원본이 보존됐다. 게시 직후 변경은 원본과 변경된 대상 모두 보존됐다. 데이터 포크는 두 시험에서 그대로였다.

Swift 테스트 220개가 통과했고, APFS·대소문자 구분 APFS·exFAT의 실제 마운트 검사 4개도 통과했다. 리소스 포크가 있는 파일의 이전 스냅샷에는 새 해시가 없어 실행 취소 확인이 실패할 수 있다. 나머지 확장 속성·ACL·시간 등 게시 전 비교와 미지원 속성 안내는 남아 있다.
