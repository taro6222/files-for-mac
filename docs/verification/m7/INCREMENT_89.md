# M7 Increment 89 — 복사·이동 충돌 정보 비교

복사·이동 정책 창에 원본과 기존 대상의 경로, 종류, 일반 파일 크기, 수정일을 표시한다. 심볼릭 링크는 링크 자체를 확인한다. 비교 영역을 스크롤하거나 텍스트를 선택할 수 있고, 접근성 이름을 제공한다.

정보 조회를 백그라운드에서 실행하며 창을 닫으면 비교 결과 갱신을 취소한다. 비교는 먼저 12개 원본을 확인하고 목록이 그보다 길면 확인 범위를 표시한다. 실제 작업을 실행할 때는 기존 엔진이 전체 항목을 다시 검사한다.

Apple Silicon macOS 27.2에서 한국어·영어와 밝게·어둡게 조합별 파일 작업 검사 56개를 통과했다. 두 충돌 창의 원본·대상 경로와 크기 표시, 읽기 전용 비교 영역, 건너뛰기 단축키와 원본·대상 보존을 확인했다. 두 파일의 콘텐츠 미리보기와 Windows 실행 화면 대조는 UI-11 검증에 남아 있다.
