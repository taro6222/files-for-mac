# M7 Increment 29 — 일반 아이콘의 확장자 조회 캐시

미리보기를 끈 파일 목록에서 일반 아이콘을 표시할 때, 같은 확장자를 매번 Uniform Type Identifier로 해석하던 호출을 줄였다. 확장자별 아이콘은 128개 제한의 메모리 캐시에 보관하며 폴더·패키지와 사용자 파일별 아이콘은 기존 경로를 이용한다. 캐시를 비우면 확장자별 아이콘과 타입별 아이콘도 다시 조회한다.

60Hz 화면의 10,000항목 스크롤 캡처에서 창 갱신 간격 p95는 33.47ms였다. 직전 화면 동기화 시험은 33.58ms였으며, 각 측정은 한 번이므로 캐시 변경의 프레임 개선 효과를 판정할 수 없다. 16.7ms 목표는 계속 확인해야 한다. [측정값](scroll-icon-cache-60hz.json)

한국어·영어와 밝게·어둡게 조합별 AppKit 파일 작업 검사 39개를 통과했다. 같은 확장자를 다시 표시할 때 타입 조회를 생략하고 캐시를 비운 뒤 다시 조회하는 동작을 확인했다.
