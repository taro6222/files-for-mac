# M7 Increment 180 — 이전 프리뷰 교체와 복원의 CPU 검증

수동 macOS CI 실행의 `verify_upgrade` 옵션을 켜면 두 러너에서 이전 프리뷰 소스 `ff22ecb8d36ca0171bca62989b7e6ae42cfcd588`와 현재 소스를 각각 유니버설 DMG로 빌드한다. 최초 설치, 손상된 교체본 거부 후 재실행, 교체, 복원의 모든 실행에서 지정 폴더 창과 실제 프로세스의 CPU 아키텍처를 확인한다. 시험은 격리된 앱 번들과 설정 도메인을 사용한다.

Apple Silicon macOS 27.2에서 이전·현재 로컬 DMG로 네 단계를 확인했다. 시작 위치·즐겨찾기·확장자 설정·사용자 파일을 대조했고, 구형 탭이 새 작업 공간 형식으로 저장된 후 이전 프리뷰에서도 열렸다. 환경 지정과 실제 macOS 버전이 다르면 실행 전에 실패한다.

정식 서명·공증된 배포 이미지의 업데이트 검증은 출시 검증 현황에서 추적한다.
