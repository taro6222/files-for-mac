# M7 Increment 274 — Finder 설치본과 실행 창 대조

다운로드한 정식 DMG의 기존 검증에 선택형 `--installed-app` 검사를 추가했다. Finder에서 처음 실행한 앱의 브라우저 창을 기록할 때 다른 경로에서 실행 중인 복사본이나 다른 빌드가 결과에 섞이는 것을 방지한다. 앱 두 슬라이스의 코드 서명 해시를 DMG 내부와 대조하고, 설치 경로에서 실행 중인 프로세스의 네이티브 아키텍처와 화면에 표시된 브라우저 창을 확인한다. 사용 절차는 [정식 DMG 검증](INCREMENT_21.md)에 기록했다.

## 검증

- Sonoma 14.8.7(23J520) Apple Silicon VM에서 프리뷰 0.1.0(1)을 복사해 Launch Services로 열었다. 브라우저 창과 arm64 프로세스를 확인했고 앱에서 arm64·x86_64 서명 해시를 읽었다.
- 같은 앱의 열지 않은 복사본을 지정했을 때 경로 검사가 실패했다. 실행 중인 arm64 앱에 x86_64를 요구했을 때도 실패했다.
- 같은 VM에서 기존 프리뷰 시작 검사를 Launch Services로 20회 실행했다. 첫 브라우저 창까지 p95 274ms, 최대 289ms였다.
- 올바른 매니페스트와 정식 파일명을 가진 서명 없는 프리뷰 이미지는 Developer ID 검사에서 거부됐다. 잘못된 설치 경로와 셸·Python 구문도 점검했다.

정식 출시 검증에는 프로젝트 인증서와 공증 프로필로 생성한 DMG가 필요하다. 깨끗한 환경에서 배포본을 다운로드한 뒤 Finder로 설치해 최초 실행 확인 창과 설치본 검증 출력을 기록해야 한다.
