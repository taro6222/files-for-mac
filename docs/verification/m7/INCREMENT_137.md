# M7 Increment 137 — 장시간 시험 결과의 빌드 식별

장시간 시험 스크립트는 종료 시 소스 커밋, 실행 파일 SHA-256, 환경, 요청한 부하와 시간, 프로세스 종료 코드 및 앱 보고서를 `result.json`에 함께 기록한다. 완료 판정에는 종료 코드 0, 요청과 일치하는 부하·시간, 경과 시간 충족, 완료 상태, 사이클과 표본이 필요하다. 원본 보고서와 종료 코드도 별도로 보관한다.

정상 결과, 시간 미충족, 실행 중 보고서, 부하 불일치, 손상된 JSON, 보고서 없이 프로세스가 실패한 경우를 검증했다. 완료 판정은 시험의 종료를 의미한다. 메모리 안정성은 표본의 추세와 함께 판단한다.

현재 소스 `7e5d11c`의 최적화 빌드에서 전체 부하 45초 시험이 종료 코드 0과 완료 상태를 기록했다. 실행 파일 체크섬을 별도로 대조했다. [45초 시험 결과](release-soak-7e5d11c-smoke.json)

기존 8시간 시험은 닫힌 창 정리를 적용한 별도 QA 바이너리에서 계속 실행 중이다. 기존 바이너리의 SHA-256은 `bbafd86dbf836fc736befc13311b106292bc6ff6b0b3a59659d9d8360ac975d7`로 확인했다. 기존 실행에는 새 결과 형식이 적용되지 않는다.
