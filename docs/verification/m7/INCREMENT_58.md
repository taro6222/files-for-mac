# M7 Increment 58 — 최근 위치 갱신과 장시간 시험 경로

폴더 방문 기록이 바뀌면 열린 홈 화면의 최근 위치를 갱신한다. 파일 목록을 표시하는 창과 앱의 외관 설정은 최근 위치 알림을 건너뛴다. 기존 전체 변경 구독과 설정 가져오기는 기존 방식대로 동작한다. 회귀 시험에는 최근 위치의 중복 방문, 지우기, 구독 해제와 일반 설정 변경을 포함했다.

장시간 시험은 브라우저와 기대 경로에 동일한 URL 표준화를 적용한다. 변경 전 바이너리는 `/private/tmp`에서 감시가 활성화되고 129개 행이 로딩된 뒤에도 실패했다. 존재하는 폴더를 가리키는 `/private/tmp` 경로가 Foundation 표준화에서 `/tmp`로 바뀌는 것을 확인했다.

Apple Silicon macOS 27.2에서 Swift 시험 213개가 통과했다. 기본 Swift 링크가 파일 속성 조회에서 지연되어 컴파일한 SwiftPM 테스트 오브젝트를 직접 링크하고 `swift test --skip-build`로 실행했다.

변경 후 `/private/tmp` 시험은 91.2초에 29사이클을 완료했다. RSS는 첫 표본 138.9 MiB, 최대 154.9 MiB, 마지막 149.4 MiB였다. 작업 폴더에서 실행 중인 이전 8시간 후보의 스택 표본에서는 FSEvents가 상위 폴더를 여는 동안 대기 중이었다. 예비 시험은 경로 비교와 실제 파일 생성·삭제 반영을 검증했으며, 작업 폴더에서의 지연과 8시간 메모리 추세는 추가 검증이 필요하다.
