# M7 Increment 259 — 설치한 macOS 앱의 PNG·PDF 미리보기

Apple Silicon macOS 27.2 (26B123)에서 소스 `93af5b7`의 [유니버설 프리뷰](PREVIEW_0.1.0.md)를 격리한 앱으로 열었다. 한국어·어두운 테마에서 실제 앱 창의 정보 패널로 시험했다.

- PDF를 선택하자 오른쪽 미리보기 패널에 빨간색 배경과 흰색 본문 `PDF Preview Fixture`가 나타났다. 접근성 트리에서도 PDF 페이지의 본문이 확인됐다.
- 같은 폴더에서 PNG를 선택하자 패널의 파일명과 접근성 설명이 갱신됐다. 왼쪽은 초록색, 오른쪽은 자홍색인 그림이 표시됐다.

이전 [AppKit 뷰 캡처](INCREMENT_230.md)에서 확인하지 못한 두 형식의 기본 렌더링을 실제 창에서 확인했다. 큰 파일, 손상된 파일, 암호로 보호된 PDF 및 Windows의 같은 형식과의 화면 대조는 열린 항목이다.
