# M7 Increment 66 — 필요한 때만 파일 목록의 Git 정보 조회

Git 상태와 커밋 열을 모두 숨긴 창에서는 폴더를 열거나 새로고침할 때 Git 조회를 시작하지 않는다. 열을 켜면 현재 폴더의 정보를 조회하고 기존 셀에 표시한다. 마지막 Git 열을 끄면 조회를 취소하고 해당 창의 Git 정보를 지운다. 독립 Git 상태 창과 동기화 명령은 기존 경로를 사용한다.

Apple Silicon macOS 27.2에서 영어·어두운 테마의 AppKit 검사 222개가 통과했다. 임시 Git 사본에서 숨겨진 열의 조회 생략, 열 활성화 뒤 상태·커밋 표시, 기존 SHA 셀 유지, 모든 열을 숨긴 뒤 조회 상태 정리를 확인했다. 장시간 메모리 효과는 추가로 검증한다.
