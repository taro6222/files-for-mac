# M7 Increment 170 — FTP·FTPS·SFTP 루프백 재검증

Apple Silicon macOS 27.2 (26B123)에서 현재 커밋 `ff22ecb8d36ca0171bca62989b7e6ae42cfcd588`의 FilesCore·Tests·Package.swift와 기존 테스트 러너를 컴파일한 소스가 일치함을 Git으로 확인했다. 기존 스크립트의 루프백 서버·임시 인증서·SSH 키 설정으로 Swift Testing 통합 검사 세 개를 실행했다.

| 프로토콜 | 확인한 동작 |
|---|---|
| FTP | 유니코드 목록, 다운로드한 바이트, 이름 변경의 기존 대상 처리, 임시 파일 정리 |
| FTPS | 신뢰 CA로 목록과 다운로드, 신뢰되지 않은 인증서 및 호스트명 불일치 거부 |
| SFTP | OpenSSH 개인 키 인증, 유니코드 목록과 다운로드, 이름 변경 시험, 호스트 키 불일치 거부, 256 MiB 전송 취소와 임시 파일 정리 |

세 통합 검사가 모두 통과했다. 외부 서버와 실제 클라우드 계정, SMB 마운트의 검증은 남아 있다.
