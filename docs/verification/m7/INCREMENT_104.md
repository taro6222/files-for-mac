# M7 Increment 104 — 화면 구조 대조와 테마 검증

Windows Files v4.2.9의 고정 소스에서 충돌, 일괄 이름 변경, 압축, 연결, Git, 팔레트, 설정, 휴지통, 사용자 지정 및 접근 오류를 확인했다. macOS 캡처와 AppKit 동작을 함께 검토해 [UI-01~20 구조 대조](../../reference/UI_BASELINE.md)에 기록했다. 동일한 조건에서 Windows 실행 화면을 캡처하고 상태별로 대조하는 작업은 남아 있다.

밝은 테마 시험에서 공유 설정을 변경하면 앱의 일반 설정 관찰자가 시험용 테마를 덮어썼다. 시험 모드에서는 이 관찰자를 설치하지 않고, 각 캡처의 실제 AppKit 테마가 요청한 테마와 일치하는지 검사한다. Apple Silicon macOS 27.2 (26B123)에서 영어·밝은 테마의 연결, 팔레트, 일반 설정과 툴바 창을 다시 렌더링해 밝은 목록과 읽을 수 있는 레이블을 확인했다.

Swift 테스트 216개와 한국어·영어 × 밝게·어둡게의 전체 AppKit 검사 각 254개를 통과했다.
