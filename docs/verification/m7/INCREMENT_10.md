# M7 Increment 10 — 로컬 프리뷰 설치·교체·복원

`scripts/verify-preview-install.py`에 이전 프리뷰와 후보의 DMG 경로를 순서대로 전달한다. 각 DMG와 같은 위치에 `.sha256` 파일이 필요하다. 로그인된 macOS GUI 세션에서 두 DMG를 읽기 전용으로 마운트한다. 실행은 별도 홈과 고유 설정 도메인을 사용하는 검증용 복사본에서 수행한다. 복사하기 전 원본 번들의 두 아키텍처 서명을 검사하고, 복사본의 번들 ID를 바꾼 뒤 ad-hoc으로 다시 서명한다.

1. 이전 앱을 테스트용 Applications 폴더에 복사한다. 임시 폴더를 시작 위치로 저장하고 실제 앱이 해당 폴더의 제목으로 창을 띄우는지 확인한다.
2. 후보 앱을 준비 경로에 복사하고 Info.plist를 손상시킨다. 서명 검사에서 거부되는지, 기존 실행 파일의 해시가 그대로인지, 기존 앱이 저장된 위치로 다시 실행되는지 확인한다.
3. 정상 후보로 교체한 뒤 실행 파일 해시와 버전, 저장된 시작 위치가 일치하는지 검사한다.
4. 이전 앱으로 되돌린 뒤에도 창이 같은 위치에서 열리고 이전 실행 파일과 사용자 파일이 그대로 있는지 확인한다.

2026-11-14 Apple Silicon macOS 27.2 (26B123)에서 네 경로 모두 통과했다. 이전 DMG는 `a06b9ac20ae9675b923327b575b1c84ef29000ba`, 후보는 `0d8122ba10815ee418c7a8c3519fd57cf2622ca8`의 프리뷰다. 두 번들의 버전 표기 0.1.0 (1)이 같아서 서로 다른 실행 파일 해시로 실제 교체와 복원을 확인했다. [실행 보고서](preview-install-local.json)

창 표시는 이 실행에서 관찰한 시점이다. 콜드 시작 성능 예산, 서로 다른 배포 버전의 설정 마이그레이션, 다운로드 검역·Gatekeeper, 깨끗한 Mac에서의 재설치는 각각 정식 이미지로 검증해야 한다.
