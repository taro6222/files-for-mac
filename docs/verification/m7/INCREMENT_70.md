# M7 Increment 70 — 손상된 분할 세션에서 시작 복구

저장된 분할 세션을 읽을 때 창 영역이 하나 또는 두 개이며 식별자가 고유한지 검사한다. 빈 영역 배열이나 중복·초과 영역을 읽으면 세션 저장소가 기존 복구 경로를 사용한다. 활성 영역 ID가 유효하지 않으면 첫 영역을 선택하고, 분할 비율은 기존 범위로 조정한다.

Apple Silicon macOS 27.2에서 Swift 시험 213개가 통과했다. 기존 세션의 왕복과 손상된 JSON 검사에 영역 개수, 중복 ID, 유효하지 않은 활성 영역 및 분할 비율을 추가했다. 같은 빌드의 격리 앱은 영역이 없는 세션을 읽을 때 구형 탭이 있으면 그 폴더를, 없으면 설정된 시작 폴더를 실제 창에서 열었다.
