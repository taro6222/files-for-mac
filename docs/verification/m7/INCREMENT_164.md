# M7 Increment 164 — 폴더 권한 일괄 적용 중단

폴더의 POSIX 권한, 확장 ACL, 그룹·사용자 소유권을 하위 항목에 적용하는 동안 권한 시트에서 중단을 요청할 수 있다. 진행 중인 파일 시스템 호출이 끝나면 다음 항목을 변경하기 전에 중단 여부를 확인한다. 변경한 항목은 유지되며 시트는 중단 여부와 적용·건너뜀·실패 건수를 표시한다.

Swift 테스트 241개가 통과했다. APFS에서 시작 전 중단 요청을 받은 POSIX·ACL·소유권 일괄 적용이 모두 0건을 보고하고 하위 파일의 권한을 유지했다. SwiftPM이 컴파일한 객체를 Swift Testing 런타임에 직접 링크해 실행했다.

한국어·영어와 밝은·어두운 테마 네 조합에서 각 AppKit 검사 269개가 통과했다. 저장 직후 중단하면 파일 모드가 유지됐으며, 같은 폴더에 다시 적용하면 파일 모드가 변경됐다. 대규모 폴더에서 일부 항목을 처리한 상태의 수동 중단은 별도 검증 항목이다.
