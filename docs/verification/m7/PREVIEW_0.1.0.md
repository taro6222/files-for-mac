# Files for Mac 0.1.0 개발 프리뷰

## 설치 이미지

- 앱 소스 `e40f23adcc772741ae99d05ef65987cc4ce1ad71`, Apple Silicon·Intel 슬라이스, macOS 14.0 배포 대상.
- 로컬 경로 `build/Files-macOS-preview.dmg`. SHA-256 `280082b455c322aa756abd2e68fc543554f75110066ca811359e6352c5d8c153`.
- DMG 내부 체크섬, SHA-256, 읽기 전용 마운트, 모든 슬라이스의 ad-hoc 서명을 검사했다. Apple Silicon에서 마운트한 이미지를 복사해 격리 경로에서 실행했다. 손상된 교체본은 거부했다. 네 단계에서 지정된 시작 폴더와 다른 저장 탭을 열었다. 교체한 앱을 정상 종료하면 구형 탭이 workspaceSessionV2에 저장됐다. 시험에서 구형 탭 키를 제거한 뒤 이전 프리뷰로 복원해 새 형식의 탭이 열리고 데이터가 유지되는 것을 확인했다. 시작 폴더, 세션 복원 설정, 즐겨찾기, 확장자 표시 설정과 사용자 파일 내용도 각 단계에서 대조했다. 두 앱의 버전 표기는 0.1.0 (1)로 같아서 실행 파일 해시를 대조했다. [설치 검증 결과](preview-install-e40f23a-notes.json) · [이전 프리뷰 기록](preview-install-3357ab6.json)

앱 소스 커밋의 스냅샷과 [갱신된 내장 릴리스 노트](INCREMENT_112.md)로 로컬 임시 경로에서 빌드하고, 같은 환경에서 설치 검증과 읽기 전용 마운트를 수행했다. 검증된 DMG와 체크섬을 프로젝트의 프리뷰 경로에 반영하고 SHA-256을 다시 대조했다.

## 검증

- Apple Silicon macOS 27.2에서 Launch Services로 20회 열고 접근성 메뉴에서 정보 창을 열었다. 공유 OS 캐시에서 정보 창 표시 p95는 523 ms, 최대 863 ms였다. [기동 검증](preview-launch-services-e40f23a-notes.json)
- 같은 소스의 AppKit 회귀 257개를 한국어·영어 × 밝게·어둡게 네 조합에서 각각 통과했다. 테스트용 디버그 앱으로 실행했다.
- 파일 작업은 템플릿, 이동 실행 취소·재실행, 복사 취소, 교체 파일 보호 및 재생성된 APFS 폴더 감시 복구를 포함한다.
- APFS·대소문자 구분 APFS·exFAT, 시스템 휴지통, 루프백 FTP/FTPS/SFTP 증거는 출시 검증 현황에서 추적한다. 이번 소스에는 테스트 프로세스를 강제 종료한 뒤 교차 볼륨의 교체 이동 실행 취소를 재개한 검증이 포함된다. [강제 종료 복구](INCREMENT_54.md)

이전 최적화 QA에서 10,000항목 전체 표시 p95 1.350초, 100,000항목 최대 샘플 RSS 275 MB를 기록했다. [Release 실측](INCREMENT_12.md)

## 포함 기능

- 네이티브 탭·분할 탐색, 상세·그리드·목록·컬럼 및 적응형 보기, 검색, Quick Look, 정보 패널과 Finder 태그.
- 파일 생성·템플릿·복사·이동·충돌 처리·휴지통, 복사·이동 실행 취소와 조건을 충족하는 같은 세션의 이동 재실행.
- ZIP/7z 생성·탐색·추출, RAR 탐색·추출, 클라우드 위치, 원격 연결과 Git 기본 작업.
- 한국어·영어, 시스템·밝게·어둡게, 명령 팔레트, 설정 백업 및 일반 설정 스크롤.

정식 서명·공증, 실제 서비스 환경과 Intel·최소 OS, 시각 비교·접근성 및 장시간 검증은 [출시 검증 현황](RELEASE_GATES.md)에 있다.
