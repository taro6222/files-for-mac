# M7 Increment 83 — 좌우 분할 비율 유지

좌우 분할을 열 때 저장된 비율을 패널 프레임에 적용한다. 분할 영역의 너비가 바뀌면 이전 너비와 기본 패널의 실제 너비로 비율을 계산해 다시 배치한다. 상하 분할은 기존 구분선 배치를 사용한다.

AppKit 검사는 저장값 35%를 적용한 좌우·상하 분할을 각각 새 창에서 복원한다. 실제 비율이 저장값과 1%p 이내인지, 활성 패널과 독립 경로·보기 모드·탐색 기록이 유지되는지 확인한다.

한국어·영어 × 밝게·어둡게에서 AppKit 검사 각 236개가 통과했다. 네 조합에서 좌우·상하 모두 35.0%로 복원됐다. 제목과 툴바 축소 실험은 비율을 개선하지 못해 제외했다. 이 검증은 초기 창 레이아웃으로 인한 크기 변경을 포함한다. 실제 구분선 드래그와 최소 창 너비의 좁은 패널 조작은 별도로 확인해야 한다.
