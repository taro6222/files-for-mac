# M7 Increment 257 — Windows 작업 센터 복사 결과 캡처

Windows 원본 Files v4.2.9에서 공통 파일 `preview.txt`를 선택하고 앱의 복사·붙여넣기 단축키로 `Workshop` 폴더에 복사한다. 대상 경로와 복사본의 SHA-256을 확인한 뒤 작업 센터에서 해당 폴더로 한 항목을 복사했다는 완료 카드를 찾는다. 완료 카드를 지운 뒤 삭제된 카드와 비활성화된 완료 항목 지우기 컨트롤, 양쪽 파일의 SHA-256 보존을 확인한다. 작업 센터의 완료·빈 화면을 PNG와 접근성 트리로 기록한다.

Python 모의 시험에서 복사, 완료 카드, 지우기 전체 경로와 다른 폴더의 완료 카드가 표시됐을 때 실패하는 것을 검증했다. 기존 속성·해시 및 보안·서명 경로, 워크플로 YAML, 대응표 감사도 통과했다. Windows 원본 실행과 전송 중 진행·취소 화면 대조가 남아 있다. [macOS 작업 센터 진행 막대](INCREMENT_255.md)
