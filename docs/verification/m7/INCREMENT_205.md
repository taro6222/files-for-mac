# M7 Increment 205 — 컬럼 보기의 열 너비 조절

컬럼 오른쪽 경계를 드래그하면 해당 컬럼의 너비를 150~620포인트 범위에서 바꿀 수 있다. 경계를 두 번 클릭하면 기본 230포인트로 돌아간다. 각 경계에는 폴더 이름과 너비 값, 증가·감소 접근성 동작이 있다.

상위 경로와 현재 폴더, 하위 폴더의 컬럼에 같은 동작을 적용한다. 너비를 조절해도 해당 경로와 파일 선택은 유지되며 옆 컬럼의 너비도 유지된다. 다시 생성되는 컬럼은 기본 너비로 시작한다.

Apple Silicon macOS 27.2에서 앱을 빌드하고 영어·밝은 테마 AppKit 검사 292개를 통과했다. 실제 컬럼 프레임을 기준으로 80포인트 드래그, 접근성 증가 동작, 최소 너비, 두 번 클릭 초기화와 파일 선택 보존을 확인했다. 한국어·영어와 밝은·어두운 테마 네 조합의 AppKit 파일 작업 검사 각 71개도 통과했다. [너비가 조정된 화면](ui-05-macos-resized-column.png)
