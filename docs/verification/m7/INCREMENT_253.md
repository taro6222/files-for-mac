# M7 Increment 253 — SMB 쓰기 거부 및 세션 재연결 실마운트 결과

macOS 15.8.2 러너에서 임시 Samba 공유를 인증 마운트했고 SMB 3.1.1을 협상했다. 두 실행에서 [일반 복사·이동·교체 및 실행 취소](INCREMENT_242.md)도 다시 통과했다.

- 읽기 전용 공유에서는 기존 파일을 조회했고 새 파일 생성이 거부됐다. FilesCore의 복사와 교체 이동은 오류를 보고했다. 두 로컬 원본과 기존 SMB 대상의 바이트가 같았고 공유에 임시 출력이나 백업이 생기지 않았으며 실행 취소 항목도 등록되지 않았다. 통합 시험 2개 통과. [GitHub Actions](https://github.com/taro6222/files-for-mac/actions/runs/43675410648)
- 서버에서 SMB 세션을 종료하자 기존 마운트 장치 번호를 유지한 채 세션 재연결 횟수가 0에서 1로 늘었다. FilesCore의 폴더 조회에서 서버가 삭제한 항목이 사라졌고 새 항목의 내용이 일치했다. 읽기 전용 공유를 포함해 통합 시험 3개 통과. [GitHub Actions](https://github.com/taro6222/files-for-mac/actions/runs/43675604203)

전송 중 연결 중단, 장기 단절, 연결된 상태에서의 서버 권한 변경, SMB 생성·접근 시간의 보존 검증은 남아 있다.
