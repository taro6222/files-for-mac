# M7 Increment 72 — 로딩 버튼의 이미지 재사용

브라우저는 새로고침과 로딩 중단에 쓰는 두 시스템 이미지를 재사용한다. 로딩 상태가 바뀔 때 버튼의 이미지, 도움말, 접근성 레이블을 갱신한다.

Apple Silicon macOS 27.2에서 영어·어두운 테마의 AppKit 검사 224개가 통과했다. 같은 로딩 상태에서 다시 그려도 이미지 객체가 유지되고, 로딩을 중단하면 새로고침 이미지와 접근성 레이블이 돌아오는 것을 확인했다.

이 변경 전 후보 `fc10112`의 8시간 시험은 494사이클, 26분 42초에 최대 RSS 185.1 MiB와 최대 물리 메모리 119.0 MiB를 기록했다. 이전 후보들의 비슷한 사이클에서 RSS는 약 175–201 MiB였다. 이 표본은 여러 배경 작업과 시점의 영향을 받으며, 최신 변경의 장시간 효과와 출시 기준은 계속 검증한다.
