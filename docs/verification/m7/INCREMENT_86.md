# M7 Increment 86 — 탭 드롭으로 분할

창 헤더의 탭 드래그 핸들을 파일 영역 가장자리로 끌면 해당 방향에 분할 패널을 연다. 기본 macOS 탭 막대는 그대로 사용한다. 왼쪽·위쪽에 놓으면 끌어온 탭이 첫 패널에, 오른쪽·아래쪽에 놓으면 두 번째 패널에 들어간다. 놓기 전에 해당 가장자리를 강조한다. [원본 Files의 분할 보기 동작](https://files.community/docs/features/dual-pane)

대상에는 두 탭의 위치·탐색 이력·보기 모드를 적용하고 끌어온 쪽에 초점을 둔다. 다른 탭에서 가져올 경우 분할을 만든 뒤 원본 탭을 닫는다. 같은 탭을 끌면 현재 탭에서 분할한다. 이미 분할된 창이나 시트가 열린 창은 드롭을 거부한다.

AppKit 검증은 네 가장자리 선택과 중앙 거부, 드롭을 적용한 뒤 방향·패널 순서·활성 패널·끌어온 탭의 탐색 이력 및 보기 모드를 검사한다. 포인터로 실제 드래그해 AppKit이 드롭 대상으로 연결하는 구간과 원본 Windows 실행 화면 대조는 남아 있다.

한국어·영어 × 밝게·어둡게의 네 조합에서 AppKit 검사 각 245개가 통과했다.
