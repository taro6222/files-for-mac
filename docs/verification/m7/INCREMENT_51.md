# M7 Increment 51 — 저널 갱신 전 중단된 같은 볼륨 실행 취소

같은 볼륨의 교체 이동 실행 취소에서 원래 위치로 항목을 돌려놓은 뒤 저널이 아직 갱신되지 않은 경우를 처리한다. 원래 위치의 항목이 이동 기록의 식별 정보와 기록된 내용에 일치하면 백업 복원만 재시도한다. 대상 경로가 점유되면 충돌로 남기고 기존 항목을 보존한다.

원래 위치로 실제 이름 변경을 수행한 뒤 이전 저널을 다시 읽고, 대상 경로가 비어 있는 경우와 외부 파일이 다시 생긴 경우를 검증했다. 프로세스 강제 종료 대신 파일 시스템과 저널의 중단 상태를 재현했다. 파일 식별자가 달라지는 교차 볼륨 복사, 전원 차단, 실제 SMB는 별도 검증이 필요하다.

Apple Silicon macOS 27.2 (26B123)에서 Swift 시험 209개를 통과했다.
