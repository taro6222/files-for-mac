# M7 Increment 148 — 같은 볼륨 이동의 충돌 보호

같은 볼륨의 일반 이동과 실행 취소에서 원본과 대상의 부모 디렉터리를 연 뒤 기존 비덮어쓰기 게시 경로를 사용한다. 게시 직전에 두 부모와 이동할 항목의 식별자를 대조한다. 원자적 이름 변경을 지원하지 않는 파일 시스템에서는 기존 호환 경로의 대상 존재 검사와 Foundation 이동을 사용한다.

시험은 이동을 확정하기 직전에 대상에 새 파일을 만든다. 실행 취소 단계에서는 원래 경로에 일반 파일 또는 끊어진 심볼릭 링크를 만든다. 충돌 후 양쪽을 대조하고, 충돌이 해소되면 같은 저널로 실행 취소를 재개한다.

전체 Swift 테스트 230개, 실제 마운트 검사 6개, 강제 종료 복구 두 조합이 통과했다. 파일·끊어진 링크와 같은 볼륨·교차 볼륨을 조합한 실행 취소 시험 네 경우가 통과했다.
