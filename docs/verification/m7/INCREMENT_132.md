# M7 Increment 132 — 검색 회귀 시험 안정화

전체 테스트에서 검색 결과가 150 ms 안에 도착한다고 가정하던 시험이 간헐적으로 실패했다. 시험이 직접 제어하는 검색 스트림을 사용해 첫 검색의 활성 상태를 확인한 뒤 다음 검색을 시작하고, 이전 검색의 늦은 결과를 보낸다. 새 검색이 종료된 뒤 결과와 건너뛴 위치 수를 대조한다. 취소 후 결과가 비고 취소 상태가 표시되는지도 확인한다. 상태 대기의 상한은 시험이 멈추지 않게 하기 위한 실패 조건이다.

빌드 직후 한 번과 같은 빌드의 재실행 다섯 번에서 전체 Swift 테스트 229개가 모두 통과했다.
