# 369단계 — 압축 편집 미구현 확인과 원격 빌드 결과

## F23 감사

고정 원본 99951c6의 ZipStorageFile/ZipStorageFolder에서 내부 파일 추가·폴더 생성·파일/폴더 이름 변경·하위 트리 삭제를 확인했다. 현재 macOS 공통 capability의 update는 세 포맷 모두 false이고 해당 편집 API/화면 흐름이 없다. 일반 파일 문맥에서 구현된 Rename/Delete 명령이나 인벤토리 378건 분류를 이 문맥의 동작 완료로 해석하지 않는다.

이 기능은 기존 F23과 MACOS_DESIGN의 임시 아카이브 교체 요구이며 새 범위가 아니다. [구현 계획과 필수 수용](../../ARCHIVE_EDITING_PLAN.md)에 원본의 실제 메서드/행, FD 기반 공통 SDK, 내용·metadata·암호 보존, 안전한 교체/복구·Undo 및 UI 기준을 연결했다. 미구현을 다음 버전으로 미루거나 capability를 켜지 않았다. 구조 감사는 통과했지만 이 감사가 기능 동작을 증명하지 않음을 명시한다.

현재 실제 제품 7z.so에서 ZIP과 7z reader 인스턴스 각각의 IOutArchive QueryInterface가 성공했다. 인스턴스는 Release했고 파일 수정/GUI 실행은 없었다. 기존 라이브러리를 재사용할 수 있다는 근거이며 실제 편집·암호·원본 보호가 구현됐다는 뜻은 아니다.
