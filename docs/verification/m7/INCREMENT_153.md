# M7 Increment 153 — macOS 파일 권한 편집

파일 또는 폴더 하나의 속성에서 권한 시트를 열어 소유자·그룹·기타의 읽기·쓰기·실행 또는 탐색 비트를 편집한다. 같은 시트에서 확장 ACL을 읽을 수 있다. POSIX 특수 비트는 저장 요청에 포함하며, 저장 뒤 운영체제가 적용한 권한을 확인한다. 편집은 선택한 항목 한 건에 적용된다.

편집을 저장할 때 심볼릭 링크 역참조 없이 연 디스크립터에서 볼륨·inode·생성 시간, POSIX 모드 및 ACL을 다시 확인한다. 관찰한 상태가 바뀌었으면 저장을 거부한다. 파일 디스크립터에 권한을 적용하므로 경로에 다른 항목이 만들어져도 그 항목에 쓰지 않는다.

Swift 테스트 232개가 통과했다. APFS에서 일반 파일과 폴더의 모드 변경, 기존 ACL과 폴더의 sticky bit 보존, ACL만 외부에서 바뀐 경우의 거부, 오래된 POSIX 모드와 다른 inode 및 심볼릭 링크 거부를 확인했다. SwiftPM이 생성한 테스트 객체를 Swift Testing 런타임에 직접 링크해 실행했다.

[원본 보안 화면](https://github.com/files-community/Files/blob/99951c66928c4da714da8b1dd46039421182cbab/src/Files.App/Views/Properties/SecurityPage.xaml)의 macOS 대응이다. 확장 ACL 항목의 추가·편집, 소유자 변경, 하위 항목 일괄 적용, Windows 실행 화면 대조와 VoiceOver 음성 출력 확인이 남아 있다.

Apple Silicon macOS 27.2에서 네 언어·테마 조합의 AppKit 검사 261개가 각각 통과했다. 권한 시트가 읽기·쓰기·실행 체크박스의 접근성 이름을 제공하고, 저장 후 속성 창과 파일 시스템의 권한이 일치함을 확인했다. 기능 인벤토리 378건의 구조 감사도 통과했다.
