# M7 Increment 161 — 폴더 하위 항목의 확장 ACL

폴더의 권한 시트에서 ACL 편집과 **하위 파일과 폴더에도 적용**을 선택하면 편집한 ACL로 같은 볼륨 안의 항목과 선택한 폴더의 ACL을 교체한다. 시트에 교체 범위와 처리 건수가 표시된다. 빈 편집기로 저장하면 대상의 ACL을 지운다.

기존 POSIX 일괄 적용의 파일 디스크립터 순회를 사용한다. 심볼릭·하드 링크, 특수 파일, 다른 볼륨과 열거 후 inode가 바뀐 항목은 건너뛴다. 먼저 폴더의 기존 권한을 확인하고 ACL을 한 번 파싱한 뒤, 적용한 항목의 ACL을 다시 읽는다. 소유권 일괄 적용은 남아 있다.

Swift 테스트 239개가 통과했다. APFS에서 기존 ACL 교체와 삭제, POSIX 모드와 링크 대상 보존, 기존 폴더 권한이 바뀐 스냅샷 거부를 확인했다. SwiftPM이 컴파일한 시험 객체를 Swift Testing 런타임에 직접 링크해 실행했다.

한국어·영어와 밝은·어두운 테마 네 조합에서 각각 AppKit 검사 267개가 통과했다. 권한 시트에서 일괄 적용을 선택하고 APFS 하위 파일에 예상 ACL이 있는지 확인했다.
