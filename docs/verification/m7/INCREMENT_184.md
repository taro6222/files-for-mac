# M7 Increment 184 — 홈 네트워크 위치 설정 분리

홈의 네트워크 위치를 별도 펼침 영역으로 제공한다. 일반 설정과 탐색 옵션에서 네트워크 위치의 표시를 바꿀 수 있다. 접기와 숨기기는 로컬 드라이브의 상태에 영향을 주지 않는다. 펼친 상태에서 마운트된 공유가 없으면 빈 상태를 표시한다.

새 설정의 네트워크 섹션은 표시하며 접힌 상태에서 시작한다. 기존 로컬 설정의 드라이브 선택값과 기존 설정 내보내기 파일은 네트워크 값이 없으면 공유하던 드라이브 상태를 이관한다. 새 내보내기 파일에는 두 영역의 상태가 각각 저장된다.

Apple Silicon macOS 27.2에서 설정 초기값, 재실행, 이전 파일 가져오기와 새 설정 내보내기 왕복의 Swift 회귀를 통과했다. AppKit 파일 작업 검증은 한국어·영어와 밝은·어두운 테마 네 조합에서 각각 68개 검사에 통과했다. 홈 키보드 탐색에서 네트워크 헤더와 공유에 도달하고, 공유를 열어 파일 목록으로 초점을 옮겼다. 드라이브와 네트워크의 숨김·접기 독립성을 시험 볼륨으로 확인했다. 영어·밝은 테마의 전체 AppKit 검사 270개도 통과했다. 실제 SMB 서버 파일 작업은 출시 검증표에서 추적한다.
