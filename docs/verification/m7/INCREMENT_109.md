# M7 Increment 109 — Git SSH 에이전트 인증

Apple Silicon macOS 27.2 (26B123)에서 `92ae7cb`의 Git 제공자를 실제 OpenSSH 서버에 연결했다. 서버는 루프백에만 바인딩했고 임시 bare 저장소, 호스트 키, 클라이언트 키, 독립 에이전트 소켓을 사용했다. 클라이언트는 서버의 호스트 키를 고정하고 개인 키 파일 대신 에이전트로 인증했다. 사용자 이름은 SSH 설정에 두었고 URL에는 호스트·포트·경로를 전달했다.

- 제공자로 두 작업 복사본을 clone했다. 첫 복사본의 커밋을 push하고, 두 번째 복사본에서 fetch 이후 한 커밋 뒤처진 상태와 fast-forward pull 이후 파일 내용을 확인했다.
- 독립 에이전트에서 키를 제거한 뒤 clone과 fetch를 다시 실행했다. 두 호출은 종료 코드 128을 반환했다. 실패한 clone의 목적지와 임시 디렉터리는 남지 않았다. 기존 복사본의 HEAD, 인덱스와 파일 내용은 인증 실패 전후가 일치했다.
- Swift 수용 시험 1개가 통과했다. 시험 종료 후 서버와 독립 에이전트를 내리고 생성한 개인 키를 삭제했다.

인증 수용 범위는 이 Mac의 실제 OpenSSH 루프백과 임시 키다. 외부 Git 서비스의 SSH 계정과 HTTPS credential helper는 출시 검증에 남아 있다.
