# M7 Increment 152 — 파일 속성의 해시 계산과 비교

파일 속성 창에서 CRC32, MD5, SHA-1, SHA-256, SHA-384, SHA-512 중 하나를 선택한다. SHA-256이 기본값이다. 붙여넣은 16진수 값과 비교하거나 파일 선택 시트에서 다른 파일을 열어 같은 알고리즘으로 비교할 수 있다. 비교하는 해시값은 대소문자와 앞뒤 공백을 허용한다. 완료, 취소, 오류와 파일 비교 결과를 AppKit 접근성 알림에 전달한다.

일반 파일을 최대 1 MiB씩 읽으며 읽기 사이에 취소를 확인한다. 파일 디스크립터의 실제 유형을 검사해 디렉터리와 FIFO 등 특수 파일을 거부한다. 기존 파일 속성 SHA-256 호출 경로는 유지한다. 파일 이동 검증은 기존 전송 엔진을 사용한다.

[원본 해시 화면](https://github.com/files-community/Files/blob/99951c66928c4da714da8b1dd46039421182cbab/src/Files.App/Views/Properties/HashesPage.xaml)의 알고리즘과 비교 작업을 대조했다. macOS는 팝업에서 한 번에 하나를 선택한다. Windows 실행 화면 대조와 실제 VoiceOver 출력 확인은 남아 있다.

전체 Swift 테스트 231개가 통과했다. 여섯 알고리즘의 알려진 벡터, 1 MiB를 넘는 CRC32 입력과 FIFO 거부를 검증했다. SwiftPM의 테스트 러너 링크가 정체되어, SwiftPM이 컴파일한 테스트 객체를 같은 Swift Testing 프레임워크에 직접 링크해 실행했다.

Apple Silicon macOS 27.2에서 한국어·영어와 밝은·어두운 테마 네 조합의 AppKit 검사 260개가 각각 통과했다. 새 검사에는 붙여넣은 값의 일치·불일치·형식 오류와 다른 파일의 일치·불일치가 포함된다. 기능 인벤토리 378건의 구조 감사도 통과했다.
