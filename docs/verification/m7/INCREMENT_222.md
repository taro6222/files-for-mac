# M7 Increment 222 — 정보 패널 본문 스크롤

정보 패널의 상세·미리보기 탭을 상단에 두고 선택한 항목의 본문을 세로로 스크롤할 수 있게 했다. 긴 파일 경로까지 확인할 수 있고, 선택을 바꾸거나 다중 미리보기에서 다른 항목으로 이동하면 본문이 상단에서 시작한다.

Apple Silicon macOS 27.2의 영어 밝은 테마에서 앱을 빌드하고 AppKit 검사 301개를 통과했다. 깊은 경로에 실제 파일을 만들어 경로 끝이 처음에는 화면 아래에 있고 스크롤 후 표시 범위에 들어오는 것을 확인했다. 다른 항목으로 바꾸면 스크롤이 상단으로 돌아왔고 `preview.txt`의 Quick Look 본문도 계속 표시됐다.
