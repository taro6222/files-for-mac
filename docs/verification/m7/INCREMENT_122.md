# M7 Increment 122 — 전송 중 수정 시간 검증

복사, 폴더 병합, 교차 볼륨 이동과 실행 취소에서 일반 파일과 폴더의 수정 시간을 비교한다. 임시 복사본과 원본을 비교할 때는 파일 시스템의 기록 정밀도를 고려한다. exFAT는 10ms, FAT는 2초, HFS는 1초 미만의 차이를 허용한다. 원본과 게시본을 각자의 이전 상태와 다시 비교할 때는 같은 수정 시간을 요구한다. [FAT와 exFAT 시간 기록 규격](https://learn.microsoft.com/en-us/openspecs/windows_protocols/ms-fsa/4e3695bd-7574-4f24-a223-b4679c065b63)

임시 복사본의 수정 시간만 60초 바꾸면 이동이 중단됐고, 원본의 내용과 수정 시간이 보존됐다. 소수 초 수정 시간이 있는 파일은 APFS·대소문자 구분 APFS·exFAT 마운트에서 이동과 실행 취소에 성공했다. Swift 테스트 224개와 실제 마운트 검사 5개가 통과했다. FAT와 HFS는 이번 마운트 시험 범위 밖이다. 생성·접근 시간과 실행 취소 저널의 확장 메타데이터 비교는 후속 검증으로 추적한다.
