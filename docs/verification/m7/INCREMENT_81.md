# M7 Increment 81 — 분할 보기 초점과 탐색 상태

다른 패널로 초점을 이동하거나 보조 패널을 닫을 때, 기본 패널에서 현재 보이는 상세·그리드·목록·컬럼 보기 또는 홈으로 초점을 전달한다. 기존에는 숨겨진 상세 테이블이 초점 대상으로 지정될 수 있었다.

AppKit에서 보조 패널로 이동했다 돌아온 뒤와 분할을 닫은 뒤 실제 첫 응답자가 기본 그리드 내부인지 확인한다. 좌우·상하 각각에 대해 별도 설정 도메인에 저장한 분할 세션을 새 브라우저 창에서 열고, 방향·활성 패널·패널 ID·폴더·보기 모드·앞뒤 탐색 기록을 비교한다.

Apple Silicon macOS 27.2에서 Swift 테스트 213개와 한국어·영어 × 밝게·어둡게 AppKit 검사 각 236개를 통과했다.

분할 비율 오차는 남아 있다. 높이 제약을 완화한 실험에서도 요청한 35%가 좌우 약 36.4%, 상하 약 49.4%로 복원되어, 해당 제약 변경을 제외했다. 회귀 보고서에 실제 비율을 기록한다. Windows 실행 화면, 탭 드롭 분할과 VoiceOver 검증도 남아 있다. [화면 구조 대조](../../reference/UI_BASELINE.md)
