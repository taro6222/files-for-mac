# M7 Increment 219 — Windows 정보 패널 캡처 경로

공통 폴더에서 `preview.txt`를 선택하고 정보 패널을 연다. 상세 탭에서 파일 이름을 확인하고 미리보기 탭에서 파일에 저장된 본문을 확인한다. 각 상태의 접근성 트리와 PNG를 저장한다. 정보 패널을 닫은 뒤 레이아웃 검사를 이어간다.

고정 Windows 원본의 정보 패널 XAML과 영어 접근성 이름을 확인했다. Python 구문 검사와 모의 접근성 트리 검사에서 상세·미리보기 영역 안에 기대한 텍스트가 표시될 때만 캡처를 승인했다. 후보를 숨기거나 패널 밖에 배치하거나 잘못된 텍스트를 주면 거부했다. Windows 실기 실행과 macOS 화면 대조는 후속 결과로 확인한다. [macOS 정보 패널](INCREMENT_218.md)
