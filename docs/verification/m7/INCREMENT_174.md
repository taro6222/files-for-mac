# M7 Increment 174 — 스트리밍 상세 목록의 기존 행 재사용

폴더 열거가 먼저 표시한 목록 끝에 행을 추가하면 AppKit 표에서도 추가된 행 범위만 삽입한다. 끝부분만 줄었을 때도 해당 범위만 제거한다. 비교에는 행의 파일 메타데이터와 그룹 제목을 포함한다. 정렬이나 메타데이터 변경으로 기존 행이 달라지거나 표시 옵션이 바뀌면 다시 읽는다.

AppKit 회귀에 제어 가능한 두 배치의 스트리밍 목록을 추가했다. 첫 배치에 표시된 파일을 선택하고 두 번째 배치를 전달한 뒤 첫 행의 셀 인스턴스와 선택이 유지되는지 확인한다. Apple Silicon macOS 27.2에서 한국어·영어와 밝은·어두운 테마 네 조합 모두 270개를 통과했다.
