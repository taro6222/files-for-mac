# M7 Increment 103 — 일괄 이름 변경의 사전 검사

일괄 이름 변경의 미리보기에서 실행과 같은 검증을 읽기 전용으로 수행한다. 잘못된 이름, 계획의 중복, 외부 항목과의 충돌 또는 사라진 원본이 있으면 문제 행을 먼저 표시하고 실행을 차단한다. 정상 계획은 실행 직전에 다시 검사한다. 번호 매기기에 숫자가 아닌 값이나 선택 개수만큼 증가시킬 수 없는 시작값을 입력하면 오류를 표시한다.

Swift 회귀에서 교환 가능한 두 항목과 중복 이름, 잘못된 이름, 사라진 원본을 한 미리보기로 검사했다. 미리보기 중 기존 파일 내용과 폴더 목록이 유지됐다. AppKit에서는 잘못된 이름이 표시되고 확인 응답을 보내도 이름 변경 작업을 시작하지 않는지 확인한다.

Swift 테스트 216개와 한국어·영어 × 밝게·어둡게 네 조합의 AppKit 파일 작업 검사 각 68개를 통과했다.
