# M7 Increment 214 — Windows 컬럼 전환 후 클릭 재시도

[Windows 탭 드롭 실행](https://github.com/taro6222/files-for-mac/actions/runs/43663386524)은 그리드 캡처를 저장한 뒤 컬럼 보기로 전환했다. `Alpha`의 접근성 요소를 찾았으나 클릭 명령에서 WinAppDriver가 상태 13과 HTTP 500을 반환해 탭 드롭까지 도달하지 못했다. 진단 트리에는 컬럼의 `Alpha`가 보이는 항목으로 남았다.

보이는 컬럼의 `Alpha`로 클릭 대상을 좁혔다. 클릭 오류가 나면 현재 컬럼과 하위 파일을 다시 읽는다. 아직 열리지 않았으면 새 요소를 찾아 클릭하고, 이미 열렸으면 결과를 사용한다. 실제 오류 트리와 모의 WinAppDriver 응답으로 첫 클릭 실패에서 복구하는 경우, 오류 응답이 왔어도 이미 열린 경우를 확인했다. 실제 Windows에서 검색·탭 드롭 캡처를 재실행한다.
