# M7 Increment 82 — 상하 분할 비율 복원

분할 구분선은 각 패널의 컨테이너 크기를 결정하고, 패널 콘텐츠는 컨테이너에 맞춰 배치한다. 이전에는 패널 자체를 분할 뷰에 넣었고, 콘텐츠의 고정 최소 높이가 저장 비율 적용을 방해했다. 기존 높이는 우선 적용하며 창이 좁거나 낮을 때 콘텐츠 영역이 줄어들 수 있다.

저장 비율 35%를 적용한 상하 분할은 변경 전 49.4%에서 변경 후 35.0%로 복원됐다. AppKit 검사는 상하 분할의 실제 높이 비율을 저장값과 1%p 이내로 비교한다. 같은 시험의 좌우 분할은 한국어 약 36.4%, 영어 약 39.7%였다. 좌우 분할의 비율 오차는 계속 추적한다.

최종 AppKit 빌드에서 한국어·영어 × 밝게·어둡게 검사 각 236개가 통과했다. 네 조합 모두 상하 분할의 실제 비율은 35.0%였다.
