# M7 Increment 84 — 최소 창 너비의 분할 조작

좌우 분할을 저장 비율 35%로 복원한 뒤 AppKit의 구분선 위치 API로 60%까지 옮긴다. 일반 창의 최소 너비로 줄인 뒤 기본 패널의 실제 너비를 다시 측정한다. 보조 패널에서 기본 패널로 전환하고 경로 입력 명령을 실행해, 남아 있는 경로 필드에 편집기가 활성화되는지도 확인한다.

이 검사는 AppKit의 구분선 위치 변경과 창 크기 변경을 재현한다. 포인터 드래그와 보조 패널의 좁은 상태에 대한 조작 검증은 별도로 남아 있다.

한국어·영어 × 밝게·어둡게 AppKit 검사 각 238개를 통과했다. 최소 너비에서 영어는 60.0%, 한국어는 60.03%였고 네 조합에서 기본 패널의 경로 편집기가 활성화됐다.
