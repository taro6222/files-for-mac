# M7 Increment 193 — 상세 보기에서 개별 폴더 크기 조회

Windows Files의 상세 보기에는 폴더별 크기 조회가 있다. macOS의 기본 패널과 분할 패널에도 같은 동작을 추가했다. `폴더 크기 계산` 설정을 꺼 둔 상태에서 크기 열의 `크기 보기`를 누르면 계산 중 상태가 표시된다. 계산을 마치면 숫자를 표시하며 읽기에 실패하면 다시 시도할 수 있다.

선택한 폴더의 하위 일반 파일을 백그라운드에서 합산한다. 심볼릭 링크는 건너뛰며 열거에 실패하거나 조회 중 폴더의 식별 정보가 바뀌면 계산을 실패로 처리한다. 폴더를 새로 읽거나 창을 닫으면 이전 작업을 취소한다. 크기에 따라 정렬된 보기에는 새 값이 반영된다.

Apple Silicon macOS 27.2에서 앱 빌드와 영어·밝은 테마 AppKit 검사 277개를 통과했다. 실제 상세 목록의 버튼을 눌러 계산 중 상태와 21바이트 결과를 확인했다. 전체 폴더 크기 설정을 유지한 채 개별 크기를 조회하는 것도 확인했다. Swift Testing의 폴더 크기 회귀 2개에서 하위 파일, 링크 건너뛰기, 사라지거나 교체된 폴더를 검사했다.

[공통 시험 폴더에서 크기 보기 버튼을 표시한 화면](ui-03-macos-folder-size.png). 버튼 문구의 대비를 개선하기 전 빌드에서 한국어·영어와 밝은·어두운 테마 네 조합의 파일 작업 AppKit 검사도 각각 69개 통과했다.
