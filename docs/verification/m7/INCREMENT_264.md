# M7 Increment 264 — SMB 접근 시각 복원

[SMB 실마운트 재시험](https://github.com/taro6222/files-for-mac/actions/runs/44077240682)에서 통합 시험 4개가 통과했다. macOS 15.8.2의 SMB 3.1.1 마운트에서 APFS 원본과 게시된 복사본의 생성·수정 시각이 일치했다. 접근 시각은 복사 중 읽기가 발생한 시각으로 바뀌었고 별도 파일에는 지정한 접근 시각을 저장할 수 있었다.

파일과 폴더의 접근 시각을 읽기 전에 기록하고 내용 검증 후 복원한다. SMB 대상에는 FILETIME의 100 ns 단위로 저장한다. 이동 시에는 게시된 SMB 경로의 파일 식별자가 달라질 수 있으므로 내용과 속성을 검증한 게시본의 식별자를 사용한다. 접근 시각 복원과 게시본 식별자 재확인 뒤 원본 삭제를 시작한다. 그 전에 오류가 발생하면 원본을 보존하고 검증된 게시본만 정리한다.

실마운트 시험에서 정상 복사·교차 볼륨 이동·APFS로의 이동 실행 취소에서 접근 시각을 대조한다. 로컬 Swift 시험은 74개 통과, 지정 환경이 없는 10개는 건너뛰었다. APFS·대소문자 구분 APFS·exFAT·FAT32·HFS+ 마운트 시험 5개도 통과했다. 이 변경을 포함한 SMB 실마운트 결과는 별도로 확인한다.
