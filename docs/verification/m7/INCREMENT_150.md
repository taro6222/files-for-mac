Apple Silicon macOS 27.2 (26B123)에서 `ade9c5f06097de0f87bfa8675cfe418326f2e525`를 디버그 빌드했다. 한국어·영어와 밝은·어두운 테마를 조합하고, 각 실행에는 독립 환경 설정과 새 검증용 출력 폴더를 사용했다. 검사는 탐색, 파일 작업 명령, Git 패널, Spotlight, 폴더 감시 재연결 및 접근성 속성을 포함한다.

기존 출력 폴더를 재사용한 첫 실행에서는 Git 상태 창과 폴더 감시 검사 다섯 건이 실패했다. 같은 실행 파일을 깨끗한 임시 체크아웃에서 실행하자 이 검사들은 네 조합에서 통과했다. 임시 체크아웃에서는 Spotlight의 소스 파일 내용 검색 두 건이 네 조합에서 실패했다. 두 검사는 실행 당시 작업 디렉터리에 있는 소스 파일의 색인에 의존한다.

원래 작업 디렉터리에서 출력 폴더만 매번 새로 만들어 다시 실행했다. 네 조합에서 각각 258개가 통과했다. [AppKit 검사 원본](appkit-regression-ade9c5f.json) 인벤토리 감사에서 명령 202개, 설정 143개, 화면 33개의 구조와 분류를 확인했다. Windows 실행 화면 대조와 VoiceOver 음성 출력 확인은 출시 검증 항목으로 남아 있다.
