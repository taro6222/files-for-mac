# M7 Increment 07 — 활성 보기 기준 렌더링

- 두 탐색 pane에서 격자·목록은 해당 보기가 표시될 때 데이터와 선택을 갱신한다. 컬럼 보기를 벗어나면 하위 열과 진행 중인 하위 열 조회를 무효화한다. 컬럼의 첫 열은 모델에서 정렬한 순서를 쓰고, 하위 열은 직접 열거한 뒤 정렬한다.
- 그룹화가 꺼진 상세 보기에서는 그룹 데이터를 만들지 않는다. 선택 항목이 없으면 선택 복원을 위해 행을 순회하지 않는다.
- 파일 작업 UI 검증은 각 보기를 실제로 활성화한 상태에서 드래그 데이터와 컨텍스트 명령을 확인한다. 상세 보기에서 파일을 추가한 뒤 격자로 전환하면 새 파일과 선택이 반영되는 경로를 추가했다.

## Release 성능

이전 검증과 같은 Apple Silicon macOS 27.2의 APFS 환경에서 최적화한 QA 빌드로 측정했다. 빈 텍스트 파일, 썸네일 끔, 따뜻한 OS 캐시 조건이다.

| 항목 | 이전 | 변경 후 |
|---|---:|---:|
| 10,000항목 첫 표시 p95 (20회) | 136 ms | 70 ms |
| 10,000항목 전체 표시 p95 (20회) | 2.607 s | 1.842 s |
| 10,000항목 최대 샘플 RSS | 180 MB | 153 MB |
| 100,000항목 전체 표시 범위 (3회) | 27.35–29.43 s | 14.01–16.72 s |
| 100,000항목 최대 샘플 RSS | 366 MB | 275 MB |

1만 항목 전체 표시가 이 시험에서 2초 목표를 충족했다. 실제 배포 앱의 콜드 시작, 화면 합성 프레임, 장시간 메모리와 8시간 지속 검증은 별도로 남아 있다.

Swift Testing 201개와 한국어·영어 두 테마의 파일 작업 AppKit 검사 각 32개를 통과했다. 새 프리뷰 DMG의 SHA-256, 읽기 전용 마운트, 두 아키텍처의 ad-hoc 서명, Apple Silicon 기동을 확인했다.

5분 유휴 RSS는 81 MB였다. [Release 원시 표본](performance-release-visible-views.json)

전체 AppKit 회귀도 한국어·영어 × 밝게·어둡게 각 218개를 통과했다.
