# M7 Increment 38 — 명령 팔레트 키보드 동선

팔레트를 연 브라우저 창의 응답자 체인으로 명령 대상을 찾는다. 해당 대상이 명령을 검증하고, 실행할 때도 같은 대상을 사용한다. 선택 없이 이름 변경을 시도하면 안내를 표시하고 팔레트를 계속 열어 둔다. Esc로 닫으면 열기 전의 경로 편집기나 컨트롤에 초점을 돌려준다. 한국어 등 IME에서 문자 조합이 진행 중이면 키 처리를 편집기에 맡긴다.

Apple Silicon macOS 27.2 (26B123)에서 AppKit 키 이벤트로 비활성 명령 실행 거부, Esc로 경로 편집기 복귀, Return으로 브라우저의 경로 입력 명령 실행을 검사했다. 한국어·영어와 밝은·어두운 모드 네 조합에서 각각 48개 검사가 통과했다. 이 검사는 브라우저 창 내부의 첫 응답자를 확인한다. 실제 데스크톱에서의 창 전환, VoiceOver 음성 출력과 IME 입력 조합은 추가 검증 대상이다.
