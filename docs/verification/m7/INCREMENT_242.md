# M7 Increment 242 — SMB 교체 이동의 백업 식별

[SMB 3.1.1 실마운트 재시험](https://github.com/taro6222/files-for-mac/actions/runs/43672215017)은 폴더 복사 및 실행 취소, 교차 볼륨 이동 및 실행 취소를 통과했다. 기존 대상 교체에서만 항목 변경 오류가 발생했다. 원본의 새 내용과 기존 대상의 내용은 모두 보존됐다.

SMB 대상의 파일 핸들을 먼저 연 상태에서 기존 대상의 백업 기준을 기록한다. 경로와 열린 파일의 식별자가 일치하는지 확인하고 변경 시각도 기준에 포함한다. 백업 내용을 읽은 뒤 이름 변경 직전에 같은 기준과 열린 파일을 다시 검사한다. 최종 백업 경로에서도 같은 핸들을 사용해 실행 취소 장부 값을 확정한다. 백업 전 검증에서 항목 변경을 감지하면 기존 대상이 변경됐다는 오류를 표시한다.

Apple Silicon에서 FilesCore 빌드와 Swift Testing 7개가 통과했다. 열린 파일의 백업 전후 식별, 동일·교차 볼륨 교체와 실행 취소, 변경된 백업의 보호, 취소 시 기존 대상 보존, SMB 메타데이터 비교를 포함한다.

[후속 실마운트 실행](https://github.com/taro6222/files-for-mac/actions/runs/43674143830)은 소스 `b13090ab0c9b3b69891fa47411679668d5f5ecff`에서 통과했다. macOS 15.8.2 arm64 러너가 Samba 4.25.1에 SMB 3.1.1로 연결했다. 목록, 생성·읽기·이름 변경·삭제 사전 검사 이후 폴더 복사, 교차 볼륨 이동, 기존 대상 교체와 각 실행 취소를 확인했다.

교체를 중단했을 때 기존 대상이 복구됐고, 백업 내용이 변경된 경우 원본과 변경된 백업 및 복구 경로가 보존됐다. 게시한 파일이 같은 내용의 다른 파일로 바뀐 경우에도 원본 삭제를 중단했다. 연결 중단·재연결, 권한 오류·갱신, 생성 및 접근 시각은 별도 검증으로 남아 있다.
