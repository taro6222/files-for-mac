# M7 Increment 171 — 통합 시험의 미실행과 실패 구분

마운트, 휴지통, 프로세스 강제 종료 복구 및 원격 프로토콜에 의존하는 시험은 해당 환경이 없으면 Swift Testing에서 건너뜀으로 표시한다. 환경을 지정했지만 필요한 필드가 빠졌거나 값이 잘못된 경우에는 실패를 기록한다. 시험 실행 로그에 건너뜀으로 표시된 항목은 출시 통합 검증의 통과 건수에 포함하지 않는다.

기본 실행은 241개를 보고했으며 이 중 11개가 건너뜀으로 표시됐다. FTP 포트만 설정한 실행은 불완전한 환경을 보고하고 실패했다. Apple Silicon macOS 27.2에서 SwiftPM이 컴파일한 객체를 Swift Testing 런타임에 직접 링크해 실행했다.

환경을 갖춘 실행에서 로컬 마운트 검사 6개, APFS 강제 종료 후 복구 세 조합, 시스템 휴지통 왕복, FTP·FTPS·SFTP 루프백 검사가 모두 통과했다. 실제 SMB 공유는 실행 환경이 없어 건너뜀으로 확인했다.
