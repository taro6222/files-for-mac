# M7 Increment 61 — 임시 경로에서 AppKit 회귀 재검증

[직전 AppKit 실행](INCREMENT_60.md)에서 실패한 그리드 선택 복원과 템플릿 파일 생성은 시험이 브라우저와 다른 경로 표기를 사용해 발생했다. 브라우저는 탐색 시 기존 `/private/tmp` 경로를 `/tmp`로 표준화한다. 회귀 시험은 원래 경로에서 선택 ID를 만들고 템플릿의 대상 폴더를 전달했다. 이로 인해 선택 ID가 달라졌고 템플릿 생성의 활성 폴더 확인이 거부됐다.

시험용 루트 디렉터리를 만든 뒤 브라우저와 같은 URL 표준화를 적용해 소스, 대상, 저널 경로를 구성한다. Apple Silicon macOS 27.2에서 `/private/tmp` 아래의 독립 AppKit 실행으로 한국어·영어와 밝은·어두운 테마를 조합해 네 번 검증했다. 그리드 선택 복원, 템플릿 파일 이름과 내용, 홈 재사용을 포함해 각 조합에서 53개 검사가 모두 통과했다.
