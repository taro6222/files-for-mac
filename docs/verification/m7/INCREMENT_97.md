# M7 Increment 97 — 속성 창의 세로 스크롤

속성 창의 내용을 세로 스크롤 영역에 배치했다. 창을 줄여도 Finder 태그, SHA-256, 코드 서명 영역에 접근할 수 있다. 속성 창을 다시 열면 스크롤은 상단에서 시작한다.

AppKit 회귀에서 파일 속성, 태그 편집, SHA-256 계산 및 서명 확인을 실행한다. 이어 창을 최소 콘텐츠 크기인 420×280포인트로 줄이고, 처음에는 보이지 않는 서명 확인 버튼 전체가 스크롤 후 표시 영역에 들어오는지 검사한다.

Apple Silicon macOS 27.2에서 한국어·영어와 밝게·어둡게의 네 조합별 전체 AppKit 검사 253개를 통과했다.

[UI-09 구조 대조](../../reference/UI_BASELINE.md)에는 고정 Windows 원본의 속성 화면 정의와 macOS 동작을 기록했다. Windows 실행 화면과 VoiceOver 대조는 남아 있다.
