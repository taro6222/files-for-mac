# M7 Increment 62 — 전체 AppKit 회귀에서 임시 경로 표준화

전체 AppKit 회귀에서도 출력 디렉터리를 만든 뒤 브라우저와 동일하게 URL을 표준화한다. `/private/tmp` 아래에서 시험용 브라우저 위치, 선택 ID, 비교 대상이 같은 경로를 사용한다. 제품의 파일 작업 코드에는 변경이 없다.

Apple Silicon macOS 27.2에서 한국어·영어와 밝은·어두운 테마의 네 조합을 실행했다. 탐색 이력의 스크롤과 선택, 잘라내기·복사 및 붙여넣기 명령, Git 상태와 SHA 셀, 폴더 감시 재연결을 포함해 각 조합의 219개 자동 검사가 모두 통과했다.
