# M7 Increment 50 — 백업 복원 전 저널 저장

교체 이동 실행 취소는 원본 위치 복원 직후 백업 복원만 남은 상태를 저널에 원자적으로 저장한 뒤 대상 경로에 백업을 게시한다. 다시 읽은 저널에서 백업 경로가 비어 있고 대상이 백업의 식별 정보 및 기록된 내용과 일치하면, 이미 게시된 백업으로 처리한다. 대상이 다른 항목이면 기존 실패·충돌 경로를 사용한다.

자동 시험은 백업 게시 직전의 저널을 읽어 보류 상태가 이미 저장됐는지 확인한다. 또한 백업은 게시됐지만 저널이 완료 상태로 갱신되지 않은 상황을 재현하고, 재시도 시 두 파일을 보존하면서 저널을 완료하는지 검사한다.

원본 위치 복원 직후 저널 쓰기 전에 프로세스가 종료되는 경우, 전원 차단에 따른 디스크 지속성, 실제 SMB 공유 복구는 추가 검증 대상이다.

Apple Silicon macOS 27.2 (26B123)에서 Swift 시험 208개를 통과했다.
