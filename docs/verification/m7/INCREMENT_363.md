# M7 Increment 363 — 별도 그룹 자식 컴파일러 관찰

상태: 현재 부모 계보 기반 관찰과 로컬 headless 검증 완료. 실제 원격 자식 스택의 회수·시간 초과 원인 확정과 M7 정식 출시는 미완료다.

## 변경 이유와 동작

이전 ARM의 빌드 관리자 관찰에는 같은 private process group의 swift-build 하나만 포함됐다. llbuild는 자식을 기다리고 있었지만 별도 그룹에서 실행되는 자식의 상태를 이 기록으로 설명할 수 없었다.

관찰은 이제 현재 ps 스냅샷의 PID/PPID 연결을 root build PID부터 따라간다. 자식이 다른 세션/그룹에 있어도 현재 부모 계보에 포함되면 기록한다. CPU가 활성인 자식을 우선하고 sample 직전에도 현재 계보와 실행 파일을 다시 확인한다. 같은 시점의 다른 프로세스 행은 파일에 저장하거나 샘플링하지 않는다. argv와 환경은 수집하지 않는다.

직접 부모와의 연결이 사라진 service/orphan을 임의로 소유 프로세스로 간주하지 않는다. 최대 네 관찰·각 최대 네 sample, 시간 간격·관찰 제한과 빌드 명령·CI 제한은 유지한다. 이번 변경은 읽기 관찰 범위이며 기존 root group 신호 전달을 다른 그룹 종료 정책으로 확대하지 않았다. 빌드를 다시 시작하지도 않는다.

## 검증

새 세션에서 자식을 실행하고 부모가 완료를 기다리는 실제 짧은 fixture를 사용했다. 기존 코드에서는 DifferentGroupChildCollected가 실패했고 빌드 자체는 정상 완료했다. 수정 후 다른 그룹의 자식 PID·부모 연결과 실제 sample 생성을 확인했다. 동시에 살아 있던 무관한 별도 fixture는 출력과 sample에서 제외했다. 직접/자식 프로세스의 종료·정상/오류 코드·관찰 중 실행 유지·SIGTERM/SIGKILL/terminal EPERM과 도구 회수까지 28개 검사가 모두 통과했다.

[소스·수정 전 재현·결과 해시](build-tree-363-verification.json)를 보존한다. 앱·SDK 소스를 바꾸지 않아 앱 빌드/기존 앱 시험을 반복하지 않았다. 로컬 GUI·전체 AppKit·장시간 시험은 시작하지 않았다.

## 원격 상태와 남은 실행

이전 bf3a91a 실행은 ARM 작업 전체 성공·Intel Debug 빌드 20분 제한 실패로 전체 실패다. Intel artifact에도 컴파일러 자식을 포함하지 못한 기존 관찰만 있어 원인을 단정하지 않는다. 종료 보고서가 없는 경우 남은 관찰과 실제 job 결론만 기록하고 정상 종료로 바꾸지 않는다.

362 격리 소스 789d9b3의 두 CPU 작업은 이번 조회에서 실행 중이었다. 이를 수동 취소/재시작하지 않았다. 새 관찰 소스의 실제 자식 스택으로 계산·대기·메모리 상태를 확인한 뒤 필요한 수정을 진행한다. 관찰 fixture 통과를 제품 빌드나 최신 SDK/지원 환경 수용으로 집계하지 않는다.

나머지 metadata·생성 계획 한도·자원 경계, 실제 입력/VoiceOver·원본 UI·외부 서비스·정식 서명/공증 게이트는 남아 있다. 인증서/프로필은 사용자 준비 중이며 로컬 장시간 시험은 자동으로 재시작하지 않는다.
