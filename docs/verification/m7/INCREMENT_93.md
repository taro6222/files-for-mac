# M7 Increment 93 — 최근 위치만 갱신하는 홈 화면

방문 기록이 바뀌면 홈의 최근 위치 목록만 갱신한다. 빠른 접근, 드라이브, 네트워크 위치는 기존 뷰를 유지한다. 폴더를 탐색 중이면 홈으로 돌아왔을 때 최근 위치를 갱신한다. 최근 위치 버튼에 키보드 초점이 있었으면 위치와 이름으로 해당 버튼을 다시 찾아 초점을 복원한다.

한국어·영어 × 밝게·어둡게 조합별 AppKit 파일 작업 검사 58개를 통과했다. 최근 위치 두 곳의 순서, 홈 제목과 네트워크 버튼의 재사용, 최근 위치가 갱신된 후 키보드 초점 복원을 확인했다. 기존 홈 키보드 탐색과 드라이브 표시 설정도 함께 검사했다.

Apple Silicon macOS 27.2에서 최적화 QA 빌드로 최근 방문을 기록하면서 탭 및 전체 부하 30분 시험을 시작했다. 두 실행의 사이클 진행을 확인했다. 메모리 개선 여부는 이전 후보 및 최근 방문을 끈 대조와 비교해 판정한다.
