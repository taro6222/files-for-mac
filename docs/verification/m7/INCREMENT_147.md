# M7 Increment 147 — 교차 볼륨 실행 취소의 충돌 보호

교차 볼륨 이동의 실행 취소는 원래 위치에 복사본을 게시할 때 열린 디렉터리 기준으로 원자적 비덮어쓰기 이름 변경을 사용한다. 게시 직전에 부모·임시 폴더의 식별자와 복사본의 식별자를 확인한다. 임시 폴더가 바뀌었으면 자동 정리도 건너뛴다.

게시 직전에 일반 파일이나 끊어진 심볼릭 링크가 생기는 경우를 각각 검사한다. 충돌이 발생하면 기존 항목과 이동 대상을 보존하고, 충돌 원인을 제거한 뒤 같은 저널로 재시도할 수 있다. 원자적 게시를 지원하지 않는 파일 시스템에서는 복원과 원본 삭제를 중단한다.

일반 파일과 끊어진 심볼릭 링크의 충돌, 충돌 해소 후 재시도, 전체 Swift 테스트 230개, 실제 마운트 검사 6개 및 강제 종료 복구 두 조합이 통과했다.
