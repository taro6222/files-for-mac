# M7 Increment 162 — 폴더 하위 항목의 소유권

파일 권한 시트에서 그룹이나 사용자를 선택한 뒤 **하위 파일과 폴더에도 적용**을 선택할 수 있다. 일반 계정에서는 그룹 변경을 제공하며, 사용자 변경은 프로세스에 시스템 권한이 있을 때 제공한다. 작업 전에 하위 적용 범위와 macOS가 setuid·setgid 비트를 해제할 수 있음을 표시한다. 완료 후 적용·건너뜀·실패 건수를 표시한다.

POSIX·ACL 일괄 적용과 같은 파일 디스크립터 순회를 사용한다. 선택한 폴더의 식별자와 기존 권한을 확인하고, 심볼릭 링크·하드 링크·특수 파일·별도 볼륨을 건너뛴다. 선택한 소유권 필드만 변경하고, 다른 소유권 필드가 유지되는지 실제 결과를 다시 읽어 확인한다.

Swift 테스트 240개가 통과했다. APFS에서 하위 파일의 그룹 변경, 사용자 소유자와 ACL 보존, 링크 대상 보존, 일반 계정의 사용자 소유권 변경 거부를 확인했다. 관리자 권한이 있는 계정에서의 실제 사용자 소유권 이전은 검증이 남아 있다. SwiftPM이 컴파일한 객체를 Swift Testing 런타임에 직접 링크해 실행했다.

한국어·영어 × 밝은·어두운 테마 네 조합의 AppKit 검사 268개가 각각 통과했다. 시트에서 그룹과 하위 적용을 선택해 실제 하위 파일의 그룹과 ACL을 대조했다.
