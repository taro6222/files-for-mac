# M7 Increment 207 — SMB 복사 내용 검증 진단

[macOS 확장을 켠 인증 SMB 실행](https://github.com/taro6222/files-for-mac/actions/runs/43659713277)에서 공유의 생성·읽기·이름 변경·삭제 사전 검사를 통과했다. 앱은 서버의 임시 복사본에서 524,288바이트를 읽었고 내용 또는 폴더 구조 일치 검사에서 복사를 중단했다. 이 실행 결과만으로는 파일 데이터 지문과 리소스 포크, 항목 구조 중 어느 부분이 달랐는지 구분할 수 없다.

SMB 통합 시험이 이 초기 복사를 완료하지 못하면 원본 바이트와 게시 경로가 그대로인지 먼저 검사한다. 같은 공유의 별도 임시 폴더에서 Foundation 복사본을 만들고 원본과 비교해 상대 경로, 파일 지문, 리소스 포크 지문, POSIX 모드와 확장 속성 이름을 기록한다. 시험용 복사본은 사용 후 제거한다. 실제 공유의 진단은 해당 버전으로 재실행해 확인한다.

로컬 APFS 시험 폴더에서 진단에 원본과 별도 복사본이 모두 나타나고 임시 폴더가 제거되는 것을 확인했다. 로컬 Swift Testing 전체 실행은 임시 진단 시험을 포함해 235개 통과, 별도 환경이 필요한 통합 시험 11개 건너뜀이다.
