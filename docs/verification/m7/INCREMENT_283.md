# M7 Increment 283 — 보존 경로에서 8시간 시험 재개

이전 실행의 프로세스와 최종 보고서가 현재 환경에서 없음을 확인하고 새 시험을 시작했다. 기본 실행 경로인 프로젝트 `build`를 사용해 임시 디렉터리 정리와 분리했다.

- 소스는 `86be2b0d92f189103dea5874cfe1a0795e52ca4b`의 Git 스냅샷이다.
- 실행 디렉터리는 `build/release-soak.JDCzWA`다. 실행 파일 SHA-256은 `cdb819fd42dc47ab3c13adda4f3642d657b0bfb2bad991fb2c6d05034e7aa2d4`이며 체크섬 재검사도 통과했다.
- Apple Silicon macOS 27.2.1(26B131)의 로컬 Data 볼륨에서 최적화 QA 앱을 실행한다. 목표는 `full` 부하 28,800초다.
- 빌드가 끝난 뒤 실제 앱 프로세스와 `running` 보고서, 완료된 첫 탐색·전송·탭 사이클을 확인했다. 이 기록은 시험 시작 증거다.

진행 중인 실행은 디렉터리의 `report.json`을 확인한다. 종료 후 `exit-status`와 `result.json`, 소스와 바이너리 해시를 대조하고 8시간 메모리 추세·감시 해제·작업 누수를 판정한다. 출시 완료 판정은 최종 결과 확인 후 진행한다.
