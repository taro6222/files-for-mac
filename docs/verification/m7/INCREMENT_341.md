# M7 Increment 341 — ZIP 암호 서비스

상태: 서비스 구현·로컬 검증 완료. 암호 생성/추출 UI와 전체 F23·M7 출시는 미완료다.

340단계 세부 대응표의 암호 요구사항을 서비스부터 구현한다. 시스템 libarchive에서 ZIP AES-256 생성과 올바른 암호의 복원을 직접 확인한 뒤 기존 ZipArchiveProvider에 암호 전달을 추가했다. 이 단위를 전체 암호 기능 완료로 집계하지 않는다. 사용자 생성·개별/일괄 추출 창의 암호 입력·취소·오류 안내·표시 전환은 다음 구현 단위이며 capability의 사용자 표시도 기존 미지원 상태를 유지한다.

## 서비스 동작

생성은 password가 없으면 기존 동작을 유지한다. 암호가 있으면 ZIP에 AES-256을 명시하며 빈 값·C 문자열을 잘라 버릴 수 있는 NUL 포함 값을 거부한다. 7z 암호 생성 요청은 지원하지 않는 조합으로 거부하고 평문 출력으로 바꾸지 않는다. 생성기 종료 결과를 확인한 뒤에만 기존 게시 경로로 돌아온다. 파일과 디렉터리의 이름은 암호화하지 않는다. ZIP 헤더·목록에서 경로가 보이므로 파일 이름 보호 기능으로 설명하지 않는다.

읽기/추출에는 암호를 libarchive reader에 전달한다. 목록 항목에 isEncrypted를 추가해 다음 UI에서 암호가 필요한 항목을 판별할 수 있게 한다. 기본값 false를 둬 기존 항목 생성과 비교를 유지한다. ZIP 목록 조회 성공은 암호 검증 성공이 아니다. 실제 데이터 읽기·추출이 성공해야 복호화 성공으로 판정한다.

암호는 String 인자로 메모리에서 전달하며 설정·저널·진행 메시지·프로세스 인수에 추가하지 않는다. Swift/C 내부 메모리의 즉시 소거나 zeroization을 보장한다고 주장하지 않는다. 새 오류는 암호 원문을 사용자 메시지로 표시하지 않는다. 원본 경로 검증·추출 한도·staging·대상 충돌 거부·부분 추출 정리를 유지한다.

암호화 옵션의 근거는 [libarchive 공식 포맷 옵션 문서](https://github.com/libarchive/libarchive/blob/v3.7.7/libarchive/archive_write_set_options.3)다. 이 Mac의 실제 시스템 라이브러리에서 별도 호출로 생성·복호화도 확인했다. 외부 7-Zip 등의 독립 구현, 최소 macOS와 두 CPU의 새 소스 수용은 별도로 남아 있다. libarchive read API에 암호를 전달할 수 있다는 사실만으로 7z·RAR 암호 지원을 표시하지 않는다.

## 검증 범위

새 Core 함수 네 개를 추가했다. 첫 함수는 저장/최고 압축 두 인자로 AES 생성·추출·올바른 암호·틀린 암호·암호 없음·헤더의 AES 방식과 암호 원문 부재를 확인한다. 나머지는 빈 값/NUL·지원하지 않는 7z 생성과 기존 파일 충돌 보존, 압축하지 않은 암호문의 비트 변경에 대한 인증 실패·평문 결과 미게시, 첫 데이터 기록 뒤 작업 취소와 임시 출력 정리를 확인한다. 암호문 변조는 저장 모드를 사용해 deflate 해제 실패만으로 인증을 판정하지 않는다.

인증서·공증 프로필은 사용자 준비 중이다. 실제 입력·VoiceOver·전체 원본 UI 상태 대조·외부 서비스·지원 환경·장시간·정식 서명/공증 등 M7 게이트는 열린 상태다.

최종 Debug·Release 빌드, Swift 전체 395개 중 성공 376개·환경 건너뜀 19개, 네 조합 기존 전체 UI 각각 312개·탭 경계 각각 18개, parity 구조 감사와 검증 스크립트 구문 검사가 통과했다. 기존 UI 개수는 늘리지 않았다. [소스·바이너리·보고서 해시와 결과](archive-password-341-verification.json). 별도 볼륨 전송 정책은 바꾸지 않아 재마운트 시험은 반복하지 않았다.

이전 소스 774083b 원격 실행에서 ARM 작업과 네 조합 306개/18개가 성공했다. 첫 Git 조회는 0.403초 미만이라 조기 스택 파일은 생성되지 않았다. Intel은 Git 검사까지 도달하지 못하고 Build app and test targets 단계의 20분 제한으로 종료됐다. 보존 로그에는 빌드 완료 1190.10초가 있으나 단계 성공으로 집계하지 않는다. AppKit 아티팩트도 없다. 컴파일 오류라고 단정하거나 검증 기준을 늘려 통과로 바꾸지 않으며 실행 시간과 컴파일 부하 원인 조사가 남아 있다.
