# M7 Increment 85 — 분할 구분선과 보조 경로 입력

좌우 분할을 35%로 복원한 뒤 구분선의 `NSSplitView.mouseDown(with:)`에 합성 마우스 이벤트를 전달한다. AppKit 추적 루프가 드래그와 버튼 해제 이벤트를 처리해 구분선을 55% 위치로 옮기는지 확인한다. 시스템 포인터나 WindowServer를 거치는 수동 드래그는 별도 검증 항목이다.

최소 창 너비 검사에서는 기본 패널의 경로 입력에 초점을 맞춘 뒤 보조 패널로 전환한다. 보조 경로 필드의 편집기가 활성화되는지 확인하고, 경로 제출 명령으로 해당 폴더에 이동하는지 검사한다.

한국어·영어 × 밝게·어둡게의 AppKit 검사 각 240개가 통과했다. 드래그 후 실제 비율은 54.996~55.000%였고 네 조합에서 보조 패널 경로 이동을 확인했다. 첫 시도의 창 이벤트 전달 방식은 구분선을 움직이지 못해 분할 뷰의 마우스 추적을 직접 호출하도록 수정했다.
