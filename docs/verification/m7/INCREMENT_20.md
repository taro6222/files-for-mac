# M7 Increment 20 — 장시간 시험의 소스 고정

`scripts/verify-release-soak.sh`는 시작할 때 HEAD를 읽어 해당 커밋의 Git 스냅샷을 별도 디렉터리에 풀고 최적화 QA 앱을 빌드한다. 실행마다 빌드 디렉터리를 분리하고, 실행 파일과 SHA-256 및 커밋 SHA를 남긴다. 작업 트리에서 파일을 수정하거나 다른 빌드가 실행되는 동안에도 보고서에 기록한 커밋이 시험 바이너리와 일치한다.

현재 안정성 시험은 최초 빌드의 증거로 계속 수집한다. 출시 후보의 판정에는 그 후보의 고정 소스로 완료한 28,800초 보고서와 메모리 추세, 실제 프로세스 종료 상태가 필요하다.

macOS 27.2 (26B123)에서 `fc960368a1f4d754ebd7e26b6574f06c26caac9e` 소스로 시험했다. 25.70초 동안 9사이클을 완료했으며 실행 파일 체크섬이 일치하고 작업용 소스·빌드 디렉터리가 정리됐다. 셸 구문 검사와 0초 입력 거부도 확인했다.
