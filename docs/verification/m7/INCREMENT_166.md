# M7 Increment 166 — 권한 시트의 대규모 작업 중간 중단

`FILES_UI_QA_PARTIAL_PERMISSION_STOP=1 scripts/verify-ui.sh`로 재현한다. 각 언어·테마 조합마다 APFS의 새 폴더에 모드가 `0600`인 일반 파일 30,000개를 만든다. 실제 권한 시트에서 폴더 모드 `0750`의 하위 적용을 시작하고, 표본 파일에서 변경을 감지하면 AppKit의 중단 버튼을 실행한다. 시트 표시의 적용 건수와 전체 파일의 모드를 대조한다.

Apple Silicon macOS 27.2 (26B123)에서 디버그 앱으로 실행했다. 네 조합 모두 중단을 표시했고 건너뜀과 실패는 0건이었다.

| 조합 | 화면에 표시된 적용 | 실제 변경 |
|---|---:|---:|
| 한국어·밝게 | 441 | 441 |
| 한국어·어둡게 | 421 | 421 |
| 영어·밝게 | 606 | 606 |
| 영어·어둡게 | 348 | 348 |

AppKit 회귀 검사 270개가 각 조합에서 통과했다. 이번 검증은 버튼에 연결된 AppKit 동작을 자동으로 실행했다. 사용자 물리 입력과 VoiceOver 음성은 별도 검증 범위다.
