# M7 Increment 165 — 대규모 폴더 권한 변경 중간 중단

앱 소스 `fdcd7da6c6a6ae894ed91ce8f271183a8c15f147`의 FilesCore를 최적화 빌드하고 Apple Silicon macOS 27.2 (26B123)의 로컬 APFS에서 실행했다. 회차마다 새 폴더에 모드가 `0600`인 일반 파일 30,000개를 만들었다. 권한을 `0640`으로 바꾸는 동안 별도 작업에서 실제 파일의 모드를 확인했고, 첫 변경을 관찰한 뒤 제품과 동일한 중단 토큰에 중단을 요청했다. 호출이 반환된 뒤 모든 파일의 모드를 읽어 결과를 대조했다.

| 회차 | 보고된 적용 | 실제 변경 | 기존 모드 유지 |
|---|---:|---:|---:|
| 1 | 379 | 379 | 29,621 |
| 2 | 418 | 418 | 29,582 |
| 3 | 369 | 369 | 29,631 |

세 회차 모두 중단 상태를 반환했다. 실패와 건너뜀은 0건이었고, 자식을 먼저 처리하는 순회에서 상위 폴더의 모드는 유지됐다. 권한 시트의 시작 직후 중단은 [AppKit 회귀](INCREMENT_164.md)에서 확인했다. 이번 중간 중단은 FilesCore 호출로 재현했다. 대규모 폴더에서 권한 시트 버튼을 직접 누르는 검증은 남아 있다.
