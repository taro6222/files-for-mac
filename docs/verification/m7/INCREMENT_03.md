# M7 Increment 03 — 대형 폴더의 중간 표시 비용

- 첫 배치를 즉시 표시한 뒤, 누적 항목 수가 직전 표시의 두 배에 도달할 때 중간 목록을 정렬해서 표시한다. 완료 후 전체 목록을 정렬한다.
- 보존할 선택이 비어 있으면 경로·identity 색인을 만들지 않는다.
- Swift Testing 200개와 AppKit 217개가 통과했다. 첫 배치 표시, 취소, 최종 정렬을 확인했다. 동일 한국어·어두운 테마 시나리오에서 20회 다중 창 왕복과 스크롤 위치 100개를 확인했다.

| 단일 10,000항목 AppKit 측정 | 기준 | 변경 후 |
|---|---:|---:|
| 첫 표시 | 57.3 ms | 46.7 ms |
| 전체 열거 및 표시 | 2.064 s | 1.803 s |
| 스크롤 단계 p95 | 3.81 ms | 3.78 ms |
| 다중 창 왕복 p95 | 4.721 s | 4.554 s |

[변경 후 표본](performance-coalesced.json)은 기준과 같은 Mac에서 기록한 Debug 값이다. 정식 Release 환경의 콜드 시작, 프레임, 메모리, 장시간 실행은 검증 대기다.
