# M7 Increment 281 — 복사·이동 중 진행 상태 표시

복사 창과 이동 창에서 현재 파일을 복사하거나 내용·실행 취소를 위한 확인을 진행할 때 애니메이션을 표시한다. 개별 파일의 바이트 진행률을 제공하지 않는 작업이므로 단계 이름과 처리할 항목 수를 함께 표시한다. 파일 작업 센터의 처리 항목 수는 기존대로 확인할 수 있다. [AppKit 진행 표시](https://developer.apple.com/documentation/appkit/nsprogressindicator/isindeterminate)

취소 버튼을 누르면 안전 지점까지 기다리는 문구를 즉시 표시한다. 복사 호출이나 검증이 돌아오기 전까지 진행 표시를 유지하며, 작업 결과가 나타날 때 애니메이션을 멈추고 진행 표시를 숨긴다. 기존 복사 취소 검증에 작업 중·취소 대기·종료 세 상태의 표시를 추가했다.

SwiftPM 디버그 앱을 Apple Silicon Sonoma 14.8.7(23J520) VM에 전달하고 바이너리 SHA-256 `ec8e58a00cd75a3a30d2d8d7e0858ca0d7e1551abb8d409d0fd20b6d2a6797b6`을 대조했다. 실제 대소문자 구분 APFS를 마운트한 상태에서 한국어·영어와 밝은·어두운 테마의 파일 작업 검사 79개씩 통과했다.

로컬 APFS에서 8 MiB 복사의 내용 검증 중 취소 버튼을 조합마다 10회 눌렀다. 클릭부터 상태가 바뀔 때까지 40회의 p95는 10.37 ms, 최대는 92.56 ms였다. 파일 엔진 반환까지 p95는 19.52 ms, 최대는 94.66 ms였다. 원본 바이트를 보존했고 공개 대상과 임시 출력이 남지 않았다.
