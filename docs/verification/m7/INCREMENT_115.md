# M7 Increment 115 — 5분 유휴 후 탐색 반복 검증

Apple Silicon macOS 27.2 (26B123)에서 고정 소스 e40f23a의 최적화 QA 앱으로 APFS의 10,000항목 폴더를 읽었다. 매번 새 프로세스를 시작하고 즉시 탐색과 300초 유휴 후 탐색을 세 쌍 측정했다. OS 캐시는 공유했고 썸네일은 제외했다. 유휴 조건에서 앱은 계속 비활성 상태였고 제품의 사용자 탐색 활동만 사용했다.

| 회차 | 즉시 첫 표시 | 즉시 전체 표시 | 유휴 후 첫 표시 | 유휴 후 전체 표시 |
|---|---:|---:|---:|---:|
| 1 | 51.8 ms | 1.354초 | 105.4 ms | 1.189초 |
| 2 | 50.0 ms | 1.047초 | 86.2 ms | 1.354초 |
| 3 | 49.6 ms | 1.296초 | 103.8 ms | 1.380초 |

세 유휴 표본 모두 첫 표시 500 ms와 전체 표시 2초 목표 범위에 있었다. 기록은 AppKit 레이아웃·그리기 호출 기준이다. 이 표본 수로 전체 사용 환경의 p95를 판정할 수 없으며, 화면 합성과 콜드 캐시 검증은 남아 있다. [측정 원본](performance-idle-repeat-e40f23a.json)
