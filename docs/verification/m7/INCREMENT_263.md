# M7 Increment 263 — macOS 작업 센터 완료 기록 지우기

작업 센터의 `완료 기록 지우기` 버튼으로 결과를 한 번에 숨길 수 있다. 진행 중인 작업과 개별 작업의 열린 세부 창은 계속 사용할 수 있다. 이미 지운 결과의 세부 창을 닫아도 같은 결과가 다시 등록되지 않는다. 지울 결과가 없으면 버튼은 비활성화된다.

Apple Silicon macOS 27.2에서 한국어·영어와 밝은·어두운 테마 네 조합마다 실제 AppKit 파일 작업 검사 77개가 통과했다. 닫은 복사 결과를 지운 뒤 진행 중인 복사의 막대와 취소를 확인했다. 새 취소 결과를 지울 때 세부 창이 열린 상태를 유지했고 창을 닫아도 지운 행이 다시 나타나지 않았다. 378건 대응표 감사도 통과했다.

[Windows 작업 센터](INCREMENT_261.md)와 완료 기록을 지우는 동선을 대조했다. Windows 전송 중 진행·취소 화면과 macOS VoiceOver 탐색은 추가 검증이 필요하다.
