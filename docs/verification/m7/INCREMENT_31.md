# M7 Increment 31 — 복사 취소의 상태 반영

AppKit 파일 작업 회귀에 복사 창의 취소 피드백 시험을 추가했다. 실제 `NSButton.performClick` 호출부터 액션 반환까지를 기록하고, 취소 토큰이 설정됐는지, 버튼이 비활성화됐는지, 상태에 취소 요청이 표시됐는지 확인했다. 각 표본은 새 창을 사용한다.

Apple Silicon macOS 27.2 (26B123)에서 한국어·영어 및 밝게·어둡게 조합별 20회, 총 80회 측정했다. p95는 3.47ms, 최댓값은 77.16ms였다. 네 조합에서 파일 작업 검사 40개씩 통과했다. [측정 표본](copy-cancellation-feedback.json)

자동화는 실제 AppKit 버튼 액션과 상태를 대상으로 했으며 전송은 시작하지 않았다. 물리 입력부터 화면에 표시될 때까지의 지연과 진행 중인 I/O 부하에서의 반응 시간은 이 수치에 포함되지 않는다. 실제 전송 취소·정리 동작은 기존 파일 작업 회귀에서 확인한다.
