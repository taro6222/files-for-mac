# M7 Increment 204 — 컬럼 보기의 오른쪽 키 이동과 선택

컬럼 보기에서 폴더 한 개를 선택한 뒤 오른쪽 방향키를 누르면 하위 컬럼에 초점을 옮긴다. 이미 열린 컬럼은 즉시 사용하고, 새 목록을 읽는 동안에는 같은 폴더와 초점이 유지된 경우에만 이동한다. 새 하위 컬럼에 항목이 있으면 첫 항목을 선택한다. 빈 컬럼에서는 파일 작업에 전달할 선택도 비운다.

하위 컬럼에 들어가도 왼쪽의 폴더 선택을 유지한다. 왼쪽 방향키로 돌아오면 부모 컬럼에 초점을 두고 해당 폴더를 다시 작업 대상으로 삼는다. 선택이나 탐색 위치가 바뀌면 이전 하위 목록 열거를 취소한다.

Apple Silicon macOS 27.2에서 앱 빌드와 영어·밝은 테마 AppKit 검사 289개를 통과했다. 공통 폴더에서 이미 열린 하위 컬럼을 선택하는 동작, 목록을 새로 읽은 뒤의 초점 이동, 부모로 돌아올 때 선택 복원을 확인했다. 한국어·영어와 밝은·어두운 테마의 AppKit 파일 작업 검사도 각 71개를 통과했다.
