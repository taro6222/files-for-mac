# M7 Increment 215 — 검색 창의 크기 필터 입력란

공통 폴더 검색을 캡처했을 때 최소·최대 크기 입력란이 좁아져 안내 문구를 읽을 수 없었다. 두 크기 입력란에 각각 104포인트를 배정하고 Finder 태그 입력란은 최소 140포인트를 확보했다. 크기 단위 선택은 같은 줄에 표시한다.

Apple Silicon macOS 27.2에서 앱을 빌드했고 영어·밝은 테마와 한국어·어두운 테마에서 AppKit 검사 각 295개를 통과했다. 두 조합 모두 창 너비 900·720포인트에서 입력란 세 개의 표시와 편집 가능 여부를 검사했다. 공통 폴더 검색은 `Alpha`의 `column-note.txt` 하나를 반환했다. [macOS 검색 화면](ui-07-macos-search-size-inputs.png)
