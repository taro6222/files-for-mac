# M7 Increment 188 — 파일 작업 센터

파일 메뉴와 명령 팔레트에서 파일 작업 창을 열 수 있다. 복사·이동·폴더 병합의 진행 상태와 열려 있는 결과를 한 목록으로 표시한다. 작업 행을 선택해 세부 창을 열거나 안전 지점 취소를 요청한다. 취소를 요청하면 중복 요청이 비활성화되고 결과가 오면 해당 행이 갱신된다. 세부 창을 닫으면 목록에서도 사라진다.

창에는 작업별 처리 항목 수를 표시한다. 복사·이동의 데이터 준비량과 측정 가능한 평균 속도는 기존 상태 문구에서 가져온다. 예상 남은 시간, 결과 창을 닫은 뒤의 기록, 전체 전송의 바이트 합계는 출시 검증표에 남는다.

Apple Silicon macOS 27.2에서 AppKit 파일 작업 회귀가 한국어·영어와 밝은·어두운 테마 네 조합마다 69개 통과했다. 실제 복사 요청을 작업 센터에서 취소해 진행 상태·취소 접수·결과·행 제거를 확인했다. 원본 바이트와 대상 파일의 부재도 확인했다.
