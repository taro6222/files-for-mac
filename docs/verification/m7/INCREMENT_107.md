# M7 Increment 107 — 느린 시작 폴더에서 창 열기

저장된 시작 위치를 일반 비동기 폴더 로더로 연다. 사라진 폴더나 파일로 바뀐 경로는 해당 경로를 표시한 상태로 기존 오류·재시도·폴더 선택 UI를 사용한다. 창 제목은 경로의 마지막 구성 요소를 사용하고 루트는 `/`로 표시한다. 첫 창을 만들 때 대상 경로의 표시 이름을 조회하지 않는다.

프로젝트의 시작 폴더에서 동일한 Launch Services·접근성 메뉴 경로를 실행했다. 동기 존재 확인만 제거한 빌드는 정상 시작 폴더에서 11.428초였다. 창 제목에서도 동기 파일 시스템 조회를 제거한 빌드로 세 조건을 두 번씩 실행했다.

| 시작 위치 | 창 표시 범위 | 정보 창 표시 범위 |
|---|---:|---:|
| 정상 폴더 | 263–562 ms | 509–807 ms |
| 누락 폴더 | 249–250 ms | 484–492 ms |
| 일반 파일 | 245–257 ms | 490–496 ms |
