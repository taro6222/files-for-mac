# M7 Increment 175 — 정렬된 상세 목록의 증분 갱신

폴더 열거가 파일을 여러 배치로 전달하면 정렬 결과에서 새 행이 기존 행 사이에 들어올 수 있다. 이전 행의 값과 상대 순서가 유지되면 AppKit 표에서 삽입된 행만 추가한다. 제거 시에도 같은 조건을 적용한다. 기존 행의 내용이나 순서, 표시 옵션이 달라지면 전체 다시 읽기를 적용한다. 두 배치를 사용하는 AppKit 회귀에서 선택한 파일이 두 번째 행에서 네 번째 행으로 밀려도 같은 셀과 선택이 유지되는지 확인한다.

Apple Silicon macOS 27.2에서 같은 SwiftPM 네이티브 엔진으로 만든 최적화 QA 빌드를 비교했다. 같은 탐색·탭·독립 창 부하에서 `heap`으로 `NSKeyValueDependencyContext`를 셌다.

| 부하 | 비교 구간 | 이전 증가 | 변경 후 증가 |
|---|---|---:|---:|
| 탐색 | 4→20사이클 | 352 | 0 |
| 탭 | 4→20사이클 | 1,040 | 688 |
| 독립 창 | 5→21사이클 | 723 | 368 |

독립 창 기준값은 같은 바이너리의 앞선 5→21사이클 표본을 사용했다. 짧은 대조에서 탐색만의 컨텍스트 증가는 멈췄으며 탭과 독립 창에서는 증가가 남았다. 전체 부하의 8시간 안정성은 별도로 판정한다.

로컬 디버그·최적화 빌드와 한국어·영어 및 밝은·어두운 테마 네 조합의 AppKit 검사 각 270개를 통과했다.
