# M7 Increment 285 — 이동 중 서버의 쓰기 권한 회수

인증 SMB 공유에 기존 대상을 두고 APFS 원본을 교체 이동한다. 기존 대상 백업과 임시 복사 폴더 생성이 끝난 `copying` 단계에서 Samba 서버의 로컬 경로를 통해 임시 폴더 권한을 `0500`으로 변경한다. 클라이언트 사전 검사 후 서버가 쓰기를 거부하는 상황을 재현한다.

시험은 권한 변경을 실제로 적용했는지 확인하고 이동 실패, 원본 내용 보존, 기존 대상 자동 복원, 임시 출력 제거와 실행 취소 기록 부재를 대조한다. 시험 환경 정리는 이 실행이 만든 임시 폴더로 한정한다. 실마운트 결과를 확인한 뒤 서버 권한 변경 게이트를 판정한다.

변경한 통합 시험 파일은 Swift 6 타입 검사, 검증 스크립트의 셸 구문 검사와 대응표 감사를 통과했다. 실제 Samba 공유에서의 동작은 CI 결과로 확인한다.
