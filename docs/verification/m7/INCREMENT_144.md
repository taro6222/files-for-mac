# M7 Increment 144 — DMG에서 복사한 앱 검증

정식 검증기는 읽기 전용 이미지에서 앱의 서명과 배포 정책을 검사하고, 격리 경로에 앱을 복사해 같은 검사를 다시 실행한다. 설치 전송에 실패했거나 복사된 파일의 서명이 깨졌으면 실패로 종료한다. 검증이 끝나면 임시 복사본과 마운트를 정리한다.

개발 프리뷰를 실제 읽기 전용으로 마운트해 복사·모든 슬라이스의 ad-hoc 서명 확인·정리를 실행했다. 프로젝트 Developer ID, 공증 및 Gatekeeper 검사는 시험에서 대역으로 대체했다. 복사 직후 번들 리소스를 손상시킨 경우 실제 코드 서명 검사가 거부했고 임시 디렉터리도 정리됐다. 정식 다운로드의 공증·배포 정책과 Finder 최초 실행은 남아 있다.
