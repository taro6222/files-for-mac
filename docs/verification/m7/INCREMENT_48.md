# M7 Increment 48 — 교체 이동 실행 취소 재시도

실행 취소에서 이동한 항목을 원래 경로로 돌려놓은 뒤 기존 대상의 백업을 복원하지 못하면, 재시도 기록에 백업 복원만 남았음을 저장한다. 재시도는 백업의 식별 정보와 기록된 내용을 검사하고, 빈 대상에만 기존 무덮어쓰기 경로로 복원한다. 원래 경로로 돌아간 항목은 다시 옮기지 않는다. 이전 실행 취소 기록은 기존 단계부터 처리한다.

원래 경로는 복원됐지만 백업 복원이 남은 저널을 만들어 다시 읽었다. 대상이 외부 파일로 점유된 동안 백업과 외부 파일이 보존됐으며, 대상이 비워지면 재시도가 백업만 복원하고 완료 기록을 남기는지 검사했다. 프로세스가 종료돼 재시도 저널을 저장할 수 없는 경우와 실제 SMB 공유는 추가 검증 대상이다.

Swift 시험 207개와 APFS·대소문자 구분 APFS·exFAT 볼륨 매트릭스 시험 3개가 통과했다.
