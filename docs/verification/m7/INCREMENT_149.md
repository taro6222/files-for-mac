# M7 Increment 149 — 백업 없는 교차 볼륨 실행 취소 재개

일반 교차 볼륨 이동의 실행 취소도 복원본을 게시하기 전에 복원본의 식별자, 내용과 메타데이터를 저널에 저장한다. 중단 뒤 재개하면 저널과 두 항목을 대조하며, 복원본이 확인되고 두 항목이 일치할 때만 이동 대상을 제거한다. 복원본의 메타데이터만 달라졌을 때도 파일과 재시도 기록을 보존한다.

재개가 완료되면 보류 저널을 소비한다. 중단 후 재개에서는 세션의 다시 실행 기록을 생성하지 않는다.

전체 Swift 테스트 231개와 실제 마운트 검사 6개가 통과했다. 두 APFS 볼륨을 사용한 강제 종료·프로세스 재시작 검사 세 조합이 통과했다. 백업 없는 조합에서 복원본 확장 속성을 수정하면 양쪽 복사본이 보존됐고, 속성을 복구하면 같은 저널로 실행 취소가 완료됐다.
