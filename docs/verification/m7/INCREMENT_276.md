# M7 Increment 276 — macOS 15 두 아키텍처의 전체 AppKit 회귀

기존 macOS 워크플로를 수동 실행할 때 `verify_full_appkit`을 선택하면 Apple Silicon과 Intel에서 전체 AppKit 검사와 창 캡처를 실행한다. 한국어·영어와 밝은·어두운 테마를 조합해 각각 별도 프로세스로 실행한다. CI가 앞 단계에서 만든 디버그 실행 파일을 사용한다.

콘텐츠 검색에는 실제 Spotlight 색인을 사용한다. 시험 전에 러너의 체크아웃에서 대상 소스 파일이 본문 질의로 반환되는지 확인한다. 설치 프리뷰와 파일 작업 검사에 더해 탐색·보기·분할·태그·검색·정보·설정·Git·압축을 검증한다. 아키텍처별 아티팩트에는 각 조합의 JSON 보고서, 로그, 실제 AppKit 창 캡처가 포함된다.

보고서가 없거나 요청한 언어·테마가 다르거나 검사가 실패하면 해당 조합을 실패로 기록한다. 남은 조합을 계속 실행해 공통 실패와 환경별 실패를 구분할 수 있다. 정식 출시 판정에는 설치 앱의 수동 UI 동선과 VoiceOver 검증이 함께 필요하다.

Sonoma 14.8.7(23J520) arm64 VM에서 Git과 Spotlight 시험 입력을 준비했다. 첫 실행은 격리 작업 공간에 7z·RAR 시험 파일이 없어 해당 검사에서 실패했다. 파일을 추가한 뒤 한국어·영어와 밝은·어두운 테마 네 조합에서 동일한 검사 281개가 모두 통과했다. 네 보고서의 검사 키와 언어·테마를 대조했다. 이 실행에 사용한 디버그 실행 파일의 SHA-256은 `1c906654862491dcf904a40ca131306a933cf53a85ef697f94cb464d7eee3901`이다. 보고서를 생성하지 않는 프로세스는 네 조합 모두 실패로 기록하고 명령이 오류로 종료되는 것을 확인했다.

[macOS 15 CI](https://github.com/taro6222/files-for-mac/actions/runs/44087558524)의 아키텍처별 실행 결과는 워크플로가 끝나면 기록한다.

이전 [macOS 15 회귀 실행](https://github.com/taro6222/files-for-mac/actions/runs/44084563628)에서 Apple Silicon은 통과했다. Intel은 컴파일 109개 단계 중 106개까지 진행하고 12분 제한에 도달했다. Intel 러너의 디버그 빌드 제한을 20분으로 늘렸다. 새 설정에서는 전체 AppKit 시험 단계까지 도달하는지 확인한다.
