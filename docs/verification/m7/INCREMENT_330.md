# M7 Increment 330 — 창별 프레임·패널 너비 세션

상태: 구현·로컬 검증 완료. 이 소스의 원격·8시간 수용은 진행하며 M7 출시는 미완료다.

기존 세션은 창 그룹·탭 순서/선택·pane 상태를 저장했지만 창별 위치/크기와 패널 너비는 없었다. 새 WorkspaceWindowGeometry가 좌표·크기와 사이드바/정보 패널의 선호 너비를 저장한다. 저장에는 실제 선택 탭의 창을 사용해 숨은 탭의 오래된 프레임을 기록하지 않는다. 최소 창에서 임시로 줄어든 유효 너비 대신 사용자 선호 너비를 보존한다.

기하 정보는 기존 workspaceSessionV2 평면 배열의 선택 메타데이터다. 이전 SplitTabState 배열 읽기를 유지한다. 그룹의 각 탭에 같은 값을 넣어 첫 탭이 손상돼도 살아 있는 탭에서 기하 정보를 복구한다. 잘못된 기하 정보만 버리고 정상 탭/다른 창을 유지한다. 좌표는 보조 화면의 음수를 허용하며 비정상·비유한·실용 범위를 벗어난 프레임은 거부한다. 패널 너비는 설계 범위로 보정한다.

복원은 저장 프레임과 가장 많이 겹치는 현재 화면을 고르고, 겹치는 화면이 없으면 현재 기본 화면을 사용한다. 기본 최소 크기와 현재 화면 범위에 맞춰 크기·좌표를 제한한다. Compact Overlay 중에는 원래 일반 창 프레임을 저장한다. 연결 해제 검사는 가상 화면 사각형 목록을 사용한 것으로 실제 케이블 연결 해제 수용과 구분한다.

같은 창의 새 탭·탭 전환·닫기 후 인접 탭에도 현재 패널 너비를 전달한다. 배경 탭을 옮길 때는 원래 그룹에서 제거한 다음 목적지 그룹의 너비를 적용한다. 선택하지 않은 삽입 직후에도 목적지 값을 갖는지 검사한다. 반복된 같은 값은 분할 뷰 재배치를 만들지 않는다. 정보 패널 표시 여부·상세/미리보기 모드는 기존의 저장된 앱 설정을 계속 사용한다.

새 Core 시험은 좌표/크기 거부·패널 너비 보정, 창별 값과 이전 배열 읽기, 손상된 기하 정보의 분리, 손상된 첫 탭 뒤 기하 정보 복구를 확인한다. AppKit은 실제 창을 닫고 새 컨트롤러로 창 두 개의 서로 다른 프레임·패널 선호 값을 복원한다. 활성 탭 너비를 바꾼 뒤 전환/닫기에서도 이어지는지와 가상 화면 경계 보정을 확인한다.
