# M7 Increment 74 — 메모리 증가의 탐색 대조 시험

장시간 시험에 탐색 대조 모드를 추가했다. 이 모드는 같은 폴더 열기, 표시 확인, 디렉터리 감시, 홈 복귀, 메모리 계측을 실행한다. 새 탭 생성·닫기와 파일 복사·삭제는 전체 모드에서 실행한다. JSON 보고서에는 실행 모드를 기록한다. 출시 판정은 기존과 같이 기본 모드인 `full`의 8시간 결과를 사용한다.

```sh
bash scripts/verify-release-soak.sh 1800 /private/tmp navigation
```

Apple Silicon macOS 27.2에서 동일한 최적화 빌드로 45초 예비 시험을 각각 실행했다. 탐색 대조 모드는 47.54초 동안 21사이클을 완료했고, 최대 물리 메모리는 52.7 MiB였다. 전체 모드는 46.99초 동안 16사이클을 완료했고, 최대 물리 메모리는 69.2 MiB였다. 셸과 바이너리 모두 잘못된 모드를 종료 코드 2로 거부했다. 이 표본은 모드 실행과 보고서를 확인한 결과다. 지속 증가가 어느 경로에서 발생하는지는 장시간 대조가 필요하다.

### 30분 대조 결과

소스 `ea22946b6ce945cd068fb4f7933d653566639b4d`에서 빌드한 동일 바이너리(SHA-256 `dcb5ecb8b6b31d9f46689050bd2743cf1e35e709d3cee1544ac6575b1f286e8b`)로 두 모드를 각각 실행했다. 두 실행 모두 완료 상태와 종료 코드 0을 확인했다.

| 모드 | 완료 시간 | 사이클 | 첫 / 마지막 물리 메모리 표본 | 최대 물리 메모리 |
|---|---:|---:|---:|---:|
| 탐색 | 1,802초 | 712 | 46.2 / 149.4 MiB | 150.6 MiB |
| 전체 | 1,801초 | 543 | 62.5 / 114.6 MiB | 124.2 MiB |

탐색만 실행해도 물리 메모리가 증가했다. 두 모드는 사이클 수가 달라 모드별 최대값을 특정 기능의 비용으로 해석할 수 없다. [후속 상세 목록 수정](INCREMENT_76.md)의 8시간 전체 시험은 진행 중이다.
