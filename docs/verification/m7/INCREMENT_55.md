# M7 Increment 55 — DMG 내용물 자동 검증

프리뷰와 정식 DMG 빌드는 서명된 앱을 패키징하기 전에 `scripts/verify-dmg-contents.sh`를 실행한다. 정식 다운로드 검증은 이미지의 서명과 공증을 검사한 뒤 읽기 전용 마운트에서 같은 검사를 실행한다. 다운로드 검증에는 라이선스와 릴리스 노트 비교를 위해 이미지 빌드에 사용한 소스 커밋이 필요하다.

앱, `/Applications` 링크, 라이선스, 릴리스 노트의 구성을 확인한다. 두 라이선스와 릴리스 노트를 소스 원본과 바이트 단위로 비교하고 릴리스 노트의 제목을 앱 버전과 대조한다. 앱 번들 구성과 식별자, 코드 서명, arm64·x86_64의 macOS 14.0 대상 및 시스템 libarchive 연결을 검사한다.

Apple Silicon Mac에서 유니버설 프리뷰 0.1.0을 빌드했고 SHA-256 대조 및 읽기 전용 마운트 검증을 통과했다. 복제한 내용물의 릴리스 노트 변경, 테스트용 7z 파일 추가, 잘못된 설치 링크, 라이선스 변경을 각각 거부했다. 정식 Developer ID 및 공증 프로필은 준비 중이며 자격 증명이 마련되면 서명·공증된 이미지에서 다운로드 검증을 실행한다.
