# M7 Increment 247 — 코드 서명 검사 출력 처리

코드 서명 검사 도구가 stdout과 stderr를 파이프에 쓰는 동안 출력을 읽는다. 중첩 번들의 진단처럼 파이프보다 큰 출력이 나오면 프로세스 종료를 먼저 기다리는 방식은 멈출 수 있다. 화면에 보관하는 진단은 기존과 같은 256 KiB로 제한하고 그 이후의 출력도 읽어 프로세스가 종료될 수 있도록 한다.

Apple Silicon macOS 27.2에서 FilesCore를 빌드했다. Swift Testing에서 1 MiB 이상을 출력하고 오류 코드 7로 종료하는 프로세스의 종료 코드와 256 KiB 제한을 확인했다. 메타데이터 파싱, 실제 ad-hoc 서명 Mach-O 및 미서명 텍스트 검사도 통과했다. 인증서로 서명한 앱과 실제 중첩 번들 대조는 남아 있다.
