# M7 Increment 130 — APFS 폴더 생성 시간 보존

APFS 볼륨 사이에서 폴더를 복사하거나 이동할 때 최상위 폴더와 하위 폴더의 생성 시간을 복원하고 검증한다. 이동 실행 취소에도 같은 복원 경로를 적용한다. 이전 저널은 기록 당시 저장한 생성 시간만 비교한다.

임시 복사본의 메타데이터를 쓰기 전에 경로의 각 구성 요소를 디렉터리 파일 디스크립터에 상대적으로 연다. 중간 경로나 최종 항목이 심볼릭 링크면 생성 시간 복원을 중단한다.

Swift 테스트 229개와 실제 APFS·대소문자 구분 APFS·exFAT 마운트 검사 6개가 통과했다. APFS 볼륨 간 복사·이동·실행 취소에서 두 폴더의 서로 다른 생성 시간이 보존됐다. 임시 경로의 하위 폴더를 심볼릭 링크로 바꾼 시험에서는 링크 밖 파일의 생성 시간이 유지됐다.
