# M7 Increment 280 — 설치 프리뷰의 정식 업데이트 메뉴

앱 소스 `40ffc39d4059f09be35e9d7efa6fcb8bd33b559c`로 유니버설 프리뷰 0.1.0(1)을 만들었다. 로컬 DMG SHA-256은 `9179564d9b9cf227d6d43626cbe8ee0a5c859d3f4998698139025289a0f6c103`이다. 읽기 전용 마운트에서 arm64와 x86_64의 ad-hoc 서명, macOS 14.0 최소 대상, `preview` 채널 및 최신 릴리스 노트를 확인했다. DMG 내부 앱 실행 파일 SHA-256은 `50a6a0ef04b79284561a4c0b0d0c17b903483bc844dc26c80aca7fa8c9294971`이다.

Apple Silicon Sonoma 14.8.7(23J520)에서 DMG의 앱을 복사하고 서명을 확인한 뒤 Launch Services로 열었다. AppKit 접근성 API로 영어와 한국어의 **업데이트 확인…** 메뉴를 실행하고 해당 창의 안내 문구를 읽었다. 두 언어 모두 공개 GitHub 조회 결과에 따라 다운로드할 정식 배포 버전이 없다고 표시했다. 메뉴 검증 전후의 설치본 서명은 유효했다.

별도 격리 설치에서 이전 프리뷰 `32110fa`를 실행하고 손상된 후보를 거부한 뒤 새 프리뷰로 교체·복원했다. 네 단계에서 설정·사용자 파일이 보존됐고 이전 및 현재 형식의 탭 세션을 복원했다. [설치·복원 보고서](preview-install-40ffc39-sonoma.json)

Developer ID로 서명·공증된 정식 릴리스를 게시한 뒤 다운로드와 실제 정식 업데이트 설치를 검증한다.
