# M7 Increment 310 — 최적화 표본과 원격 실패 결과 대조

상태: 로컬 최적화 성능 기준·기록 검증 통과. 두 CPU 원격 검증과 정식 출시·전체 M7 완료는 진행 중이다.

`4a19117`의 Git archive에서 별도로 빌드한 최적화 QA를 사용했다. 로컬 10,000항목 20개 프로세스의 원본 표본에서 첫 표시 p95는 0.052991250초, 모델 열거 p95는 0.444648375초, 목록 반영 p95는 0.453041083초다. 100,000항목은 세 표본이며 모델 열거 최대 3.954384750초다. 100,000항목 20회 수용이나 콜드 시작 결과로 해석하지 않는다. 300초 유휴 측정까지 스크립트가 정상 종료했고 원본 표본·요약·소스·CPU 대조가 통과했다. [원본 보고서](optimized-performance-4a19117-local.json), [기준 판정](optimized-performance-4a19117-local-assessment.json).

로컬 환경은 Apple Silicon·24 GiB·macOS 27.2.1(26B131)·APFS다. 최적화 QA 바이너리 SHA-256은 `3c714e0bee40a4bac71700503fd4703b5b8093374b3ff2318fcea407bf6c7f43`이다. 유휴 후 모델 열거는 0.414489333초, 첫 표시는 0.059756750초, 유휴 RSS는 94,666,752바이트였다. 한 번의 유휴 관찰이며 장시간 메모리 안정성을 뜻하지 않는다.

측정 중 이전 소스의 장시간 시험 두 개가 함께 실행됐다. 격리된 처리량 비교, 서명된 설치 앱, 실제 입력·프레임 표시, 최소 OS·CPU 매트릭스의 정식 수용과 구분한다. 두 CPU의 새 최적화 CI와 전체 AppKit CI도 별도 실행 중이다.

이전 입력 수정본 `2899ed2`의 원격 검증은 전체 실패다. 두 CPU의 Xcode 빌드와 ARM 전체 검증은 성공했다. Intel 전체 AppKit은 한국어 두 테마와 영어 어두운 테마에서 각각 283개를 통과했으나, 영어 밝은 테마에서 `folderSizeCalculation` 한 개가 실패했다. 목록 10,000개는 준비됐지만 자동 크기가 기존 5초 안에 반영되지 않았고 작업은 대기 중이었다. 같은 프로세스의 개별 크기 조회는 21바이트로 성공했다. 이것만으로 원인이나 수정 완료를 단정하지 않는다. 대기 시간·검사 수·성공 조건은 그대로 유지한다.
