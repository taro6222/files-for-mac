# M7 Increment 59 — 로컬 임시 경로에서 8시간 시험 시작

`scripts/verify-release-soak.sh`는 두 번째 인자로 기존 디렉터리를 받아 해당 경로에 독립 빌드·시험 폴더를 만든다. 인자를 생략하면 프로젝트의 `build`를 사용한다. 실행 증거에는 소스 SHA, 바이너리 SHA-256, macOS 버전과 함께 `df -P` 결과를 남긴다.

Apple Silicon macOS 27.2에서 `dab9839c983185302d7db6604b1202d41ba885b7`의 최적화 빌드를 `/private/tmp`에 생성했다. 바이너리 SHA-256과 실행 프로세스, 28,800초 목표가 일치함을 확인했다. 실행 중인 표본에서 46.2초 동안 16사이클을 완료했다. 같은 시점에 작업 폴더의 이전 후보 `7ca42b8`는 724.3초 동안 30사이클을 완료했다. 후보와 경로가 모두 달라 이 표본으로 경로만의 영향을 정량화할 수 없다.

셸 구문 검사와 0초·일반 파일을 부모로 지정한 입력의 거부를 확인했다. 로컬 임시 경로에서 시작한 8시간 시험은 진행 중이며 완료 시간, 종료 상태, 메모리 추세가 출시 판정에 필요하다.
