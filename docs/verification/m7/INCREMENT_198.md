# M7 Increment 198 — 상세 보기의 기본 Finder 태그 열

Windows 원본처럼 상세 보기에서 이름 다음에 태그 열을 기본 표시한다. 저장한 표시 설정과 기존 창의 열 레이아웃을 읽으며 태그 열을 숨긴 설정을 유지한다. 태그 설정이 없는 예전 설정 파일을 가져오면 기본값을 적용한다.

보조 패널에도 Finder 태그 열을 추가했다. 두 패널은 항목의 태그를 같은 형식으로 표시하고 이름·크기 등과 함께 정렬 및 열 너비 자동 맞춤을 지원한다. 탐색 옵션에서 Finder 태그 열을 켜거나 끄면 두 패널에 반영된다. 새 기본 열 배치에서는 이름·수정일·종류 열의 초기 너비를 조정해 크기 열까지 보이도록 했다.

Apple Silicon macOS 27.2에서 앱 빌드, Swift Testing의 열 설정 기본값·저장 회귀와 영어·밝은 테마 AppKit 검사 282개를 통과했다. 열 너비를 최종 조정하기 전 빌드에서도 양쪽 패널의 기본 표시·숨기기·다시 표시를 포함한 파일 작업 검사 70개가 한국어·영어와 밝은·어두운 테마 네 조합에서 각각 통과했다. [자동 맞춤을 적용한 공통 폴더 화면](ui-03-macos-default-tag-column.png)
