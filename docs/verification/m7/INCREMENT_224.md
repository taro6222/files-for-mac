# M7 Increment 224 — Windows와 macOS 정보 패널 대조

[Windows 원본 실행](https://github.com/taro6222/files-for-mac/actions/runs/43665796968)에서 고정 SHA `99951c66928c4da714da8b1dd46039421182cbab`의 상세·미리보기 탭을 캡처했다. 접근성 트리에서 상세의 `preview.txt`와 미리보기의 `Files reference preview`가 각 영역에 표시됐고, 두 PNG의 SHA-256이 실행 기록과 일치했다. 실행은 두 화면을 저장한 뒤 컬럼 보기 단계에서 창을 잃어 실패했다. [Windows 상세](ui-08-windows-reference-details.png) · [Windows 미리보기](ui-08-windows-reference-preview.png)

두 앱은 파일 목록 옆에 상세·미리보기 탭을 표시한다. 공통 파일의 이름·경로·수정일과 같은 미리보기 본문을 확인했다. 이 Windows 실행의 상세 패널에는 아이콘·생성일·태그 편집·속성 바로가기가 표시된다. 현재 macOS 상세 패널에는 종류·크기·소유자와 Finder 태그가 표시된다. 생성일과 태그 편집·속성 바로가기, 다른 종류의 미리보기 상태를 추가로 검증한다.
