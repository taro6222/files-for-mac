# M7 Increment 80 — Quick Look 패널의 선택과 닫기

Quick Look 패널은 앱에서 공유한다. 닫기 요청을 받은 컨트롤러가 현재 데이터 소스를 맡고 있을 때만 패널을 닫고 연결을 해제한다. 다른 컨트롤러에서 시작한 미리보기에는 영향을 주지 않는다.

AppKit 검증에서 기존의 폴더 대신 실제 텍스트 파일을 선택한다. 패널의 현재 Quick Look 항목 URL을 선택한 파일과 대조하고, 다른 컨트롤러의 닫기 요청을 무시하는지 확인한다. 현재 컨트롤러가 닫은 후에는 데이터 소스 연결과 항목 목록이 해제되는지 확인한다. 이 자동화 환경에서는 공유 패널의 표시 상태가 지속된 사례가 있어 창이 사라지는 동작은 별도 실행 검증으로 남겼다.

AppKit 캡처에는 파일명이 나타났으나 본문은 관찰되지 않았다. Quick Look 확장별 콘텐츠 렌더링 검증은 남아 있다. 응답자 체인에 패널 제어를 맡긴 실험에서 선택 항목이 사라지는 회귀가 발생해 해당 변경을 제외했다. [Apple Quick Look 패널 문서](https://developer.apple.com/documentation/quicklookui/qlpreviewpanel)

최종 제품 코드에서 AppKit 빌드와 한국어·영어 × 밝게·어둡게 검사 각 232개를 통과했다.
