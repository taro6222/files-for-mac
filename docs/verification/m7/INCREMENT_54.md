# M7 Increment 54 — 교차 볼륨 실행 취소 강제 종료 검증

`scripts/verify-move-undo-interruption.sh`는 현재 Mac의 로컬 파일 시스템과 임시 APFS 디스크 이미지 사이에서 교체 이동을 수행한다. 실행 취소가 원래 경로에 검증 사본을 게시한 직후 테스트 프로세스에 SIGKILL을 보낸다. 새 테스트 프로세스는 같은 저널을 읽고 두 사본과 기존 백업의 내용을 검사한 뒤 남은 복원을 수행한다.

재개 시험에서 서로 다른 프로세스 ID, 이전 실행의 완료 저널 부재, 두 사본과 백업의 중단 시점 내용, 복원 후 양쪽 경로의 내용 및 보류 저널 소비를 확인한다. 별도 물리 디스크, 전원 차단, 실제 SMB와 앱 UI를 통한 재시작 검증은 남아 있다.

Apple Silicon macOS 27.2 (26B123)에서 강제 종료 후 새 프로세스의 복원 시험 1개와 일반 Swift 회귀 시험 212개가 통과했다. 일반 회귀에서는 강제 종료 시험의 환경 변수를 설정하지 않는다.
