# M7 Increment 277 — SMB 파일 기록 중 세션 중단 시험

APFS에서 인증 SMB 공유로 384 MiB 파일을 교차 볼륨 이동한다. 서버의 로컬 파일에서 임시 게시본 앞부분의 데이터와 아직 기록되지 않은 끝부분을 관찰한 뒤 Samba 세션 종료를 요청한다. 요청 반환 직후에도 끝부분이 비어 있어야 한다. 파일 크기가 먼저 할당되는 경우도 있으므로 실제 바이트를 읽어 기록 진행을 판정한다.

같은 마운트의 재연결 횟수와 장치 번호를 확인한다. 이동이 끝났으면 대상 전체의 내용을 비교하고 실행 취소로 원본을 복원한다. 이동이 실패했으면 공개 대상이나 실행 취소 기록이 없어야 한다. 두 경우 모두 시험 종료 시 원본 내용의 일치와 임시 파일 제거를 확인한다.

이 시험은 [게시 뒤 원본 삭제 전 중단](INCREMENT_275.md)보다 앞선 기록 단계에서 세션을 끊는다. 변경한 Swift 통합 시험 파일의 Swift 6 타입 검사, 셸·Python 구문 검사와 대응표 감사가 통과했다. 실마운트 결과는 macOS CI에서 확인한다. 장기 단절과 외부 서버 권한 변경은 별도로 검증한다.

[실마운트 실행](https://github.com/taro6222/files-for-mac/actions/runs/44088721660)에서 커밋 `32110fa`의 통합 시험 6개가 통과했다. 기록 중 종료 요청이 돌아왔을 때 서버 파일의 끝부분이 여전히 비어 있었고 재연결 횟수는 2에서 3으로 증가했다. 이동은 `partial`로 종료됐으며 시험은 원본 내용 일치, 공개 대상 부재, 실행 취소 기록 부재와 임시 파일 정리를 확인했다. 같은 실행에서 시각 보존과 게시 후 교체 이동·실행 취소도 통과했다.
