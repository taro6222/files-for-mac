# M7 Increment 140 — 복사·이동 결과의 접근성 알림

복사와 이동 결과에 취소한 항목 수를 표시하고, 이동 결과에는 실행하지 않은 항목 수도 표시한다. 작업 저널을 저장하지 못한 경우에는 접근성 알림에 오류를 포함한다. 이동 자체에 실패하면 접근성 알림으로 오류 설명도 전달한다.

자동 검사는 AppKit이 접근성 알림에 넘기는 문자열에 복사 취소 건수와 이동 충돌 건수가 들어가는지 확인한다. 데스크톱 연결을 두 번 시도했으나 시간 제한을 초과해 실제 VoiceOver 음성 및 자막 패널은 검증하지 못했다. 실제 확인 시 탐색→복사→충돌 처리의 초점 순서와 결과를 읽고, 취소한 작업과 저널 저장 실패에서도 알림이 전달되는지 대조한다. [Apple VoiceOver 자막 패널 안내](https://support.apple.com/guide/voiceover/use-the-braille-and-caption-panel-unac078/mac)

한국어·영어와 밝은·어두운 테마의 AppKit 파일 작업 시험이 조합별 68개씩 통과했다.
