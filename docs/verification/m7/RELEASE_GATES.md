# M7 출시 검증 현황

| 검증 | 현재 증거 | 완료에 필요한 실행 |
|---|---|---|
| 로컬 설치 이미지 | Apple Silicon 마운트, 체크섬, ad-hoc 앱 서명 및 실행 | 깨끗한 Mac에서 다운로드·설치·재실행 |
| Developer ID·공증 | 공증 응답 검사와 최종 이미지 검증 경로, 모의 실패에서 기존 산출물 보존 확인. 자격 증명 준비 중 | 설치된 인증서와 Keychain 프로필로 정식 DMG를 만들고 Gatekeeper 검사 |
| OS·CPU 환경 | Apple Silicon macOS 27.2에서 실행, Intel용 바이너리 교차 컴파일 | Intel 및 최소 지원 macOS 14에서 실행·회귀 |
| 로컬·네트워크 볼륨 | APFS·대소문자 구분 APFS·exFAT 파일 작업과 일괄 이름 교환, 시스템 휴지통 검증 | 실제 SMB 공유에서 재연결, 중단, 권한, 갱신 |
| 외부 서비스 | FTP/FTPS/SFTP 루프백 및 Git 임시 원격 검증 | 실제 클라우드 계정, 외부 서버 인증·오프라인, Git 인증 조합 |
| 기능·화면 대응 | 명령·설정·화면 378건 분류, 한국어·영어 AppKit 자동화, 복사·이동 충돌 정책과 결과 키보드 검증 | 전체 키보드 동선, 사용자 동선별 적용 기능 검증, Windows 기준 화면 실제 대조 및 VoiceOver |
| 성능·장시간 | 최적화 빌드 10,000항목 전체 표시 p95 1.350초, 100,000항목 13.16–13.90초. 프리뷰 새 프로세스 20회에서 창 표시 p95 248 ms. 장시간 검증 예비 실행 28사이클 통과 | 배포 앱 콜드 시작부터 상호작용까지, 화면 프레임·장시간 메모리·8시간 지속 검증 |
| 업데이트·복구 | 기존 설정 형식과 JSON 내보내기·가져오기 자동화. 격리 프리뷰 설치·손상본 거부·교체·복원 통과 | 정식 버전 간 설정 마이그레이션, 설치 실패 복구 및 배포 이미지 버전 확인 |
| 라이선스·릴리스 노트 | 앱·DMG 라이선스, 설치·복구 안내, OS 제공 libarchive 연결 및 테스트 fixture 제외 확인 | 서명·공증된 정식 이미지에서 내용 재검사 |

[정식 출시 기준](../../VALIDATION_AND_RELEASE.md)은 이 표의 환경별 실행 결과가 갖춰진 뒤 판정한다.
