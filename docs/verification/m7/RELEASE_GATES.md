# M7 출시 검증 현황

| 검증 | 현재 증거 | 완료에 필요한 실행 |
|---|---|---|
| 로컬 설치 이미지 | Apple Silicon 마운트, 체크섬, ad-hoc 앱 서명 및 실행 | 깨끗한 Mac에서 다운로드·설치·재실행 |
| Developer ID·공증 | 공증 응답 검사와 다운로드 DMG 검증 경로, 모의 실패에서 기존 산출물 보존 확인. 자격 증명 준비 중 | 설치된 인증서와 Keychain 프로필로 정식 DMG를 만들고 다운로드 후 검증 및 실행 |
| OS·CPU 환경 | Apple Silicon macOS 27.2에서 실행, DMG의 arm64·x86_64 최소 대상 macOS 14.0 및 서명 확인 | Intel 및 최소 지원 macOS 14에서 실행·회귀 |
| 로컬·네트워크 볼륨 | APFS·대소문자 구분 APFS·exFAT 파일 작업, 일괄 이름 교환과 교체 중 취소, 시스템 휴지통 검증. 루프백 SMB 마운트와 [무응답 검증 종료](INCREMENT_36.md) 확인 | 정상 응답하는 SMB 공유에서 파일 작업, 재연결, 중단, 권한, 갱신 |
| 외부 서비스 | FTP/FTPS/SFTP 루프백 및 Git 임시 원격 검증 | 실제 클라우드 계정, 외부 서버 인증·오프라인, Git 인증 조합 |
| 기능·화면 대응 | 명령·설정·화면 378건 분류, 한국어·영어 AppKit 자동화, 복사·이동 충돌 키보드 검증, UI-01~05 원본 XAML과 macOS 구조 대조 | 전체 키보드 동선, 사용자 동선별 적용 기능 검증, Windows 기준 화면 실제 대조 및 VoiceOver |
| 성능·장시간 | 최적화 빌드 10,000항목 전체 표시 p95 1.350초, 100,000항목 13.16–13.90초. 프리뷰 창 표시 p95 248 ms. APFS 512 MiB 파일은 검증을 포함한 네이티브 기준 처리량의 102.95%. 장시간 검증 예비 실행 통과 | 콜드 시작부터 상호작용까지, 60Hz 스크롤 프레임 목표 재검증(대조군과 스크롤 모두 창 캡처 p95 약 33ms), 장시간 메모리·8시간 지속 검증 |
| 업데이트·복구 | 최초 v1 설정 파일 가져오기와 다시 읽기, 미래 스키마 거부. 격리 프리뷰 설치·손상본 거부·교체·복원 통과 | 정식 버전 간 설정 마이그레이션, 설치 실패 복구 및 배포 이미지 버전 확인 |
| 라이선스·릴리스 노트 | 앱·DMG 라이선스, 설치·복구 안내, OS 제공 libarchive 연결 및 테스트 fixture 제외 확인 | 서명·공증된 정식 이미지에서 내용 재검사 |
