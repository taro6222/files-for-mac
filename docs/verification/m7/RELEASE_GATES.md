# M7 출시 검증 현황

| 검증 | 현재 증거 | 완료에 필요한 실행 |
|---|---|---|
| 로컬 설치 이미지 | Apple Silicon 마운트, 체크섬, ad-hoc 앱 서명 및 실행 | 깨끗한 Mac에서 다운로드·설치·재실행 |
| Developer ID·공증 | 서명·공증 실행 경로 제공 | 설치된 인증서와 Keychain 프로필로 정식 DMG를 만들고 Gatekeeper 검사 |
| OS·CPU 환경 | Apple Silicon macOS 27.2에서 실행, Intel용 바이너리 교차 컴파일 | Intel 및 최소 지원 macOS 14에서 실행·회귀 |
| 로컬·네트워크 볼륨 | APFS·대소문자 구분 APFS·exFAT와 시스템 휴지통 통과 | 실제 SMB 공유에서 재연결, 중단, 권한, 갱신 |
| 외부 서비스 | FTP/FTPS/SFTP 루프백 및 Git 임시 원격 검증 | 실제 클라우드 계정, 외부 서버 인증·오프라인, Git 인증 조합 |
| 기능·화면 대응 | 명령·설정·화면 378건 분류, 한국어·영어 AppKit 자동화 | 사용자 동선별 적용 기능 검증, Windows 기준 화면 실제 대조 및 VoiceOver |
| 성능·장시간 | 최적화 빌드 10,000·100,000항목과 5분 유휴 RSS 측정. 10,000항목 전체 표시 p95 1.842초로 시험 목표 충족. 장시간 검증 예비 실행 28사이클 통과 | 배포 앱 콜드 시작, 화면 프레임·장시간 메모리·8시간 지속 검증 |
| 업데이트·복구 | 기존 설정 형식과 JSON 설정 내보내기·가져오기 자동화 | 정식 버전 교체 후 첫 실행, 설치 실패 복구, 배포 이미지 버전 확인 |
