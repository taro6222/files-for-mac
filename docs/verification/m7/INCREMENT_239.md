# M7 Increment 239 — SMB 수정 시각 정밀도

[SMB 3.1.1 실마운트 시험](https://github.com/taro6222/files-for-mac/actions/runs/43670246753)에서 기본 파일 작업, 교차 볼륨 이동과 실행 취소가 통과했다. 폴더 내 파일의 복사본은 수정 시각이 약 119ns 달라 검증에서 중단됐고 원본은 보존됐다. 기존 대상이 있는 교체 이동도 실패했다.

SMB가 포함된 전송의 수정 시각 비교는 프로토콜의 100ns 눈금과 두 Foundation Date 값의 표현 간격 중 큰 값 한 단위를 더한 범위에서 반올림 차이를 허용한다. 원본 재검사와 실행 취소 장부의 대조에는 정확한 일치가 계속 필요하다. 교체 시험이 실패하면 앱이 보고한 오류와 원본·기존 대상의 바이트 보존을 확인한다. [파일 시각 형식](https://learn.microsoft.com/en-us/openspecs/windows_protocols/ms-fscc/a69cc039-d288-4673-9598-772b6083f8bf)

Apple Silicon에서 수정 시각 반올림과 원본·장부 검증, 열린 파일 식별자 및 교체 복구를 포함한 Swift Testing 5개를 통과했다. SwiftPM의 전체 시험 번들 링크가 지연되어 컴파일된 시험 오브젝트를 개별 실행 파일로 연결했다. 폴더 복사와 교체 이동 결과는 실제 SMB 재시험에서 확인한다.
