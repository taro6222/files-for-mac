# M7 Increment 19 — 교체 이동의 백업 복원 실패 기록

교체 이동이 취소되거나 실패하면 이미 확보한 기존 대상 백업을 복원한다. 복원할 폴더가 작업 시작 시 열었던 폴더인지 확인하고, 대상 이름이 다른 항목으로 점유된 경우 백업과 점유 항목을 보존한다. 자동 복원에 실패하면 저널의 백업 경로를 유지하고 결과 창에 한국어·영어로 표시한다.

교차 볼륨 이동의 검증 단계에서 새 파일을 대상 이름에 만들고 취소하는 회귀 시험을 추가했다. 원본·동시에 생성된 대상·기존 백업의 내용과 결과 및 저널의 백업 경로를 모두 검사한다. Swift 테스트 202개 및 실제 APFS·대소문자 구분 APFS·exFAT 볼륨 검사 3개를 통과했다. 네트워크 단절·재연결은 마운트된 SMB 공유에서 별도로 확인해야 한다.

한국어·영어와 밝게·어둡게 조합별 AppKit 파일 작업 회귀 38개를 통과했다. 백업 경로는 충돌을 주입한 Swift 검사에서 확인했다.
