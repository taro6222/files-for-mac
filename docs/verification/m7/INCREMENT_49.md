# M7 Increment 49 — 실행 취소 도중 발생한 복원 충돌

교체 이동을 실행 취소하다 기존 대상의 백업을 복원할 경로가 점유되면, 결과를 일반 실패 대신 경로 충돌로 표시한다. 실행 취소가 원래 파일을 돌려놓은 직후, 백업을 게시하기 전에 테스트가 같은 이름의 외부 파일을 생성한다.

테스트는 앱이 실제로 저장한 저널을 다시 읽어 백업 복원만 남았는지 확인한다. 대상이 계속 점유돼 있으면 외부 파일과 백업을 보존하고, 경로가 비워지면 백업만 복원한다. 원래 파일의 내용과 완료된 저널의 정리도 확인한다. 프로세스 강제 종료와 실제 SMB에서 같은 시나리오를 실행하는 검증은 남아 있다.

Apple Silicon macOS 27.2 (26B123)에서 Swift 회귀 시험 207개를 통과했다.
