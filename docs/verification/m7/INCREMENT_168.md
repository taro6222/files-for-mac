# M7 Increment 168 — SMB 사전 검사 중단 위치와 시험 폴더 기록

사전 검사는 고유한 폴더 경로를 생성 시도 전에 출력한다. 쓰기·읽기·이름 변경·정리의 시작도 각각 기록한다. 제한 시간이 지나면 기존 프로세스 그룹 종료를 적용한다. 공유가 다시 응답할 때 출력된 경로로 시험 파일을 확인할 수 있다.

APFS 대역에서 쓰기·읽기·이름 변경·정리별 오류와 지연을 주입했다. 오류 네 건은 코드 75, 지연 네 건은 코드 124를 반환했고 Swift 통합 시험에는 진입하지 않았다. 중단 뒤 남은 폴더는 로그의 경로와 일치했고, 별도로 만든 폴더는 유지됐다. 정상 왕복과 정리도 확인했다.

이 Mac에는 SMB 마운트가 없었다. 루프백 TCP 445 연결은 열렸으나, 자격 증명 없는 `smbutil view`는 연결 시간 초과로 코드 68을 반환했다. 실제 SMB 공유의 통합 검증은 남아 있다.
