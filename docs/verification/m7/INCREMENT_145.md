# M7 Increment 145 — 강제 종료 뒤 교체 이동의 메타데이터 보호

로컬 APFS와 별도로 마운트한 APFS 사이의 교체 이동을 실행 취소하다가 검증 복사본 게시 직후 테스트 프로세스를 SIGKILL로 종료했다. 새 프로세스에서 복원본에 확장 속성만 추가하자 재개가 충돌로 중단됐다. 복원본과 이동 대상, 기존 대상 백업은 모두 보존됐다.

시험에서 추가한 속성을 제거하고 보류 저널로 다시 실행하자 원래 위치와 기존 대상이 각각 복원됐다. 두 파일의 내용과 서로 다른 생성 시간이 보존됐다. 강제 종료 후 재개 시험 1개와 전체 Swift 테스트 229개가 통과했다.
