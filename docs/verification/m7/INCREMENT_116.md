# M7 Increment 116 — 개행과 선행 공백이 있는 Git 파일명

Git 상태 조회는 NUL로 레코드를 구분하고 경로의 개행·탭·선행 공백을 보존한다. 저장소 경로는 명령이 덧붙인 마지막 줄바꿈만 제거한다. Git 상태 패널의 경로 열은 개행, 캐리지 리턴, 탭과 역슬래시를 이스케이프해 한 줄에 표시한다. [Git 상태의 NUL 구분 경로 형식](https://git-scm.com/docs/git-status#_pathname_format_notes_and_z)

Apple Silicon의 APFS 임시 저장소에서 공백과 개행으로 끝나는 저장소 경로, 선행 공백과 한글이 있는 수정 파일, 선행 하이픈과 CRLF가 있는 이름 변경 원본, 개행이 있는 이름 변경 대상과 미추적 파일을 사용했다. 폴더 목록과 Git 상태에 원래 문자열이 유지됐으며 이름 변경의 원본·대상 경로를 함께 확인했다. 상대 경로의 상위 디렉터리 이동은 거부했다.

Swift 테스트 218개와 영어·밝은 테마의 AppKit 회귀 257개가 통과했다. Windows 실행 화면 비교는 남아 있다.

후속 AppKit 검사에서는 한글, 선행 공백과 하이픈, 역슬래시, 탭과 CRLF를 한 파일명에 넣었다. 네 언어·테마 조합에서 Git 상태 패널의 한 줄 표기와 같은 파일의 상세 보기 Git 상태를 확인했다. 각 조합의 전체 258개 검사가 통과했다. 영어·밝게 및 한국어·어둡게 캡처에서 개행과 탭이 행을 나누지 않는 것을 시각 확인했다.
