# M7 Increment 268 — 홈 복귀 시 폴더 감시 해제

주 창에서 다른 폴더로 이동하거나 창을 닫을 때 감시 작업의 Task 핸들을 해제한다. 최적화 부하 시험은 파일 목록에서 홈으로 돌아올 때 폴더 감시 상태가 유휴이고 경로와 Task 핸들이 비어 있는지 확인한다. 이전 감시 객체를 약한 참조로 대조해 5초 안에 해제되지 않으면 실패한다. 보고서에는 확인한 해제 횟수를 기록한다.

Apple Silicon macOS 27.2의 실제 AppKit 최적화 빌드에서 전체 부하 11사이클과 탐색 부하 14사이클이 각각 30초 이상 정상 실행됐다. 두 실행에서 감시 해제 횟수는 사이클 수와 일치했다. 이 검사를 포함한 8시간 안정성은 별도로 판정한다.
