# M7 Increment 159 — 사용자 소유권과 macOS 권한 확인

파일 권한 시트에 현재 소유자의 UID를 표시한다. 이미 사용자 소유권을 변경할 권한으로 실행된 프로세스에서는 계정 목록을 표시한다. 일반 계정에서는 편집을 비활성화하고 필요한 macOS 권한을 안내한다. 출시 설계의 권한 경계에 따라 앱 전체를 관리자 권한으로 다시 실행하는 동작은 없다.

저장 시 현재 사용자·그룹과 파일 식별자, 모드 및 ACL을 대조한다. 사용자 소유권 변경은 열린 파일 디스크립터를 통해 요청하고 적용된 UID를 확인한다. 기존 그룹과 ACL을 바꾸는 요청은 보내지 않는다. macOS가 setuid 또는 setgid 비트를 해제할 수 있음을 시트에 표시한다.

일반 계정에서 다른 사용자로 소유자를 바꾸면 macOS가 요청을 거부하며 기존 사용자·그룹과 모드가 유지된다. 전체 Swift 테스트 237개가 통과했다. SwiftPM이 컴파일한 테스트 객체를 Swift Testing 런타임에 직접 링크했다. 권한이 있는 계정에서의 실제 소유권 이전과 일반 앱의 관리자 승인 흐름은 검증 및 구현이 남아 있다.

한국어·영어와 밝은·어두운 테마 네 조합에서 각각 AppKit 검사 265개가 통과했다. 일반 사용자로 실행한 권한 시트에서 현재 UID를 읽고 사용자 소유권 편집이 비활성화됨을 확인했다. 기존 POSIX·그룹 소유권·ACL 편집 검사도 통과했다.
