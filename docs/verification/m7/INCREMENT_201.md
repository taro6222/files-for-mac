# M7 Increment 201 — Windows와 macOS 컬럼 보기 대조

[Windows 실기 실행](https://github.com/taro6222/files-for-mac/actions/runs/43658973559)이 성공했다. Windows 빌드 26100 x64의 Files 4.2.9에서 공통 폴더의 다섯 항목과 `Alpha`를 선택했을 때 인접 컬럼의 `column-note.txt`를 접근성 트리로 확인했다. 캡처의 SHA-256은 실행 기록과 일치한다. [Windows 컬럼 화면](ui-05-windows-reference-columns.png) · [캡처 정보](windows-reference-columns-4.2.9.json)

[macOS 컬럼 화면](ui-05-macos-reference-columns.png)에서도 `Alpha`를 선택하면 오른쪽 컬럼에 동일한 하위 항목이 나온다. Windows 화면은 볼륨 아래 상위 경로의 목록을 왼쪽 세 컬럼에 함께 표시하며, 이 시험에서 다섯 컬럼을 열었다. macOS 화면은 탐색 중인 공통 폴더에서 시작해 두 컬럼을 열었다. 캡처의 창 크기와 포인터 상태가 달라 동일 조건의 시각 검증이 남아 있다.
