# M7 Increment 24 — 대용량 복사 처리량

```sh
bash scripts/verify-copy-throughput.sh bef5272 56e9553
```

두 커밋의 FilesCore를 각각 최적화 빌드한다. 같은 512 MiB 파일을 APFS의 새 대상 경로에 다섯 번씩 복사한다. 타이머에는 앱의 정상 복사 호출, 내용 검증, 게시, 작업 저널 및 실행 취소 기록 저장이 들어간다. 매 표본 뒤 파일 권한과 실행 취소 기록을 확인하며, 실행 취소를 통해 복사본의 식별자·내용·권한이 기록과 일치하는지 검증한 뒤 해당 복사본을 제거한다. 이 후속 검사는 측정 시간에서 제외한다.

실행 순서는 이전 커밋에서 후보 커밋 순이다. OS 캐시를 비우지 않았다. 별도의 장시간 안정성 시험이 실행 중이었다. 앱 코드 변경 전후를 같은 정책으로 비교했으며, 설계서의 native copy 대비 80% 판정에는 별도의 동등한 기준 구현과 측정이 필요하다.

Apple Silicon macOS 27.2 (26B123)에서 복사 시간 중앙값이 0.964초에서 0.586초로 줄었다. 같은 크기 기준 처리량 중앙값은 531.3 MiB/s에서 873.1 MiB/s로 늘었다. 열 개 표본 모두 권한과 실행 취소 검증을 통과했다. [원시 표본](copy-throughput-local.json)
