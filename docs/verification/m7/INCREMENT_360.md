# M7 Increment 360 — 원격 빌드 프로세스 진단

상태: Debug·프리뷰 패키징 진단 연결과 로컬 headless 도구 검증 완료. 원격 시간 초과의 원인 확정·해결과 M7 정식 출시는 미완료다.

## 확인한 상태

이전 358 소스 ARM 로그는 테스트 실행 파일 링크 뒤 더 이상 진척을 기록하지 않고 Debug 빌드 12분 제한으로 종료했다. 로그만으로 컴파일 계산·메모리 압박·시스템 호출 대기 중 어느 것인지 구분할 수 없다. 로컬 CLT 6.4.2에서 이전에 보존한 getcwd/getxattr 스택을 원격 Xcode 26.3/Swift 6.2.4의 원인으로 단정하지 않는다.

같은 358 실행의 Intel은 이번 조회에서 Debug 빌드·Swift 시험·제한 실행기·실제 파일 작업/AppKit 계약·복구 시험을 통과했고 프리뷰 패키징 중이었다. 전체 workflow 성공이나 최신 359 소스 수용은 아니다. 359 실행은 처음 조회에서 pending이었다. 기존 실행을 수동 취소하거나 재시작하지 않았다.

## 동작

build-with-diagnostics.py가 명령을 private process group으로 한 번 실행하고 원래 stdout/stderr와 종료 코드를 유지한다. 120초 뒤, 이후 각 관찰 완료에서 240초 간격으로 최대 네 번 해당 그룹의 PID·부모·CPU·RSS·상태·실행 파일 경로를 기록한다. 활성 자식 우선 최대 네 개를 /usr/bin/sample로 1초 관찰한다. 환경과 명령의 전체 argv를 ps로 수집하지 않는다. 각 sample 도구의 8초 관찰 제한은 빌드를 중단하거나 다시 시작하지 않는다. 관찰 실패는 기록하고 같은 빌드를 계속 기다린다.

외부 SIGINT/SIGTERM은 소유 명령 그룹으로 전달하며 관찰 도구도 종료한다. 5초 뒤에도 종료되지 않으면 해당 그룹을 SIGKILL하고 직접 자식을 wait로 회수한다. 취소 상태와 실제 명령 종료 코드를 별도로 남긴다. 관찰 중 취소와 예외에서도 소유한 도구를 정리한다. JSON은 임시 파일 작성 후 rename해 중간 쓰기를 최종 보고서로 읽지 않게 한다.

기존 Debug 빌드와 build-dmg.sh --preview에 연결했다. 설치 앱 시작 검사는 기존 명령을 그대로 유지하고 진단 대상 패키징 명령과 구분한다. Debug 12분/20분·프리뷰 단계 15분 제한과 빌드 옵션은 변경하지 않았다. build monitor smoke와 각 프로세스/스택 기록을 always artifact로 보관한다. 직전 단계의 cancel-in-progress:false도 유지한다.

## 검증

짧은 Python fixture로 실제 도구 15개 검사를 모두 통과했다. 정상 출력/성공 코드, 실패 코드 23의 전달, 실제 sample 생성, 관찰을 거친 같은 2초 명령의 정상 완료와 재실행 부재를 확인했다. 관찰 중 SIGTERM을 보내 SIGTERM을 무시하는 부모/자식을 종료하고 직접 자식과 sample 도구를 회수했다. 일반 취소 대기는 5초이며 시험에서는 0.25초로 줄여 사용했다. 살아 있지 않은 zombie도 terminal로 구분하므로 손자 프로세스를 직접 wait했다고 주장하지 않는다.

YAML 파싱과 Debug·Release 진단 연결, 기존 제한 시간·자동 취소 해제 유지도 확인했다. 앱 소스·SDK·서명 코드는 바꾸지 않아 앱 빌드나 기존 앱 시험을 반복하지 않았다. 로컬 GUI·전체 AppKit·장시간 시험은 시작하지 않았다. [소스·시험·로그 해시](build-diagnostics-360-verification.json)를 따른다.

## 남은 실행

이 진단기를 포함한 실제 두 CPU workflow의 프로세스/스택을 회수해 원인을 확정하고 수정 후 빌드·제품 수용을 진행한다. 도구 smoke 성공을 제품 빌드 성공으로 집계하지 않는다. 나머지 metadata, helper 권한/자원 격리, 큰 생성 계획, 지원 OS/CPU·실제 입력/VoiceOver·원본 UI·정식 서명/공증 게이트도 열린 상태다. 인증서/프로필은 사용자 준비 중이며 로컬 장시간 시험은 자동 재시작하지 않는다.
