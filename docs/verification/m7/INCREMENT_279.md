# M7 Increment 279 — 앱의 정식 업데이트 확인

Files macOS 앱 메뉴와 명령 팔레트에 **업데이트 확인…**을 추가했다. 사용자가 명령을 실행하면 공개 GitHub Releases API에서 정식 릴리스를 확인한다. 버전을 세 숫자로 비교하고 올라간 버전의 정식 DMG와 SHA-256 파일이 모두 올라온 경우 GitHub 릴리스 열기 버튼을 표시한다. 프리뷰에서 정식 릴리스로 전환할 때는 표시 버전이 같아도 설치할 수 있다. [GitHub Releases API](https://docs.github.com/en/rest/releases/releases#get-the-latest-release)

구성한 프로젝트의 고정 경로로 브라우저를 열며 릴리스 응답에 포함된 외부 페이지 URL은 사용하지 않는다. 정식 배포 없음, 새 버전 없음, 조회 실패를 화면에서 구분한다. 다운로드·체크섬 확인·앱 교체와 복원 방법은 [설치 안내](../../RELEASE_NOTES.md)에 기록했다.

로컬 앱과 프리뷰의 번들 채널은 `preview`다. 정식 DMG는 서명 전에 복사한 앱에 `stable`을 표시하고 검증 시 대조한다. 실제 정식 릴리스의 다운로드, 서명과 공증, 기존 사용자의 수동 교체는 인증서와 배포 후보 준비 후 검증한다.

실제 공개 주소를 Swift 검사기로 조회해 정식 배포 없음 상태를 확인했다. Sonoma 14.8.7에서 AppKit 업데이트 창에 시험 응답을 주입해 한국어와 영어의 설치 버전·배포 버전 표시, GitHub 버튼, 연결 오류와 다른 화면에서 버튼이 숨겨지는 동작을 확인했다.

SwiftPM 앱 빌드와 업데이트 단위 시험 두 개가 통과했다. 시험에서 버전의 숫자 비교, 같은 버전의 프리뷰 전환, 빠진 패키지와 준비 중인 릴리스, 잘못된 주소·메타데이터, HTTP 오류를 확인했다.
