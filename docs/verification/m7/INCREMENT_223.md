# M7 Increment 223 — SMB 실마운트 시험의 실패 분리

[SMB 3.1.1 재시험](https://github.com/taro6222/files-for-mac/actions/runs/43665287162)에서 인증 마운트와 기본 파일 작업, 앱 복사, 대상 파일의 바이트 대조를 통과했다. 복사 실행 취소는 실패해 대상에 복사본이 남았고, 이어진 이동의 결과는 `partial`이며 실행 취소 장부가 없었다. 이번 복사에서는 수정 시각 차이가 재현되지 않았다.

복사, 목록 조회, 이동에 각각 별도 시험 폴더를 사용한다. 복사 실행 취소가 실패하면 게시된 파일이 보존됐는지 확인하고 장부와 현재 파일의 내용·모드·확장 속성·ACL·타임스탬프를 대조한다. 이동이 실패하면 원본의 바이트를 확인하고 작업 메시지와 별도 복사 대조를 남긴다. Apple Silicon에서 수정한 Swift Testing 파일의 타입 검사를 통과했다. 원인과 왕복 성공 여부는 다음 SMB 실행으로 확인한다.
