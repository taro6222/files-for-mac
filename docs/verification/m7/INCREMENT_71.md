# M7 Increment 71 — 일부 탭이 손상된 세션 복원

저장된 작업 공간을 탭별로 읽어 손상된 항목을 건너뛴다. 정상 탭은 원래 순서대로 열리고, 저장된 선택 위치는 손상된 탭을 건너뛰기 전의 인덱스로 찾는다. 선택한 탭이 손상된 경우 첫 정상 탭을 표시한다. 정상 탭이 하나도 없으면 기존 구형 세션 또는 시작 폴더 복구 경로를 사용한다.

Apple Silicon macOS 27.2에서 Swift 시험 213개가 통과했다. 회귀 시험에서 정상 항목 사이의 빈 영역과 null을 건너뛰고 원래 인덱스를 보존했다. 격리 앱에 정상 탭 두 개 사이에 빈 영역 탭을 넣어 실행했다. 마지막 정상 탭을 지정한 때와 손상된 탭을 지정한 때에 각각 예상 창이 화면에 표시됐고, 정상 종료 뒤 정상 탭 두 개가 저장됐다.

종료 시 AppKit이 키 창을 이미 해제했으면 마지막으로 초점이 있었던 브라우저를 사용한다. 열린 브라우저가 있지만 초점 기록이 없으면 첫 탭을 저장한다. 후속 격리 실행에서 정상 탭을 지정한 경우와 손상된 탭에서 대체 탭을 표시한 경우에 정상 종료 후 저장된 인덱스가 각각 1과 0임을 확인했다. Swift 시험 213개도 다시 통과했다.
