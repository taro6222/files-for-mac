# M7 Increment 141 — SMB 검증의 디렉터리 조회 확인

통합 시험을 시작하기 전에 마운트한 공유의 디렉터리를 실제로 열거한다. 스크립트는 마운트 검사, 디렉터리 열거, 파일 작업 시험 중 현재 단계를 출력한다. 열거 오류는 코드 74, 전체 제한 시간 초과는 코드 124로 종료한다.

로컬 대역으로 정상 열거 뒤 시험 진입, 열거 오류, 열거 지연 시 종료를 검증했다. 실제 APFS 경로와 존재하지 않는 경로도 각각 코드 65와 66으로 거부했다. SMB 3.0.2 대조의 임시 Samba 컨테이너는 Created 상태에서 멈춰 마운트까지 진행하지 못했다. 이번에 만든 컨테이너는 제거했다. 실제 SMB 파일 작업과 연결 중단·재연결 검증은 남아 있다.
