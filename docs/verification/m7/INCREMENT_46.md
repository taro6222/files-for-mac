# M7 Increment 46 — 실행 취소 기록을 위한 검증 중 취소

이동 창은 실행 취소 기록용으로 폴더 내용을 확인하는 동안 해당 단계를 한국어와 영어로 표시한다. 교체할 폴더의 검증을 마친 뒤 백업으로 옮기기 직전에 취소 상태와 파일 식별 정보를 다시 검사한다. 백업이 만들어지기 전에 취소되면 최종 저널에 미생성 백업 경로가 남지 않는다.

실제 APFS·대소문자 구분 APFS·exFAT 동일 볼륨 이동에서 교체할 폴더의 검증 시작 직후 취소했다. 원본과 기존 대상의 하위 파일 내용, 취소 상태, 백업 파일 부재, 최종 저널을 검사한다. SMB에서의 중단과 재연결은 별도로 검증해야 한다.

Apple Silicon macOS 27.2 (26B123)에서 Swift 시험 206개, 실제 볼륨 매트릭스 시험 3개, 한국어·영어와 밝게·어둡게 조합별 AppKit 시험 51개가 통과했다.
