# 386 — 최신 프리뷰 전달과 Intel 실제 수용 기록

## 프리뷰

앱 코드 `c4c4f6ec7131ea231910e39eb8015e44f2021190`으로 유니버설 개발 프리뷰를 만들었다. 383 이미지 뒤에 수정한 복구 상세 경로 줄바꿈과 추출 창 종료 취소·작업 참조 정리가 포함된다. 383 이미지를 덮어쓰지 않으며 새 경로는 `build/preview-386/Files-macOS-preview.dmg`다. DEBUG 암호 요청 추적 변경은 시험 코드이며 Release 암호 입력 방식 변경으로 설명하지 않는다.

## Intel 원격 보고서

[기존 실행 45882828053](https://github.com/taro6222/files-for-mac/actions/runs/45882828053)의 앱 코드 `7e31fc6f246b5c677b46b80daf4b42b67c435f17`, x86_64 보고서 12개를 그대로 보존했다. ko-light/ko-dark/en-light/en-dark 각각 전체 AppKit 369개·탭 경계 18개·마운트 파일 작업 85개가 모두 true다. 이전에 실패했던 Git 취소 정리 조건도 이번 파일 작업 보고서에서는 통과했다. [원본 보고서](ui-386-intel/volume-ko-light.json).

이는 해당 소스의 프로그램 방식 UI 실행 증거다. 물리 입력·VoiceOver 수용 또는 최신 `c4c4f6e`의 UI 통과로 승계하지 않는다. 같은 실행 ARM은 실패했으므로 두 CPU 전체 성공으로 집계하지 않는다. 최신 소스의 [45888418153](https://github.com/taro6222/files-for-mac/actions/runs/45888418153)은 기존 핸들을 유지하며 별도로 확인한다. 관찰 기한 때문에 재시작하지 않았다.

## 남은 요구

F23의 다른 게시 방식·압축 저장 metadata·실패 출력 정리 및 전체 경계 수용, 최신 양 CPU/지원 OS·물리 입력·VoiceOver·시각 대조·장시간·실제 외부 서비스 수용, Developer ID 서명·공증과 정식 설치/업데이트 수용은 미완료다. 인증서/공증 프로필은 사용자 준비 중이며 다시 요구하지 않는다. 로컬 GUI·전체 AppKit·장시간 시험 앱은 실행하지 않았다. M7과 원본 기능/UI 전체 동등성은 진행 중이다.
