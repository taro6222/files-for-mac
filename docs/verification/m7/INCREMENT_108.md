# M7 Increment 108 — Git 병합 충돌 표시

병합되지 않은 파일의 상태를 읽고 Git 상태 패널에 변경 수와 충돌 수를 표시한다. 상태 패널에는 Git의 두 글자 상태 코드와 병합 충돌을 알리는 접근성 이름이 표시된다. 상세 보기의 Git 열에도 같은 상태 코드가 들어간다. [Git 상태 출력 형식](https://git-scm.com/docs/git-status#_porcelain_format_version_2)

Swift 회귀에서는 별도의 임시 저장소에서 두 브랜치가 같은 파일을 수정하도록 커밋한 뒤 병합했다. 상태 조회가 공백으로 시작하는 한글 경로와 `UU` 상태, 추적하지 않은 다른 파일을 함께 반환하는지 검사한다. 조회 전후의 HEAD, 병합 인덱스와 충돌 파일 내용을 비교한다. AppKit에서는 `AA` 상태의 충돌 수, 상태 코드, 접근성 이름과 상세 열을 검사한다.

Swift 테스트 217개와 한국어·영어 × 밝게·어둡게 AppKit 회귀 255개를 각 조합에서 통과했다. 인증 HTTPS/SSH와 Windows에서 같은 화면 상태의 대조는 남아 있다.
