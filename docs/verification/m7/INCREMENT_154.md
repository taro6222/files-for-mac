# M7 Increment 154 — 확장 ACL 편집

파일 권한 시트의 **ACL 편집**에서 macOS ACL 텍스트를 한 줄에 한 항목씩 추가·수정·삭제할 수 있다. 기존 항목과 순서가 편집기에 표시된다. 모든 항목을 지우면 빈 ACL을 저장한다. POSIX 모드와 ACL 편집은 각각 저장한다.

시스템 파서와 유효성 검사를 거친 뒤, 파일을 열어 디스크립터의 식별자와 기존 POSIX 모드·ACL을 대조한다. 불일치하거나 입력 형식이 잘못되면 적용하지 않는다. ACL 전체의 헤더와 상속 플래그를 보존한다.

Swift 테스트 233개가 통과했다. APFS에서 순서와 항목별 상속 플래그, 잘못된 입력과 오래된 스냅샷 거부, 전체 항목 삭제 및 POSIX 모드 보존을 확인했다. 별도 APFS 시험에서 ACL 전체의 `no_inherit`도 항목 편집 후 유지됐다. SwiftPM이 컴파일한 테스트 객체를 Swift Testing 런타임에 직접 링크해 실행했다.

원본의 항목별 체크박스와 계정 선택 대신 macOS ACL 형식을 사용한다. 계정 선택기, 소유자 변경, 하위 항목 일괄 적용 및 Windows 실행 화면 대조는 남아 있다.

Apple Silicon macOS 27.2에서 한국어·영어와 밝은·어두운 테마 네 조합의 AppKit 검사 262개가 각각 통과했다. ACL 헤더 보존을 추가한 최종 빌드에서 한국어·밝은 테마 262개를 다시 실행해 통과했다. 두 빌드에서 시트 저장 후 실제 파일에 ACL이 적용되고 POSIX 모드가 유지됨을 확인했다.
