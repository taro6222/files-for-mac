# M7 Increment 57 — Git 열 갱신과 장시간 시험

파일 목록은 Git 상태와 커밋 정보가 도착하면 현재 표시 중인 Git 셀의 값을 갱신한다. 화면 밖 셀은 표시될 때 최신 값을 읽는다. 이렇게 상태 표시를 바꿀 때 전체 행과 선택을 다시 구성하던 경로를 제거했다. AppKit 회귀 항목은 표시 중인 SHA 셀과 선택 행이 비동기 응답 전후에 유지되는지 검사한다.

Apple Silicon macOS 27.2 (26B123)에서 Swift 시험 212개가 통과했다. 한국어 AppKit 실행에서 Git 관련 항목과 새 셀 유지 검사가 통과했다. 전체 화면 회귀에서는 스크롤 위치 복원과 클립보드 항목이 실패했다. 변경 전 대조 실행에서도 스크롤 위치 복원이 실패했고, 별도의 디렉터리 감시 항목이 실패했다.

최적화 시험 빌드는 65사이클, 259.6초 시점에 목록 준비 확인 중 종료됐다. 두 힙 표본에서 `NSTableCellView`는 132개에서 168개, AppKit 의존성 컨텍스트는 9,054개에서 16,776개로 늘었다. 8시간을 목표로 했던 기존 후보도 267사이클 뒤 같은 종류의 검사에서 종료됐다. 두 실패에서 행 개수는 기대값과 같았다. 다음 실행은 같은 검사 조건으로 위치, 로딩, 감시 상태, 로드 오류 여부도 보고한다. 장시간 메모리와 8시간 실행은 출시 전 검증 항목으로 남아 있다.
