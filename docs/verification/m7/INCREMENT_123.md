# M7 Increment 123 — 전송 검증 실패 안내

복사, 폴더 병합, 교차 볼륨 이동과 그 실행 취소에서 임시 복사본의 검증에 실패하면 어떤 항목이 일치하지 않았는지 결과에 기록한다. 파일 내용과 폴더 구조, 태그 등 확장 속성, ACL, POSIX 권한, 수정 시간을 구분한다. 실패는 기존 복사·이동 결과 창에서 파일 경로와 함께 한국어 또는 영어로 표시된다.

이 안내는 임시 복사본을 게시하기 전 비교에 적용한다. 원본이 전송 중 변경되었거나, 게시 뒤 원본 또는 대상이 변경된 경우에는 해당 단계의 오류를 표시한다. 생성·접근 시간과 완료된 작업의 실행 취소 저널에 저장하는 확장 메타데이터는 후속 검증 대상이다.

Swift 테스트 224개와 실제 마운트 검사 5개가 통과했다. 임시 복사본의 ACL·POSIX 권한·수정 시간을 각각 바꾼 시험과 실제 exFAT에서 ACL을 보존할 수 없는 이동의 결과 메시지를 확인했다. 한국어·영어와 밝은·어두운 테마에서 기존 AppKit 파일 작업 검사가 조합별 68개 통과했다. 새 문구는 작업 결과 데이터에서 확인했으며, AppKit 회귀는 기존 결과 창과 키보드 동선을 실행했다.
