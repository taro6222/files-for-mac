# M7 Increment 75 — 장시간 탐색의 상세 셀 계측

최적화된 장시간 시험에서 주 창의 상세 목록이 만든 `NSTableCellView`를 약한 참조로 추적한다. 보고서의 `retainedPrimaryDetailCells`는 메모리 표본을 수집할 때 아직 해제되지 않은 셀 수다. 홈으로 돌아온 직후 채취하므로 화면에서 사라진 셀도 포함한다. 보조 탭의 셀은 이 수치에 포함되지 않는다. 일반 Release 빌드에는 계측 코드를 넣지 않는다.

Apple Silicon macOS 27.2에서 같은 QA 바이너리로 아래 예비 시험을 완료했다.

| 부하 | 시간 | 사이클 | 첫 표본 / 마지막 표본의 상세 셀 |
|---|---:|---:|---:|
| 탐색 | 46.90초 | 21 | 88 / 60 |
| 탐색·전송·탭 | 45.51초 | 16 | 88 / 28 |

별도로 일반 Release 빌드를 완료하고 실행 파일에 계측용 필드가 없음을 확인했다. 이전 대조 시험의 탐색 모드는 보조 탭과 전송 없이 물리 메모리 표본이 46.2 MiB에서 약 10.7분 뒤 84.7 MiB로 늘었다. 상세 셀 보유가 증가분을 얼마나 설명하는지 판정하려면 동일한 시간과 사이클에서 목록 갱신 실험과 비교해야 한다.
