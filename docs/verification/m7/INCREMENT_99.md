# M7 Increment 99 — 스크롤 처리 시간 계측

최적화 QA 빌드에서 스크롤 호출 간격과 AppKit 처리 시간을 계측한다. `timer`는 스크롤 위치와 스크롤바를 갱신한다. `layout`은 같은 동작 뒤 레이아웃과 그리기를 즉시 요청한다. 두 모드는 타이머로 구동된다.

Apple Silicon macOS 27.2에서 APFS의 10,000항목을 열고 두 모드 각각 360회, 총 4,320포인트를 스크롤했다.

| 모드 | AppKit 처리 p95 | 최대 | 호출 간격 25ms 초과 |
|---|---:|---:|---:|
| 타이머 | 1.47 ms | 2.01 ms | 0 / 359 |
| 타이머 + 레이아웃·그리기 | 1.57 ms | 6.62 ms | 0 / 359 |

현재 세션에서는 화면 동기화 모드와 색 변경 대조가 제한 시간 내 360회 콜백을 완료하지 못했다. 위 수치는 AppKit 호출의 처리 시간이며 화면 합성 프레임과 60Hz 출시 기준은 검증 대기다.
