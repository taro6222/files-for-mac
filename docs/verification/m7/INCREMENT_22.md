# M7 Increment 22 — 이전 설정 파일 가져오기

설정 가져오기는 먼저 파일의 스키마 버전을 검사한다. 지원 범위 밖의 버전은 설정을 쓰기 전에 거부하며, 고급 설정의 가져오기 결과에도 이 앱 버전에서 읽을 수 없다고 표시한다.

최초 설정 내보내기 구현 `5333d92`의 v1 구조로 작성한 fixture를 현재 앱의 설정 저장소로 가져왔다. 즐겨찾기와 최근 위치, 사이드바·툴바 순서, 보기, 테마와 폴더별 설정의 유지, 이후 추가된 옵션의 기본값 적용을 확인했다. 새 설정 저장소 인스턴스로 다시 읽고, 현재 구조와 다른 v2 파일을 가져오려 해도 저장된 설정이 보존되는지 검사했다.

정식 서명된 버전 간 교체와 Finder 설치 검증은 남아 있다.

macOS 27.2 (26B123)에서 Swift 테스트 203개와 한국어·영어 및 밝게·어둡게 조합별 AppKit 검사 218개를 통과했다. 설정 가져오기의 데이터 검증은 Swift 테스트에서 수행했다.
