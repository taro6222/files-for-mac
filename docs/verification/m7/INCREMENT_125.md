# M7 Increment 125 — 이동 실행 취소의 메타데이터 보호

새 이동 저널은 게시 대상과 덮어쓰기 백업의 확장 속성·ACL 해시, 수정 시간, 내용과 권한을 기록한다. 실행 취소 전에 파일 식별자와 기록을 비교하며, 수정된 파일은 해당 위치에 남긴다. 교차 볼륨 이동의 실행 취소 중에 중단되면 복원한 임시 복사본의 검증 정보도 저널에서 읽는다. 이전 저널에는 당시 기록된 검증 기준을 적용한다.

같은 볼륨에서 이름을 바꾸는 이동에도 실행 취소를 제공하기 위해 파일을 읽어 스냅샷을 작성한다. 대용량 파일에서 이 작업의 지연은 추가 측정 대상이다. 실행 취소 뒤 다시 실행할 때의 메타데이터 검증과 생성·접근 시간 검증도 후속 작업이다.

Swift 테스트 226개와 실제 APFS·대소문자 구분 APFS·exFAT 마운트 검사 5개가 통과했다. 대상과 백업에 각각 확장 속성만 추가한 경우, 두 파일과 실행 취소 기록이 모두 보존됐다. 이전 형식의 폴더 저널과 교차 볼륨 복원 중단 후 재개도 통과했다.
