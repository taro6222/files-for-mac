# M7 Increment 142 — SMB 파일 목록 검증 보강

SMB 파일 작업 시험에서 앱의 `LocalFileSystem`으로 복사 전후의 공유 목록과 유니코드 하위 경로를 확인한다. 복사 실행 취소 뒤 복사본이 목록에서 사라지는지 검사한다. 앱의 전송 명령 밖에서 파일을 생성·이름 변경·삭제한 뒤 다시 읽은 목록도 확인한다. 이 검사는 다시 읽기 경로를 다룬다. 서버에서 다른 클라이언트가 변경했을 때 자동 갱신되는 동작은 별도 확인이 필요하다.

로컬 Samba 이미지에서 포트 전달을 붙인 경우와 붙이지 않은 경우 모두 단순 명령 실행이 10초 안에 시작되지 않았다. 관리 권한 없이 별도 포트에서 실행한 macOS 내장 SMB 서버는 종료 코드 71을 반환했다. 따라서 실제 SMB에서 추가한 검사를 실행하지 못했다.

Swift 테스트 229개가 통과했다. 실제 마운트가 설정되지 않은 실행에서는 SMB 시험 본문을 건너뛴다.
