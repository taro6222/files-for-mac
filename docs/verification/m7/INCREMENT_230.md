# M7 Increment 230 — PNG·PDF 미리보기 캡처 검증 상태

Apple Silicon macOS 27.2에서 임시 PNG와 PDF를 만들고 선택된 파일의 URL이 Quick Look 정보 패널에 전달된 상태에서 화면 증거를 수집했다. AppKit 뷰 캡처는 기존 텍스트 본문을 확인했지만 PNG와 PDF의 밝은 색상 본문을 담지 못했다. 같은 시험 창에 대해 `screencapture`를 실행했을 때 창 이미지 생성이 실패했다.

PNG·PDF가 실제 화면에 어떻게 표시되는지는 이 결과로 판정할 수 없다. 정보 패널의 PNG·PDF 상태 검증을 열린 항목으로 유지한다. [텍스트 본문 검증](INCREMENT_220.md)
