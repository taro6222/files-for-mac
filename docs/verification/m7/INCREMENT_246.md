# M7 Increment 246 — SMB 세션 재연결 시험

임시 Samba 서버에서 macOS 러너의 루프백 SMB 연결을 끊는다. 끊기 전 마운트에서 읽은 파일을 서버 쪽에서 삭제하고 새 파일을 만든다. 기존 마운트에서 새 파일의 바이트가 읽히고 macOS 세션의 재연결 횟수가 증가하며 마운트 장치 번호가 유지돼야 한다. [Samba 연결 종료 명령](https://www.samba.org/samba/docs/current/man-html/smbcontrol.1.html)

재연결이 확인되면 FilesCore의 폴더 조회가 새 파일을 열고 이전 파일을 목록에서 제외하는지 확인한다. 기존 복사·이동·교체, 읽기 전용 공유 시험도 실행한다.

Python 모의 시험에서 세션 횟수가 증가할 때 통과하고 그대로이면 실패하는 것을 확인했다. Swift 시험 세 건은 컴파일됐고 로컬에서 SMB 시험 환경이 없으면 건너뛰었다. YAML과 대응표 감사도 통과했다. 실마운트 결과, 장기 단절, 전송 중 연결 중단은 추가 검증이 필요하다.
