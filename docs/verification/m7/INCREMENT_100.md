# M7 Increment 100 — 파일 작업의 부분 성공 결과

복사 결과의 요약에 실패 항목과 실행하지 못한 항목의 수를 표시한다. 복사와 이동이 끝나면 진행 막대를 숨기고 결과를 표시한다. 작업이 진행되는 동안에는 항목 수 기준 진행 막대, 현재 단계, 취소 동작을 제공한다.

실제 복사 창에서 정상 파일과 사라진 원본을 한 작업으로 실행했다. 결과가 완료 1/2, 실패 1을 표시하고 진행 막대를 숨기는지 확인했다. 대상에 정상 파일의 내용이 그대로 있고 사라진 원본 이름의 출력은 없음을 검사했다. Apple Silicon macOS 27.2의 한국어·영어와 밝게·어둡게 네 조합에서 각각 파일 작업 검사 64개를 통과했다.

[UI-10 구조 대조](../../reference/UI_BASELINE.md)에 Windows 상태 센터와 macOS 작업 창의 대응 및 남은 항목을 기록했다.

후속 변경에서는 복사와 이동의 현재 항목 뒤에 대기 중인 항목 수를 표시한다. 현재 처리 중인 항목은 이 수에 포함하지 않는다. 실제 두 항목 복사와 이동에서 마지막 진행 업데이트에 파일명과 남은 항목 0개가 함께 표시되는지 확인했다. 한국어·영어와 밝게·어둡게 네 조합에서 각각 파일 작업 검사 67개를 통과했다. 바이트 단위의 남은 양과 전송 속도는 별도 구현이 필요하다.

일반 파일 복사와 교차 볼륨 이동의 검증 단계에서 임시 경로에 준비된 논리 바이트를 표시한다. 복사 호출이 0.1초 이상 걸린 경우 호출 전체의 평균 속도도 표시한다. 검증과 결과 확정 시간은 속도 계산에 포함하지 않는다. 폴더, 심볼릭 링크, 같은 볼륨의 이름 변경에는 이 수치를 표시하지 않는다. 복사 호출 중의 실시간 바이트와 작업 전체의 남은 바이트는 추가 계측이 필요하다.

AppKit의 실제 복사 취소 시험에서 검증 단계에 전달된 바이트를 원본 길이와 대조하고, 복사 창에 준비된 데이터가 표시된 상태에서 취소해 임시 출력 정리와 원본 보존을 확인했다. Swift 테스트 215개와 네 언어·테마 조합의 AppKit 파일 작업 검사 각 67개를 통과했다.
