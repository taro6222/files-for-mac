# M7 Increment 100 — 파일 작업의 부분 성공 결과

복사 결과의 요약에 실패 항목과 실행하지 못한 항목의 수를 표시한다. 복사와 이동이 끝나면 진행 막대를 숨기고 결과를 표시한다. 작업이 진행되는 동안에는 항목 수 기준 진행 막대, 현재 단계, 취소 동작을 제공한다.

실제 복사 창에서 정상 파일과 사라진 원본을 한 작업으로 실행했다. 결과가 완료 1/2, 실패 1을 표시하고 진행 막대를 숨기는지 확인했다. 대상에 정상 파일의 내용이 그대로 있고 사라진 원본 이름의 출력은 없음을 검사했다. Apple Silicon macOS 27.2의 한국어·영어와 밝게·어둡게 네 조합에서 각각 파일 작업 검사 64개를 통과했다.

[UI-10 구조 대조](../../reference/UI_BASELINE.md)에 Windows 상태 센터와 macOS 작업 창의 대응 및 남은 항목을 기록했다.
