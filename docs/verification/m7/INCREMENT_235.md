# M7 Increment 235 — Windows 속성 시험의 드라이버 연결

[속성·해시 실행](https://github.com/taro6222/files-for-mac/actions/runs/43669592587)에서 설치된 Files 창의 핸들을 확인했다. WinAppDriver의 세션 생성 요청이 응답 제한을 넘겨 속성 화면에 도달하지 못했다. 세션 생성 요청의 제한을 45초로 늘리고 나머지 요청은 기존 제한을 사용한다. 드라이버의 표준 출력과 오류도 실행 산출물에 남긴다.

Python 모의 요청으로 세션 생성과 일반 요청에 서로 다른 제한을 적용하는 것을 확인했다. YAML 입력과 인벤토리 감사를 통과했다. 실제 속성·해시 화면은 후속 Windows 실행에서 확인한다.
