# M7 Increment 167 — SMB 파일 작업 사전 검사

SMB 검증 스크립트는 마운트 확인과 디렉터리 열거 후 고유한 임시 폴더에서 파일 생성·읽기·이름 변경·삭제를 검사한다. 읽은 바이트와 이름 변경 결과를 확인한 뒤 Swift 통합 시험을 시작한다. 사전 파일 작업 실패는 코드 75, 전체 제한 시간 초과는 코드 124를 반환한다. 강제 종료 시 공유에 `.files-smb-probe-*` 폴더가 남을 수 있다.

로컬 대역에서 정상 왕복 및 임시 폴더 정리, 읽기 오류(75), 응답 지연 제한(124)을 확인했다. 실패나 지연 시 Swift 시험 진입을 막았다. 실제 APFS 경로 거부(65)와 셸 구문도 확인했다.

Apple Silicon macOS 27.2에서 기존 로컬 Samba 이미지의 `/bin/true` 기동을 재시도했다. 루프백 포트 전달 유무와 관계없이 14초 안에 시작되지 않았고 두 임시 컨테이너를 제거했다. 이 실행에서는 정상 응답하는 SMB 마운트를 확보하지 못했다. 실제 공유에서 복사·이동·복구와 서버 연결 중단·재연결 검증은 남아 있다.
