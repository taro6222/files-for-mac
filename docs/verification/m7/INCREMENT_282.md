# M7 Increment 282 — Intel 전체 AppKit 시간 초과 진단

[macOS 15 실행](https://github.com/taro6222/files-for-mac/actions/runs/44091931429)에서 Intel 빌드와 Swift 시험, 실제 볼륨 검사, 한국어·영어와 밝은·어두운 테마의 파일 작업 검사 79개씩은 통과했다. 전체 AppKit 검사는 네 조합 모두 180초에 도달해 종료됐다. 각 조합에서 캡처 38~39장이 생성됐지만 최종 보고서와 정체 지점을 설명하는 로그가 없어 전체 통과로 판정할 수 없다. Apple Silicon 작업은 취소됐다.

전체 UI 실행기가 시간 초과 전에 실행 중인 앱의 스택을 1초간 수집하도록 변경했다. 수집은 최대 5초로 제한하고 이후 앱을 종료·회수한다. 실패한 조합 다음의 언어·테마 검사를 계속하며 스택 파일을 CI 아티팩트에 보존한다.

같은 Python 실행 코드에 짧은 시험 제한을 적용해 멈춘 프로세스의 실제 스택 생성과 종료·회수를 확인했다. 정상 보고서는 통과했고 보고서가 없는 정상 종료 프로세스는 실패로 기록됐다. 셸·워크플로 구문 검사도 통과했다. 다음 Intel 실행에서 스택을 확인해 원인을 좁힌다.

중단 전에 실행한 8시간 시험의 프로세스와 임시 보고서는 현재 환경에서 찾을 수 없었다. 종료 코드와 최종 보고서를 회수하지 못했으므로 이 실행의 8시간 검증은 미확인으로 유지한다.
