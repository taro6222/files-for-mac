# M7 Increment 227 — Windows 탭 드래그 환경 진단

[Windows 재시험](https://github.com/taro6222/files-for-mac/actions/runs/43666344006)은 `Ctrl+Shift+Tab`으로 첫 탭을 선택했고 공통 폴더와 항목을 확인했다. 드래그 이후에도 두 탭과 한 패널이 남아 분할 상태가 확인되지 않았다.

고정 원본에서 관리자 권한 여부에 따라 탭 드래그를 활성화하는 조건을 확인했다. 재시험은 실행 중인 Files와 드라이버 스크립트의 토큰 승격 여부를 로그에 남기고, 마우스 버튼을 누르기 전과 놓기 전에 실제 화면 좌표를 대조한다. Python 구문 검사와 모의 Windows 호출로 승격 상태 두 가지, 핸들 정리, 좌표 불일치 시 버튼 해제를 확인했다. 탭 드래그 결과는 실제 Windows 재시험으로 확인한다.
