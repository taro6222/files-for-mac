# M7 Increment 65 — 장시간 시험의 종료 증거

장시간 시험 스크립트는 앱 프로세스가 끝나면 실제 종료 코드를 `exit-status`에 원자적으로 저장하고 같은 코드를 반환한다. 앱 보고서와 별도로 확인할 수 있어, 앱이 최종 보고서를 쓰기 전에 종료되는 경우에도 증거가 남는다.

Apple Silicon macOS 27.2에서 최신 후보 `b59771af9ca12c8f6ea50720948426dbba952654`로 20초 예비 시험을 실행했다. 22.34초에 8사이클을 완료했고, 앱 보고서는 `completed`, 저장된 종료 코드는 0이었다. 모의 프로세스가 17로 종료했을 때 보고서가 없어도 종료 코드가 17로 전달되고 저장되는 것을 확인했다.

같은 후보의 28,800초 실행을 별도로 시작했다. 프로세스와 바이너리 SHA-256을 확인했으며 53.2초에 19사이클을 마쳤다. 이전 후보 `dab9839`도 계속 실행 중이다. 장시간 실행 두 건은 이 스크립트 변경보다 먼저 시작했으므로 종료 코드는 실행 세션에서 확인해야 한다.
