# M7 Increment 30 — 스크롤 프레임 측정의 대조군

`verify-scroll-window.sh control`은 목록을 고정한 채 동일한 60Hz 화면 갱신 콜백에서 64×64pt 레이어의 색을 360회 교대한다. `display` 모드는 같은 창의 10,000항목 파일 목록을 화면 갱신에 맞춰 스크롤한다. 두 모드를 같은 최적화 빌드와 창 캡처 도구에서 한 번씩 실행했다.

| 동작 | 창 갱신 간격 p95 | 25ms 초과 간격 |
|---|---:|---:|
| 레이어 색 변경 | 33.30ms | 42/312 |
| 파일 목록 스크롤 | 33.02ms | 28/321 |

Apple Silicon macOS 27.2 (26B123), 60Hz에서 두 동작은 각각 약 6.0초 걸렸다. 파일 목록을 움직이지 않는 대조군에서도 33ms 간격이 나타났다. 이 캡처 경로의 p95만으로는 목록 렌더링의 16.7ms 예산을 판정할 수 없다. Instruments 또는 실제 화면 표시를 별도로 확인할 수 있는 환경이 필요하다. [측정값](scroll-control-60hz.json)
