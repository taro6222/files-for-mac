# M7 Increment 232 — Windows 속성·해시 화면 단독 실행

Windows 캡처의 `properties` 범위는 공통 폴더의 `preview.txt`를 선택해 원본 앱의 속성 창을 연다. 파일 이름 입력란에서 선택 항목을 확인하고 일반 화면을 캡처한다. 해시 화면에서는 테스트 파일로 계산한 SHA-256과 표시값이 일치한 뒤 화면을 저장한다. 각 화면의 접근성 트리와 PNG가 실행 결과에 포함된다.

고정 원본의 속성 창과 해시 화면에 있는 컨트롤 이름을 대조했다. Python 구문과 워크플로 입력을 검사했고, 모의 접근성 트리에서 올바른 이름과 해시만 승인했다. 실제 원본 앱에서의 화면 확인을 진행한다. [기존 macOS 해시 검증](INCREMENT_152.md)
