# M7 Increment 146 — 백업 복원 직전 강제 종료 검증

실제 APFS 마운트에서 교체 이동을 실행 취소하는 중 두 지점에서 프로세스를 강제 종료했다. 첫 번째는 검증 사본을 원래 위치에 게시한 직후다. 두 번째는 이동 대상을 제거하고 백업 복원 대기 상태를 저장한 직후다.

두 번째 지점에서 재시작하기 전에 대상 경로에 다른 파일을 만들었다. 실행 취소는 충돌로 중단됐고 새 파일과 기존 대상 백업이 보존됐다. 시험 파일을 제거한 뒤 같은 저널을 재개하자 기존 대상이 복원됐다. 양쪽 파일의 내용과 생성 시간이 맞았고 보류 기록이 소비됐다. 강제 종료 복구 두 조합과 전체 Swift 테스트 229개가 통과했다.
