# M7 Increment 111 — 보조 패널 폴더 읽기 중단과 재시도

분할 보기의 보조 패널은 폴더를 읽는 중에 도구 모음 버튼을 읽기 중단으로 표시한다. 접근성 이름과 툴팁도 현재 동작을 알린다. 중단하면 상태 표시줄에서 새로고침을 안내한다. 중단 뒤 도착한 읽기 결과와 폴더 변경 알림을 무시하며, 새로고침하면 다시 읽는다.

AppKit 재현에서는 지연된 폴더 읽기를 접근성 동작으로 중단한다. 중단 이후 파일 변경 이벤트를 전달하고 목록과 중단 상태가 유지되는지 확인한다. 같은 버튼으로 새로고침한 뒤 파일 목록이 표시되는지 검사한다.

Swift 테스트 217개와 한국어·영어 × 밝게·어둡게 전체 AppKit 검사 257개를 각 조합에서 통과했다.

별도 프리뷰에서 외부 프로세스가 보낸 키 이벤트로 검색 창과 복사 동선을 재현하려 했으나 창 전환을 관찰하지 못했다. [기존 AppKit 응답자 체인 검사](INCREMENT_69.md)는 복사 동선의 증거로 유지한다. 실제 데스크톱 키 입력과 VoiceOver 출력 검증은 남아 있다.
