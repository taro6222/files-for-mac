# M7 Increment 289 — 설치 프리뷰의 실제 키보드 복사 동선

Apple Silicon macOS 27.2.1(26B131)에서 프리뷰 `40ffc39`를 별도 번들 ID와 설정·시험 홈으로 복사하고 ad-hoc 서명을 적용했다. 실제 CGEvent 키 입력으로 한국어와 영어에서 파일 목록 초점, 방향키 선택, Command-C, Command-L 경로 입력, Return 이동, Command-V와 충돌 시트의 Command-S를 실행했다. 키 입력은 시험 앱이 활성 상태일 때만 보냈다. [시험 정보와 결과](keyboard-copy-40ffc39-macos27.2.1.json)

접근성 API로 실제 초점과 선택 행을 확인했고 원본·대상 창 제목, 복사 결과의 충돌 1건을 읽었다. 두 언어 모두 건너뛰기 완료를 확인했으며 원본과 기존 대상 바이트가 보존됐다. 대상에는 추가 파일이 생기지 않았다. 시험 앱의 코드 서명도 유효했다.

첫 시도는 시험 도구가 문자 입력 이벤트에 이전 Command 플래그를 이어받아 경로가 바뀌지 않았다. 문자 이벤트의 플래그를 비우고 선택 입력 뒤 실제 포커스·선택을 관찰한 다음 두 언어의 전체 동선을 재실행해 통과했다. VoiceOver 음성·자막과 전체 키보드 업무 동선은 별도로 검증한다.
