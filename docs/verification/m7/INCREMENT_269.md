# M7 Increment 269 — 파일 작업 센터 키보드 동작

작업 센터를 열면 작업 목록을 첫 초점 대상으로 삼는다. 선택한 작업의 세부 창은 Return으로 열고, 진행 중인 작업에는 Command+마침표로 취소를 요청한다. 버튼의 활성화 상태는 선택한 작업에 맞춰 갱신된다.

Apple Silicon macOS 27.2에서 한국어·영어와 밝은·어두운 테마 네 조합으로 실제 AppKit 파일 작업 검사 78개씩을 통과했다. 작업 센터에 보낸 Return 키로 선택한 복사 창이 활성화됐고, Command+마침표 뒤 복사가 취소됐다. 작업 센터와 결과 창의 기존 동작도 같은 실행에서 확인했다. 실제 VoiceOver 탐색은 남아 있다.
