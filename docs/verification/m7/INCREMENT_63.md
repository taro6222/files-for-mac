# M7 Increment 63 — 파일 변경 시 공통 아이콘 재사용

디렉터리 감시에서 변경을 받으면 파일 전용 아이콘 캐시만 비운다. 파일 이름이나 형식이 바뀌면 새 목록 항목의 확장자로 공통 아이콘을 찾는다. 같은 확장자의 공통 아이콘은 재사용한다. 명시적 새로고침과 캐시 지우기는 전체 캐시를 비운다.

Apple Silicon macOS 27.2에서 영어·어두운 테마의 AppKit 검사 220개가 통과했다. 새 검사는 변경 후 파일 전용 아이콘을 다시 읽고 공통 아이콘 객체는 유지하는지 확인한다. 장시간 메모리 판정은 남아 있다.

현재 호스트에서 `arch -x86_64 /usr/bin/uname -m`은 실행을 거부했다. Intel에서의 앱 기동 및 최소 macOS 14 검증은 출시 조건에 유지한다.
