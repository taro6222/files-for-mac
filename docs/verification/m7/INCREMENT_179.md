# M7 Increment 179 — AppKit 파일 작업의 두 아키텍처 회귀

macOS 15의 Apple Silicon·Intel CI에서 같은 디버그 앱으로 파일 작업 AppKit 회귀를 실행하도록 했다. 한국어·영어와 밝은·어두운 테마의 각 실행은 새 시험 폴더와 앱 설정 도메인을 사용한다. 보고서 누락, 실패한 검사, 비정상 종료, 제한 시간 초과 시 검증 실패를 기록한다.

Apple Silicon macOS 27.2에서 네 조합 각각 68개를 통과했다. 그중 탐색 키 이벤트로 파일을 선택하고, 앱의 복사 응답자를 거쳐 홈의 대상 폴더를 연 뒤 붙여넣기로 충돌 시트를 여는 흐름을 검사했다. 같은 도구가 실행 파일 부재와 보고서를 쓰지 않는 실행을 거부하는 것도 확인했다.

앱 내부 키 이벤트와 응답자 체인, 파일 상태 및 충돌 처리를 검사한다. 물리 키보드 입력, VoiceOver 음성, 설치 프리뷰의 전체 수동 UI 동선은 별도 검증 항목이다.

## 장시간 시험의 빌드 대조

같은 앱 소스 `d50015f`에서 기존 Swift Build와 SwiftPM 네이티브 엔진의 최적화 QA 실행 파일을 같은 Mac에서 병렬로 125초 실행했다. 두 시험 모두 완료됐다. 바이너리와 빌드 옵션이 달라 엔진 자체의 영향을 단정할 수 없다.

| 빌드 | 완료 사이클 | 물리 메모리 최고치 | 32사이클의 AppKit 관찰 컨텍스트 |
|---|---:|---:|---:|
| Swift Build | 43 | 67.2 MiB | 2,080 |
| SwiftPM 네이티브 | 42 | 78.5 MiB | 3,916 |

현재 앱 소스의 정규 8시간 전체 시험을 `9c56f83a9cf23b867d5e25488659116db32e795c`의 Swift Build 최적화 QA 바이너리로 시작했다. 바이너리 SHA-256은 `66cd600e126b4a7d5aa55c2a013a84ca9183c17569f7d8bd03c73db19fc2a808`이다. 기존 바이너리의 8시간 실행도 계속된다.

[커밋 `9c56f83`의 GitHub Actions](https://github.com/taro6222/files-for-mac/actions/runs/43644178030)에서 Apple Silicon과 Intel의 AppKit 파일 작업 단계가 모두 통과했다.
