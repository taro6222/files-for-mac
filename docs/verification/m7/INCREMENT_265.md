# M7 Increment 265 — SMB 교체 이동 중 세션 중단 시험

실제 Samba 공유에 기존 파일을 두고 APFS에서 내용이 다른 파일을 교체 이동한다. 새 파일을 게시했고 원본이 남은 시점에 루프백 세션을 끊는다. 이동은 같은 마운트에서 새 파일을 읽고 재연결 카운터가 증가할 때까지 대기한다.

작업이 성공하면 새 바이트와 이동 실행 취소 결과를 검증한다. 실패하면 원본과 기존 대상의 바이트를 검증한다. 기존 대상이 분리돼 있으면 작업이 보고한 복구 백업에서 확인한다. 실패한 이동의 실행 취소 기록이 생기지 않는지도 확인한다.

로컬에서 Swift 통합 시험 다섯 개를 컴파일했고 SMB 전용 환경이 없는 실행에서는 건너뛰었다. 셸·Python 구문과 대응표 감사도 통과했다. 실마운트 결과는 별도로 확인한다. 이 시험은 게시 후 원본 삭제 전 중단을 다룬다. 파일 데이터가 기록되는 도중의 단절과 장기 단절은 추가로 검증한다.
