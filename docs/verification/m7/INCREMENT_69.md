# M7 Increment 69 — 탐색에서 복사 충돌 처리까지

AppKit 검증을 파일 선택부터 복사 결과 창까지 이어 실행한다. 방향키로 원본을 선택하고, 초점이 있는 파일 테이블에 복사 메뉴 액션을 전달한다. 홈에서 방향키와 Return으로 즐겨찾기 대상 폴더를 연 뒤, 붙여넣기 메뉴 액션을 초점 대상에 전달한다. 충돌 시 Command-S로 건너뛰고, 결과 창의 접근성 레이블과 Return으로 닫히는 동작을 확인한다. 원본과 기존 대상의 내용이 유지되고 중복 파일이 생성되지 않는지도 대조한다.

시험은 독립 pasteboard를 사용한다. Apple Silicon macOS 27.2에서 한국어·영어와 밝은·어두운 테마의 네 조합에서 각각 54개 검사가 통과했다. 복사·붙여넣기는 메뉴 액션 전달로 확인했으며, 해당 키 조합의 실제 메뉴 디스패치와 VoiceOver 검증은 남아 있다.
