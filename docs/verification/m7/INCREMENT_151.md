# M7 Increment 151 — AppKit 검증 폴더 격리

`scripts/verify-ui.sh`가 실행할 때마다 새 임시 폴더를 만들고, 시작할 때 결과 폴더 경로를 출력한다. 언어·테마 조합마다 하위 폴더를 사용한다. Spotlight의 실제 색인을 사용하는 검사는 기존대로 프로젝트 소스 경로에서 실행된다. 실패한 실행의 로그와 캡처는 출력한 경로에 남는다.

Bash 구문 검사와 Apple Silicon macOS 27.2의 기본 실행을 확인했다. 한국어·영어와 밝은·어두운 테마의 네 조합에서 각각 258개가 통과했다. 조합별 보고서를 새 폴더에서 확인했다. 이전 재사용 방식과 임시 체크아웃의 재실행 결과는 [AppKit 회귀 기록](INCREMENT_150.md)에 있다.
