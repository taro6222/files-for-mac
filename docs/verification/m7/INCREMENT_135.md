# M7 Increment 135 — exFAT 전송 결과의 접근 시간

APFS와 exFAT 사이의 복사·이동에서 파일과 폴더의 접근 시간을 결과에 복원한다. exFAT에 기록하면 macOS가 노출하는 짝수 초 단위로 내림하고, 되돌릴 때는 exFAT에 저장된 값을 사용한다.

세 파일 시스템의 실제 마운트에서 홀수 초 + 999 ms를 입력했다. exFAT는 직전 짝수 초를 반환했다. FAT32에서는 파일이 날짜 단위 값으로 바뀌었고 폴더는 설정값을 반영하지 않았다. 저널링 HFS+에서는 파일과 폴더 모두 설정값을 반영하지 않았다. FAT32와 HFS+에서 `fsetattrlist`와 `futimens`가 성공을 반환해도 같은 결과였다. 해당 두 형식의 접근 시간 복원은 적용하지 않는다.

Swift 테스트 229개와 실제 마운트 검사 6개가 통과했다. APFS에서 exFAT로 복사·이동한 최상위 폴더, 하위 폴더와 일반 파일의 접근 시간을 확인했다. 이동 실행 취소로 APFS에 복원한 일반 파일은 exFAT에서 확인한 접근 시간을 유지했다.
