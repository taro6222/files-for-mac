# M7 Increment 160 — 폴더 하위 항목의 POSIX 권한

파일 권한 시트에서 폴더를 열고 **하위 파일과 폴더에도 적용**을 선택하면 해당 폴더와 내부 항목에 같은 읽기·쓰기·실행 비트를 적용한다. 시트는 처리 후 적용·건너뜀·실패 건수를 표시한다. 각 항목의 특수 비트를 보존하도록 요청하고 실제 적용값을 확인한다.

선택한 폴더의 식별자와 기존 권한을 다시 확인한다. 자식 항목은 열린 부모 디렉터리를 기준으로 열고, 열거된 inode와 같은 볼륨인지 대조한다. 심볼릭 링크, 하드 링크, 특수 파일, 다른 볼륨은 건너뛴다. 하위 폴더를 읽고 나서 상위 폴더의 모드를 변경하므로 탐색 비트를 제거하는 경우에도 순회할 수 있다.

일괄 적용의 범위는 POSIX 비트다. ACL과 소유권 일괄 적용은 남아 있다.

Swift 테스트 238개가 통과했다. 하위 폴더에서 탐색 비트를 제거하는 경우와 심볼릭·하드 링크의 외부 대상 보존을 실제 APFS에서 확인했다. 별도 APFS 이미지가 하위 경로에 마운트된 경우, 마운트 경로를 건너뛰고 안의 파일 모드를 유지했다. SwiftPM이 컴파일한 테스트 객체를 Swift Testing 런타임에 직접 링크해 실행했다.

한국어·영어와 밝은·어두운 테마 네 조합에서 AppKit 검사 266개가 각각 통과했다. 파일 속성에서 하위 적용 옵션을 선택해 파일에 폴더의 모드가 실제로 적용됐는지 확인했다.
