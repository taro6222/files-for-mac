# M7 Increment 231 — Windows 탭 드롭 단독 실행

[Windows 전체 캡처](https://github.com/taro6222/files-for-mac/actions/runs/43667903035)는 컬럼 보기 전환 중 선택한 창을 잃어 탭 드롭 단계에 도달하지 못했다. 워크플로에서 `tab-drop` 범위를 선택하면 홈과 공통 폴더를 확인한 뒤 기존 탭 드롭 검사로 바로 이동한다. 기본 `all` 실행도 같은 탭 드롭 함수를 사용한다.

Python 구문, 워크플로 입력의 기본값과 선택값을 확인했다. 이전 Windows 실행에서 저장한 탭과 분할 패널 접근성 트리를 입력으로 사용한 모의 시험에서 실제 경로·탭 선택·분할 판정 및 캡처 호출을 확인했다. 탭 드롭과 권한·좌표 진단은 실제 Windows 단독 실행으로 확인한다.
