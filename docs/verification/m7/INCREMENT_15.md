# M7 Increment 15 — 이동 충돌의 키보드와 접근성

이동 충돌 정책 창에서 ⌘S는 충돌 건너뛰기를 선택하고 Esc는 취소한다. 이동 중 Esc로 취소를 요청하고, 결과가 표시되면 Return으로 창을 닫을 수 있다. 진행률과 상세 결과에 한국어·영어 접근성 이름을 제공하고, 취소 요청과 결과 요약을 macOS 접근성 알림으로 전달한다. 결과 요약에서 충돌 건수를 기타 실패와 구분한다.

실제 AppKit 이동 충돌 창에 ⌘S 이벤트를 전달해 원본과 기존 대상의 내용이 유지되는지 확인했다. 결과 창에서 접근성 이름과 충돌 1건 표시를 확인하고 Return으로 닫았다. 이동 저널은 시험용 브라우저에 지정한 경로에 저장했다.

macOS 27.2 (26B123)에서 한국어·영어와 밝게·어둡게 조합별 AppKit 파일 작업 검사 38개를 통과했다.

이 시험은 앱 내부 이벤트로 수행했다. 시스템 폴더 선택부터 결과까지의 실제 키 입력과 VoiceOver 출력은 별도 검증 항목이다.
