# M7 Increment 134 — APFS 전송 결과의 접근 시간

APFS 간 복사와 폴더 병합은 검증을 마친 임시 복사본에 원본의 접근 시간을 복원한 뒤 게시한다. 교차 볼륨 이동과 그 실행 취소는 마지막 대상 검증을 마친 뒤 접근 시간을 복원하고, 복원이 확인돼야 출발 항목을 삭제한다. 파일 디스크립터를 열 때 심볼릭 링크를 거부하고 복사본의 장치·inode를 대조한다.

접근 시간은 원본을 처음 읽기 전에 기록한다. 검증 과정 자체가 접근 시간을 바꿀 수 있어 실행 취소 저널의 변경 감지에는 접근 시간을 포함하지 않는다. 읽기 과정이 원본의 접근 시간에 미치는 영향과 APFS 외 볼륨의 접근 시간은 추가 검증이 필요하다.

Swift 테스트 229개와 실제 마운트 검사 6개가 통과했다. 두 APFS 볼륨 간 복사, 이동, 이동 실행 취소 직후에 결과 파일을 읽기 전에 접근 시간을 확인했다. 각 작업에서 지정한 접근 시간이 보존됐다.
