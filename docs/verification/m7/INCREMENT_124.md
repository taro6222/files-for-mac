# M7 Increment 124 — 복사 실행 취소의 메타데이터 보호

복사, 폴더 병합과 일괄 병합은 게시 전에 검증한 대상의 식별자, 내용, 권한과 함께 확장 속성 및 ACL의 해시와 수정 시간을 실행 취소 저널에 기록한다. 실행 취소는 파일을 삭제하기 전에 이 기록과 현재 상태를 비교한다. 파일 내용이 같아도 Finder 태그 등 확장 속성이 바뀌면 복사본을 보존한다. 폴더는 내부 항목도 비교한다.

이전 저널은 저장된 식별자와 내용·권한으로 비교한다. 해당 형식에는 새 메타데이터가 포함되지 않는다. 이동 실행 취소의 저널과 생성·접근 시간 검증은 후속 작업이다.

Swift 테스트 225개와 실제 APFS·대소문자 구분 APFS·exFAT 마운트 검사 5개가 통과했다. 일반 복사와 폴더 병합에서 확장 속성만 추가한 파일 보존, 일괄 병합의 저널 전달, 메타데이터 필드가 없는 이전 기록의 실행 취소를 확인했다.
