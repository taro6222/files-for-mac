# M7 Increment 262 — 8시간 전체 부하 세 빌드 결과

Apple Silicon macOS 27.2 (26B123)에서 탐색·탭·복사·감시 부하를 각각 28,800초 이상 실행했다. 세 실행 모두 종료 코드 0을 기록했고 실행 파일의 SHA-256을 시작 기록과 대조했다. 주 상세 목록 셀은 세 시험에서 모두 최대 44개였다.

시간별 값은 물리 메모리 표본의 중앙값이다. 세 실행은 같은 시스템에서 일부 시간에 겹쳤다. 앞선 두 빌드는 후반 감소 직전까지 시간대별 중앙값이 계속 늘어 장시간 메모리 기준을 통과하지 못했다. 이전 프리뷰 소스의 후반 4시간 중앙값은 146.4~158.0 MiB였다. 빌드 조건과 동시 부하가 있어 차이의 원인을 특정하지 않는다. [앱 소스·Mach-O 대조](INCREMENT_187.md)

현재 프리뷰 `93af5b7`의 장시간 메모리 판정과 감시·작업 누수 검증은 열린 상태다.
