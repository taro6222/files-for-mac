# M7 Increment 352 — 7z 고급 생성 옵션과 설정 복원

상태: 구현·로컬 headless 검증 완료, 새 옵션 화면의 원격 수용 대기. M7 완료가 아니다.

## 사용자 동작

생성 창에 사전 크기·워드 크기·CPU 스레드와 예상/사용 가능 메모리를 연결했다. [고정 원본 ViewModel](https://github.com/files-community/Files/blob/99951c66928c4da714da8b1dd46039421182cbab/src/Files.App/Dialogs/CreateArchiveDialog.xaml.cs)의 자동+64/256 KiB·1~1024 MiB 사전, 자동+8/16/32/64/128/256/273 워드 선택을 대응한다. 자동 사전은 Ultra 64 MiB, High 32 MiB, Normal 16 MiB, Low 1 MiB, Fast 64 KiB로 정하고 실제 SDK에도 이 값을 전달한다. 새 SDK 버전의 다른 자동 기본값에 맡겨 화면과 생성 값을 다르게 만들지 않는다. 자동 워드는 Normal 이하 32, High/Ultra 64다.

스레드는 현재 Mac 논리 CPU 범위의 정수만 입력할 수 있다. 엔진 API는 1~512의 요청 범위를 검증하며 입력 크기·SDK 정규화에 따라 실제 동시 스레드는 줄 수 있다. 이 단계는 요청 값 연결이며 실제 스레드 사용량 측정 완료가 아니다. ZIP 또는 SDK 없는 개발 실행에서는 적용할 수 없는 고급 컨트롤을 비활성화한다. 저장 수준에서는 사전·워드 선택을 비활성화하고 이전 선택은 보존한다. ZIP의 CPU 옵션 연결은 이 구현에 포함하지 않는다.

형식과 고급 옵션을 저장해 새 창·설정 재생성에서 복원하고 설정 내보내기/가져오기에도 포함한다. 이전 v1 설정에 새 필드가 없으면 ZIP·자동 사전/워드·현재 Mac CPU 기본값을 사용한다. 손상된 로컬 저장값은 기본값으로 복구하고 잘못된 가져오기는 다른 설정을 변경하기 전에 거부한다. 다른 Mac에서 저장한 스레드 수는 화면에서 현재 CPU 범위로 표시한다. 암호는 저장하지 않는다.

메모리는 원본의 LZMA2 근사식 `(사전 × 11.5 + 6 MiB) × ceil(요청 스레드 / 2)`를 사용한다. 저장 수준은 SDK Copy 모델의 1 MiB 추정으로 표시한다. SDK 버퍼·런타임과 실제 입력에 따른 차이가 있으므로 상한이나 할당 성공 보장이 아니다. 사용 가능 값은 Mach VM의 현재 free+inactive 페이지 추정이며 wired/compressed 페이지를 더하지 않는다. 실제 RSS·스레드 측정과 메모리 격리는 별도 수용 항목이다.

## 엔진과 검증

create 요청의 dictionarySize/wordSize/threads를 Swift와 worker 양쪽에서 검증한다. SDK ISetProperties의 숫자 사전 값은 바이트 수가 아닌 log2이므로 명시적으로 변환해 `0=LZMA2`, `0d`, `0fb`, `mt`에 연결한다. 기존 private 출력 FD·원본 identity 확인·정상 종료 후 RENAME_EXCL 게시·취소 정리를 유지한다.

- 새 세 Swift 검사와 기존 SDK/번들 회귀를 합한 30개가 건너뜀 없이 5.742초에 통과했다. 64 KiB/256 KiB/1 MiB 사전·8/273/64 워드·1/4/2 스레드 조합으로 생성하고, 공식 7-Zip의 목록에서 LZMA2:16/18/20 사전 속성을 확인한 뒤 3 MiB 원문을 복원했다. 설정 재생성·가져오기/구형 호환·손상 입력 시 전체 상태 보존도 확인했다.
- native SDK 프로토콜 검사는 71개가 통과했다. 새 조건은 Boolean/소수/미지원 사전·워드와 0/음수/범위 초과 스레드를 출력 전에 거부하고 원본을 보존함을 확인한다.
- Debug 71.10초, native Release 55.19초와 새 ad-hoc preview 번들의 서명/해시 검증이 통과했다. 새 AppKit 파일을 Xcode 생성 프로젝트에 반영했다. parity 구조 감사와 셸 구문·공백 검사가 통과했다.

[소스/결과 해시](archive-options-352-verification.json)를 보존한다. 전체 Core와 로컬 GUI·장시간 시험은 반복하지 않았다. 원격 AppKit에는 옵션 선택·저장/재개방·저장 수준 활성 조건과 잘못된 스레드 입력·추정 표시 조건 두 개를 추가했다. 기대 총량은 327개지만 아직 새 화면의 실제 수용 결과로 집계하지 않는다.
