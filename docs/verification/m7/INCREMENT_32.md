# M7 Increment 32 — 실제 복사 검증 단계의 취소 반응

AppKit 시험에서 8 MiB 파일을 임시 위치에 실제로 복사했다. 엔진이 게시 전 검증 단계에 들어가면 최대 5초 동안 시험 버튼 액션을 기다린다. 버튼 액션에서 취소 토큰과 상태 문구가 즉시 바뀌는지 확인하고, 작업 결과가 돌아온 뒤 원본 내용과 대상 폴더 항목이 그대로이며 임시 복사본이 남지 않았는지 검사한다.

Apple Silicon macOS 27.2 (26B123)에서 한국어·영어 및 밝게·어둡게 조합별 10회, 총 40회 실행했다. 버튼 액션부터 상태 반영까지 p95는 31.14ms, 최댓값은 33.13ms였다. 버튼 액션부터 복사 엔진이 정리하고 결과를 반환할 때까지 p95는 31.90ms, 최댓값은 33.95ms였다. 네 조합에서 AppKit 파일 작업 검사 41개씩을 통과했다. [측정 표본](copy-cancellation-verifying.json)

이 수치는 로컬 복사에서 제어한 안전 지점의 결과다. 장치나 네트워크 호출이 진행 중인 상태, 물리 입력 및 실제 화면 표시까지의 지연은 별도 검증 범위다.
