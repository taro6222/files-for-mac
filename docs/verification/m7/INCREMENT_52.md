# M7 Increment 52 — 교차 볼륨 실행 취소의 복사 기록

교차 볼륨 교체 이동을 실행 취소할 때 임시 복사본의 식별 정보와 검증한 내용을 원래 위치에 게시하기 전에 저널에 저장한다. 재시도 시 이동 대상 경로가 비어 있고 원래 위치의 항목이 이 기록과 일치하면 남은 백업 복원만 수행한다. 이전 저널도 읽을 수 있다.

교차 볼륨 경로를 강제한 로컬 테스트에서 실제 실행 취소로 기록을 생성하고, 이후의 백업 복원 표시가 저장되기 전에 중단된 상태를 재현했다. 복원 사본은 이전 이동 대상과 식별자가 다르며, 재시도 후 원래 파일과 교체 전 백업의 내용을 확인했다.

두 위치에 파일이 남은 경우 자동 삭제 없이 기존 충돌 검사를 적용한다. 실제 프로세스 강제 종료, 전원 차단, 별도 물리 볼륨과 SMB에서의 중단 복구는 추가 검증 대상이다.

Swift 시험 210개와 기존 APFS·대소문자 구분 APFS·exFAT 볼륨 매트릭스 3개가 통과했다.
