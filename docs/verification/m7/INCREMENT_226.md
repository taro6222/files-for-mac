# M7 Increment 226 — 정보 패널 생성일과 편집 바로가기

파일 상세에 생성일을 추가하고 선택한 항목의 속성을 바로 열 수 있게 했다. 단일 선택에서는 Finder 태그 편집 버튼으로 같은 속성 창의 태그 입력란을 열고 초점을 준다. 여러 항목을 선택하면 속성 요약을 열 수 있다. [Windows와 macOS 대조](INCREMENT_224.md)

Apple Silicon macOS 27.2의 영어 밝은 테마에서 앱을 빌드하고 AppKit 검사 304개를 통과했다. 공통 폴더의 `preview.txt`에 대해 생성일을 파일 속성과 대조하고, 각 버튼이 같은 파일을 여는지와 Finder 태그 필드가 실제 편집기를 얻는지 확인했다. 정보 패널 스크롤과 Quick Look 본문 검사도 통과했다. [macOS 상세 화면](ui-08-macos-reference-details-actions.png)
