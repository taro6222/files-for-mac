# M7 Increment 237 — 닫힌 파일 작업 결과

복사·이동·폴더 병합의 세부 창을 닫아도 작업 센터에서 작업 종류, 대상 경로와 최종 상태를 다시 볼 수 있다. 닫힌 결과는 최근 순으로 50건까지 앱 메모리에 보관한다. 작업 센터를 닫았다 다시 열어도 같은 앱 실행 중에는 기록이 유지된다. 결과 창이 열린 경우에 세부 정보를 열 수 있고, 진행 중인 작업은 안전 지점에서 취소할 수 있다.

Apple Silicon macOS 27.2의 AppKit 파일 작업 회귀에서 한국어·영어와 밝은·어두운 테마 네 조합마다 72개가 통과했다. 실제 복사를 작업 센터에서 취소한 뒤 작업 창을 닫고 센터를 다시 열어, 이어지는 취소 결과와 대상 경로를 확인했다. 원본 바이트와 대상 파일의 부재를 확인했다.
