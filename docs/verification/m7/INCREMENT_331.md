# M7 Increment 331 — 모든 새 탭 경로의 이중 패널 기본값

상태: 구현·로컬 검증 완료. 새 소스 원격·8시간 수용은 진행하며 M7 출시는 미완료다.

설정 카탈로그의 `AlwaysOpenDualPaneInNewTab`은 저장·설정 화면·⌘T에 연결돼 있었지만, 폴더를 새 탭으로 열거나 세션 복원 후 시작 탭을 추가하는 경로는 설정을 적용하지 않았다. AppDelegate의 실제 창 생성기로 정책을 모았다. 새 폴더 탭은 선택된 폴더를, 빈 탭은 Home을 양쪽 패널에 연다. 소스 창이 없는 새 탭 요청도 명시적으로 처리한다. 설정 적용은 창을 그룹에 붙이거나 표시하기 전에 끝난다.

일반 새 창은 기존 단일 패널 기본값을 유지한다. 저장된 workspace나 TabSnapshot을 받는 복제·닫은 탭 재열기·세션 복원은 설정으로 덮어쓰지 않는다. 배경 열기와 새 탭 선택 설정도 공통 생성기에서 처리한다. 시작 시 추가되는 탭의 명시적인 선택 정책은 유지한다.

실제 창 생성기와 격리된 설정 저장소로 빈 탭·폴더 탭·시작 추가 탭의 이중 패널, 배경/명시적 선택, 명시적 단일·분할 상태, 일반 새 창 및 설정 비활성화를 확인한다. 테스트 종료 시 생성한 창만 닫고 테스트 이전의 닫은 탭 기록을 복원한다. 물리 키 입력 수용을 뜻하지 않는다.

## 검증

첫 UI 실행은 비동기 분할 복원 완료 전에 상태를 읽어 `newTabPolicyPreservesExplicitState`가 실패했다. 검증 코드를 기존 비동기 복원의 완료를 최대 5초 기다리도록 수정했고, 동일한 단일/분할 보존 조건을 유지한다. 제품 복원 코드는 바꾸지 않았다.

Swift 총 389개 중 성공 370개·환경 건너뜀 19개. 네 언어/테마 조합에서 전체 UI 각각 302개와 탭 경계 각각 18개, Debug·일반 Release·최적화 QA Release와 parity 분류 감사가 통과했다. [소스·바이너리·결과 해시](new-tab-331-verification.json)에 기록한다. 두 CPU Xcode 성공과 전체 검증 진행은 직전 `4a41d12` 소스 결과이며 최신 소스의 수용을 대신하지 않는다. 이 변경은 파일 작업·감시·창 수명 알고리즘을 변경하지 않는다. 이전 소스 `4a41d12`의 8시간 진단과 두 CPU 원격 검증을 중단하거나 새 결과로 간주하지 않는다. 새 소스 원격/최신 8시간·실제 입력/VoiceOver·지원 환경·원본 UI 전체 비교·실제 외부 서비스·Intel 기준 성능·서명/공증 수용은 남아 있다. 사용자의 인증서·notarytool 프로필은 준비 중이다.
