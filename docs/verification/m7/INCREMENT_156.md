# M7 Increment 156 — ACL 계정 목록

파일 권한 시트에서 ACL을 편집할 때 계정 유형을 선택하면 macOS가 열거한 사용자 또는 그룹의 짧은 이름을 별도 팝업 목록으로 표시한다. 목록에서 고르거나 이름을 직접 입력할 수 있다. 규칙을 추가할 때 기존 macOS ACL 이름 검증을 사용한다.

계정 목록은 백그라운드에서 조회한다. 사용자와 그룹을 연달아 선택하면 마지막 선택과 일치하는 목록만 화면에 반영한다. 전체 Swift 테스트 235개가 통과했으며, 동시 사용자·그룹 조회와 중복 제거를 확인했다. SwiftPM이 컴파일한 테스트 객체를 Swift Testing 런타임에 직접 링크해 실행했다.

한국어·영어 × 밝은·어두운 테마 네 조합에서 AppKit 검사 263개가 각각 통과했다. 목록에서 everyone 그룹을 골라 쓰기 규칙을 저장한 뒤, 기존 읽기 규칙과 순서 및 POSIX 모드가 유지됨을 확인했다. 초기 콤보 박스 구현에서는 AppKit 시험이 시간 제한을 초과해 별도 팝업과 입력 필드로 바꿨다.
