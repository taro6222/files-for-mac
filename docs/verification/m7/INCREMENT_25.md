# M7 Increment 25 — 네이티브 복사 처리량 비교

`verify-copy-throughput.sh`에 macOS `FileManager.copyItem` 단일 파일 기준을 추가했다. 양쪽 모두 원본 SHA-256·권한 확인, 임시 복사본 검증, 원본 재확인, 이름을 덮어쓰지 않는 게시 및 저널·실행 취소 기록 쓰기를 포함한다. 매 표본에서 복사본의 권한을 검사하고 앱의 실행 취소로 해당 출력만 제거했다.

Apple Silicon macOS 27.2 (26B123)의 APFS에서 같은 512 MiB 파일로 후보 앱과 기준을 번갈아 각 5회 실행했다. 후보 복사 시간 중앙값은 0.560초, 기준은 0.577초였다. 후보 처리량은 기준의 **102.95%**로, 이 시험 조건에서 설계 목표 80%를 충족했다. [원시 측정값](copy-throughput-native.json)

OS 캐시를 비우지 않았고 장시간 안정성 시험도 실행 중이었다. 기준은 고정된 단일 파일과 빈 대상에 맞췄으며, 상대 경로 보호·디렉터리 순회·여러 파일·취소·네트워크 지연을 이 측정에 포함하지 않았다.
