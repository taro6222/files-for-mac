# M7 Increment 126 — 이동 다시 실행의 메타데이터 보호

이동을 실행 취소할 때 복원한 파일의 식별자, 내용, 권한, 확장 속성, ACL과 수정 시간을 다시 실행 기록에 담는다. 교차 볼륨에서는 출발지의 기존 기록 대신 실제 검증한 복원본의 기록을 사용한다. 이 방식은 파일 시스템마다 표시 권한과 수정 시간 정밀도가 달라지는 경우를 처리한다.

다시 실행할 때 복원 이후 파일이 변경됐으면 이동을 중단한다. 기존 대상이 있는 경우에는 대상과 복원본을 보존한다. 덮어쓰기로 수행한 이동은 기존과 같이 다시 실행 대상에 포함하지 않는다.

복원된 파일에 확장 속성만 추가한 경우 다시 실행이 중단되고 파일과 속성이 보존됐다. APFS·대소문자 구분 APFS·exFAT 실제 볼륨에서 소수 초 수정 시간이 있는 파일의 이동·실행 취소·다시 실행이 통과했다. Swift 테스트 226개와 마운트 검사 5개가 통과했다.
