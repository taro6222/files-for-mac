# M7 Increment 138 — 최신 후보 8시간 부하 시험

Apple Silicon macOS 27.2 (26B123)에서 소스 커밋 `e73bc232d4a699eb83852a74ecfff01a3cdcc265`의 최적화 QA 빌드로 28,800초 전체 부하 시험을 시작했다. 프리뷰를 빌드한 커밋 `a2c8467`과 앱 소스 및 패키지 정의가 일치한다. QA 바이너리의 SHA-256은 `3fe1482c2d4f42ed43b38f6c9fb6b5a56c15f1a5cb22c049463f79348bfb2f67`이며 체크섬 파일과 대조했다.

첫 확인에서 실행 중인 프로세스와 6사이클을 확인했다. 전체 부하는 탐색·탭 생성과 닫기·파일 복사·파일 감시 갱신을 반복한다. 종료 결과와 메모리 추세는 완료 후 판정한다. 기존의 창 정리 QA 빌드도 별도 프로세스에서 계속 시험 중이다.
