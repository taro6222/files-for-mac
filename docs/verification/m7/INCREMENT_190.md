# M7 Increment 190 — 홈 빠른 접근과 드라이브 카드 배치

[Windows 런타임 홈 화면](INCREMENT_189.md)에서 확인한 다열 배치를 macOS의 빠른 접근과 드라이브에 적용했다. 빠른 접근 카드에는 아이콘과 폴더 이름을 위아래로 표시한다. 드라이브 카드는 이름·가용 공간·사용률을 유지한다. 제목은 창 상단에 표시하므로 홈 콘텐츠에서는 제목과 안내 문구를 반복하지 않는다.

창 너비에 따라 카드 열 수를 조정한다. 카드 순서와 초점은 크기를 바꿔도 유지된다. 좌우 방향키는 같은 행의 카드 사이를 이동하고, 위아래 방향키는 홈의 기존 탐색 순서를 따른다. 카드의 경로 열기와 컨텍스트 메뉴, 마운트된 네트워크 위치의 독립 표시·접기 설정도 유지한다.

Apple Silicon macOS 27.2의 영어·밝은 테마 AppKit 검사 272개가 통과했다. 시험에서 빠른 접근 카드 8개를 900pt와 1,500pt 창에 재배치하고, 기존 버튼과 초점이 유지되는지, 우측 방향키가 다음 카드에 도달하는지 확인했다. 두 드라이브가 같은 행에 표시됨도 확인했다. [macOS 홈 카드 캡처](ui-01-macos-home-cards.png)

파일 작업 AppKit 검사도 한국어·영어와 밝은·어두운 테마 네 조합에서 각각 69개 통과했다. 각 조합에서 기존 키보드 동선으로 네트워크 위치를 열고 파일 목록으로 초점이 이동하는 것과 드라이브·네트워크 위젯의 독립 상태를 확인했다.
