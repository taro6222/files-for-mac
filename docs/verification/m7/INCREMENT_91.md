# M7 Increment 91 — 충돌 이미지와 PDF 미리보기

복사·이동 충돌 창에 원본과 기존 대상의 이미지 및 PDF 첫 페이지를 표시한다. 기존 텍스트 미리보기처럼 마지막 경로 요소의 심볼릭 링크를 따라가지 않고, 열린 파일의 식별자를 검사한 뒤 읽는다.

이미지와 PDF는 파일당 최대 8 MiB를 읽는다. ImageIO는 이미지의 첫 프레임을 만들고, Core Graphics는 PDF 첫 페이지를 그린다. 썸네일의 긴 변을 최대 240픽셀로 제한하고 파일 경로와 접근성 비교 영역 안에 해당 미리보기의 종류를 텍스트로 표시한다. 범위를 넘거나 디코딩할 수 없는 파일은 미리보기 불가 상태를 표시한다.

AppKit 검증은 PNG와 PDF 두 쌍을 실제 충돌 창에 올린다. 원본 PNG는 빨강, 대상 PNG는 초록, 원본 PDF는 파랑, 대상 PDF는 노랑으로 만들어 첨부 썸네일의 중앙 픽셀과 순서를 확인한다. 이전 텍스트 비교 및 두 파일 보존 검사도 실행한다.

충돌 창의 비교 영역을 240포인트 높이로 늘리고 썸네일의 표시 크기를 긴 변 기준 160포인트로 제한했다. 파일 경로, 속성, 미리보기 이름과 텍스트 본문은 테마에 맞는 시스템 텍스트 색상을 사용한다.

Apple Silicon macOS 27.2에서 한국어·영어 × 밝게·어둡게의 파일 작업 검사 각 58개가 통과했다. 마지막 PDF 첨부까지 스크롤해 첨부 영역 전체가 스크롤 뷰 안에 들어오는지 검사했다. 각 조합의 비교 영역 시작과 끝을 캡처해 글자 대비와 썸네일 배치를 확인했다. 다른 이미지 형식, Windows 실행 화면 대조, VoiceOver 음성 검증은 남아 있다.

파일 형식이 PDF이거나 헤더가 PDF인 항목은 PDF로 해석한다. 헤더가 손상된 PDF가 일반 텍스트로 표시되던 동작을 수정했다. 원본과 대상 각각에 손상된 PDF·PNG 및 정상 PNG를 가리키는 심볼릭 링크를 추가했다. 네 언어·테마 조합에서 각각 61개 검사를 통과했으며, 손상 파일과 링크에는 미리보기 불가 상태가 표시되고 정상 PNG·PDF의 네 썸네일은 계속 표시되는 것을 확인했다.
