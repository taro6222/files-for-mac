# M7 Increment 211 — SMB의 빈 리소스 포크 처리

[SMB 진단 실행](https://github.com/taro6222/files-for-mac/actions/runs/43662584813)에서 로컬 APFS와 SMB 복사본의 디렉터리 구조, POSIX 모드, 데이터 SHA-256이 일치했다. APFS에는 리소스 포크가 없었고, SMB는 SHA-256이 빈 바이트열에 해당하는 0바이트 리소스 포크를 보고했다. 복사는 게시 전에 중단됐고 시험은 원본과 게시 경로가 보존됐는지 확인했다.

전송 비교에서 SMB가 보고한 0바이트 리소스 포크와 없음을 같은 파일 내용으로 처리한다. 데이터 지문, 실제 리소스 포크 내용, 항목 이름, POSIX 권한과 기타 메타데이터는 계속 검증한다. 장부의 원본·게시본 지문과 같은 위치에서의 변경 검사는 기존 표현을 사용한다.

Apple Silicon 빌드와 Swift Testing 전체 로컬 실행에서 235개가 통과했고 별도 환경을 요구하는 통합 시험 11개는 건너뛰었다. APFS·대소문자 구분 APFS·exFAT·FAT32·HFS+를 임시로 마운트한 실볼륨 시험의 선택된 검사 6개도 통과했다. SMB 원격 복사·이동·실행 취소 결과는 수정한 빌드의 인증 마운트 재시험에서 확인한다.
