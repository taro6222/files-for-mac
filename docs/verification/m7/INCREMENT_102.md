# M7 Increment 102 — 실패한 이동 항목 다시 시도

같은 볼륨의 일반 이동에서 충돌을 건너뛰는 정책을 선택한 경우, 실패한 항목의 원본을 여전히 식별할 수 있으면 다시 시도할 수 있다. 재시도는 원본과 대상 폴더의 식별자를 확인하고, 대상에 이름이 겹치면 건너뛴다. 교체 이동, 교차 볼륨 이동, 폴더 펼치기, 취소 및 저널 오류가 있는 결과는 이 재시도에서 제외한다.

재시도는 디렉터리 디스크립터를 사용하는 덮어쓰기 없는 원자적 이름 변경을 요구한다. 파일 시스템이 이를 지원하지 않으면 해당 항목을 실패로 표시한다.

AppKit 검사는 두 파일을 이동하면서 한 원본의 부모 폴더에서 쓰기 권한을 제거한다. 권한을 복원한 뒤 실패 항목만 다시 이동되고, 두 대상의 내용이 유지되는지 확인한다. 코어 검사는 다른 파일로 교체된 원본과 이미 존재하는 대상을 보존하는지 확인한다.

Swift 테스트 215개와 한국어·영어 × 밝게·어둡게 네 조합의 AppKit 파일 작업 검사 각 66개가 통과했다.
