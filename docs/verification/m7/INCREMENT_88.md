# M7 Increment 88 — 탭 반복 부하 대조

장시간 시험에 `tabs`를 추가했다. 같은 폴더 탐색과 홈 복귀 사이에 네이티브 탭을 열고, 보조 탭에서 목록과 폴더 감시가 준비될 때까지 기다린 뒤 닫는다. 탭 닫기 콜백, 탭과 감시 객체 해제, 탭 그룹에서의 제거를 검사한다. 파일 복사·삭제는 기본 `full` 모드에서 실행한다.

```sh
bash scripts/verify-release-soak.sh 1800 /private/tmp tabs
```

8시간 후보에서 주 창의 보유 셀이 주기 표본마다 88개 이하였지만, 약 115분까지 물리 메모리 최대값이 188 MiB로 늘었다. 동일 바이너리에서 `navigation`, `tabs`, `full`의 시간별 표본을 비교해 추가 증가가 어느 동작에서 시작되는지 확인한다. 출시는 전체 부하의 8시간 결과와 메모리 추세를 함께 판정한다.

Apple Silicon macOS 27.2에서 같은 QA 바이너리로 35초 예비 시험을 완료했다. 탐색은 17사이클, 탐색·탭은 16사이클, 전체는 13사이클이었다. 셸 구문 검사와 잘못된 모드의 종료 코드 2를 확인했다.

같은 바이너리(SHA-256 `c736de9da114cfbfb8bf6b3e2b7ffc6bbea49ee8a5e7cb6619cf9eb29ba853a2`)에서 세 모드의 30분 시험을 시작했고 별도 실행 프로세스를 확인했다. 완료 표본은 추후 반영한다.
