# M7 Increment 128 — 이동 실행 취소의 중복 읽기 제거

이동 실행 취소가 시작될 때 대상의 식별자, 내용, 권한과 메타데이터를 한 번 읽어 기존 저널과 비교한다. 같은 볼륨에서는 이 결과를 다시 실행 기록에 사용한다. 기존 경로에 다른 파일이 있거나 상위 폴더가 없어졌을 때의 결과도 유지한다.

이전 저널의 리소스 포크 호환 처리를 동일한 스냅샷에 적용한다. 교차 볼륨에서는 임시 복사본의 내용과 메타데이터를 검증하고 게시 후 원본을 재확인하는 절차를 유지한다.

Apple Silicon macOS 27.2의 로컬 APFS에서 [이전 측정](INCREMENT_127.md)과 같은 최적화 빌드 설정과 512 MiB 임시 파일을 사용했다. OS 캐시를 공유한 5회에서 실행 취소는 210.7–227.7 ms, 중앙값 218.7 ms로 이전 중앙값 402.4 ms보다 45.7% 짧았다. 파일 이동 중앙값은 204.7 ms에서 218.9 ms로 늘었다. 실행은 별도로 진행했고 앱 화면 표시 시간과 콜드 캐시는 측정하지 않았다.

전체 Swift 테스트 227개와 실제 마운트 검사 5개가 통과했다. 첫 실행에서는 150 ms를 고정 대기하는 검색 테스트가 실패했다. 벤치마크가 끝난 뒤 같은 빌드의 전체 테스트를 재실행했을 때 통과했다.
