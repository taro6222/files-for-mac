# M7 Increment 23 — 복사 검증과 실행 취소 기록

복사 전에 원본 내용과 권한을 한 번의 순회로 기록하고, 복사 후 임시 파일을 검증하면서 실행 취소용 스냅샷도 만든다. 원본 재검증과 대상 이름 충돌 처리는 계속 적용한다. 게시 전에 확보한 파일 식별자와 내용을 실행 취소 기준으로 사용하므로, 게시 직후 대상 경로가 바뀌어도 이후 파일을 실행 취소 대상으로 기록하지 않는다.

폴더 병합의 실행 취소는 개별 복사 결과의 스냅샷을 모아 기록한다. 실행 취소 파일을 직접 저장하지 않는 개별 복사에서도 스냅샷을 제공한다.

Swift 테스트 203개와 실제 APFS·대소문자 구분 APFS·exFAT 볼륨 검사 3개를 통과했다. 대용량 복사 처리량과 8시간 안정성은 출시 후보에서 별도로 판정한다.
