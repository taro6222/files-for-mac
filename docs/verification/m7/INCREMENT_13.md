# M7 Increment 13 — 실제 exFAT 일괄 이름 변경

실제 exFAT 시험에서 두 파일의 이름을 교환할 때 `RENAME_EXCL`이 지원되지 않아 작업이 실패했다. 일괄 이름 변경의 임시 이동과 최종 이름 확정에 단일 이름 변경과 같은 충돌 검사 경로를 적용했다. 실패하면 아직 최종 이름을 확정하지 않은 항목을 원래 이름으로 복구한다. 원래 이름이 이미 점유됐으면 임시 항목을 보존하고 위치를 결과와 저널에 기록한다. 화면에는 중단 여부와 확정된 항목 수를 표시한다.

실제 APFS·대소문자 구분 APFS·exFAT에서 두 파일의 이름을 교환한 뒤 각각의 내용을 확인했다. 대소문자를 구분하지 않는 볼륨에선 `Output.txt`와 `output.txt`가 충돌할 때 먼저 확정한 파일을 보존하고, 두 번째 파일을 원래 이름으로 복구하며, 임시 파일이 남지 않는지 검증했다. 이 경로는 부분 완료로 표시된다.

macOS 27.2 (26B123)에서 Swift Testing 201개, 실제 볼륨 매트릭스 3개, 한국어·영어 및 밝게·어둡게 조합별 AppKit 파일 작업 회귀 32개가 통과했다.
