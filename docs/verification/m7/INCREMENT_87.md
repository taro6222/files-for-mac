# M7 Increment 87 — 탭 드롭과 세션 복원 충돌 방지

분할 세션을 복원하는 동안 해당 창을 탭 드롭의 출발지나 대상으로 사용할 수 없게 했다. 보조 패널이 아직 화면에 붙지 않은 시점에도 복원 중인 두 패널의 상태를 보호한다.

AppKit 회귀는 두 창을 네이티브 탭 그룹에 넣고 분할을 적용한다. 네 방향에서 원본 탭의 닫기 콜백, 그룹에서 원본 탭 제거, 대상 창 유지와 양쪽 패널의 탐색 상태를 확인한다. 같은 탭을 드롭하면 창이 유지되고, 이미 분할된 창에 다시 드롭하면 기존 패널이 유지되는지도 확인한다.

한국어·영어 × 밝게·어둡게의 네 조합에서 AppKit 검사 각 248개를 통과했다.

이 검사는 앱 내부에서 드롭 적용 경로를 호출한다. 데스크톱 제어 연결이 시간 초과됐으며, 전역 포인터 이벤트 주입은 다른 앱에 영향을 줄 수 있어 자동 승인 검토에서 거부됐다. 실제 포인터 드래그와 WindowServer를 통한 대상 전달은 검증 대기다.
