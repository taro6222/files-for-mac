# M7 Increment 241 — 속성 창에서 이름 변경

탐색기에서 단일 항목의 속성을 열면 전체 파일 이름을 편집하고 변경할 수 있다. 편집 대상은 속성 창을 열 때 선택한 항목이다. 항목 식별자를 확인할 수 있는 경우에 이름 편집을 제공한다.

탐색기 이름 변경과 같은 확장자 경고 설정, 원본 식별자 검사, 충돌 보호와 작업 장부를 사용한다. 성공하면 속성 창을 닫고 원래 폴더가 열린 목록을 다시 읽는다. 이름 충돌이나 검증 실패가 발생하면 속성 창에서 오류를 확인하고 다시 편집할 수 있다.

Apple Silicon macOS 27.2에서 한국어·영어와 밝은·어두운 테마 네 조합마다 파일 작업 AppKit 검사 76개가 통과했다. 같은 이름 입력의 비활성화, 이름 충돌에서 양쪽 파일 보존, 확장자 변경 취소, 이름 변경 후 데이터와 목록을 확인했다. 원본 식별자 불일치와 심볼릭 링크 이름 변경의 FilesCore 시험도 통과했다.

영어·밝은 테마의 전체 AppKit 검사 307개가 통과했다. [공통 시험 파일의 속성 화면](ui-09-macos-reference-rename.png)에서 새 이름 입력란과 변경 전 비활성 상태의 버튼을 확인했다.
