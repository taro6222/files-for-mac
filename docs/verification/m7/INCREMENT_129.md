# M7 Increment 129 — 일반 파일의 생성 시간 검증

APFS 간 복사와 교차 볼륨 이동에서 일반 파일의 생성 시간을 보존하고 확인한다. Foundation이 다른 볼륨에서 새 생성 시간을 부여하는 경우 임시 파일에 원래 시간을 복원한다. 복원 뒤 비교에서 생성 시간이 다르면 작업을 중단하고 원본을 보존한다. 새 실행 취소 기록에는 일반 파일의 생성 시간을 담으며, 이전 기록에는 당시 저장된 비교 항목을 적용한다. APFS 외 볼륨 사이의 생성 시간 보존 검증은 남아 있다.

초기 시험에서 Foundation의 디렉터리 복사가 새 생성 시간을 부여하는 동작을 확인했다. 디렉터리 생성 시간 보존은 후속 작업이다. 로컬 APFS에서 접근 시간을 과거로 설정한 파일을 한 번 읽자 접근 시간이 현재 시각으로 갱신됐다. 접근 시간 보존은 검증 읽기의 영향을 제어한 뒤 확인해야 한다.

Swift 테스트 227개와 실제 APFS·대소문자 구분 APFS·exFAT 마운트 검사 5개가 통과했다. 임시 일반 파일의 생성 시간 변경으로 인한 전송 중단과 실제 APFS 볼륨 간 복사·이동·실행 취소에서의 생성 시간 보존을 확인했다. 앞선 시험에서는 고정 대기를 사용하는 검색 테스트가 한 번 실패했다. 최종 실행에서는 통과했다.
