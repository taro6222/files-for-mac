# M7 Increment 105 — 목록 표시 시점에서 성능 측정

폴더 읽기를 끝낸 뒤 별도 타이머가 깨어나기를 기다리던 성능 계측을 바꿨다. 모델 변경이 AppKit 목록으로 전달되는 콜백에서 첫 100개 이상과 전체 행의 레이아웃·표시 시간을 기록한다. RSS는 별도로 샘플링한다. 이전 표본의 전체 표시에는 모델 읽기 완료 이후 타이머가 다시 실행되기까지의 대기 시간도 포함됐다. 화면 합성 프레임은 별도 검증이 필요하다.

Apple Silicon macOS 27.2 (26B123)의 APFS 폴더에서 최적화 QA 앱을 실행했다. 10,000항목의 즉시 탐색에서 사용자 작업 활동을 끈 표본은 첫 표시 52 ms, 전체 표시 0.877초였다. 켠 표본은 첫 표시 57 ms, 전체 표시 0.746초였다. 두 표본에서 모델 행 도착과 읽기 완료 이후의 표시 시간 순서를 확인했다. 각 조건의 5분 유휴 표본은 실행 중이다.
