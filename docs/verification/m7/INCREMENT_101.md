# M7 Increment 101 — 실패한 복사 항목 다시 시도

복사 결과 창에서 실패 항목만 새 작업으로 다시 시도할 수 있다. 이전에 복사된 항목, 충돌로 건너뛴 항목, 취소되거나 실행되지 않은 항목은 재시도 대상에서 제외한다. 임시 출력이 남은 실패 항목도 제외하며, 저널 오류가 있으면 재시도 버튼을 표시하지 않는다.

재시도는 최초 복사에서 확인한 대상 폴더를 사용한다. 복사 엔진이 해당 폴더의 경로와 파일 시스템 식별자를 검사하며, 대상에 같은 이름이 있으면 건너뛴다. 다른 복사·이동·병합 또는 파일 작업이 실행 중이면 재시도를 시작하지 않는다.

AppKit 검사는 복사에 실패한 원본을 복구한 뒤 재시도한다. 실패했던 파일의 새 출력과 이미 성공한 출력의 내용이 정확한지 확인한다. 코어 회귀는 대상 폴더가 같은 경로의 새 폴더로 교체됐을 때 두 폴더 모두 비어 있고 원본이 유지되는지 검사한다.

Swift Testing 214개와 한국어·영어 × 밝게·어둡게 네 조합의 AppKit 파일 작업 검사 각 65개가 통과했다.

이동 실패 재시도, 작업 통합 목록, 전송 속도·남은 양과 Windows 실행 화면 대조는 남아 있다.
