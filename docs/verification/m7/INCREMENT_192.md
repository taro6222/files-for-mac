# M7 Increment 192 — 홈의 최근 파일

홈에 최근 파일 표시·접기·기록 지우기를 추가했다. 파일을 다시 열면 목록 맨 앞으로 이동하고 경로는 최대 10개를 기기에 저장한다. 일반 설정과 탐색 옵션의 표시 설정, 펼침 상태, 방문한 폴더의 최근 위치는 각각 독립적이다. 이전 설정 파일을 가져오면 최근 파일은 표시하고 펼친다. 설정 내보내기에는 표시·펼침 상태를 포함하며 최근 파일 경로는 기기에 저장한다.

일반 파일 열기, 분할 패널·응용 프로그램 선택·TextEdit로 연 파일, 내용을 성공적으로 읽은 압축 파일이 목록에 들어간다. 최근 파일을 다시 열 때도 일반 파일 열기 경로를 사용한다. 파일 기록의 변경은 홈의 최근 파일 영역에만 적용한다. Windows 원본은 운영체제의 최근 항목을 제공하며 macOS 위젯은 이 앱에서 연 항목을 제공한다.

Apple Silicon macOS 27.2의 영어·밝은 테마 AppKit 검사 275개와 Swift Testing의 최근 파일 회귀를 통과했다. AppKit에서 성공·실패 열기 요청, 재열기 순서, 다른 홈 구역 유지와 독립 기록 지우기를 확인했다. Swift Testing에서는 10개 제한, 중복 방지, 재실행, 기존 설정 가져오기와 경로의 내보내기 제외를 확인했다. [최근 파일 화면](ui-01-macos-recent-files.png)

한국어·영어와 밝은·어두운 테마 네 조합에서 파일 작업 AppKit 검사도 각각 69개 통과했다.
