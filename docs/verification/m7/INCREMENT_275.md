# M7 Increment 275 — SMB 시각 보존과 교체 이동 재연결

[GitHub Actions의 실마운트 시험](https://github.com/taro6222/files-for-mac/actions/runs/44084138180)에서 커밋 `a4e472ae499b097cadb0fb2fe692fcb8654dc55d`의 SMB 통합 시험 5개가 통과했다. macOS 15.8.2(24H232)에서 Samba 4.25.1의 인증 공유를 SMB 3.1.1로 마운트했다.

- APFS 원본, SMB 복사본, SMB 이동본, 실행 취소 후 APFS 복원본의 생성·수정·접근 시각이 시험 로그에서 일치했다. 이동에 지정한 접근 시각의 하위 42ns는 SMB의 100ns 정밀도에 맞춰 기록됐고, 실행 취소로 내용이 APFS에 돌아왔다.
- 읽기 전용 공유의 쓰기 거부와 원본·기존 대상 보존을 확인했다. 일반 재연결에서는 같은 마운트에 새 목록과 파일 내용이 나타났다.
- 교체 이동에서 새 대상을 게시한 뒤 원본 삭제 전에 세션을 끊었다. 동일 마운트의 재연결 횟수가 1에서 2로 늘었고 이동과 실행 취소가 완료됐다. 실행 취소에서 기존 대상 바이트가 복원됐다.

이 실행은 루프백에서 짧은 세션 중단을 재현했다. 파일 데이터 기록 도중의 중단, 장기 단절, 외부 서버 권한 변경은 출시 검증에 남아 있다. 이 소스 수정이 들어간 [새 설치 프리뷰](INCREMENT_278.md)로 기존 후보를 교체했다.
