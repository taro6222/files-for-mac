# M7 Increment 79 — 정보 패널의 다중 선택 미리보기

정보 패널의 미리보기 탭에서 여러 항목을 선택하면 이전·다음 버튼과 현재 위치를 표시한다. 파일을 넘길 때 같은 Quick Look 뷰의 대상을 바꾼다. 폴더에서는 미리보기 불가 상태를 표시하고 앞뒤 항목으로 이동할 수 있다. 첫 항목에서 이전 버튼을, 마지막 항목에서 다음 버튼을 비활성화한다. 상세 탭에서는 선택에 포함된 파일과 폴더 수를 표시한다.

AppKit 검증은 실제 탐색 목록에서 폴더와 파일을 함께 선택한다. 폴더에 Quick Look 대상이 없는지, 다음 파일에서 미리보기 URL이 바뀌는지, 마지막 항목에서 다음 버튼이 비활성화되는지, 이전 파일로 돌아온 뒤 목록의 선택이 유지되는지 확인한다. 패널을 닫았을 때 Quick Look 대상이 해제되는지도 확인한다.

Apple Silicon macOS 27.2에서 Swift 테스트 213개와 한국어·영어 × 밝게·어둡게의 AppKit 검사 각 229개를 통과했다.

Windows 기준의 상세·미리보기 구성은 고정된 원본 XAML과 대조했다. 실제 Windows 화면 및 Quick Look 확장별 콘텐츠·실패 상태의 검증이 남아 있다. [화면 구조 대조](../../reference/UI_BASELINE.md)
