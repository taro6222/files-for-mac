# M7 Increment 169 — 로컬 볼륨과 강제 종료 복구 재검증

현재 소스 `2454ac94e56fe18c414da02dd0f834ab5a24eca1`에서 FilesCore·Tests·Package.swift가 러너를 컴파일한 `fdcd7da6c6a6ae894ed91ce8f271183a8c15f147`과 일치함을 확인했다. Apple Silicon macOS 27.2 (26B123)에서 기존 검증 스크립트의 디스크 이미지 생성·마운트·해제 절차를 사용했다. Swift Testing은 기존 객체를 직접 링크한 러너의 임시 복사본에 로더 경로를 지정해 실행했다.

| 확인 범위 | 결과 |
|---|---|
| APFS, 대소문자 구분 APFS, exFAT, FAT32, HFS+ | 마운트 검사 6개 통과. APFS 메타데이터 보존, exFAT ACL 전송 실패 시 원본 보존, 네 형식의 하위 생성 시간 포함 |
| 교차 볼륨 이동 실행 취소 | APFS의 세 중단 지점에서 작업 프로세스가 SIGKILL로 종료된 뒤, 별도 프로세스의 재개 검사 통과 |
| 시스템 휴지통 | 유니코드 파일을 휴지통으로 옮기고 별도 폴더에 복원한 뒤 내용 대조 통과 |

마운트·복구와 휴지통 검증은 로컬 시험 범위다. SMB 공유, 다른 OS·CPU 환경 및 배포용 서명 검증이 남아 있다.
