# M7 Increment 37 — 홈 키보드 탐색

홈으로 이동하면 첫 번째 홈 버튼에 초점을 놓는다. 위·아래 방향키는 섹션 버튼부터 즐겨찾기, 드라이브 카드의 열기 버튼, 네트워크 위치와 최근 위치 순서로 표시된 버튼을 이동한다. 초점이 화면 밖으로 이동하면 홈을 스크롤한다. Return과 Space로 실행할 수 있으며, 섹션을 접고 펼쳐 화면을 다시 그릴 때 그 버튼의 초점을 유지한다. 홈에서 위치를 열면 해당 위치의 파일 보기에 초점을 옮긴다.

Apple Silicon macOS 27.2 (26B123)에서 `scripts/verify-m2-ui.sh`로 사이드바를 숨긴 홈에 진입해 AppKit 키 이벤트로 즐겨찾기 통과, Return으로 드라이브 접기, Space로 펼치기, 중첩 드라이브 카드 이동, 네트워크 위치 열기, 파일 목록 초점까지 확인했다. 한국어·영어와 밝게·어둡게의 네 조합에서 각각 45개 검사가 통과했다. 네트워크 위치에는 APFS 폴더의 모의 마운트 정보를 사용했다. 실제 SMB 파일 작업과 VoiceOver 검증은 [출시 검증 현황](RELEASE_GATES.md)에서 계속 추적한다.
