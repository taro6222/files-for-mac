# M1 사이드바 및 키보드 조작 검증

검증일: 2026-09-09 · 상태: 세 번째 개발 단위 완료, 전체 M1 수용 검증 진행 중

## 변경

- 사이드바 즐겨찾기·위치 섹션 접기/펼치기 및 섹션 순서 변경.
- 순서·접힘 값을 공유 설정에 저장해 창 간 통지 및 재실행 복원.
- 저장된 섹션 배열의 중복·알 수 없는 값을 제거하고 누락된 기본 섹션 복원.
- 섹션 경계에서는 위/아래 이동 메뉴 비활성화.
- 접기 후 새 섹션 버튼으로 키보드 포커스 복원. 접근성 이름에 펼치기/접기 동작 명시.
- 사이드바 항목에서 위/아래 화살표 이동, Space 실행, Shift+F10 문맥 메뉴.
- ⌃⌘S 사이드바 초점, ⇧⌘L 파일 목록 초점, ⇧⌘H 홈, ⌘, 보기 옵션 명령 추가.
- 뒤로/앞으로/상위/선택 열기 메뉴의 사용 가능 여부를 현재 문맥으로 검증.
- 빈 목록 공간 이중 클릭으로 기존 선택 항목이 열리는 동작 방지.
- 사이드바 holding priority와 분할 autosave를 설정해 내용 변경 시 폭 변동을 줄임.

## 자동 검증

- Swift Testing 21개 통과: 기존 18개 + 섹션 저장/복원 + 잘못된 저장값 복구 + 읽기 권한 없는 디렉터리 오류.
- 권한 테스트는 별도 임시 폴더의 권한을 000으로 변경해 검사하고 defer에서 700으로 복원·제거한다.
- 실제 FSEvents 접근이 가능한 실행 환경에서 테스트했다. 사용자 파일을 테스트 대상으로 변경하지 않았다.
- Release 앱 빌드 및 Xcode debug 앱 빌드 통과.

1만 개 fixture 단일 측정: provider 첫 128개 0.010085167초, 전체 열거 0.74983325초. UI frame/p95 측정으로 간주하지 않는다.

## 실제 앱 검증

1. 즐겨찾기 섹션 클릭 → 자식 항목 숨김, 접근성 이름이 '즐겨찾기 펼치기'로 변경.
2. 위치 섹션 문맥 메뉴에서 위로 이동 → 위치가 즐겨찾기보다 위에 표시.
3. 앱 종료/재실행 → 변경한 순서와 접힌 즐겨찾기 상태 복원.
4. ⌃⌘S → 홈 버튼 초점, ↓ → 다음 섹션 초점, Space → 섹션 접기 및 해당 버튼 초점 유지.
5. Shift+F10 → 섹션 문맥 메뉴 표시, 경계 이동 명령 비활성화 확인.
6. 검증 후 즐겨찾기→위치 순서와 모두 펼친 상태로 복원.
7. 한국어·현재 시스템 어두운 테마에서 홈·사이드바 배치 확인.

접근성 트리와 키보드 조작 확인은 VoiceOver 전체 음성 읽기 검증과 다르다. 밝은 테마·영어·최소 창·원본 Windows 대조·다른 OS/CPU의 전체 게이트는 아직 남아 있다.
