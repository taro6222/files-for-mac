# M1 탐색 기능 보강 검증

검증일: 2026-09-09 · 상태: 두 번째 개발 단위 검증 완료, M1 전체 게이트 진행 중

## 구현

- 경로 추천: 절대/상대 경로, 한글, 숨김 접두어, 폴더만 추천. 입력 debounce·취소·세대 검사. 드롭다운 선택 또는 Tab 완성.
- 파일 확장자 표시 옵션: 표시 이름만 변경하며 파일 URL/실제 이름은 보존. dotfile과 폴더 이름은 유지.
- 홈: 드라이브 용량·사용량, 스크롤, 빠른 접근/드라이브/최근 위치 섹션 표시 옵션, 최근 기록 삭제.
- 공유 설정: 모든 창이 하나의 main-actor store를 사용. 즐겨찾기 추가/제거·위/아래 순서 변경과 설정을 저장하고 각 창에 통지.
- 파일 identity: device/inode/birth 기반 보조 identity. 경로 기반 항목 ID는 hard link를 구분하기 위해 유지. 외부 rename 시 양쪽에서 유일한 identity에 한해 선택을 따라감.
- 비동기 폴더 감시: FSEvents를 사용해 현재 디렉터리와 직접 자식의 변경을 반영. UI thread의 2초 mtime polling 제거. 감시 생성 실패는 상태 표시줄에 노출.
- 배치 열거: 첫 128개, 이후 최대 1,024개씩 전달. 신규 탐색은 배치마다 표시하고 갱신은 기존 목록을 유지한 후 교체.
- 창 종료: 이벤트 스트림·추천 작업·설정 관찰자를 해제하고 앱의 창 배열에서 제거.

## 자동 테스트

Xcode 26.6 / Swift 6.3.3 / Apple Silicon / macOS 26.6.2에서 **18개 테스트 통과**.

기존 8개 회귀에 다음을 추가했다.

1. 상대·절대·한글·숨김 폴더 추천 및 일반 파일 제외.
2. 확장자 숨김 시 identity와 dotfile/폴더 이름 보존.
3. 공유 설정의 다중 관찰자 통지, 순서 저장, 재생성 후 복원.
4. 최근 위치 중복 제거·10개 제한·삭제 후 저장 상태.
5. 선택 복원의 rename/hard link/동일 경로 교체 구분.
6. 실제 파일 rename 전후 identity 및 선택 복원.
7. 첫 128개 배치 및 하위 폴더 미재귀 확인.
8. 실제 외부 파일 내용 변경에 대한 FSEvents 수신과 종료.
9. 파일을 폴더로 열 때 오류 반환.
10. 모델의 첫 배치 선표시와 이동 후 이전 배치 폐기.

FSEvents 서비스가 실행 샌드박스에서 차단되는 환경에서는 실제 서비스 접근이 가능한 실행 권한으로 테스트했다. 이때도 임시 fixture 외의 사용자 파일은 변경하지 않았다.

## 성능 측정

10,000개 0바이트 파일, 단일 실행, 기본 metadata + 파일 identity 포함:

- 첫 128개 provider 배치: 0.010491542초.
- 전체 provider 열거: 0.771085959초.

UI 첫 frame/p95/콜드 시작 측정은 아니다. 목록의 최종 정렬·레이아웃 시간은 별도 측정이 필요하다.

## 실제 UI 확인

CUA로 release .app을 실행해 다음을 확인했다.

- 홈 드라이브 카드에 총 용량·여유 공간·사용량 표시, 세로 스크롤 정상.
- `.../Files/So` 입력 후 Tab → `.../Files/Sources/`, Return → 실제 Sources 폴더 이동.
- ⌘↓로 선택한 FilesCore 폴더 열기.
- 보기 옵션에서 확장자 표시 해제 → `.swift`가 숨겨짐. 다시 켜서 원래 설정 복원.
- 프로젝트 `build/ui-fixture`의 before.txt 선택 → 외부에서 after.txt로 이름 변경 → 자동 갱신 후 선택 유지 확인.

실제 실행에서 보인 개인 위치 정보는 이미지 파일로 저장소에 저장하지 않았다. 원본 Windows와의 시각 일치, 밝은 테마·영어·최소 창·VoiceOver 전체 게이트는 아직 미완료다.

## 발견 및 수정

- NSString 경로 확장 과정에서 끝의 `/`가 사라져 상위 폴더의 자기 자신을 추천하던 문제: 원본 입력으로 끝 구분자 판단.
- FSEvents가 `/private/var`로 보내는 이벤트와 `/var` 감시 경로 비교 불일치: 동일 정규화 적용.
- 부하가 있는 새 폴더에서도 전체 열거를 기다리던 문제: 스트림 배치 표시.

M2 파일 쓰기·충돌·Undo는 아직 구현하지 않았다.
